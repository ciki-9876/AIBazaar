# Audience recordings

- `audience-cheer.ogg`: **Cheers**, AuraVoice / Nocturnal_Vanguard, CC0. Source: https://opengameart.org/node/147417 ; original `cheers_1.ogg`.
- `audience-applause.wav`: excerpt with a fade from **Applause in a large hall or church**, eXpl0it3r, CC0. Source: https://opengameart.org/content/applause-in-a-large-hall-or-church ; original `applause-clapping-church-crowd-immersive.wav`.

Both source pages explicitly publish these recordings under CC0. They are served locally with the game; no runtime request is sent to the source sites. The source of applause is kept in the local working evidence directory, while the short production excerpt is checked in here.
