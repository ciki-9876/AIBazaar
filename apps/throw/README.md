# 万灯城 · 甩牌对决

This is a standalone production project. Its route is `app/page.tsx`; the complete UI and deterministic duel rules are in `src/`. It does not import the elevator project or the resonance project.

Run it from the repository root with `npm run dev:throw:cards`. Build with `npm run build:throw:cards`; output goes to `apps/throw/dist/client`.
