# Lux3D 基地精修与战斗表现

入口：`/art/base/refined/`；原版 `/art/base/` 保留用于对照。

五种设施来自 Lux3D 国际站。舱体由 Blender 精确搭建，导轨与原有槽位一致，门与墙分别命名，建造视角可隐藏侧墙。GLB 材质与贴图内嵌；网页使用纹理缩至 1024 的派生资源，原始文件未覆盖。运行时不调用生成服务。

生成报价累计 92 / 100 积分：发电机 20、医疗 13、培育初稿 13、设备台 13、储藏 20、培育修订 13。培育初稿因遮挡作物而未选用；费用仍计入预算。余额 8 不继续生成。

## 维护

- 场景模型：`public/art-assets/lux3d/`。设施外形独立于 `base-state.ts` 规则，可单独替换。
- Blender 脚本：`scripts/art-base/`。默认读取本机 `outputs/lux3d-base-v2/` 中已交付的派生设施，重新运行不产生生成积分。
- 完整原始资产、来源与哈希记录、离线 `preview.html`：`outputs/lux3d-base-v2/delivery/`。
- 可编辑文件：`outputs/lux3d-base-v2/blender/f9-lux3d-base.blend`；同目录有舱内与建造视角 PNG。
- 交付预览是独立离线模型查看器；网页沙盘额外提供拆建、配方运行、开关舱门和灯光切换。

## 导航与卡牌

静态导出的跨页入口使用普通文档链接，避免客户端 RSC 路由拦截点击。页面内交互照常由 React 处理。

3D 卡牌采用实体卡壳与 CSS3D 文字卡面。名称、效果数值、等级与冷却为 HTML text，仅物品插图使用位图。共用同一透视相机。小卡采用图文并排以保留插图辨识度。

回放以连续渲染时钟推进，规则快照依旧为 250ms。弹道每帧按实际飞行时间计算位置，特效使用可复用粒子组；暂停、倍速、拖动与重置共用同一时钟。回到后台后单帧推进最多 100ms，避免突然跳过整段战斗。

## 验证

TypeScript、定向 lint、基地槽位/配方与连续时钟测试；浏览器核对设施加载、上下战斗布局、真实文本、拆建、生产与页面跳转。美术原型不写入冒险存档。
