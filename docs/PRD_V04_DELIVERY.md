# f9 电梯原型 PRD v0.4

本轮依据已归档的 v0.3 验收意见推进；v0.4 的验收存储和导出独立，不自动继承通过状态。

## 可交互范围

- 双方三路九格完整棋盘；单卡可占 1–3 个连续格，不跨路、不重叠，整卡只有一个计时器。天气改变地形与冷却。普通卡无需能源；产能卡与耗能卡组成可选构筑。
- 十张样例卡，包括新增脉冲线圈和蓄能阵列。奇迹稀有度采用非线性初始/成长系数和可执行的三次触发回响词缀；品质和等级可培养，稀有度固定。
- 八种基地设施支持建设、拆除、扩建及每日使用；生产、医疗、预报、回收、鉴定充能、燃料储存、出勤准备均改变对应状态。终端不占模块格。
- 连续救援额外费用为 3/5/7/9，睡眠不清零，正常撤离清零；保险容积随电梯升级从 2 到 4 到 6，普通背包仍为 12/16/20。
- 玩家与机器人初始生命维持配额统一为 18；机器人按日扣费并模拟失败与连续救援。

## 仍需验收的数值与边界

18 配额、救援递增曲线、保险扩容节点、设施每天各一次、拆除返还一半材料，以及奇迹固定回响均为本轮可试验方案，并非已经确认的最终平衡。

本产品仍为按模块拆分的交互原型。基地补给出勤使用明确标记的脚本结算；各模块样例状态未连接成完整长局。楼层生成仍为确定性模板模拟，没有调用真实大模型；机器人不是完整独立策略智能体。
