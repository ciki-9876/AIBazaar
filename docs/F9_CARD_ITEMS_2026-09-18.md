## 2. 核心玩法：同一件物品的两种价值

玩家先看楼层工具需求，再决定保留哪些实体、转化哪些战斗卡。出勤后搜查和交易增加选择；现场机关把实体用途兑现为探索收益或战前准备；回家免费鉴定可把耐用工具转成卡，直接带着选择进入布阵。战斗结算展示实际损伤、关键破路与有效贡献，再决定下一趟携带和搭配。

实体和卡牌共用原UID，不复制、不自动转化。鉴定是单向的：转化后失去实体用途。耐用工具用过后仍可转化；补漏胶与蚀液喷壶是消耗品，用尽的那件本体不能再转化。每件耐用实体每次出勤限用一次，每层每种机关也只能处理一次。重复往返不会刷奖励。

三个取舍层次：

1. **出门前**：带一格缓冲垫保精力，还是把它变成战斗减伤？留两格绞盘省路费，还是让卷簧弩占据主输出位？
2. **到机关时**：金币、基地进度、探索续航和下一战防御中选一种产物。工具决定产物，操作题只验证读懂现场线索。
3. **战斗前后**：定向屏障准备可以补强受压路线；卡牌换位仍在战斗外完成。不要把额外屏障或充能量直接当成胜因，观察实际被吸收的伤害和生效目标。

保留电梯房间、回家鉴定、自动战斗、三路屏障、固定横向占格、自动上阵、现有成长与资源。冒险开局仍只开4格，没有搬入试验场的九格全开。

## 4. 六类小游戏与节点需求

| 节点 | 可见线索与玩家输入 | 判定 | 两种工具的取舍 |
|---|---|---|---|
| 承重夹层 | 左/中/右标记中找空心铆钉，点击细缝 | 所选位置等于线索位置 | 较少金币+战前屏障 / 较多金币 |
| 断续继电站 | 铭牌公开三色信号，依次点击端子，可撤销 | 三色顺序完全一致 | 电力供基地设备 / 下一战生命 |
| 悬空载台 | 左臂2、负载3/4/5，右臂1；调配重滑块 | 两侧力矩相等，答案6/8/10 | 本趟节省精力 / 下次基地升级折扣 |
| 泄压气室 | 阀门权重1/2/4；目标3/5/6，逐个开关 | 权重和恰好达标 | 消耗胶换屏障 / 保留垫并恢复精力 |
| 反应实验台 | 公示水与试剂比例，输入试剂份数 | 按本次铭牌比例计算 | 消耗喷壶变现 / 保存菌种提高本局上限 |
| 污染分馏井 | 铭牌给出沉淀→加热→冷凝，依次设置 | 工序顺序一致 | 电力+指定路线准备 / 更多精力 |

题目按种子、楼层、节点生成并稳定保存对应输入，刷新不换答案。没有隐藏概率失败、计时操作或突然改变题面。接线和分馏共享顺序控件，但一项侧重信号匹配、一项侧重工艺；目前仍属于轻量读题玩法，尚未证实长期重复游玩的趣味。

统一结算规则：

- 选择、调节、取消均不扣费。只有随身背包/安全容器中的对应**实体**能操作，仓库与战斗卡不替代。
- 错误提交消耗2精力；不消耗本体、不发奖、不前进，可调整重试。
- 正确提交：同一预览函数计算实际收益、操作费和路费；检查后一次提交。若无法承担成功结算后的路费，按钮不可用，后端也原子拒绝。
- 无工具可绕行：消耗6精力及路费，并永久放弃此层该机关奖励。页面明确提示这一点。
- 已处理机关重返只扣通行路费。旧结果不会重新开奖。
- 非法参数、错误场景和无工具请求均不改原状态。消费按所选UID删除，不消费别的副本。

## 5. 节点安排、自然供给与玩法闭环

每层9—11个节点。开头固定为**搜查→第一物品机关→普通战→商人**，其余含第二种物品机关、休整、精英、1—3个原有事件/谜题/缓存/交易/危险节点，最后BOSS。第一机关1F为泄压、2F为分馏，之后按六类轮转；第二机关由种子选取且不与第一处重复。旧事件继续存在，打火机用途保留。

具体低成本供给：

1. 新开局已有猎隙刃@下路1、补漏胶@上路1、破门钉枪@中路1—2，恰好占4个已解锁格；背包另给一件未鉴定缓冲垫。
2. 新世界1F首件实体固定为缓冲垫，2F首件固定为蒸馏器；其余五件从十二件池中生成。搜查费用沿用原规则（基础10精力），拾取实体不额外收费。共享存货仍可能被原有AI流程消耗，不另造个人无限仓库。
3. 1F商人的首个实体固定缓冲垫，2—3F固定蒸馏器，均为1格、4金币；只售一次，沿用交易和售出记录。
4. 普通掉落、游商随机栏和精英掉落全部从十二张现卡产生，没有英雄归属门槛。

因此首趟即可用初始缓冲垫通过泄压；拾取另一件后，一件继续留作工具，另一件回家免费转化并替换上路补漏胶。无需稀有掉落、升级九格或手工注入理想卡组。两者取舍明确：缓冲垫减免直接伤害，补漏胶周期修复更强，对侵蚀的应对也不同。

## 6. 特殊数值机制与生命周期

| 数值 | 写入时点 | 使用/失效 | 上限与含义 |
|---|---|---|---|
| 下一战宿主准备 | 催化管作业成功 | 下一次开战写入快照后清零；撤离/回收清零 | +32，只限本次出勤 |
| 指定路线屏障准备 | 钉枪、胶、泵作业成功 | 与上项同生命周期 | 每路+36；不修复正在进行的战斗 |
| 便捷路程 | 绞盘成功 | 每次节点转移减1，撤离清零 | 设为3段，不无限累加；不减搜查、操作或撤离本身费用 |
| 菌种研究 | 培养皿成功 | 同一局跨天保留；新开局清零 | 宿主上限累计+10，不是额外生命次数 |
| 升级抵扣 | 配重锤成功 | 下一次成功升级自动使用并清零 | 累计4金币；升级失败不扣 |
| 金币、电力、精力 | 作业成功 | 沿用现有资源规则 | 电力不会自动变成鉴定电荷 |

战斗宿主上限 = 240 + 10×(电梯等级−1) + 菌种研究 + 下一战生命准备。

每路开场屏障 = round(宿主上限×30%) + 该路线额外屏障准备。因此宿主上限变化也会改变基础屏障，预览同时显示宿主和三路数值。例：Lv1使用催化管后，下场宿主240→256，各路72→77；若另有上路+12、下路+8准备，实际为89/77/85。

开战前敌情与实际开战共用同一生成逻辑。所有准备在写入 `duel` 后消耗；回放和存档恢复读该快照，不重新获得或再次消耗准备。战斗中仍不允许换位。

## 10. 旧卡退役与存档兼容

活跃卡池从46张统一为12张。旧10张通用牌与24张英雄牌的定义、旧玩法页面、对应试验场数据和旧评估脚本已退役。冒险、图鉴、商人、掉落、敌阵、`/lab`、`/art` 共用当前卡池；`/heroes` 作为当前试验场兼容入口，`/legacy` 仅保留旧午夜集市存档导出。

`lib/card-migration.ts` 中34个旧ID仅是**迁移别名**，不能直接创建或掉落旧牌。库存、仓库、楼层存货及当前战斗快照均迁移；保留UID、等级、品质、容器位置、上阵起点和资源。原3格卡缩为2格，释放一格；不挤牌、不自动重排。卡牌机制会改变，映射不是战术等价承诺。

上述位置保留针对当前横放格式。更早的竖放背包存档沿用既存横放整理流程，可能重新安排容器槽位；放不下的物品保存在仓库，不丢弃。

已鉴定旧bell/cell/coil/b-cart每张补1金币，battery补3金币，抵消降低的固定稀有度售价值；仅自有已鉴定库存补一次，不给共享存货和敌阵发钱。迁移幂等。

首次读取旧版电梯档前保留 `.pre-catalog12` 本机备份；导入旧档时另存 `.pre-catalog12.import`。没有删除正常存档键。新字段可缺省；损坏版本、非法数值、非法旧占格被拒。进行中战斗使用迁移后的快照重播，数值变化可能改变原本未结算结果；需要恢复原规则时使用备份和旧版本，不能声称无损复现旧战斗。

正在探索的旧路线和节点序号在加载时不改变；下一次新出勤才采用新版路线。不会在加载时重扣路费或发奖。更早的午夜集市 `f9.game.run.v1` 是另一种数据格式，不强行映射，原数据保留并可在 `/legacy` 导出。

## 11. 已知风险、未做内容与验收清单

**已知风险**：开放混搭、高品质成长尚未平衡；首轮研究已经揭示反冲板偏强、辅助边际分偏低。新的实体收益虽有次数/上限限制，其长期金币、电力和精力价值仍待玩家验证。自动脚本原有固定策略在8F出现BOSS同时致死，本轮只承诺自然1—5F回归通过，未为了让脚本通关而全局重平衡。
