# F9 AI训练里程碑与正式规则刷新

结论：可以在AI尚未完结时人工介入，先抓行为问题，再做完整赛段验收。合入主游戏需要三个核心场景共用一名真实选手、遵守正式规则并通过连续试玩；单个清怪训练场通过不等于可合入。此文刷新截至2026年10月5日的目标，门槛数字为助手建议起点，后续课程须在训练前冻结。

## 里程碑与当前状态

| 阶段 | 交付与通过条件 | 人工介入方式 | 当前状态 |
| --- | --- | --- | --- |
| M0 可追溯训练闭环 | 有可执行课程、个人观察、真实权重更新、父版本、分离种子、回放和成本报告；失败也保留 | 检查训练方向与明显评分漏洞 | 局部闭环已完成，五轮均有证据；不代表正式规则全部覆盖 |
| M1 单项能力验证 | 战斗／搜索、邮件、离屏各自通过课程；新增执行器有未训练对照，不能靠隐藏信息 | 可以提前指出正常、最差、随机案例哪里蠢，不要求等所有能力通过 | 第五轮小战场各类12/12；邮件与离屏尚未训练过关；新地图族和构筑未验收 |
| M2 最新候选的专项交互试玩 | 将候选显式接入独立实验入口；可重置种子、重现失败、记录操作与反馈；退出与暂停可靠 | 真正操控玩家、写信、改变条件测试AI，并把失败保存为训练题 | 现有邮件／遭遇／离屏基线可试玩；第五轮候选仍离线，尚未接到网页。下一项应交付该试玩桥接，而非继续堆离线成绩 |
| M3 同一选手的5–20F闭环 | 统一UID、库存、配装、票、救援、关系和计划；邮件→现场→离屏→再见面保持状态；正式私人层／据点和预算可执行 | 连续两赛段，测试履约、背约、争票、救援和升层 | 未完成；旧六层离屏实验与孤立遭遇不能代替 |
| M4 鲁棒性与连续博弈 | 多种子、未见地图族／配装、不同对手；三倾向可辨认；三场景不互相掩盖退步；浏览器和Windows实际负载 | 正常／最差／随机局，加少量不知道模型版本的对照试玩；用户体验独立签收 | 未完成 |
| M5 可合入的首个版本 | 对指定规则／能力范围验收通过；完整赛季可运行，公平与守恒无解释不清的错误；存档兼容、超时降级和全库／三正式项目构建通过 | 用户确认智能和体验，并明确请求合入主游戏 | 未达到；AGENTS.md要求实验结束并获合并请求后才迁入电梯，不提前发布 |
| M6 内容扩展与维护 | 新规则或机制登记差异、补执行与输入、专项补训、旧能力回归，再晋升 | 用实际新内容错例反馈 | 合入后长期维护；首版完成不等于以后永远不用训练 |

阶段可以按能力分别推进。M2的探索性反馈可提前开始，M4的封存体验验收则必须针对实际候选；不能以用户试玩过旧模型算新模型验收。当前最合理的下一交付是最新候选的专项交互试玩，同时补正式规则的统一状态；不是等待所有内容开发完才让用户看AI。

“完结”指**某个明确规则版本、能力范围与设备范围的首版通过**，不是保证任何未来道具或任意局面都聪明。用户满意为独立条件，不由助手自动代签。建议先约定10个案例／场景和一段5–20F连续试玩，按理解局势、取舍、变招、关系记忆、行为可理解五项评价；4/5可作讨论起点，不是已经达标。

## 已执行规则对训练目标的影响

| 正式机制 | AI必须学会 | 核心验收 |
| --- | --- | --- |
| 3F守卫结算给唯一首票；4F安全集结；5F全员同tick开赛 | 分清准备与赛事；广播未完不出发，准备期不杀人 | 首票不重复、开赛资源只初始化一次、共同阶段正确 |
| 私人楼层；每十层共享据点及100F | 私人层不能与玩家直接相遇，邮件会面安排在共享点 | 不承诺闯入对方私人房间；现场／离屏在合法区域切换 |
| 普通票上限10、支付升层距离、Lv.2–5跨度3/5/7/9 | 计算到下一据点的票和补给；跨度不越据点，低层关闭后不可返回 | 无透支、越过据点或回低层；比较路线与留搜收益 |
| 同层物资／票源一次性、脑浆预算36；重新进入不刷新 | 知道耗尽与深搜风险，不无限刷怪获取升级材料 | 同UID只领一次，不把无穷击杀当成长目标 |
| 10–90F首人真实到达后冻结名单，N−X金票；前点未结算后点不发票 | 判断未发行、地面、持有、兑换与无资格机会，考虑等待成本 | 不虚构倒计时或增发；人数变化不重算已发票 |
| 可持多张金票，但返个人电梯最多一张；资格单次兑换 | 拿票后及时合法返回，扔下多余票，按承诺或博弈安排位置 | 票不能保险／仓储／销毁；拿到不等于晋级，无重复兑换 |
| 精力、食水有限；电梯也代谢；休息耗食水 | 预算探索、返程、休息、升级和预留救援，留未来行动能力 | 普通返程／升层不补满，不靠无尽喝水休息刷分 |
| 真急救包＋食物＋水一次性预留救援；缺套装永久死亡 | 为风险准备库存，在升级和救援之间权衡，死亡有真实成本 | 完整原子扣费，背包／未兑换票掉落，装备与保险按实际救援／永久死亡规则处理 |
| 100F唯一终局票合法带回才获胜 | 重视最终资格和撤出，不能只冲到100F | 同一账本、只有合法带回才判胜，无101F |
| 同场PvP现在为明确选择目标；射程／视线／同一冷却 | 基于合法目标、关系与代价压制或退让 | 不能免费多打一份人类攻击；未来红灯规则另版 |
| 终端／菜单／失焦共同暂停，不补离线时间 | 重放相同tick；模型等待不凭空给AI私人免费停表 | 过期决策重新核验，等待沿可行旧计划或明示统一暂停，不静默冻结单个AI的代谢 |

**正式目标改为：合法性与状态守恒→晋级／合法撤出→未来行动能力与资源预算→性格、关系和合理风险。** 击杀、受伤、搜获、地图覆盖都是诊断或阶段信号。清场用于隔离测试战斗能力，不是每个私人房间都必须清完；有票有货时合理撤离不应被罚，有安全目标却健康空包提前退也不能被奖励。

## 新设计方向的待支持课程

| 方向与状态 | 需要的新观察／课程 | 现在的处理 |
| --- | --- | --- |
| 用户明确道具配装养成、商店为主要获取、商品回收；详细货币、店铺更新待验证 | 实际余额／货价／格位、环境预告与采购配装，商品运输机会成本 | 登记未来目标；v9尚无货币／商店，不伪造购物训练 |
| 用户明确环境续航、更多怪物、状态与原创元素反应；四元素／六反应和数字为候选 | 来源、范围、预警、持续、抗性、盾、电力、附着与组合能力，而非只看物品名字 | 每机制先有实验执行器，再加入课程；本轮仅已有范围、快慢怪、远程预警和遮挡 |
| 用户明确杀戮默认关绿灯、主动开红灯、AI同能力；启动0.6秒等为候选 | 公共灯色、阶段、对外许可、当前合法对象、残留来源与授权版本；开关博弈和邮件意图 | 新规则版待实现后训练；v9继续按明确选目标PvP。绿灯非免伤等细则不当已批准规则 |
| 用户明确共同世界的AI竞争与三场景一致 | 同一个选手事实／计划／承诺；明确记录欺骗，机会变化后更新 | M3最优先系统工作；现有邮件、现场与六层离屏仍为分离实验 |

对更新中的主游戏定期刷新能力清单；同机制新增内容先测再决定补训，新机制或核心改版明确更换数据／规则版本。实验可自由发明道具，但实验验收通过不能自动批准主游戏设计。

## 各里程碑建议的技术门槛

M1本轮课程冻结了每类清场≥80%、死亡不增加、平均受伤较父版本增幅≤3、击杀不低于父版本98%、回放无误。第五轮通过这套小环境门槛，不能外推到新地图族。

第五轮搜索以全部墙体为公共几何，只有敌人位置受个人视野限制；未知地形的迷雾探索尚未验证。其数值规则教师也达72/72，因此只证明局部搜索接口可训练，没有证明网络比规则搜索更强。M2人工测试与M4未见地图课程需检验这些边界。

M3建议先用5–20F执行镜像和正式契约用例，做至少1万次UID／库存／票／救援／状态交接检查，规则错误为0。私人层、据点、等待、换场、暂停、存读档和过期决策都要覆盖；不得用跨产品导入绕开隔离，也不重新生成旧黄金回放。

M4建议冻结多地图／对手／构筑评测，各场景单独通过：邮件无旁白、事实冲突≤1%、有效答复≥90%、条件仍可执行的诚实约定兑现≥95%；可解同场／离屏基础目标≥85%，无目的超过10秒循环局<1%，资源可行却无效行动困死<5%。规则拦截与备用控制器接管单列，不拿修复后的结果掩盖模型错误。

Windows与浏览器分别测渲染同时运行的11名选手、邮件排队、冷启动、内存与超时。单角色Node微基准不是双端发行证明。全百层测试要记录实际合法晋级、资源亏空、救援与终局；允许合法落败，不能每人都获胜。

这些是待冻结的建议标准。最终合入由指定版本的自动证据、用户连续试玩和明确合并请求共同决定；后续扩展继续保留旧模型、回归与可回滚数据。
