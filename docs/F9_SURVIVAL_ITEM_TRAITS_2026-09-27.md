# F9 实时探索：物品特性规范

状态：本轮已实装；适用于 survival 原型，不覆盖独立卡牌分支。最新修订见 [ADR-0023](./design-log/decisions/ADR-0023-survival-sight-brains-and-recovery.md)，初版决定见 [ADR-0022](./design-log/decisions/ADR-0022-survival-interaction-and-theme-creatures.md)。

## 数据与语义

物品仍保存稳定 uid、kind、尺寸和占格。特性来自 `lib/survival-item-traits.ts` 的完整目录，不在每个存档内复制一份，避免旧物品与新 UI 使用不同规则。

| 词条 | 行为约束 |
| --- | --- |
| 可使用 | 提供明确的主动使用动作与效果；当前四种补给均支持。恢复已满时不消耗。 |
| 可装备 | 允许进入十格装备栏；普通背包与保护格不激活装备效果。 |
| 战斗 | 装备后的攻击或战斗支援；武器伤害、间隔和相邻数值继续由战斗规则计算。 |
| 机制 | 装备后改变探索机制。电筒增加 2 米光明视野，不产生随身实体光源；多支不叠加被动半径。 |
| 消耗品 | 通过合法使用或材料交付消耗实例。此标签本身不等于“可以吃掉”。 |
| 升级材料 | 可用于匹配的升级配方；只在整笔支付成立时扣除。 |
| 关键物品 | 有明确进度用途，当前用于手机、首个能源核心的识别提示；不自带无敌、免丢失或无限复制规则。 |
| 相邻 | 生效取决于装备栏邻接关系，隔空格断开。 |
| 可堆叠 | 同种同品质合并，上限来自统一物品定义；每份保留稳定身份。脑浆当前上限20。 |
| 贵重物 | 当前只有净水机芯，主要用途是带回与携行价值；尚未实现商店，不显示“可出售”。 |

“被保护”“已装备”“任务已交付”是位置或状态，不是物品永久词条。“可堆叠”已用于脑浆；“可制造”“可交易”尚未实现，不提前给物品贴标签。

## 跨界面约束

- 所有补给的主动效果与自动效果读取同一份定义；装备资格、被动视野也来自此目录。
- 保护格暂停效果。手动使用前须取回普通背包，与原有保全取舍一致。
- 使用不存在的 uid、不匹配的物品、满值补给，必须无副作用；有效恢复按实际缺口结算并记录真实实例。
- 手动补给同样进入返程的“已用”记录，不能误算为丢失。
- 第一顿面包发放时饱食最多为 55，吃完最高到 100，饮水为 60。旧的“满饱食、尚未吃面包”存档恢复为 55，避免防浪费规则卡住教学。
- 物品说明显示词条及简短效果。数值不通过描述文本反向解析。

## 扩展约束

新物品必须同时补齐特性、可执行效果和说明；仅有标签但无执行器的“可使用”不合法。以后新增钥匙、开关工具等，可扩展使用效果的类型联合，不能在背包页面继续按名称堆分支。战斗细节可保留独立效果表，但资格和触发位置仍遵循本规范。

## 2026-09-28：携行与支付

初始背包为16格（4×4），装备十格保持不变，基础格全部正方形。脑浆描述：打爆怪物掉落脑浆很合理，升级电脑需要脑浆也很合理。普通背包死亡时移入原地背包容器；装备与安全容器保留。当前居所1→2要求30脑浆经验和2机械零件，支付多出的经验存入电梯；失败支付不会部分扣除。
