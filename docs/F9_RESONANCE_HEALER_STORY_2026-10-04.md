# 共鸣卡牌：《听风之旅》主线剧本与心景战斗

日期：2026-10-04。产品：`apps/resonance`。

用户已决定：音乐治愈心魔、温馨冒险、治愈师主角、玩家演奏对抗有独立冷却技能的实体怪物、单场多个敌人。以下人物、场景、对白、敌群和章节顺序为本轮创作，已接入六场可玩叙事切片；不等同于完整60–90分钟养成局已完成。

## 一、故事的承诺

你不是替别人决定人生的英雄，而是愿意停下来听完一首歌的人。

世界里，没能说出、无人回应、长久压住的情绪，会在一个人的「心景」里形成心魔。心景是一处能被治愈师与音乐触及的幻想空间：磨坊里堆起无穷的行李，灯塔外的海潮重复着同一天，工坊的钟永远催人快一点。心魔会把人困在反复的恐惧与自责中，但这个人本身不是敌人。

治愈师先征得对方愿意倾听的回应，再通过音乐进入心景。战斗中的伤害是旋律削弱心魔的实体；治疗是主角恢复生命，防护是「定心」。界面仍直接写生命、伤害、治疗、毒、灼烧和减伤，避免包装让规则难懂。心魔消散后，对方重新获得迈出下一步的空间；具体下一步由他自己选择。

温馨不是所有人被一首歌变成开心的人。它来自结束后那个小而具体的行动：唱一句、睡一晚、去买桃子、把礼物送出、主动向朋友开口。

旧版「归物师与利益派争夺物品」「血量代表羁绊、输赢转移器具」「终局给归物站送物」由新叙事接替，不再作为这条主线的解释。旧音乐盒、师傅、万灯城和旅途器具保留为新的记忆纽带，历史设计文档仍保留。

## 二、主角与主要人物

| 人物 | 起点 | 变化与作用 |
| --- | --- | --- |

## 三、开篇：六格漫画与教学

完整开篇建议六格，游戏当前以逐格像素场景与对白呈现，可跳过重看。

1. **窗边。** 小阿弦蜷坐在窗下，音乐盒的发条停着。框外文字：「有一段时间，阿弦把所有想说的话，都留在了心里。」没有大段解释家庭变故。
2. **半首曲子。** 许师傅坐在旁边，不看怀表，也不追问。师傅：「今天不用唱完。我们先听这一半。」最后一个音符落下，小阿弦轻轻接了一声。
3. **若干年后。** 镜头切到后院，长大的阿弦把茶壶、旧伞和音乐盒摆在演奏台上。阿弦：「原来器具也能记住一段声音。」师傅：「人送你的声音，更要好好带着。」
4. **教学心景。** 一只怯声团从阿弦没说完的句子里探头。师傅：「心魔会自己出招。你排好器具，让歌带着线走。先看它的行动，再看自己的生命。」进入第一场教学战。
5. **来信。** 小禾的信纸附着三片不同的叶子。「听风会快到了，可沿路有几个人很久没有出门。若你愿意，请来听听他们没能说完的话。」
6. **启程。** 师傅给背包放入热茶与空白乐谱。师傅：「别急着替别人写结尾。」阿弦：「那我就先去听一听。」推门，风带出标题《听风之旅》。

原型先交代过去与师傅的教导，后院教学胜利后接上来信与启程，按以上顺序推进。当前场景为代码绘制的像素画与逐格对白，不声称已完成六幅最终漫画插画资产。

教学只要求三件事：认识自己的歌曲；知道首扫立即发动；看懂心魔的行动条。第一次胜利后不弹十项机制说明。师傅：「到了旅途中，先听人说话，再进入他的心景。」

## 四、旅途主线

### 第一章：雨停驿站——没唱完的小合唱

**到达。** 驿站门外的雨很轻，芽芽却紧紧捏着合唱曲谱。小禾没有替她解释，而是把椅子搬过来。

芽芽：「上次唱跑调了，大家笑了。我不想再上台……可我还想和朋友一起唱。」

阿弦：「今天先不去舞台。你愿意在这里，只唱给小禾听吗？我替你把那些吵闹的声音安静下来。」

**心景。** 大而空的礼堂，座椅像浪一样来回。怯声团吞掉句尾；苛责刺把「还不够好」一遍遍投过来。两只心魔各自行动，前者稳定直攻，后者直攻并施毒。让玩家第一次比较「先消灭稳定压力」与「先消灭持续伤害源」。

**走出。** 芽芽：「我还是有一点怕。你们明天还会听吗？」小禾：「会。今天只唱一句，明天也可以只唱一句。」芽芽唱得很小声，驿站门外，雨恰好停了。

**成长包装建议。** 小禾借给主角一盏书桌小灯，芽芽给空白乐谱画了一个歪歪的音符。卡牌收集来自人物关系和探索，不来自抢走受助者的东西。原型当前11卡直接开放试验，没有提前实现这套奖励解锁。

### 第二章：纸风磨坊——把肩上的风放下来

**到达。** 磨坊外摆着修到一半的工具。牧舟说自己不累，却不断丢落零件。

牧舟：「屋顶没修完，妹妹的药还没送，磨坊也不能停……我不累，只是最近总听见钟响。」

阿弦：「你真的已经做了很多。我们先把今晚交给街坊，好吗？不是所有事情都必须由你一个人完成。」

**心景。** 一座被纸袋与行李压弯的风车。负重壳蓄力重击、定时保护自己；催促钟用短冷却攻击，并制造灼烧。没有第二条扫描线。玩家用一条自己的线对付慢重击与快频率压力，选择集火顺序和治疗位置。

**走出。** 牧舟醒来，窗外还在转。牧舟：「我睡着的时候，磨坊竟然也没有塌。」街坊：「明天还是一起修。你负责教，我们负责搭把手。」

他把一把旧伞送给阿弦。伞柄上刻着新话：「轮到你歇一歇。」这成为补丁旧伞的来历。

### 第三章：晚灯海岬——留一盏灯，也留一扇门

**到达。** 灯塔里放着两副餐具，其中一副总没有盛汤。南婆婆抚摸唱针，已经很久没有下过山。

南婆婆：「他走后，灯塔每天还亮着。我怕哪天忘了他的声音，就连灯都不敢离开。」

阿弦：「我们可以把那首曲子记下来。记得一个人，不一定要一直待在最后见到他的地方。」

**心景。** 海浪一遍遍退回同一条线。旧日回声治疗生命比例最低的存活同伴；负重壳顶在前面；怯声团持续攻击。第一次三实体敌群，支持者的回血弹道清楚可见。先攻回声可阻断续航，先攻残血单位也可减少敌方动作；伤害不会溢出到下一只。

**走出。** 阿弦陪她把那段旋律记下来，没有给曲谱取名。南婆婆：「我想去集市买两颗桃子。他喜欢的，我也喜欢。」她仍会想他，只是今晚，也给自己煮了一碗热汤。

这一段呼应主角的童年。阿弦第一次没有急着回答「会好起来」，而是说：「我陪你走到山脚。」

### 第四章：晴窗工坊——有裂纹的，也可以发光

**到达。** 灯架上挂满「差一点」的纸签。青石女儿画的邀请函，已经从桌边落到地上。

青石：「这只灯还差一点。只要再改一点，我就能把它送给女儿了。她说了好多次没关系，可我不能让她失望。」

阿弦：「也许她等的，是你和灯一起回来。要不要先问问她喜欢哪一道光？」

**心景。** 工坊里有三个不断改写的影子：苛责刺、催促钟、旧日回声。不是血量最高的一关，但持续压力和治疗互相支持。合理的优先目标、净化与防护编排在这里汇合。

**走出。** 女儿把灯摆在窗前，裂口照出细长的光。「这个裂口像一条小河。我最喜欢这里。」青石第一次放下工具：「那……今天就不修它了。我们去河边走走。」

阿弦在自己的乐谱上擦掉「等我准备好了」六个字。

### 终章：万灯城——轮到你，也被听见

**到达。** 广场的听风会如期举行。四个章节的人都来了。阿弦站到中央，却唱不出第一句。

阿弦内心：「你能帮助别人，为什么连自己都照顾不好？」周围声音渐渐远去，广场进入他的心景。

许师傅：「会照顾人，不代表你不会难过。今天不用站在所有人的前面。我们陪你一起。」

小禾：「芽芽来唱第一句。牧舟替你撑伞。南婆婆带了热汤。你的歌里，早就有我们了。」

**心景。** 无声长夜是主实体，攻击间隔较长、攻击力高，还有更长冷却的夜潮。旧日回声不断拉回过去，催促钟不断逼他立刻证明自己。最终敌群并不装备一首更厉害的歌，仍使用怪物独立技能。

**终局。** 心魔消散，战场空出一块能听见风的地方。阿弦：「我没有变成再也不会害怕的人。只是这次，我知道可以向谁开口。」

朋友们：「下一次风吹起来，我们也会在。」

所有人的声音进入同一首歌。空白乐谱写满了不同旋律。最后一格，阿弦给新来信回复：「我会来，但请先为自己倒一杯热茶。」旅途可以继续，主角这次也带着朋友给他的照顾出发。

## 五、卡牌收集、局内成长与关卡的重新包装

以下是养成系统的叙事规格，保留过去「收藏解锁、局内数值重养」的意图。本轮战斗切片没有实现完整商店、数值升级、分支地图或局外收藏。

- **卡牌：共鸣器具。** 可直接演奏的乐器，也包括保存回忆的茶壶、旧伞、灯、药匣与放映机。阿弦借助器具让旋律获得治疗、防护或穿透心魔的力量。可爱主体仍取决于器具与故事，不强制小动物。
- **获得：旅途拾得、器具匠买卖、居民赠予、师傅传授。** 受助者的回礼是自主选择，不设「救完必须给牌」的道德交易。
- **局内数值养成：修调。** 在安静的休息处修弦、添灯油、补伞面、整理乐谱。成长提高的是本局器具的共鸣数值，不是量化受助者有多爱玩家。
- **配合成长：合奏领悟。** 倾听不同人的经历让阿弦学会不同的衔接方式；可选择专长，但不把「对话选对答案」变成伤害奖励唯一来源。
- **歌曲：同行的主旋律。** 装备曲目决定节拍与核心能力。玩家自己的歌持续播放，卡牌随拍点发动；怪物没有歌曲、编排台或扫描线。
- **局外收藏：旅途手记与曲谱。** 记录遇见的人、器具来历、章节后续；解锁后续开局的新选择。本局数值仍从起点培养，不出售永久攻击优势。
- **每局结构建议：教学可跳过 → 2至3个沿途人物心景 → 万灯城集会收尾。** 完整故事首通依章推进；自由旅途可组合人物支线。60–90分钟来自事件、构筑与休息，而非把一场战斗拉长到十分钟。
- **战败：退出心景休息。** 心魔不交易赎金、也不夺走物品。未来若保留旅费消耗，应来自药品与住宿，不能继续使用旧版利益派赎回的解释。原型无资源惩罚，可重新编排重试。

## 六、已落地的战斗合同

| 规则 | 本轮行为 |
| --- | --- |
| 玩家演奏 | 原11卡、四套预设、九格、1至3格尺寸、歌曲能力不变；每格两拍，每圈首扫立即发动并重置线冷却 |
| 对手 | 一至四只心魔实体；章节使用一至三只；各有生命、攻击力、独立技能和独立时钟 |
| 集火 | 开战前选优先UID；存活时持续攻击它；它消散后下一次发动自动攻击列表中的第一只存活心魔 |
| 持续伤害 | 毒与灼烧附在具体实体；换目标不转移已附状态，新状态等下一次公共每秒结算 |
| 溢出 | 单次攻击只打发起时的目标；过量伤害不跳转，吸血只计算实际直伤，避免小怪成为无限回血来源 |
| 心魔治疗 | 只选当前存活且生命比例最低的同伴；相同比例按敌群稳定顺序；不复活消散者 |
| 同时行动 | 同一tick先形成双方意图，再共同结算，允许同归于尽；当tick开始已死亡的敌人不能行动 |
| 玩家防护 | 保留旧版下一次共同承伤结算减免：同tick的多个敌人攻击一起被保护，然后消耗一次；不按敌群顺序偷换效果 |
| 展示 | 最近到期技能常驻行动条，全部技能按需查看；攻击、治疗弹道实际指向具体实体；生命反馈延迟300ms与命中同步，规则不延迟 |
| 回放 | 新 `rhythm-healing-v3` 保存怪物属性、UID、优先目标、我方歌曲与编排；旧v1/v2保持历史试演，不混迁 |

六场默认战斗在固定参数下均可胜利，主要验证完整流程；不能用默认全胜宣称套路或难度已平衡。当前数值与心魔技能还需要试玩调整。
