## 必须修复的原型缺失

1. 基地页应恢复真实可操作的建造模块，展示设施、占槽、成本、能力和拆换反馈。v0.3 的日程终端替代了此前的建造操作，导致验收入口退步。
2. 战斗页应展示敌方完整三路九格、卡牌占位、地形、冷却、触发和卡牌说明。仅显示敌方主人状态和阵容文字不足以判断战斗。
3. 多格卡需统一处理锚点、连续占位、合法移动、被占格、解锁格和容量检查。同一张卡只发动一次，不能因覆盖多格重复运行效果。不得跨路。
4. 去除全员供能模式的最终规则假设。供能流派用明确的发电、储能、耗能卡形成体系，普通卡不因缺电停止运行。

## 奇迹稀有度的特殊性

用户附注为：“奇迹品质带来超出线性幅度的数值提升以及一个额外特殊效果词条”。按此前五档稀有度与三层品质定义，本文将“奇迹品质”解释为最高档“奇迹稀有度”，仍在鉴定时确定且不可培养。

奇迹档是普通有限系数规则的例外：提供非线性强度跃迁和一个额外特殊词条；其余四档仍采用已选择的有限初始与成长系数。尚未确定跃迁倍率、词条池、词条是否随机、是否允许重复及其触发上限，不把草案数值当作已批准值。

特殊词条应使用受控效果与事件规则，不能由自然语言直接执行。它可以改变循环或触发关系，但不应产生无限递归、无限资源或不可解释的即时必胜。需要提供词条发生前后的战斗对照。

## 基地经营扩充方向（待设计，并非已验收数值）

设施需要改变出勤策略和资源转换方式，避免全部退化成材料换补给或单纯加上限。建议先比较以下八类能力，再决定首个十层版本保留哪些：

| 设施候选 | 主要决策价值 | 需要付出的代价或机会成本 |
| --- | --- | --- |
| 补给培育舱 | 稳定日常补给 | 消耗原料、电力和每日生产额度 |
| 蓄电/发电模块 | 为终端及设施储备普通电力 | 消耗燃料或精力；不产生生命维持配额 |
| 医疗休整舱 | 改善休息恢复或移除有限伤势 | 消耗医疗物资；与生产设施争夺空间 |
| 气象观测台 | 获取次日预报及更远层环境情报 | 消耗电力，提供信息优势而非直接伤害加成 |
| 回收工坊 | 改善废物拆解和升级投入回收 | 消耗处理额度，回收率必须低于可套利阈值 |
| 便携设备台 | 充填鉴定器、加工探索工具 | 材料与电力投入换取探索选择 |
| 打包/储藏模块 | 改善仓库与出勤携带取舍 | 仓储、普通包、安全容器分别设容量和升级条件 |
| 地形适应模块 | 制作一次性保温、绝缘或遮蔽装备 | 根据已知天气提前投入物资，不能永久免疫全部天气 |

建议保留补给、精力、电力、材料、配额作为核心数值，先丰富转换关系、信息和每日额度；是否增加新资源，应由设施差异确实需要来决定。用户要求扩充可玩性，并未确认额外资源种类。

## 需要明确的具体规则

- 连续救援的递增序列、上限，以及一次成功出勤还是睡觉后重置连续计数。不能默认睡觉就清零，否则玩家可能规避递增惩罚。
- 安全容器的升级等级、容量上限和可存物限制。
- 多格卡是否分 1 / 2 / 3 格，以及初始四个开放格中连续空间如何分配；早期掉落的大卡应有可预期的使用路线。
- 建筑种类、槽位、拆卸代价与每日生产的额度归属：全基地一次还是各设施一次，需要结合设施数量重新定稿。
- 奇迹词条的生成、揭示与持久化方式，以及其与品质解锁效果的叠加规则。

下一轮原型优先顺序：敌我完整棋盘与多格卡 → 恢复并扩充基地建造 → 供能流派 → 奇迹词条样卡 → 救援递增及安全容器成长。所有新数值继续明确标为待验收建议。
