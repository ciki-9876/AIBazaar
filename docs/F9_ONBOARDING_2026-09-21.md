## 具体规则与可复测流程
新开局：弹弓首战 → 领取敌方猎隙刃并上阵 → 第二间搜刮补漏胶与缓冲垫 → 第三间接管道（补漏胶可增加步数，缓冲垫保留供教学转化）→ 宝箱获得鉴定仪 → 鉴定缓冲垫 → 中路布防 → 守卫 → 武器战利品及终极宝箱 → 总结归返 → 售卖 / 购买 / 鉴定 / 睡眠。

鉴定品质按存档种子与物品实例确定：普通45%、罕见28%、稀有17%、传说8%、奇迹2%。稀有和传说为精制，奇迹为大师；结果影响实际解锁能力，不只是染色。上述为配置分布，不是小样本实测概率。
商店每日2只鉴定仪，每只12金币；电梯Lv.4开放鉴定台，每次2金币、不限制次数。旧有设备制作途径保留。
