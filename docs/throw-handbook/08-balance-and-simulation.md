# 08 · 平衡与模拟

2026-10-12 当前规则：对决 v16 / 冒险 v10。第四幕、26件本体字段改装、金级同款材料且不限数量、自动出牌、三人独立配置见[ADR-0064](../design-log/decisions/ADR-0064-throw-millbrook-upgrades-and-autoplay.md)、[第四幕内容](../F9_THROW_MILLBROOK_2026-10-12.md)与[实测记录](../design-log/iterations/F9/2026-10-12-throw-millbrook-upgrades-and-autoplay.md)。下文此前版本的机制及证据有冲突时按本修订为准；历史结果不重写。


当前正式规则为 v14：禁手按开场/白热/落幕缩放为每张 1、2/3、1/2 秒；落幕每半秒结算、每次伤害按原秒数公式不变，见 [ADR-0062](../design-log/decisions/ADR-0062-throw-readable-recovery-and-local-leases.md)。v8 的每轮 2 张发牌、v13 的移除灼烧出牌自伤继续沿用。AI 思考可与禁手重叠，但额外思考仍使单张节奏慢于真人；矩阵不能代替真人节奏。移除烫手后原灼烧预设掉至 35% 全场下限之下，因此 v13 已把其中的双响铃换成飞牌修缮箱；v14 没有再次改道具、预设或克制门槛。旧参数扫描见 [v13 迭代](../design-log/iterations/F9/2026-10-11-throw-recovery-and-westport.md)。下面 v4／v5 与 [v12 结果](../design-log/iterations/F9/2026-10-11-throw-quick-draw-and-feedback.md) 都是各自版本的历史证据；不带人物身份的预设矩阵不能证明快抽、改装、莫莉或双人赛已经平衡。

2026-10-11 的 v14 同种子/同座位对照，`balance-matrix.mjs 40`：10 条克制均通过 ≥60%，六套全场均值仍为 49/53/52/41/52/53%；逐格最大变化为 3 个百分点。这里是基础预设回归证据，不能据此宣称半秒落幕的真人体验或第三幕长期难度已验收，详见 [v14 记录](../design-log/iterations/F9/2026-10-11-throw-readable-recovery-and-local-leases.md)。

**任何数值改动都要有前后对比数据。** 「感觉强了一点」不是理由；「矩阵里从 48% 到 61%」才是。

## 1. 工具

都在 `apps/throw/tools/`，用 Node 直接运行，不需要构建：

| 脚本 | 用途 | 典型耗时 |
|---|---|---|
| `sim-proxy.mjs` | 共享的代理玩家：用和 AI 一样的函数替玩家出牌，遵守演出规矩 | — |
| `balance-matrix.mjs [N] [--kits kits.json]` | 六套预设两两对战的胜率矩阵 + 检查每条 `beats` 声明 | N=40 约 25 秒（v6 起对局更短） |
| `story-sim.mjs [N] [battleId …]` | 用几种「玩家此时可能带的巡演箱」打剧情对决，看难度曲线 | 每场 N=40 约 1 分钟 |
| `card-exposure.mjs [N]` | 一张指定的牌每局进手、被甩出、落幕后被甩出的概率 | N=10 约 20 秒 |
| `enchant-power.mjs [N]` | 每种通用附魔单独装满时对全场的胜率变化 | N=10 约 3 分钟 |
| `build-audit.mjs` | 构筑空间审计：确定性地随机抽几千套合法巡演箱（外加只用一两个家族的专精箱），对六套预设打座位对称的对局，统计胜率分布、按家族数的平均强度、强箱里的道具和遗物倍率；再用 20 种子精测最强的 60 套 | 3000 套约 12 分钟（2 个分片并行）+ 精测约 4 分钟 |
| `relic-swap.mjs [N]` | 每套卡组换上每件遗物（和不带）对全场的胜率 | N=20 约 1.5 分钟；结论至少用 N=20（每格 120 局） |

```bash
node apps/throw/tools/balance-matrix.mjs 40
node apps/throw/tools/balance-matrix.mjs 20 --kits my-kits.json
node apps/throw/tools/story-sim.mjs 40 pike juno show-quick
```

`--kits` 的 JSON 格式：

```json
{ "hybrid": { "style": "guard", "items": ["umbrella", "ward", "mend", "wash", "quick"], "relic": "bastion" } }
```

## 2. 读懂矩阵

- 每格是**行打列**的胜率，已经做了座位对称（双方各坐一次先手位后取平均），平局算半场。
- `avg` 列是这套卡组对全场的平均。
- 底部列出每条克制声明，`ok` / `FAIL`。

**验收标准**（与 `throw-strategy.test.mjs` 的回归测试一致）：

| 指标 | 要求 |
|---|---|
| 每条声明的克制 | ≥ 60% |
| 每套卡组的全场均值 | 35–65% |
| 样本量 | 正式结论至少 N=40；N<16 只用来快速试方向 |

小样本会抖：N=6 时「护灯克星光」显示 54%（FAIL），而 200 个种子的正式矩阵是 76%。**看到 FAIL 先加大 N 再下结论。**

硬克制是刻意保留的（v5 里快甩打余烬只有 14%，护灯打快甩只有 20%）：知道对手是谁就换道具，是这类构筑游戏的核心乐趣。只要剧情里强敌之前有情报，硬克制就是好设计。

## 3. 剧情难度曲线

`story-sim.mjs` 用 `KITS` 里的几种巡演箱（`early`、`mend`、`guard`、`poison`、`burn`、`combo`）打每场剧情对决。目标：

| 位置 | 用默认巡演箱的胜率 | 用对的巡演箱的胜率 |
|---|---|---|
| 一幕开头的对决 | 70–90% | — |
| 一幕中段 | 50–70% | ≥ 80% |
| 强敌 / 决赛 | 15–50% | ≥ 65% |
| 街头演出 | 50–100% | ≥ 80% |

「默认巡演箱输、换对了就赢」是**理想的强敌**——它逼玩家去读档案、去商店。第二幕的派克：默认箱 13%，带毒 68%，正是这个形状。

开新的一幕时，把这一幕玩家能拿到的新巡演箱加进 `KITS`。

## 4. 变种强度

变种只在剧情里用，竞技矩阵一律白牌。检查方法：一方按稀有度上限装满牌匣，放在高点数牌上，另一方用白牌，跑全场。当前基线约 **+25 个百分点**（白牌 39–61% → 满牌匣 68–81%）。新变种之后：

- 整体优势不应超过 +30 个百分点；
- 单独只装某一种附魔时，不应比装满混合牌匣还强（否则它就是「唯一正确答案」）。

### 4.1 设计变种和遗物前先看出场率

一张指定的牌每局被甩出的概率约 38%，落幕后才被甩出的概率约 1.3%（v6／v7，`card-exposure.mjs`；v5 为 40% 和 2.7%）。所以：

- 变种是高光，不是引擎：任何时候打出都要有价值；
- 「落幕期间」只能当加成，不能是唯一条件；
- 遗物验收用 `relic-swap.mjs`：专属遗物在本流派排前 2，没有遗物是 3 套以上卡组的最佳，没有遗物在所有卡组上都等于不带。

## 5. 参数扫描

调一个参数时，不要只试一个值。至少试三个点并记录：

| 参数 | 试过的值 | 结果 | 选择 |
|---|---|---|---|
| 落幕开始与递增 | 45 / 60 / 75 秒起；每秒 +1 / +2 | 矩阵差别都在 ±5 个百分点内，克制环都成立 | 60 秒、+1：整一分钟开始，伤害就等于落幕秒数，最好读 |
| 速战速决时限 | 45 / 64 / 70 秒 | 45 秒 0%，70 秒 98%，太难或白送 | 64 秒：要动脑但能赢，落幕帮一把 |
| 变种强度 | 第一版：镀金 ×3、描银 ×2、上限 12/6/3 | 满牌匣对白牌 72–88%，主要来自点数类 | 镀金 ×2、描银 +4、上限 8/4/3：68–81%。上限已在 ADR-0058 取消，强度改由获取节奏控制 |

扫描结果写进 iteration 记录，包括没选的值。

## 6. 已知局限

- **代理玩家不是人。** 快甩和蓄爆的强度高度依赖出手时机，真人可能显著不同。数值定稿前需要真人试玩（记录写在 `docs/design-log/playtests/`）。
- **构筑空间要定期审计。** 新增道具、改数值后跑一次 `build-audit.mjs`（用法见脚本头注释）。v8 的审计显示最强的随机箱对六套预设 100%，前 60 套全部超过 65%。v9 的处理与结果见 [ADR-0056](../design-log/decisions/ADR-0056-throw-v9-build-space.md)。
- **审计的 AI 节奏有偏差。** 快甩风格每 1.5 秒思考一次，其他风格 2.6–3 秒，所以被判为快甩的箱子出手更多。这个偏差和真人更快的方向一致，但读审计数字时要记住。
- **AI 只有六种风格。** 剧情敌人可以换道具和牌匣，但出牌节奏只能从六种里选。

## 气场曲线（v11，ADR-0059）

- `tools/growth-curve.mjs [N] [城市…]`：每座城市三档玩家（下限、中位、上限的变种收集）对这座城市的强敌（目标变种数的 70%，气场 × 1.1），六种流派互打。验收：中位玩家对局 42–50 秒，拖进落幕不超过 30%。改装还没实装，没有计入。
- `PRESENCE=343 node tools/story-sim.mjs 24 juno`：剧情模拟可以指定主角的气场；对手用对决定义里的 `presence`。
- 2026-10-10 基线（N=2）：布里奇波特中位 43.9 秒、拖进落幕 19%；世界大剧院中位 46.6 秒、28%。朱诺（374）对默认箱：主角 320 时 25%，343 时 38%，364（寄宿房 + 好心情）时 50%。
- 曲线的推导（关掉落幕测「自然时长」，反推需要多少气场）见设计文档 1.2。
