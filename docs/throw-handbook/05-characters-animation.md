# 05 · 角色与动画

## 1. 原理：一副骨骼，全员换装

所有角色共用 `rig.tsx` 里的**同一副矢量骨骼**。角色之间的区别只是一份「造型」（`Look`）数据：体型、配色、发型、帽子、眼镜、胡子、服装款式。没有逐帧图集，动作是每帧实时计算的。

好处：加一个角色只要写 20 行数据；所有角色自动拥有行走、待机、呼吸、眨眼、甩牌、受击动作。

对白里只出现正在说话者的头像：玩家固定左侧，NPC 固定右侧，另一侧留空位。桌面和手机都保留两侧位置，旁白不显示头像，也不能冒充某个人物。新对话涉及多名 NPC 时仍把当前 NPC 放在右侧，头像裁切与台词身份都要核对。

## 2. 造型数据 `Look`

```ts
juno: {
  name: '朱诺·贝尔',
  scale: 0.92,              // 身高系数，1 = 标准成年人（154 世界单位）
  lean: 3,                  // 身体前倾角度（度），老人和疲惫的人更大
  skin: '#c99272', skinShade: '#a8765a',
  hair: '#24170f',
  coat: '#c08a2e', coatShade: '#8f6420', coatLight: '#dba64a',  // 主色、暗部、受光
  sleeve: '#c08a2e', forearm: '#c08a2e',   // 袖子；卷袖时 forearm 用肤色
  trouser: '#2b2a33', boot: '#1d1b20',
  body: 'jacket',           // 'frock' | 'vest' | 'overall' | 'tails' | 'jacket' | 'dress' | 'apron'
  hairStyle: 'bob',         // 'eli' | 'reed' | 'mia' | 'felix' | 'bob' | 'bun' | 'curly' | 'bald' | 'perm' | 'crop'
  hat: 'cap',               // 可选：'top' | 'cap' | 'peaked' | 'bowler' | 'brim' | 'helmet' | 'kerchief' | 'headscarf'
  hatColor: '#3b3f46',
  accent: '#2d6870',        // 领带、领结、围裙、镶边
  // 可选：glasses: 'round' | 'cateye'；moustache: true；skirt: dress 的长裙 / apron 的围裙布
},
```

### 2.1 造型规范

- **剪影优先**：同一场景里的角色，只看黑色剪影也要能分清。靠体型（`scale`、`lean`）、帽子和服装款式区分，而不是靠颜色。
- **三色原则**：每个角色一个主色（外套）、一个辅色（裤/裙）、一个点缀（`accent`）。点缀色从色板里取。
- **职业一眼可读**：警长戴头盔（`helmet`），司机戴鸭舌帽（`peaked`），厨子系围裙（`apron`），售票员戴猫眼镜（`cateye`）。
- 主角伊莱（`eli`）的孔雀蓝外套是主角专属色，其他角色不要用相近的颜色做外套。
- 配色给出三档：`coat`（基础）、`coatShade`（约暗 30%）、`coatLight`（约亮 20%）。

### 2.2 扩展新部件

需要新发型或新帽子时：

1. 在 `Look` 类型的联合里加一个值。
2. 在 `Hair` / `Hat` 组件的 `switch` 里加一个 `case`，坐标以头部中心为原点。
3. 高帽子（会超出头像裁切框的）加进 `TALL_HATS`，头像裁切会自动放大。
4. 用两个以上角色穿上它截图检查，确认它是「部件」而不是某个人专属。

## 3. 比例与骨骼常量

| 常量 | 值 | 含义 |
|---|---|---|
| 骨骼身高 | ~192 | 头顶到脚底 |
| `FIGURE_SCALE` | 0.8 | 行走场景中的缩放，成年人 ≈ 154 世界单位 |
| `THIGH` / `SHIN` | 44 / 44 | 大腿 / 小腿 |
| `SHOULDER` | −152 | 肩高（脚底为 0） |
| `UPPER` / `FORE` | 30 / 28 | 上臂 / 前臂 |
| `STRIDE` | 152 | 一个完整步态周期走过的距离 |

改这些常量会影响全部角色，非必要不动。

## 4. 动作

### 4.1 行走：相位跟着距离走

步态相位 = 已走距离 ÷ (`STRIDE` × `scale`) × 2π。**相位来自距离，不来自时间**，所以不管帧率多少、走得多快，脚都不会在地上打滑。场景层把角色走过的距离通过 `travel` ref 传给 `Rig`。

### 4.2 状态混合

`walk`（站→走）和 `duel`（站→对决姿态）都是 0–1 的混合量，用 `approach()` 平滑过渡，不会突变。

### 4.3 动作包络

由 `action = { kind: 'throw' | 'hit', id }` 触发，`id` 变化即重播：

| 动作 | 时长 | 分段 |
|---|---|---|
| 甩牌 `throw` | ~0.67 秒 | 蓄力 0.12 秒 → 甩出 0.1 秒 → 收势 0.45 秒 |
| 受击 `hit` | 0.55 秒 | 后仰后恢复 |

待机：呼吸（约 1.75 rad/s 的正弦）和随机间隔的眨眼。每个角色有 `phaseOffset`，同屏多人不会同步呼吸。

### 4.4 新动作的规则

- 用包络函数（时间 → 0–1 的权重），叠加在现有姿态上，不要替换整套姿态。
- 每段写清时长常量和注释，像现有的 `// Throw: wind 0.12s, snap 0.1s, settle 0.45s.`。
- 减少动态效果模式下：循环动作（呼吸、步态）停在中立位；一次性动作可以保留但缩短。
- 动作是表现层，**不能影响规则时序**。对决里伤害发生在规则 tick 上，动画只是追上去播。

## 5. 使用角色

| 场合 | 用法 |
|---|---|
| 行走场景 | `StageScene` 自动按热点画出 NPC（`kind: 'npc'` + `character`） |
| 对话头像 | `<Figure character="juno" crop="head" height={64} />` |
| 对决两侧 | `<Figure character=… crop="full" stance="duel" action={…} />` |
| 半身像 | `crop="bust"` |

## 6. 加一个新角色：步骤

1. `adventure-types.ts`：`CharacterId` 联合里加 id。
2. 内容模块的 `*_CAST` 里加 `{ name, role }`。`role` 是一行身份描述，带一点幽默：「司机斯坦 · 城际巴士司机 · 厕所鉴赏家」。
3. `rig.tsx`：`RigId` 里加 id，`LOOKS` 里加造型。**测试会检查每个说话的角色都有骨骼。**
4. 地图上放热点：`{ id, x, label, kind: 'npc', character }`，需要按剧情出现/消失就加 `when`。
5. 截图：行走场景（和相邻角色比剪影）、对话头像（帽子是否被裁）、对决全身。
6. 如果是对手：对手档案 `DossierPanel` 的 `ORDER` 和 `GOSSIP` 里加一条。
