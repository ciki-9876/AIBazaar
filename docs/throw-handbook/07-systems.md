# 07 · 养成与经济系统

2026-10-12 当前规则：对决 v16 / 冒险 v10。第四幕、26件本体字段改装、金级同款材料且不限数量、自动出牌、三人独立配置见[ADR-0064](../design-log/decisions/ADR-0064-throw-millbrook-upgrades-and-autoplay.md)、[第四幕内容](../F9_THROW_MILLBROOK_2026-10-12.md)与[实测记录](../design-log/iterations/F9/2026-10-12-throw-millbrook-upgrades-and-autoplay.md)。下文此前版本的机制及证据有冲突时按本修订为准；历史结果不重写。


第二幕引入了四个系统：演出费、霍布斯旧货铺、街头演出、对手档案；外加冒险存档。这一章讲它们的设计原则和改法。

## 1. 三条原则

1. **钱买东西、机会和状态；时间买成长。** 演出费换道具、遗物、变种、情报、住处和伙食；每一件都是一个选择，而不是「伤害 +10%」。住处和心情给气场的百分比加成是**状态**：每周付钱维持，停付就掉，合计上限 +18%。气场的永久部分（底子、名气）和台龄只能花时段去挣。（2026-10-10 由「钱买选择，不买数值」改写，见 [ADR-0059](../design-log/decisions/ADR-0059-throw-growth-intel-rewards-cities.md)。）
2. **习惯靠观察，正式赛配置靠情报。** 当前已实现：练习场全公开；街头演出部分迷雾；正式演出通过看报、打听、观摩、后台逐项揭开配置。对手档案另记玩家亲眼见过的花色、牌型和战绩。八卦写「怎么打他」，不要把未经确认的配置当作事实。第三章对手也会按玩家公开出牌倾向准备。
3. **所有交易都是原子的。** 钱不够、已拥有、未上架——任何一种失败都不改变任何状态。

## 2. 演出费（fee）

- 存在 `AdventureState.fee`，只能通过 `grant()` 增加、`buyOffer()` / `pay` 选项减少。
- 来源：每场对决的**首胜**奖励、一次性支线奖励；第二幕街头演出另有每场每周一次的 £3 复演费。普通复赛不再发首胜奖励。
- 预算：第二幕一周目可得约 **260**，商店全部货品约 **580**。玩家只能买下不到一半——**买什么就是构筑选择**。新的一幕也按这个比例（收入 ≈ 货架总价的 40–50%）设计。
- 定价锚点：

| 货品 | 价格 |
|---|---|
| 稀有变种 | 12–15 |
| 1 格道具 | 18 |
| 2 格道具 | 20–25 |
| 3 格道具 | 26–28 |
| 遗物 | 30–40 |
| 史诗变种 | 35 |

界面上演出费统一用 `<Fee value={…} />`（`adventure-panels.tsx`）显示，带 £ 符号。

## 3. 商店

```ts
{ id: 'cinder', kind: 'item', ref: 'cinder', price: 20, note: '罗茜换新炉子以后扔掉的。还能用，太能用了。', stocked: after('rosie') },
{ id: 'v-gold', kind: 'variant', ref: '2-12:gold', price: 35, note: '♣Q · 镀金。…', stocked: (s) => s.flags.mainHall },
```

- `kind`：`item` / `relic` / `variant`。变种的 `ref` 是 `'{花色}-{点数}:{附魔id}'`，花色 0♠ 1♥ 2♣ 3♦，点数 2–14。
- `stocked(state)`：上架条件。**「赢了谁，就有谁的货」**——打败青苔派的艾格尼丝之后，毒流道具上架。这让每场胜利都打开新的构筑方向。
- `note`：店主的一句话，用店主的声音写（见文案指南）。
- 买下的道具进入巡演箱，变种进入牌匣；第一、二幕已拥有的不可重复买；第三幕起允许重复购买道具作为同款改装材料，原件独占身份不改变。
- 引擎函数：`shopFor(state)` 取本城货架，再由 `offerStocked`、`offerOwned`、`buyOffer` 执行原子交易。第三章工坊货架不能直接复用第二章全部库存。

商店展示按 `kind` 分成「道具」「遗物」「变种」标签页；每个商品都显示自己的 `price`，不能只在购买按钮显示价格。切换标签只筛选展示，不改变库存、拥有状态或演出费。手机布局与空货架状态也需要检查。

## 4. 街头演出（带规矩的对决）

每场演出 = 一条 `ShowDefinition`（标题、规矩文字、简介）+ 一条 `BattleDefinition`（id 为 `show-<id>`，带 `terms` 或 `kit`）。

| 规矩类型 | 实现 | 例子 |
|---|---|---|
| 花色限制 | `terms.suits` | （试过「只出红牌」，因手牌被黑牌堵死而不可赢，已撤下） |
| 张数限制 | `terms.minCards` / `maxCards` | 两张起甩、一张就够 |
| 血线 | `terms.hpFloor` | 别让茶凉：气场跌破一半即失败。数值按 320 写，开局时按上台者的气场上限等比缩放 |
| 时限 | `terms.deadlineMs` | 速战速决：64 秒内获胜 |
| 指定巡演箱 | `kit.only` | 借来的箱子 |
| 禁止家族 | `kit.banFamilies` | 无盾之夜 |

设计新规矩时：

- 规矩必须**能被界面清楚表达**：违规时按钮置灰并写明原因，而不是出牌后才失败。
- 跑模拟：常见巡演箱下胜率应在 **50–100%** 之间，至少一种巡演箱 ≥ 80%。低于这个就是谜题而不是演出。例：时限 45 秒胜率 0%，70 秒 98%，最终定 64 秒。
- 规矩文字照「规则先说清楚」：`每次至少甩 2 张牌。`，笑话写在 `blurb`。

## 5. 对手档案

- 每场对决结束后，引擎根据规则层的 `tally`（对手每种花色、每种牌型甩了多少）更新 `state.dossier[opponent]`。
- 只记录：交手次数、胜负、花色比例、最常出的牌型，外加一条 `GOSSIP` 八卦。
- 里德的教学局不记。
- 新对手：在 `GOSSIP` 里加一句八卦，在 `DossierPanel` 的 `ORDER` 里加 id。
- 八卦的写法：一两句**可执行的情报**——他靠什么赢、怕什么——最多带半句笑话。例（派克）：「盾厚，铜镜反射大牌。单张削盾且不被反射，剧毒直接穿盾。」；不重要的人可以只是个笑话（斯坦）：「他从没赢过。也从没真正想赢。」

## 6. 存档

- 自动保存在 `localStorage`，键 `aibazaar.throw.adventure`；读写都在 `magician-adventure.tsx`。
- 新增系统字段时（比如第三幕的「声望」）：
  1. 加到 `AdventureState`，在 `createAdventure` 初始化；
  2. 在 `restoreAdventure` 里校验类型和范围；
  3. 升 `ADVENTURE_VERSION`，写旧版本迁移（缺字段补默认值）；
  4. 测试：新存档往返、旧存档迁移、篡改过的存档被拒绝。
- 不要在存档里放可以推导出来的东西（比如「已赢场数」可以从 `won` 推出）。

当前冒险版本为 **v8**，支持 v3 → v4 → v5 → v6 → v7 → v8 迁移链：旧 `order` 整理遗物移除引用，默认整理仍可用；v7 的 `backpackGuided` 保留。v8 新增 `pendingReward`、`noraSeries`、`itemUpgrades`、`homeReturn`、`publicStyle` 及第三章旗标；旧档的新字段补空值，原财产、胜场、剧团和时钟不重置。v7 已在战斗后支付的奖励不能推断为 v8 待领物，否则读档会重发。新 pending 收据必须对应正在播放的结果对白、真实物品与实际配置的奖励金额；重复已领首胜或篡改金额会拒绝恢复。

## 7. 新系统的检查问题

上线一个新系统之前，回答：

1. 它给玩家**新的选择**，还是只给更大的数字？（后者不做）
2. 它从哪一幕开始？第一次出现时谁来介绍？（每个系统都要有一个 NPC 用一段对话介绍它）
3. 它的状态存在哪里？要不要升存档版本？
4. 失败分支是否原子？
5. 界面在手机上放得下吗？

## 7. 剧团、好感与招募（v5）

见 [ADR-0057](../design-log/decisions/ADR-0057-throw-troupe-gauntlet-identity.md) 与[设计文档](../F9_THROW_TROUPE_GAUNTLET_2026-10-10.md)。

**当前开放时机已修订**：朱诺仍在第二章决赛获胜对白结束后加入并说明剧团；到第三章后才开放剧团管理、成员上场与酒馆招募。`troupeUnlocked` 同时看引导完成和到过第三章；回访第一、二章不会重新锁定。旧档里已有的斯坦、罗茜、朱诺不会被删除。

- **状态**：存档里有三个新字段。
  - `troupe`：伊莱永远排第一；
  - `affinity`：每人 0–100；
  - `bonds`：已经用掉的一次性好感时刻。
- **三种招募**：每个可招募的人都写进 `RECRUITS`（`bridgeport.ts`），包括招募方式和提示语。

  | 方式 | 怎么写 |
  |---|---|
  | 剧情 | 在剧情对白的 `effect` 里写 `recruit` |
  | 酒馆 | 告示板打开独立招募看板，展示角色/条件并执行现有原子招募；不只靠长对话选项 |
  | 好感 | 满了 `threshold`，对话路由就切到邀请对话 |

- **好感来源**：
  - 对白效果 `affinity: { who, amount, id }`：`id` 写进 `bonds`，同一个时刻只算一次。新的 `id` 要加到 `BOND_IDS`，存档校验靠它。
  - 战斗奖励 `reward.affinity`：和演出费一样，只在首胜时给。
- **不加数值**：好感只解锁内容，不提供战斗加成（ADR-0057 决定 4）。
- **成员上场**：解锁剧团后，街头演出可派愿意上场且有床位的成员；普通剧情对决和借来的巡演箱只能伊莱上。地铁双人赛是明确的双人例外。成员带自己的专属牌匣（`memberBook`）；伊莱已获得的变种从原主人的可用牌匣移除，例如朱诺交出的 ♠J。
- **莫莉**：第三章三首点歌首胜各 +20 好感，满 60 后另行邀请；完成邀请对白才加入，每周工资 £5，自带治疗天赋、主动手法与薄荷牌。
- **存档**：v4 的存档迁移后，剧团只有伊莱，没有好感。名册里没有伊莱、有不认识的角色、有重复，好感越界，或者出现未知的 `bonds`，整份存档都拒绝。

## 8. 气场、日程、住处与伙食、情报（v6）

见 [ADR-0059](../design-log/decisions/ADR-0059-throw-growth-intel-rewards-cities.md) 与[设计文档](../F9_THROW_GROWTH_INTEL_REWARDS_2026-10-10.md)。规则在 `magician-world.ts`；当前内容来自 `bridgeport.ts`、`westport.ts`、`lodgings.ts`，不能再把第二章 `LODGINGS` 当作所有城市通用清单。

- **气场** = (280 + 5 ×（台龄等级 − 1）+ 名气) × (1 + 住处% + 心情%)，四舍五入（`presenceBreakdown`）。
  - 台龄：上台一场 +1；首胜再加（正式 +2，城市强敌 +5，街头 +1）；排练 +2。等级门槛 5 × n(n−1)/2，上限 20 级。
  - 名气：首胜时加 `BattleDefinition.fame`；初始 40（320 = 280 + 40）。
  - 对手的气场写在 `BattleDefinition.presence`，不写就是 320。城市强敌按「玩家离开时的气场 × 1.1」。
  - 新成员入团时，台龄不低于「伊莱的等级 − 3」（`joinTroupe`）。
- **时钟**（第二幕起）：一天三个时段。对决、看报、打听、喝茶、排练、帮房东干活、「歇一会」各用一个时段；说话、走路、买东西不花时间。主线比赛没有日期限制。
- **周日结账**（`settleWeek`）：按顺序扣房租、伙食、薪水，然后结算心情；结果写进 `notice`，回到街上时弹出。钱不够时：房租记欠，伙食自动降档，薪水欠给排在后面的人。
- **欠租三步**：警告 → 排练室上锁、全员心情 −1 → 搬回斯坦的巴士。**永远不会失去成员、道具或进度**。
- **心情**五档，伊莱最低「低落」。罢演的人不能上台；再降就「回家吃几顿」，离团一周，回来时心情平常，带一罐果酱（`keepsakes`）。
- **情报**：练习场全公开；街头演出看得见打法和 ≥2 格的道具；`formal: true` 的对决全迷雾。来源：看报（上午）、酒馆（晚上）、观摩（晚上）、后台打点（主厅开放后）。传闻的真假写在 `RUMOURS` 里，`intel.test.mjs` 会对照真实配置检查。对决结束后全部确认，假传闻进 `debunked`，第一次被骗时多德太太出面解释，周日报纸登更正启事。
- **加新城市时**：写 `LODGINGS`（价格按这座城市的收入尺度，标准档约占每周收入 15%）、新成员的 `wage` 和 `stage`、正式对决的 `formal` / `fame` / `presence`、每个正式对手至少一条报纸传闻和一条酒馆传闻。
- **存档 v6**：新字段都在 `validLife` 里逐项校验；v5 存档按已赢的对决补算台龄和名气，住处从巴士开始。

## 9. 背包入口与统一收获（v7）

见 [ADR-0060](../design-log/decisions/ADR-0060-throw-quick-draw-and-readable-progress.md)。

- 背包从第一章真正结束后开放，条件为 `flags.departed || act > 1`；直接选择第二章同样开放。它统一管理卡牌、道具、遗物、布阵，复用现有合法牌匣和十格巡演箱规则。
- 短引导在下一次可探索且其他弹窗关闭时出现，可完成或跳过；`acknowledgeBackpack` 以 `backpackGuided` 持久化一次性阅读，不在初次资格赛获胜就提前开放。
- 收获由 `adventureGains(before, after)` 生成，物品/遗物取有效拥有列表的新增，卡牌取已拥有变种新增，普通收入取实际正增量。失败操作、重复给予已有物、读入旧存档不弹虚假收获。
- **v8 领取时机**：战斗结束只记录待发收据，获奖对白完整结束时才原子发放并生成收获弹窗；购买与普通支线仍在实际交付动作后显示。刷新页面保留未读对白与待领物；不能提前弹窗，也不能关弹窗时再授一次。对决消耗时段，因此遇到周日先结当时账单，尚未交付的战利品不先记进余额。
- 一次交易内的道具、遗物、变种和钱合成一份独立弹窗；连续交易排队。资产已在规则中落账，点击确认只是关闭，不能再次调用 `grant`。
- `progression-feedback.test.mjs` 与 `westport.test.mjs` 覆盖章结束门槛、旧档补齐、奖励类型/时机/重复、商店收据、周日结算和招募失败原子性；浏览器须走通战报 → 获奖对白 → 收获 → 后续引导。

## 10. 第三章实体剧团、改装与接力（v8 / 对决 v13）

`lodgingsFor(state)` 仅返回本城清单。每城都有可进入的剧团住所，巴士也能进入；室内伙伴来自真实名册，离家成员不出现，团务桌打开同一套管理面板。巴士驾驶席可回访三座已开放城市；换城市时住处回到当地免费巴士泊位，不会丢伙伴、财物或时钟。

| 城市 | 住处阶梯（周租） | 主要区别 |
|---|---|---|
| 格雷维克 | 巴士 0 / 里德工坊阁楼 4 / 抒情剧院后台 9 | 床位 2/3/5，气场 0/2/5%；有茶歇与排练加成 |
| 布里奇波特 | 巴士 0 / 醉鹅阁楼 6 / 寄宿房 12 / 剧院套间 20 | 床位 2/3/5/7，气场 0/3/6/10%；高级房排练额外 1/2 台龄 |
| 韦斯特港 | 巴士 0 / 旧灯塔看守屋 5 / 盐风晒网阁 8 / 六码头排练仓 18 / 广播塔驻演公寓 30 | 床位 2/3/4/6/8，气场 0/2/3/6/10%；排练额外 1/2 台龄，顶档茶歇额外恢复 2 档心情 |

`recovery`、`rehearsalBonus` 是实际规则字段，说明文字必须与其相符。房间价格、床位与总收益同城逐级增加；这种定价目前是设计值，未被整章真人经济数据校准。

海风工坊提供九类实际可升级道具：飞牌修缮箱、双响茶壶、织序风扇、四色灯笼、星光放映机、补丁旧伞、守灯小毯、回暖小灯、焰纹放映机。银级 £12，金级另付 £28 且先有银级；分别给该道具基础直伤/产盾/治疗 +15% / +30%，向下取整后再应用已有相邻等修饰。最多两件金级；冷却、概率、剧毒/灼烧层数和其它工具数值不借此提升。`upgradeItem` 只允许第三章工坊、真实拥有且白名单中的道具，失败不扣钱。当前是两个等级，不是旧提案里的银级二选一分支与金级特殊条款全量实装。

地铁 `wp-relay` 是独立双人赛：伊莱首发，默认一名有床位、未离家且愿意出场的真实伙伴接力；敌方基特首发、维尔接力。规则通过 `DuelReserve` 传替补，伙伴保留各自身份与牌匣。击倒一人会在同一场对决切换，不重开对决时钟，存活一侧保留气场/护盾/状态/手牌，整队退场才结胜负。它不回填已撤回的第二章姐妹强制失败教程。

反情报只使用公开数据：`playerSuits` / `playerKinds` 决定 `publicStyle`，联赛侦察局按该分类选择配置；广播假消息改变诺拉第二局准备。它没有读玩家未公开的即时布阵。诺拉公开的第一局笔记始终诚实，`noraSeries` 持久化局数，先拿两胜结束；结果和奖励仍走正常收据。此版本没有实现后续城市、自由编辑假消息或任意人数团队赛。


## 11. v9：管家租住与一次免费借住

住处入口和租金说明要落在实际建筑中。玩家可以先看房，访问不会更换租约，也不能获得未租房的收益。找到屋内管家，读完明确首付及周租说明后选择确认，才原子支付首周并退掉旧租约；旧房已付租金不退，不能同时保留两套收益。巴士也是可进入且有管家登记的免费兜底，原有搬回巴士清欠规则保留。

旧灯塔看守屋正常周租 £5、3 位伙伴床位、气场 +2%，不含排练加成。第三幕第一次接钥匙是朱诺朋友提供的一次免费借住，入住期间周租为 £0；离开这处根据地或换城市结束优惠，再租必须付正常 £5。`westLoanUsed` 保存权益已使用，`westLoanActive` 表示当前免租，`westHomeGuided` 控制先安家再报名。换房失败与拒绝确认不消耗这份人情。`lodgingOf` 返回真实生效费用，面板与周结算不能仍把免费期写成 £5。

冒险版本为 `magician-adventure-v9`；新增 `viewedLodging` 与三个旗标。v8 已报名第三章的旧档保持原租约、费用、伙伴和剧情，免于补走新引导；尚未报名的旧档获得新的安家目标。v3–v7 仍按既有链迁移。对照测试覆盖第三章前置、重复免费、全部 12 处住所/巴士租入、看房/租约身份隔离、迁移与失败原子性。

## 12. 双人赛独立备战（对决 v15）

`wp-relay` 仍要求伊莱和一名真实就绪伙伴，但伙伴预设只作为默认分配建议，不能提供公共池之外的道具。备战可切换两人分别编辑箱子/遗物/牌匣；每份有自己的 10 格，已有收藏独占分配，无全队共用格数。入场按这两份实际配置构造首发与替补，改装只作用于各自携带的物件。牌池含公共收藏和该队员实际自带且未移交的变种，白牌始终可用。

`PreparedThrowLoadout.members[performer]` 是 v9 保存 envelope 的可选元数据；旧的单箱对象继续有效，角色 ID、格位、遗物和牌匣逐项校验。离开/重试对局保存两份配置，后续同一伙伴再上场沿用；启动先按实际拥有池收敛并校验当前两人的独占分配。仅打开第二棒页或牌匣不得改动首发。真实替补资格继续由剧团状态决定，保存配置不能招募未加入的人。
