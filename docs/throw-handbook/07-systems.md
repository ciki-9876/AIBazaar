# 07 · 养成与经济系统

第二幕引入了四个系统：演出费、霍布斯旧货铺、街头演出、对手档案；外加冒险存档。这一章讲它们的设计原则和改法。

## 1. 三条原则

1. **钱买东西、机会和状态；时间买成长。** 演出费换道具、遗物、变种、情报、住处和伙食；每一件都是一个选择，而不是「伤害 +10%」。住处和心情给气场的百分比加成是**状态**：每周付钱维持，停付就掉，合计上限 +18%。气场的永久部分（底子、名气）和台龄只能花时段去挣。（2026-10-10 由「钱买选择，不买数值」改写，见 [ADR-0059](../design-log/decisions/ADR-0059-throw-growth-intel-rewards-cities.md)。）
2. **配置公开，习惯靠观察。** 整备界面的「敌人预览」公开对手的巡演箱、遗物、牌匣变种和规矩；对手档案只记录玩家亲眼见过的打法（甩了哪些花色、什么牌型、交手战绩）。八卦写「怎么打他」，不要重复配置。见 [ADR-0054](../design-log/decisions/ADR-0054-throw-scouting-and-onboarding-polish.md)。**规划中**（[ADR-0059](../design-log/decisions/ADR-0059-throw-growth-intel-rewards-cities.md)，未实装）：只有练习场全公开；街头演出部分迷雾；正式演出靠情报逐项揭开。
3. **所有交易都是原子的。** 钱不够、已拥有、未上架——任何一种失败都不改变任何状态。

## 2. 演出费（fee）

- 存在 `AdventureState.fee`，只能通过 `grant()` 增加、`buyOffer()` / `pay` 选项减少。
- 来源：每场对决的**首胜**奖励、一次性支线奖励。重打不给钱，所以不存在刷钱。
- 预算：第二幕一周目可得约 **260**，商店全部货品约 **580**。玩家只能买下不到一半——**买什么就是构筑选择**。新的一幕也按这个比例（收入 ≈ 货架总价的 40–50%）设计。
- 定价锚点：

| 货品 | 价格 |
|---|---|
| 稀有变种 | 12–15 |
| 1 格道具 | 18 |
| 2 格道具 | 20–25 |
| 3 格道具 | 26–28 |
| 遗物 | 30–40 |
| 史诗变种 | 35 |

界面上演出费统一用 `<Fee value={…} />`（`adventure-panels.tsx`）显示，带 £ 符号。

## 3. 商店

```ts
{ id: 'cinder', kind: 'item', ref: 'cinder', price: 20, note: '罗茜换新炉子以后扔掉的。还能用，太能用了。', stocked: after('rosie') },
{ id: 'v-gold', kind: 'variant', ref: '2-12:gold', price: 35, note: '♣Q · 镀金。…', stocked: (s) => s.flags.mainHall },
```

- `kind`：`item` / `relic` / `variant`。变种的 `ref` 是 `'{花色}-{点数}:{附魔id}'`，花色 0♠ 1♥ 2♣ 3♦，点数 2–14。
- `stocked(state)`：上架条件。**「赢了谁，就有谁的货」**——打败青苔派的艾格尼丝之后，毒流道具上架。这让每场胜利都打开新的构筑方向。
- `note`：店主的一句话，用店主的声音写（见文案指南）。
- 买下的道具进入巡演箱，变种进入牌匣；已拥有的显示「已拥有」，不能重复买。
- 引擎函数：`offerStocked`、`offerOwned`、`buyOffer`（原子）。

商店展示按 `kind` 分成「道具」「遗物」「变种」标签页；每个商品都显示自己的 `price`，不能只在购买按钮显示价格。切换标签只筛选展示，不改变库存、拥有状态或演出费。手机布局与空货架状态也需要检查。

## 4. 街头演出（带规矩的对决）

每场演出 = 一条 `ShowDefinition`（标题、规矩文字、简介）+ 一条 `BattleDefinition`（id 为 `show-<id>`，带 `terms` 或 `kit`）。

| 规矩类型 | 实现 | 例子 |
|---|---|---|
| 花色限制 | `terms.suits` | （试过「只出红牌」，因手牌被黑牌堵死而不可赢，已撤下） |
| 张数限制 | `terms.minCards` / `maxCards` | 两张起甩、一张就够 |
| 血线 | `terms.hpFloor` | 别让茶凉：生命跌破 160 即失败 |
| 时限 | `terms.deadlineMs` | 速战速决：64 秒内获胜 |
| 指定巡演箱 | `kit.only` | 借来的箱子 |
| 禁止家族 | `kit.banFamilies` | 无盾之夜 |

设计新规矩时：

- 规矩必须**能被界面清楚表达**：违规时按钮置灰并写明原因，而不是出牌后才失败。
- 跑模拟：常见巡演箱下胜率应在 **50–100%** 之间，至少一种巡演箱 ≥ 80%。低于这个就是谜题而不是演出。例：时限 45 秒胜率 0%，70 秒 98%，最终定 64 秒。
- 规矩文字照「规则先说清楚」：`每次至少甩 2 张牌。`，笑话写在 `blurb`。

## 5. 对手档案

- 每场对决结束后，引擎根据规则层的 `tally`（对手每种花色、每种牌型甩了多少）更新 `state.dossier[opponent]`。
- 只记录：交手次数、胜负、花色比例、最常出的牌型，外加一条 `GOSSIP` 八卦。
- 里德的教学局不记。
- 新对手：在 `GOSSIP` 里加一句八卦，在 `DossierPanel` 的 `ORDER` 里加 id。
- 八卦的写法：一两句**可执行的情报**——他靠什么赢、怕什么——最多带半句笑话。例（派克）：「盾厚，铜镜反射大牌。单张削盾且不被反射，剧毒直接穿盾。」；不重要的人可以只是个笑话（斯坦）：「他从没赢过。也从没真正想赢。」

## 6. 存档

- 自动保存在 `localStorage`，键 `aibazaar.throw.adventure`；读写都在 `magician-adventure.tsx`。
- 新增系统字段时（比如第三幕的「声望」）：
  1. 加到 `AdventureState`，在 `createAdventure` 初始化；
  2. 在 `restoreAdventure` 里校验类型和范围；
  3. 升 `ADVENTURE_VERSION`，写旧版本迁移（缺字段补默认值）；
  4. 测试：新存档往返、旧存档迁移、篡改过的存档被拒绝。
- 不要在存档里放可以推导出来的东西（比如「已赢场数」可以从 `won` 推出）。

当前冒险版本为 v4，支持迁移 v3：旧 `order` 整理遗物移除引用，默认整理仍可用。对手档案的各花色／牌型计数、胜负和返场坐标都要逐项校验；不能只验最外层对象后就接受嵌套坏数据。

## 7. 新系统的检查问题

上线一个新系统之前，回答：

1. 它给玩家**新的选择**，还是只给更大的数字？（后者不做）
2. 它从哪一幕开始？第一次出现时谁来介绍？（每个系统都要有一个 NPC 用一段对话介绍它）
3. 它的状态存在哪里？要不要升存档版本？
4. 失败分支是否原子？
5. 界面在手机上放得下吗？

## 7. 剧团、好感与招募（v5）

见 [ADR-0057](../design-log/decisions/ADR-0057-throw-troupe-gauntlet-identity.md) 与[设计文档](../F9_THROW_TROUPE_GAUNTLET_2026-10-10.md)。

- **状态**：存档里有三个新字段。
  - `troupe`：伊莱永远排第一；
  - `affinity`：每人 0–100；
  - `bonds`：已经用掉的一次性好感时刻。
- **三种招募**：每个可招募的人都写进 `RECRUITS`（`bridgeport.ts`），包括招募方式和提示语。

  | 方式 | 怎么写 |
  |---|---|
  | 剧情 | 在剧情对白的 `effect` 里写 `recruit` |
  | 酒馆 | 告示板对话里用 `pay` 选项，再接一段带 `recruit` 的对话 |
  | 好感 | 满了 `threshold`，对话路由就切到邀请对话 |

- **好感来源**：
  - 对白效果 `affinity: { who, amount, id }`：`id` 写进 `bonds`，同一个时刻只算一次。新的 `id` 要加到 `BOND_IDS`，存档校验靠它。
  - 战斗奖励 `reward.affinity`：和演出费一样，只在首胜时给。
- **不加数值**：好感只解锁内容，不提供战斗加成（ADR-0057 决定 4）。
- **成员上场**：街头演出时可以派任何成员上台；剧情对决和借来的巡演箱只能伊莱上。成员带自己的专属牌匣（`memberBook`）。伊莱已经拥有的变种，会从原主人的牌匣里去掉，比如朱诺交出的 ♠J。
- **存档**：v4 的存档迁移后，剧团只有伊莱，没有好感。名册里没有伊莱、有不认识的角色、有重复，好感越界，或者出现未知的 `bonds`，整份存档都拒绝。
