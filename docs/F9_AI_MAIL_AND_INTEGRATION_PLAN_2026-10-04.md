# F9 竞争者接入顺序与电梯邮件方案

日期：2026-10-04。已确认：用户接受上一轮开发顺序，要求记入项目；希望保留电梯内少量邮件对话，接受延迟和廉价模型，要求对话与行动状态一致，允许角色有意欺骗。以下状态结构、模型选择和实验范围为助手提案，邮件未实装，未下载模型或调用付费推理。

## 已确认的开发顺序

| 顺序 | 工作 | 交付要求 |
| --- | --- | --- |
| 1 | 统一正式游戏与 Demo 的行动执行 | 玩家和 AI 使用共同的移动、搜刮、伤害、物品、死亡和取票规则，避免维持两套战斗逻辑 |
| 2 | 接入通行证竞争 | 真实争抢终端、共同打守卫、补给与上楼取舍，执行器产生实际扣票和赛事结果 |
| 3 | 持续身份与关系记忆 | 同一个人跨返程、楼层保留资源与亲历事件，而非重新生成一名 NPC |
| 4 | 最小协商 | 补给请求、物资换票、共同打守卫的提议能够接受、拒绝和实际执行 |
| 5 | 下一版策略训练与验证 | 连续轨迹、人工复核与反事实测试，检查局势和关系能否改变选择 |

上一轮建议的正式游戏实验门槛是单名选手完成出门、争夺、返程和上楼；共享时钟、物品、票源、怪物、暂停规则；有限感知；过期决策与异常回复安全拒绝；可保存、回放。默认启用还需验证跨楼层及离屏行动的因果连续性、人物差异、合作或威慑对选择的影响、双端性能和恢复。

第三层节目揭晓至第十层首次审查、每次一名对手且可切换三类人物，是上一轮助手建议的切片范围。用户本轮明确认可的是推进顺序；完整切片细则仍待实现验证。邮件实验可以先于这段切片检验状态契约，但不表示其余步骤已完成。

## 当前实现证据

[首次遭遇 Demo](./F9_AI_ENCOUNTER_DEMO_2026-10-03.md)已用浏览器 Worker 中的 1,152 参数 MLP 选择合法行动，规则执行真实移动、搜刮、战斗、赠送和撤离。它是合成标签模仿模型，不是大语言模型；当前关系只有遭遇内的有限数值，没有持续承诺、结盟计划、自由邮件或跨层社交记忆。

主内容工作区另有百层竞速与共享票源接口；本 AI 工作区未合并该工作区的开发中改动。后续接入需先对齐内容版本和规则接口。不会在邮件中宣称原型不存在的交易、结盟或票据转移已经发生。

## 同一角色状态供两种模型使用

建议一个竞争者只拥有一份权威角色状态。实时策略模型与邮件语言模型按任务读取它的不同视图，向同一个更新入口提交提案；两个模型各自的上下文缓存均不具备状态权威。

| 状态 | 内容与用途 |
| --- | --- |
| 资源事实 | 自己的真实背包、票、精神状态、楼层；仍由规则执行器管理 |
| 有限认知 | 亲眼见到的事件、公开广播、收到的信件；玩家说法作为带来源的信念，不自动成为世界事实 |
| 人格与关系经历 | 价值排序、援助、攻击、履约与违约证据；记忆摘要不是唯一原始记录 |
| 真实计划 | 当前目标、合作或敌对意图、期限、改变计划的条件和修订号 |
| 公开约定 | 双方、目标、交换条款、条件、有效范围及提议／接受／履行／违约等状态；口头结盟不会自动产生强制免伤规则 |
| 发言与邮件 | 角色向玩家说过什么、发送和送达的模拟 tick、对应条款和事件引用 |
| 隐藏欺骗计划 | 角色有意误导谁、公开说法与真实意图的差别、预期收益及执行条件；仅调试端可见 |

邮件可使角色重新考虑合作：语言模型理解条件并提出接受、拒绝、还价、变更计划或欺骗。程序核验信息来源、行为能力、资源和状态版本，原子提交合法提案，再交给行动模型执行。因此对话能改变行动，且不会形成两个独立人格。

持续行动模型必须增加计划、约定、相关记忆和新行动候选的输入并重新验证；当前小网络不能仅靠附上一封信就理解结盟。通常按已接受的计划行动；新的危险、利益或证据可以触发改变计划，并留下真实事件。安全避险可先响应，不能把每帧重新评分造成的摇摆包装为人物反转。

## 回信产生与提交

1. 玩家在电梯写信，记录收件人、消息 ID、赛季、角色已知上下文和相关状态修订号。玩家文字是角色发言，不是修改模型权限或赛事规则的指令。
2. 异步模型返回结构化沟通意图、明确条款、计划变更提案、选择披露的信息及短正文。无须等待每帧决策，不向模型提供他人隐藏背包或全场权威状态。
3. 邮件提交入口读取最新相关状态，核验条款和能力；先提交计划／约定与发言记录，再将对应回信送入信箱。状态提交与邮件入箱应原子、幂等，重试不重复结盟、转移物品或送信。
4. 等待中角色死亡、淘汰、目标消失或相关计划变更时，拒绝过期变更并重新生成、改为有依据的撤回消息或保留等待状态。无关世界 tick 推进不自动使全部回复失效。
5. 同一角色的相关计划更新有明确提交次序。记录模型版本、输入快照、提案、应用 tick 与回执，回放使用已记录结果，不重新调用模型猜测旧决定。

推理等待使用适配层现实时间，游戏结果使用显式模拟 tick。等待回复不额外扣某一方资格时间；电梯界面是否暂停沿用正式游戏的共同暂停规则，不另造邮件专属竞速规则。玩家离开邮件界面后可继续等待、之后在电梯查收。

自然语言仅靠提示词不能保证永远无矛盾。建议第一版把结盟、交易、地点、数量、期限、接受／拒绝等重要陈述限制为结构化沟通内容，由程序渲染关键句和条款。模型保留措辞、情绪、议价与非关键表达自由；检测到与沟通意图冲突的正文时重生成，持续失败则用同一已批准沟通意图的确定性短句，不能用默认策略代替角色作决定。更开放的正文语义一致性仍需人工评测，不宣称形式保证。

## 欺骗与矛盾的区别

真诚合作时，真实计划为共同取得资源，公开约定指向同一目标，邮件可以承诺协作，行动模型据此前往和配合。条件发生变化后可以重新决定，变更须有记录和实际后果。

有意欺骗时，角色先产生“假意合作、让玩家吸引守卫、自己抢先登记”的隐藏意图，公开邮件答应合作；条件满足后执行预定抢先行动，约定记录变为违约。欺骗是同一状态中明确存在的真实计划与公开说法差异，不能在两个模型偶然冲突后补写“他其实在撒谎”来掩盖错误。

不预写每个人必须背叛或固定背叛率。也不能让所有真假承诺有不同的公开样式，向玩家直接泄露结果。真实状态只对开发调试可见，玩家通过行动与履约情况判断可信度。

## 廉价模型候选

截至 2026-10-04 核对官方资料，以下只是候选，尚未测试 F9 中文人设、协议输出、复杂条款或本机速度。

- 本地候选 Qwen3-4B-Instruct-2507：官方提供 4B 非思考指令模型与 Apache 2.0 许可。可测试量化运行，推理不产生服务商按次 API 费；不代表电力、硬件、服务器或浏览器分发成本为零，也不代表普通浏览器都能运行。[官方模型卡](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507)。
- 免费云端实验候选 Gemini 2.5 Flash-Lite：官方列有免费层，付费标准文本输入每百万 token 0.10 美元、输出 0.40 美元。免费层受项目／模型额度等限制，不能承诺无限免费发行；可用性、延迟与具体账户额度待实测。[官方价格](https://ai.google.dev/gemini-api/docs/pricing)、[额度说明](https://ai.google.dev/gemini-api/docs/rate-limits)。
- 低价云端候选 DeepSeek Flash：官方当前输入未命中缓存每百万 token 0.15／0.30 美元、输出 0.60／1.20 美元，对应非高峰／高峰；支持 JSON 和工具调用。选择非思考短输出可作为邮件实验候选，实际质量和 token 用量待测。[官方价格与模式](https://api-docs.deepseek.com/quick_start/pricing/)。

建议先选一个廉价云端或本地服务完成同一状态契约的对照实验，供应商做可替换适配；不先为邮件微调模型。网页使用开发后端／正式代理，服务密钥不放浏览器。Windows 可连接本地模型服务；双端共享协议，但不宣称所有玩家硬件都能离线运行生成模型。

压缩成本的方法是只在收到邮件或确有必要联系玩家时生成，检索相关事件而非附上完整日志，限制短邮件输出并记录真实 token。模型不可用时保留待回复，不生成未经批准的联盟或交易。购买、部署和付费调用尚未授权执行。

## 首次邮件实验验收

建议一名竞争者、同一真实遭遇状态，加电梯内邮件界面、自由输入短信和关键条款。先覆盖求水、共同打守卫、拒绝或还价，以及假意合作四类交涉。邮件承诺只引用已实现行动；新行动需要先接入执行器。

检查真诚接受后行动配合、拒绝后不会突然履约、明确欺骗后行动实现隐藏计划；等待期间计划改变不会送达过期接受；重复提交不产生重复资源或约定；未知信息不会被写为事实；保存恢复和回放保留同样关系、承诺与邮件；不同模型适配不会改变权威状态规则。

固定危险、物资、关系后，改变玩家提议应可能改变选择；改变自身利益后，三类人物也应能改变立场。接口测试证明一致性，连续试玩和人工审核证明博弈体验；两类证据不能互相替代。
