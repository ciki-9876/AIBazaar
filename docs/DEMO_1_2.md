# 电梯房间、成长节奏与在途弹道

## 首页与入口

以全屏电梯房间为首页：密闭金属墙、顶灯、门、床、桌面和终端。开局醒来对白也发生在同一个空间。物件具备文字标签、键盘焦点和明确的点击入口。

- 桌面：行装、免费鉴定、构筑；Lv.2 后增加培养与分解。
- 门：选择楼层；每日出勤已用仍能查看路线，但不能再次出发。
- 床：展示恢复与配额代价后睡眠；提示未出勤时将放弃当天机会。
- 终端：顶部切换电梯改造、幸存者榜、旅程日志、下一次出发。
- 右上角：当前阶段可理解的资源；材料在 Lv.1 只随升级、交易等具体用途展示。
- 左上角设置：最高记录、重开、指南、导入导出、设计档案和旧版入口。

## 资源循环与开放节奏

| 电梯等级 | 新内容 | 玩家此时需要理解的循环 |
| --- | --- | --- |
| Lv.1 | 配额、精力、补给；基础免费鉴定与构筑 | 补给支撑出勤和睡眠，带回实体免费鉴定。材料用于电梯升级和交易，先在相关界面解释。 |
| Lv.2 | 材料常驻显示、药品、废料；医疗站、回收台；卡牌培养与分解 | 多余物品分解为材料，废料回收为材料，材料投入构筑；药品恢复精力。 |
| Lv.3 | 电力、燃料；发电机、设备台、储藏架；便携鉴定 | 废料制燃料，燃料发电，电力和材料制作鉴定电荷。免费仪器送入仓库，必须主动装包才能带入楼层。 |
| Lv.4 | 种植架、天气观测 | 材料和电力转成补给；免费观测下一天天气，改善路线选择。 |
| Lv.5 | 地形准备；再次扩容 | 材料和电力换探索效率，为特定路线做准备。 |
| Lv.6 | 完整战斗布局 | 在完整九格中优化天气、护甲、冷却和弹道的配合。 |

未开放资源不出现在搜查或商人清单，仍保留在共享楼层账本中；对应功能也有规则层的等级门槛。事件与危险节点不要求尚未开放的资源。初始医疗与电力等储备沿用原平衡数值，升级后由终端解封，旧档库存不抹除。旧档已安装设施继续可使用，避免升级版本使基地失效。

每个设施每日一次；睡眠消耗生命维持配额，资源转化不能无限延长局数。免费基地鉴定始终可用，便携鉴定属于效率提升，不是基础构筑的门槛。

## 停靠点与跳层

进入高层只记录访问，不提交停靠点。成功通关并正常撤离，才提交新停靠高度与最高通关记录。未通关正常撤离保住物资并回到原停靠点；强制救援同样返回原停靠点，但扣配额并丢失普通背包。出勤不返还，楼层物资不重置。

旧档若无停靠点字段，以最高成功通关高度恢复，解决旧版本跳层失败后的锁死问题。正常选层不能低于已确认停靠点。

## 弹道参与结算

模拟拆分发射、在途、到达。发射时锁定目标并消耗能量，飞行期间没有提前扣血或添加护盾。到达时按目标卡牌护甲折算伤害，再扣宿主护盾与生命。治疗、护盾、能量和充能也在到达时生效。同一时间到达的伤害统一提交，允许同归于尽。

默认 1 倍播放。水果刀与导电索飞行 1 秒，脉冲线圈 0.75 秒，蓄热砖 1.5 秒，其余 1.25 秒。每张战斗卡可覆盖 flightTime（0.5–3 秒，按 0.25 秒步长量化）。速度目前以飞行时长表达，未来若引入距离、拦截或反射可继续扩展在途实体。当前未实装这些未来技能。

弹道从真实卡牌中心飞到目标中心，暂停与倍速同步模拟。自动化验证同样的两张牌会因到达速度不同而改变胜负，等速致死弹道仍会同时结算。

护甲银边已移除，改为我方右下角、敌方左下角图标和数值；宿主护盾仍属于宿主面板，二者不混用。
