# 新手前三间：单刀、转化与图形机关

日期：2026-09-20。范围：新开局引导关的前三间与必要的后续接通；不代表全部新手引导已经定稿。

## 本轮流程

起身 → 看看门外 → 图标化出发成本 → 第一间单刀迎战 → 六段暂停聚焦讲解 → 第二间开箱 → 拾取钉枪、缓冲垫、便携鉴定仪 → 花1电荷鉴定钉枪 → 装备到连续空格 → 显示武器1→2及实际新增伤害 → 第三间垫上缓冲垫 → 旋转管道接通泄压出口 → 前室查看敌情/布阵 → 守卫 → 正常返回电梯。

## 图形玩法调研与选择

- [Flow Free 官方介绍](https://www.bigduckgames.com/flowfree)：连接目标、连续路径反馈。借鉴“是否连通一眼可见”，不复制其关卡或美术。
- [Simon Tatham Net 官方手册](https://www.chiark.greenend.org.uk/~sgtatham/puzzles/doc/net.html)：旋转拼块、连通区域高亮、可重复布局。与旧气室的蒸汽出口包装贴合。
- [Candy Crush 官方控制说明](https://candycrush.zendesk.com/hc/en-us/articles/360000750278-Controls-how-to-switch-and-match-candies)：交换形成三连及连锁补充。本轮不选：还需解释匹配、补充与步数，且与隔热工具关系较弱。这是设计判断，不是玩家研究结论。
- QTE 是候选方向，本轮不引入反应时限，避免同时教授物品用途与限时输入。

最终不是扩建小游戏库，而是一个五段有效管道、九格画面的短机关。明亮管道来自入口的真实连通遍历；只有贯通出口才能提交。没有计时器；旋转、重置、关闭说明不扣资源。缓冲垫在提交时再次核验，沿用已有现场效果：+12精力、操作-2、路程-3，本次自然流程80→87，工具保留。

## 引导模板与文案

`FocusGuide` 接受目标选择器、标题、正文、进度和回调；聚焦区域、背景遮罩、键盘焦点约束、尺寸/滚动更新可复用。普通说明可关闭、通过问号重看；首战依次讲解宿主生命、三路屏障、冷却、出手、破路、胜利目标。

首战播放从真实模拟帧读取出手与命中时点。弹窗显示“战斗已暂停”，时钟与弹道动画一起停；下一步仅解除该段暂停，不修改用户的播放偏好。讲解进度随存档保存。后续重播遵守已完成的进度，不强制重复六段教学。

第二、三间移除侧栏、撤离区、资源总览和长篇规则。保留当前动作、图标成本、机关收益和出错反馈。新卡默认展示同一 `describeCard` 来源的当前能力，完整资料按需展开；不把升阶规则默认堆给新玩家。

## 存档与边界

- 不删除、重置或重排已有路线4/5存档。游戏界面新建时显式开启路线6；`newRun(seed)`原调用仍可生成兼容旧流程，`newRun(seed,true)`生成新引导。
- 只新增可选的引导步骤与路线版本；实例UID、上阵位置、随机种子保持稳定。完成1F后退出引导限制。
- 暂未提交的管道旋转属于免费预览，刷新会重置；已提交的气室使用原有一次性完成记录，不能重复领奖。
- 本轮不全面更换其他楼层的数值机关，不改首次回家/第二次出勤的系统解锁，不扩卡池。
