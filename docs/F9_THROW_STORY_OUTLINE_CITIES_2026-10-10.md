## 0. 为什么要调整

旧大纲是按「幕」写的：每幕是一串比赛，中间穿插支线。加入日程和生活玩法以后，玩家在一座城市里**住下来**：

- 他有住处，有常去的酒馆，认识报刊亭的老太太；
- 离开时，带走的不只是奖杯，还有一段关系和一个故事。

所以叙事单位从「幕」变成「城市」。每座城市要回答三个问题：

| 问题 | 例子（布里奇波特） |
|---|---|
| **里程碑**：伊莱在这里变成了什么人？ | 从「有资格」到「有观众」 |
| **强敌的故事**：这座城市的主线 | 朱诺为什么不肯离开这座小镇 |
| **季节**：这里是什么时节，有什么节庆？ | 春天，园艺展 |

另外：

- **剧团和车轮战在旧大纲里没有家**。新增米尔布鲁克，让剧团有一座自己的城市。
- **主线和支线分开**：
  - 主线永远是「了解这座城市的强敌，打败他，理解他」；
  - 八卦、怪谈、镇上的人，是嵌入在旅途中的支线故事。这个形式参照《匹克威克外传》。

### 1.1 每座城市的结构

| 阶段 | 时间 | 内容 |
|---|---|---|
| **抵达** | 第 1 周前半 | 新的住处、酒馆、报刊亭；**第一次见到这座城市的强敌**，知道他想要什么 |
| **扎根** | 中间几周 | 联赛或系列赛按固定的晚上进行；日程里打听强敌的情报、喝茶、接差事；镇志（支线）逐条推进；招募新成员 |
| **转折** | 倒数第二周 | **强敌的秘密被揭开**：他为什么是这样的人 |
| **决战与告别** | 最后一周 | 强敌决战；节庆；告别宴或站台送别；剧团合照（收藏品）；斯坦的巴士开往下一座城市 |

- **每周最多 2 件必做的事**（主线比赛、主线对白），其余全是可选。
- **没有硬性日历**：主线比赛输了，下周再打，代价是时间。错过的只有**限时的节庆和一次性事件**，它们只影响收藏品和支线。
- 想多住几周也可以：城市的日常内容是循环的（报纸、酒馆、街头演出），但「新鲜内容」有上限，见第 4 节。

### 1.2 六种主线套路

每座城市的主线都是「挑战并战胜强敌」，但打败他的方式、故事的形状、教会玩家的东西，各不相同。这一点参照《西游记》：每一站的妖怪手段不同，解法也不同。

| 城市 | 强敌 | 套路 | 故事的形状 | 打败他靠什么（玩法） | 主要参照 |
|---|---|---|---|---|---|
| 格雷维克 | 菲利克斯 | **守门人**：证明你有资格出门 | 一道门槛 | 读懂克制环：他打火，就带盾 | 成长小说的出发 |
| 布里奇波特 | 朱诺 | **爬梯子**：从早场的三个观众，到挑战全镇的台柱 | 一路向上 | 赢下观众（街头演出、名气），应对快甩 | 《后翼弃兵》的地方赛、克拉姆尔斯剧团 |
| 韦斯特港 | 诺拉 | **谍战**：两个魔术师互相研究 | 猫捉老鼠，几次反转 | 情报和反情报；准备两套方案 | 《致命魔术》、《马戏团之夜》 |
| 米尔布鲁克 | 霍尔特 | **团队赛**：拼凑的剧团，对上四十年不败的老牌剧团 | 集结 → 受挫 → 重聚 | 排兵布阵、出场顺序、成员心情 | 《好伙伴》、《后翼弃兵》的莫斯科 |
| 奥罗拉 | 阿德里安 | **诱惑**：一座什么都能买的城市，和另一个自己 | 邀约 → 代价 → 拒绝 | 拒绝捷径；把舞台规则算进构筑 | 《天路历程》的名利场、《圣诞颂歌》 |
| 世界大剧院 | 阿斯特 | **终局考试**：他看得见你的一切 | 重逢 → 前夜 → 决战 | 全部所学，加上众人相助 | 《后翼弃兵》的封盘之夜 |

**被打败的强敌不会消失**：他们成为帮手、成员、笔友，或者决赛观众席里的一个人。决赛前夜，他们每人打来一通电话。

## 2. 逐城大纲

### 2.1 格雷维克 · 早春 · 3 天 · 守门人（已实装）

| 项目 | 内容 |
|---|---|
| 里程碑 | 有名字的参赛者 |
| 强敌 | 菲利克斯：礼貌而刻薄的报幕员兼资格赛对手，认定伊莱「只是来参加社区才艺表演」 |
| 主线 | 吊灯事故 → 米娅的盾 → 资格赛击败菲利克斯（已实装） |
| 生活玩法 | **不开日程**。这一幕是教学，保持线性，约 30 分钟 |
| 收尾 | 离开时，**里德送一个剪贴簿**：之后所有剪报、节目单、明信片都贴在里面（收藏品系统的入口） |
| 他之后 | 每到一座城市，菲利克斯都寄来一张刻薄的明信片；在韦斯特港，他会重新登场（见 2.3） |

### 2.2 布里奇波特 · 春 · 3 周 · 爬梯子（已实装对决，需要补日程层）

> 一座有桥、有集市、有一间只在周四营业的剧院的小镇。

| 项目 | 内容 |
|---|---|
| 里程碑 | **有观众的魔术师**：第一次有人专门为他买票 |
| 强敌 | **朱诺·贝尔**：街头魔术师、小镇台柱，出手极快 |
| 新系统 | 演出费、道具铺、街头演出、对手档案（已实装）；**一周日程**、**情报**（看报、酒馆），**第一次被假情报骗**也在这里（低代价的小组赛） |
| 剧团 | 朱诺（剧情）、罗茜（好感）、斯坦（酒馆）已实装；**普赖斯姐妹**（支线后加入） |
| 节庆 | **园艺展**：艾格尼丝是评委 |

**主线：朱诺为什么不肯离开**

| 拍 | 周 | 内容 |
|---|---|---|
| 起 | 1 | 伊莱被排到早上 9 点的早场，观众三人，其中一人是来躲雨的。朱诺是周四晚场的头牌。她当面说：「这里的观众不等人。」 |
| 承 | 1–2 | 伊莱去集市街头演出攒观众。朱诺每天在不同的街角演出，总是抢走他的人群。**情报教学**：观摩她的街头演出，就能看清她的打法，但得先打听到她今天在哪个街角 |
| 转 | 2 | 小组赛连胜以后，伊莱在后台听到：朱诺拒绝过三次巡演邀约。不是因为不敢去大城市，而是因为**周四剧院靠她一个人撑着上座率**：她一走，剧院就要关门 |
| 合 | 3 | 决赛对朱诺。赢下以后，周四剧院的观众席里有一半是伊莱带来的人，剧院不再只靠一个人。朱诺第一次觉得自己可以走了：「下次我也会准备新招。」她入团 |

- **教学意图**（沿用）：一路靠护盾的玩家，在这里被单张削盾教育。
- **参照**：《后翼弃兵》里，贝丝打败州冠军贝尔蒂克，后者转而帮她；克拉姆尔斯剧团那种外省小剧场的滑稽和热闹。

**支线（镇志）**：

- **周四剧院的 C7 座**：
  - 报刊亭的多德太太每个周四都坐 C7。原来剧院老板的亡妻生前每周四登台，多德太太是她的妹妹，答应过姐姐「每场都来」。
  - 结局取决于玩家在这座城市演过多少场：演得多，决赛那晚坐满，她把 C7 的座位牌送给伊莱（珍藏）；演得少，C7 那晚是空的。
  - 这条支线和主线的「剧院上座率」互相呼应。
- **霍布斯的药匣**（沿用）。
- **普赖斯姐妹的赌约**（沿用）。
- **司机的厕所**（沿用）。

### 2.3 韦斯特港 · 夏 · 4 周 · 谍战

> 一座有地铁、高架桥、广播塔和海鸥的港口城市。海鸥是这里唯一不需要门票就能进剧院的观众。

| 项目 | 内容 |
|---|---|
| 里程碑 | **被研究的职业选手**：第一次有人为了打败他而研究他 |
| 强敌 | **诺拉·哈特**：学院派，严谨；赛前公开自己的战术笔记，因为「藏着掖着不体面」 |
| 新系统 | 道具改装、三局两胜；**对手侦察你**、**放假消息** |
| 剧团 | **车轮战 2v2**：地铁卖艺人联盟的街头团体赛；招募**午夜莫莉**（回血，好感） |
| 节庆 | **海边档期**：码头剧场连演一周 |

**主线：两个魔术师互相研究**

| 拍 | 周 | 内容 |
|---|---|---|
| 起 | 1 | 报纸头条称伊莱是「乡村奇迹」。记者西奥·格兰特被派来证明他只是侥幸。诺拉在联赛公报上发表了一篇分析伊莱四场公开对局的笔记：「作为研究材料有点单薄。」 |
| 承 | 1–2 | 联赛常规赛：对手开始带着克制伊莱的箱子来。伊莱第一次看到「他们也有你的档案」。玩家学会两件事：读对手档案、换箱子 |
| 转 1 | 2–3 | **卧底**：伊莱的巡演箱配置，总是提前出现在对手手里。追查下去，泄密的是**菲利克斯**：他被降级到暖场，缺钱，把情报卖给了诺拉的经纪人。玩家可以选择揭发他，或者**反过来利用他**，通过他把一个假箱子送过去 |
| 转 2 | 3 | 诺拉知道自己收到的是买来的情报以后，**拒绝使用它**，并在公报上发了一则声明。她要赢得干净。伊莱第一次真正尊重这个对手 |
| 合 | 4 | 广播塔访谈：主持人问「运气还能持续多久」，伊莱可以借机放出假消息。然后是诺拉系列赛（三局两胜）：她的笔记对第一局是诚实的，后两局要靠伊莱自己推断 |

- 赛后，诺拉说：「这次我输给了你的判断，不是没见过的招。」从此两人交换笔记。
- 西奥在报纸上登出**更正启事**：「本报此前称伊莱·维尔为乡村奇迹，有误。他不是奇迹。」这条和情报系统里每周的「更正启事」是同一个笑点。
- 菲利克斯如果被原谅，会在第六站念对伊莱的名字。
- **参照**：
  - 《致命魔术》：魔术师之间的窃密，卧底倒戈，用假线索误导对手；
  - 《马戏团之夜》：记者为了揭穿表演者而跟着她，最后被她改变。

**支线（镇志）**：

- **溺水的魔术师**：
  - 传说 1920 年代有个魔术师在栈桥表演水下逃脱，再也没上来。
  - 其实他为了躲债游到了一艘拖船上，后来自己当了船长：他就是九十岁的布兰尼根。
  - 结局：在栈桥上打完那场「没演完的戏」；报纸头条「溺水魔术师现身还钱，金额为 4 镑 6 便士」。
- **午夜莫莉的电台**（沿用）。
- **地铁卖艺人**（沿用）。

### 2.4 米尔布鲁克 · 秋 · 3 周 · 团队赛（新增城市）

> 北方的纺织小镇。烟囱比树多，铜管乐队比烟囱多。镇上每个人都欠别人一顿饭，所以没人搬走。

| 项目 | 内容 |
|---|---|
| 里程碑 | **一个剧团的团长**：伊莱第一次要为别人的输赢负责 |
| 强敌 | **阿瑟·霍尔特与纺锤剧团**：霍尔特是老团长，像管纺织厂一样管剧团：严格、守时、从不捧个人明星。纺锤剧团在联赛四十年不败 |
| 规则 | 米尔布鲁克没有个人赛，只有**剧团联赛**。联赛冠军的团长能拿到世界赛的外卡名额 |
| 新系统 | **车轮战 3v3**；**敌方剧团**；成员心情和「有人罢演」 |
| 剧团 | 斯坦的回归；招募铜管乐队的小号手（新角色，草案） |
| 节庆 | **篝火之夜**（11 月 5 日）：余烬流的主场；♦5「十一月五日」这张传奇牌的专属剧情 |

**主线：拼凑的剧团，对上四十年不败的剧团**

| 拍 | 周 | 内容 |
|---|---|---|
| 起 | 1 | 霍尔特看完伊莱的个人表演，只说了一句：「剧团不是一个人。」伊莱第一次要排出一个三人阵容。巴士开进米尔布鲁克时，斯坦一句话也没说。镇上的人都认识他，叫他「小斯坦」 |
| 承 | 1–2 | 联赛常规赛。伊莱要排阵、照顾成员的心情、处理成员之间的矛盾。纺锤剧团的阵容是公开的，**出场顺序**才是要打听的情报 |
| 转 1 | 2 | **一场演出被破坏**：后台的灯被剪断，道具被调包。所有人都怀疑纺锤剧团。真相是镇上的庄家：全镇都押纺锤剧团赢，他收买了场务。霍尔特知道后大怒，自掏腰包赔了损失，并要求重赛 |
| 转 2 | 2–3 | **斯坦的过去**：酒馆的老人说，四十年前纺锤剧团有个最有天赋的少年，在联赛决赛上**冷场**了：牌全掉在地上，观众开始笑，他就那样站着。第二天他去考了巴士驾照。那场决赛的对手，就是年轻的霍尔特。霍尔特私下对伊莱说，他赢了，但他一直知道「那个孩子比我好」 |
| 合 | 3 | 联赛决赛 3v3。**如果打听到了纺锤剧团的出场顺序，玩家可以把斯坦排在霍尔特对面**；前提是之前陪斯坦把好感推到「知己」。那一局的台词全部替换。赢输都没关系，斯坦打完了 |

- 赛后，霍尔特把指挥棒交给伊莱（「其他」类投放）。
- 斯坦的手法升级为「重新来过」：一局里一次，把整手牌放回牌堆底，重新发同样张数。
- 第二天早上，斯坦照常开巴士：「还是这个比较适合我。不过谢谢你。」他带伊莱去看他小时候发现的「全镇最好的厕所」，在剧院后台。四十年前那个晚上，他就是躲在那里。
- **参照**：
  - 《好伙伴》：出发点就是约克郡的纺织小镇；一群各有毛病的人被一个剧团拼在一起；一场遭到破坏的演出；
  - 《后翼弃兵》：贝丝在莫斯科发现苏联棋手互相帮忙，而她只有一个人；
  - 《匹克威克外传》的《流浪艺人的故事》：一个落魄艺人的过去。

**为什么要新增这座城市**：

- 剧团、车轮战、成员心情、敌方剧团，在旧大纲里都没有主场。塞进韦斯特港或奥罗拉，会抢那两座城市自己的主题。
- 旧大纲从韦斯特港（职业）直接跳到奥罗拉（商业与自我），中间缺一段**温暖**的东西。米尔布鲁克是全程唯一一座「不比个人赛」的城市，节奏可以慢下来。

**支线（镇志）**：

## 3. 新的时长预算

**基准**：一周日程约 21 个时段，平均约 45–60 分钟游玩（含 2–4 场对决）。

|---|---|---|---|---|
| 格雷维克 | 3 天 | 0.4 | 0.1 | 0.5 |
| 布里奇波特 | 3 周 | 3.5 | 3 | 6.5 |
| 韦斯特港 | 4 周 | 4.5 | 4 | 8.5 |
| 米尔布鲁克 | 3 周 | 3.5 | 3 | 6.5 |
| 奥罗拉 | 4 周 | 4.5 | 4 | 8.5 |
| 世界大剧院 | 2 周 | 3.5 | 1 | 4.5 |

| 通关后：重开剧院、巡演、全力复赛、里德的抽屉 | — | — | 10+ | 10+ |
| **总计** | | | | **47+** |

比旧大纲多约 8 小时：新增的米尔布鲁克约占 6.5 小时，日程层分摊到各城市。

### 3.1 旧原则的修订

旧大纲的关键原则是「时长来自更多不同的对手和构筑问题，而不是更多血量」。这条**仍然成立**：

- 气场成长**不延长对局**。它是为了抵消卡牌的数值膨胀。实测下，强敌对决稳定在 44–47 秒，基准是 43 秒。
- 新增的时长来自两处：更多不同的对手；城市生活（人、故事、情报）。

修订后的原则：**时长来自更多的对手、更多的人和更多的故事，而不是更长的对局。**

## 4. 内容量：一座城市要准备多少东西

「在一座城市停留更久可以接受，只要内容量跟得上。」下表是一座 3–4 周城市的最低内容清单：

| 内容 | 每座城市 | 说明 |
|---|---|---|
| 主线 | 4–5 拍，围绕强敌 | 套路不同（1.2） |
| 有名字的对手 | 10–14 | 主线 6–8，支线 4–6 |
| 街头演出（条件对决） | 8–12 | 条件可以复用，对手和对白要换 |
| 镇志（支线） | 8–12 条传闻 | 其中 3–4 条串成一个有结局的支线故事 |
| 下午茶和酒馆对白 | 每位成员每座城市 3–4 段 | 成员会对这座城市、这个强敌发表看法 |
| 报纸 | 每周 1 期 | 头条接主线，副刊接镇志，末版是更正启事 |
| 差事 | 4–6 件 | 每件 1–3 个时段 |
| 节庆活动 | 1 个 | 限时 1 周 |
| 收藏品 | 15–25 件 | 按[成长文档](./F9_THROW_GROWTH_INTEL_REWARDS_2026-10-10.md) 3.5 的稀有度分配 |
| 本地菜 | 3–4 道 | 每道一张食谱 |
| 新地点 | 5–7 个 | 住处、酒馆、报刊亭、比赛场馆，加 1–3 个特色地点 |

**防止「住久了没东西做」**：

- 每周至少有 1 件新鲜的可选事件（新传闻、新人物、新差事）。
- 当一座城市的新鲜内容快用完时，报纸会登出「下一座城市」的消息，酒馆里也会有人开始问「你什么时候走」。这是自然的离开提示，而不是强制。

## 6. 开发顺序建议

1. **气场**：规则层的气场上限改造；剧情模拟按城市曲线验收。它不依赖其他系统，也是数值膨胀的前提。
2. **一周日程的最小版**：只在布里奇波特，三个时段，现有的地点和对白挂上去；加房租和伙食的最小版。
3. **情报**：报纸和酒馆两个来源，对朱诺和小组赛对手生效；敌人预览加迷雾；第一次假情报的脚本。
4. **布里奇波特主线补完**：朱诺「为什么不肯走」，加上 C7 支线。验证「主线围绕强敌、支线是镇志」这套写法。
5. 用布里奇波特做完整切片，真人试玩；然后再做韦斯特港。

## 7. 需要用户确认的点

1. 六种主线套路（1.2），以及每座城市的四到五拍。
2. 韦斯特港让**菲利克斯当泄密者**（2.3 转 1）。这改动了旧大纲里他「被降级到暖场、伊莱帮他修聚光灯」的支线：修灯变成原谅他之后的事。
3. 米尔布鲁克的强敌是新角色**阿瑟·霍尔特**，他和斯坦的过去连在一起。
4. 世界大剧院决赛前夜的**电话情报**，由每座城市的结局决定。
5. 奥罗拉加一场**提前输给阿斯特**的慈善表演赛。
