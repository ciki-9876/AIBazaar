# 甩牌对决：世界观候选

日期：2026-10-04。状态：助手脑暴，用户尚未选定；没有替换正式剧情。

## 已知边界

用户认为甩牌核心玩法已经成立，要求探索差异较大的世界观。当前独立项目为 `apps/throw`；主动甩牌、单击单选／连续框选、扑克牌型、十格道具和单遗物保持现行规则。共鸣卡牌和电梯各自拥有其他故事与规则。

现有温暖纸纹与像素旧物是本轮 UI 的延续，不是新题材必须遵守的世界观。沿用此前的 60–90 分钟旅途目标作为叙事比较的起点；新方向涉及的章节数、奖励、敌人和事件均未实装。

## 判断标准

甩牌有三个容易成为作品标识的动作：等待并观察手牌、圈起一组牌、亲手把组合甩到敌人身上。题材最好解释这个实体动作，而不只是把伤害数字改名。

世界观要给玩家一个明确身份和每局可以完成的事情；道具的位置、单件遗物和不同牌型要有发展空间。四花色暂不固定为四种伤害属性，否则会提前限制现有的梅花剧毒、红心净化与后续混合构筑。

## 1. 流浪魔术团：最后一场谢幕

**气质：温暖、活泼、奇幻冒险。** 奶油纸张、深绿幕布、红铜机关、彩色票根和手绘海报；像素人物夸张而可爱，爆发时强调灯光、星屑与舞台机关。

在这个世界，真正的魔术能让想象短暂成真。玩家是散伙剧团的年轻魔术师，带着一副师傅留下的纸牌和空舞台箱，沿旧巡演路线找回团员，准备一场重新开幕的演出。

- **为什么甩牌：** 魔术师把纸牌当作承载术式的实体媒介；甩出的瞬间术式展开，直接与对手交锋。战斗使用生命，舞台演出是表现与情境，不另外增加“掌声血量”。
- **组合与构筑：** 单牌是敏捷的小戏法，对子是双重机关，顺子是连续表演，同花是统一主题的大魔术。十格舞台箱摆放机关、灯具、药剂与助手用具，邻接决定共演；遗物是招牌演出的核心道具。
- **一局轨迹：** 街头试演 → 镇上剧院 → 漂浮集市 → 城市大剧场。途中招募帮手、换装机关、接受表演邀请；阶段对手为不同流派的魔术师，最终完成一场大型魔术对决与重新开幕。
- **人物冲突：** 同伴有人想继续冒险，有人已安定下来；成功不必等于所有人回到旧生活。强劲的商业剧团可以是竞争对手，也可以成为后来的盟友。
- **适配与风险：** 现有灯、钟、伞、茶壶、风扇都有自然用途，改造成本较低；需要把魔术交锋做得有力量，避免像没有危险的儿童表演。

## 2. 命运怪盗：偷走明天的人

**气质：都市怪盗、潇洒反叛。** 靛蓝夜色、黑白剪影、朱红警报、金色命运线；干净大胆的构图，爆发用切割画面与花色印记。

一座城市的“好运”被几大财团储存、交易。穷街区的人连一次转机都被抵押了。玩家是能把概率压进扑克牌的怪盗，目标是盗出命运金库里被收走的明天。

- **为什么甩牌：** 牌是被封存的概率，击中目标时强行兑现一段结果；更复杂的牌型让多个结果同时成立。这里的扑克牌直接参与战斗，不以赌场押注作为主要玩法。
- **组合与构筑：** 装置包括烟雾针、破解器、发条计时器、替身投影和命运放大器。十格工具腰带的接线位置影响联动；遗物是一件从重要人物手里夺来的独门宝物。
- **一局轨迹：** 选择劫案 → 在街区搜集情报和装备 → 闯过财团安保与追猎者 → 潜入金库 → 带着偷回的命运逃离。阶段 Boss 是守库人和其他怪盗；终局给受害者一个具体的新机会。
- **人物冲突：** 玩家可以把好运还给某人，也能为自己保留，但不用在战斗界面里处理长篇道德讨论。对手不是统一的贪婪商人，有人相信稳定分配好运才是公平。
- **适配与风险：** 扑克和爽快爆发结合最直接，主角辨识度强；当前旧物美术需要较大幅度替换，剧情不能只有抽象的“偷好运”，应展示居民生活真正改变。

## 3. 纸符行旅：百鬼邮路

**气质：东方民俗奇幻、奇怪而有烟火气。** 米白符纸、朱砂、墨蓝夜色、灯笼与旧邮驿；既有热闹市集，也有怪异山路，不默认全程恐怖。

阴阳之间有一条邮路。某次断邮让人与鬼互相等不到回信，怨念堵住驿站。玩家是新入行的符使，拿着一封无法查到收件人的信，修复驿路并追查它的来处。

- **为什么甩牌：** 玩家掷出的是真实纸符。四花色是便于识别的符印，点数是符序；连牌形成完整法式。保留红黑扑克牌语法，造型东方化，不另外要求玩家学习一套不兼容的文字牌。
- **组合与构筑：** 十格法器盒装铃、镜、香炉、针、符印与药包，邻接表现为法器互相借力；遗物是师门传承或鬼客赠物。
- **一局轨迹：** 人间邮驿 → 水边鬼市 → 山路客栈 → 遗失驿站 → 终点渡口。每站先找过路方法、处理委托，再挑战守路者；最终让一封回信抵达，并获得一段人物关系的收束。
- **人物冲突：** 一方想让所有信继续传送，一方认为某些告别应该停在过去。战斗可以是守路者试炼、阻路妖物和符使冲突，不把每位收信人都变成敌人。
- **适配与风险：** 掷符动作和旧物道具结合自然，适合保留温度；四花色需要视觉设计才能和东方民俗融洽，不能只把普通扑克名称改成“符”。

## 4. 星海快递：没人领取的最后一箱

**气质：明亮、轻科技、轻喜剧公路冒险。** 雾白机壳、浅蓝玻璃、珊瑚橙警示、圆润机器人与干净的像素星港；温暖来自人物和物件细节。

星际航线被大公司切断，偏远聚落只能等着逐渐断联。玩家驾驶一艘小快递船，决定把仓库里积压多年的包裹送到远方，其中一箱始终没有收件记录。

- **为什么甩牌：** 扑克原本是船员间流行的纸牌玩具，后来成为“折叠能量片”的标准外形。玩家戴着投射手套甩出能量片，牌型是多片同时展开的组合协议。保持实体牌飞行，避免只在屏幕上发数据。
- **组合与构筑：** 道具为线圈、冷却器、回收模块、生物滤罐与护盾发生器；十格模块座的邻接表示真实接线；遗物是一件改变整艘船运作方式的特殊模块。
- **一局轨迹：** 港口备货 → 多个星站岔路 → 封锁检查 → 荒废中转站 → 偏远终点。途中送小包裹、维修船舱并决定绕路；最终交付那箱货物，恢复一条被遗忘的联系。
- **人物冲突：** 小船长不想成为英雄，只是不愿意把“无人领取”当成丢掉的理由。公司守卫也可以有自己的订单和家乡。
- **适配与风险：** 可把 UI 做得简洁而可爱，题材容纳多种装备；扑克牌为何成为能源标准需要开篇一个直观场景，否则容易显得牵强。此方向建议先做一场星港交锋再决定。

## 5. 失眠图书馆：把梦还给夜晚

**气质：超现实童话、安静又奇诡。** 墨色线条、象牙白、少量高饱和梦境颜色；战场留白，组合出手时短暂展开整页幻想。与前四种的热闹氛围形成明显差异。

城市的人逐渐不再做梦。夜里开放的图书馆收集那些被截断的梦，玩家是临时夜班管理员，进入书页世界寻找梦境的结尾。

- **为什么甩牌：** 未完成的梦被折成纸牌。掷出的纸牌会把梦的片段变成实体，打散阻挡旅途的“空白”；点数与花色仍是读牌语法，不要求玩家解谜才能出牌。
- **组合与构筑：** 对子让两个梦像重合，顺子补全连续片段，同花展开同一梦境。十格书匣安放催眠钟、剪纸刀、音乐盒和修页工具；遗物是一个坚持保留的现实记忆。
- **一局轨迹：** 接到一本缺页的梦书 → 选择不同书页岔路 → 面对重复的噩梦 → 找到缺失的现实细节 → 补完结尾，把梦还给主人。每局可以有独立角色与结局。
- **人物冲突：** 补完梦不一定意味着实现愿望，有时意味着接受告别；玩家的能力与一个自己不愿结束的梦有关。
- **适配与风险：** 美术空间大，能够用少量场景做强主题；抽象程度最高，必须让玩家明确知道眼前为何交战，避免情绪叙事抢占快速甩牌的注意力。

## 本轮建议与取舍

**优先“流浪魔术团”**：动作、现有物件、美术温度和组合爆发有同一条因果线。可以先用现有素材做一场魔术师交锋，不需要先换整套画面才能判断题材是否成立。

**第二候选“命运怪盗”**：如果目标是尽快形成更鲜明、潇洒的作品身份，它比继续围绕旧物修复更贴合主动甩牌。代价是人物、工具和场景都要重建。

纸符行旅适合东方烟火气；星海快递适合此前偏好的简洁轻科技；失眠图书馆适合更浓的作者性与情绪表达。这些是创作判断，没有商业表现或玩家偏好证据。

本轮不推荐把甩牌硬塞回“被遗弃物品的灵魂对决”：原故事强调关爱与修复，当前核心动作更强调抓住机会、主动爆发，两者可以结合，但需要重新解释角色的能力与攻击动作。旧归物师历史仍保留，不视为错误或删除。

选定方向后，下一步应先完成一个主角、一位阶段对手、一段出发目标、同一套构筑的三件道具与一件遗物，以及一场真实甩牌对战。验收动作与题材是否一致，再扩写全局主线。
