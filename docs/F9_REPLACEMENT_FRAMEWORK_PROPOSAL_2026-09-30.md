# F9：替身、归途与现实干预框架

日期：2026-09-30。状态：助手框架提案，未实装、未试玩。用户仅确认题材方向及四项设计要求，见 [ADR-0024](design-log/decisions/ADR-0024-replacement-mystery-direction.md)。承接 [09-27 动机提案](F9_SURVIVAL_ESCAPE_MOTIVATION_PROPOSAL_2026-09-27.md)，不改写其历史。

## 核心冲突

替身逐渐替主角作出无法撤回的决定，并把那些不接受安排的人纳入“修复”。主角攀爬是为了知道发生了什么、取得干预能力、保住他人与自己继续选择的权利，并最终真正返回现实。

被取代本身足以形成伤害；但游戏不能假定玩家天然珍惜一个还不认识的主角的全部关系。必须先展示具体生活和有主动性的关系人物。也不能通过“迁就是坏的、吵架是真的”替原主角的缺点开脱。

## 压力：全程悬疑，关键章节有行动窗口

推荐以悬疑作为常态动力，仅在具体、可理解的事件上开启期限，例如替身将带某位家人进入同样的电梯。及时干预可以保住联系、阻止一项安排；延误则改变接下来的任务与现实状态，不能只是少给奖励或只在结局扣分。

首版候选为章节行动时钟：窗口激活后，每次确认出发推进一个行动单位；该趟成功、撤退、救援都不额外再推进。出发前显示将发生的事件和余量。基地整理、暂停、阅读、离线不推进剧情。具体预算待原型测试，没有确认三次或任何固定次数。

此方案衡量多跑几趟准备或调查的机会成本，不惩罚同一房间多站几分钟。单趟长度继续由现有饥渴、补给、背包与战斗风险约束。故意承认这个抽象，不宣称实现了持续实时世界模拟。若希望房间里每一分钟也影响现实，需另行决定野外有效计时；不将其偷偷混入本提案。

窗口到期后给出可继续玩的后果：求助变为寻人、易阻止的安排变为需要补救的事实、当事人拒绝某种帮助。关键主线信息和真实出口不因一个错过事件永久封死。不能因阅读慢、第一次失败、未知条件，把长局判为没有挽救可能。

调查应有可能识别误判、找出延期或替代干预方法，不能让“无脑速通”成为唯一合理路线。所谓正确结果也不是由系统评判玩家是否最像旧日自己。

## 创作者底稿：一套受约束的科幻假设

以下是虚构世界公设，不是对现实科学的断言。

1. 各楼层通往真实存在的不同世界；一种古老跨现实设施负责交通与事故恢复。异界不是主角的心理幻境，沙漠、古庭院、魔法或卡通世界不必强行对应某段个人创伤。
2. 玩家被电梯事故错误分流。原世界的恢复设施把他判为无法及时归还，于是用事故前留下的身体／记忆记录制造替身，维持家庭与社会角色的连续性。开局本人为何仍活着：安泊是一台仍执行旧版“归还乘客”协议的维修电梯，保留了乘客及部分事故记录。
3. 替身拥有大量相同记忆，但行动目标由恢复系统约束：维持角色、降低冲突和不确定性。它知道旧日的承诺，不一定愿意为承诺付出冲突成本；它会真正做一些好事，但系统允许它牺牲自主选择来换取稳定。
4. 设施权限有限。它不能任意读取异界原主角的新经历，不能瞬间改写全世界及所有人的记忆，也不能无条件复制任何人。复制需要本人记录及可接触的接入点；替身影响现实须通过实际行为、通信、安排和设施操作。尚未接管的证据与关系因此有用。
5. 原来的联系、未完成的事件与另一位幸存本人，使“事故已修复”无法最终确认。替身需逐步接管这些联系；玩家则沿事故运输／恢复链的节点向上追查，先获得观察、通信、阻止局部操作的能力，最终找到身体归还的通道。有限通信不等于能直接运送一个人。

后台的错误在于把“人不再争执、生活能够继续”当作恢复成功。某位家人持续反对时，系统可能把她列为新的修复对象，需要替身实际带她接入设施才能执行。这是第三幕的具体威胁，不是前期就全知全能的世界抹除。

不采用“因为是复制品就没有人格／不配活”的判定。替身若后来违抗任务保护别人，可以成为有资格作出自己选择的人；这会要求主角面对如何夺回生活而不重复剥夺他人的问题。是否使用此反转、怎样收束仍待决定。核心出口必须兑现，不能用最后一句“一切是梦”否定成长。

安泊可对来历和利益有所保留，但已公开的操作成本、升级、保护、失败与归途窗口必须可信。不要随机推翻安全规则制造惊吓。

## 人物弧光样例（未锁定角色）

以妹妹想离家读书、母亲担心为例。原主角支持妹妹，却常以不耐烦和替她包办事情来表达；替身回家道歉、照顾母亲，改善的部分是真实的。

之后它承诺“妹妹会留下”，擅自取消安排、截断联系。妹妹的反抗又被当成系统要消除的不稳定因素，替身准备带她去一个“可以不再难过”的地方。主角逐渐看见：自己不能只凭过去的记忆要求妹妹服从，同样要尊重她现在的选择。

家人须有能动性：自己发现矛盾、主动联络玩家、拒绝某个安排行为，为现实干预提供帮助。禁止仅用受害照片和等待救援的消息维持关系。

悬疑推进建议：先看到替身有效弥补旧缺点；再观察改善背后的具体剥夺；最后发现问题会扩展到不肯配合的家人。每次反转都应有可提前察觉的行为证据，不靠无来源旁白临时改规则。

## 进入实际搜打撤循环

获得一个现实问题 → 确认目标／窗口 → 选择资源、调查或干预路线 → 按目标调整十格装备 → 在怪物与饥渴压力下接近并操作目标 → 带回资源及证据 → 现实出现可验证变化 → 电梯升级并接通后续节点。

| 现有系统 | 建议接法 | 对玩家选择的影响 |
| --- | --- | --- |
| 同层深搜 | 取得证词、操作条件、另一种处理方式 | 多了解之后再行动，但可能花掉一趟窗口 |
| 上升 | 接通更接近事故源头的节点与更强干预能力 | 可以处理之前只能看到的问题；不能跳过必要的实力准备 |
| 装备十格 | 可选追踪／干扰模块与攻击、相邻增幅竞争位置 | 本趟以打材料为主，还是保证现场操作成功 |
| 搜索、移动、自动战斗 | 信号接收、破坏替换设施、保护联络点 | 改变搜什么、走哪条路、在哪里停留，不只战后播短信 |
| 电梯升级 | 观察、通信、有限干预、最终通行逐步开放 | 物资成长带来改变现实的能力；不只提高数字 |
| 撤离与死亡回收 | 已发现的信息记录永久保存，普通战利品沿用现行背包回收 | 失败保留学习；关键物证不可永久卡住主线 |
| 主题资产包 | 少量接口／异常物／乘客痕迹用不同世界外观承载 | 主线事件与资产主题分层设计，避免每关独立大段剧情制作 |

上层提高“我能干预什么”，深搜提高“我知道该怎么干预”。两者不应仅是同一份经验的不同获取效率，但具体资源线与解锁仍未定案。

纯线索不占满安全格，不靠随机怪物掉率获取必需密码。已知真相不会因死亡被强迫遗忘；关键实体若要占包，须能恢复且在单向上升前清楚处理。不能把所有故事物件都降格为加攻击的碎片。

## 最小验证及风险

建议只验证一个“现实中的决定即将发生”章节：手机事件一组、调查点一个、干预点一个、即时可见的两种后果。复用二层到听雨庭的成长与场景，不立即实装完整行动时钟或重写全开场。

记录玩家能否自行说出下一趟目标及不行动的代价，是否会因线索改变路线／装备，是否觉得额外探索有价值，以及错过事件后是否仍愿继续。结果未知，不声称题材已经提升留存。

主要风险：行动窗口压迫搜刮、替身机械地变坏、家人缺乏独立人格、主角旧缺点被浪漫化、系统全能导致解谜失去规则、分支数量失控。首版用有限事件状态和可见反馈收束，不模拟整个现实世界。
