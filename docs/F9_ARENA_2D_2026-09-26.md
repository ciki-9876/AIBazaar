# F9 2D 战斗试玩

后续美术对照已接入：A+B 绘本与 A+G 贴纸，详见 [双版本试玩](./F9_ARENA_LIGHT_VARIANTS_2026-09-26.md)。下文保留首次实装记录；当前 `/arena/2d` 默认绘本版。

入口：`/arena/2d`；本地运行 `npm run dev -- --host 127.0.0.1 --port 4173` 后访问 <http://localhost:4173/arena/2d>。

## 体验

1. 直接使用示例阵容，或清空后从武装库选牌／拖牌。1 至 3 格不能跨路线，同名最多两张。
2. 点击我方路线下的增幅器入口选择效果。点卡牌查看全文、移动或移回武装库。
3. 开始对战后可暂停、切换倍速、逐帧、拖动时间轴。点击装备查看详情会暂停，关闭按此前状态恢复。
4. 战后回看局势转折、各路收益与逐卡运转。胜利后可以请求对手应对，再调整自己的阵容。
5. 对局档案保存在当前浏览器，支持导出、导入和重建回放。2D 与原有战术桌共用既有档案格式。

## 主要实现文件

- `app/arena/arena-experience.tsx`：共享布阵、战斗、回放及档案流程。
- `app/arena/2d/page.tsx`、`app/arena/page.tsx`：2D 和既有 3D 入口。
- `app/arena/flat-table.tsx`：2D 桌面、占位、屏障和真实事件反馈。
- `app/arena/collectible-card.tsx`、`app/arena/arena-2d.css`：收藏卡、动态数值列表、冷却和流光。
- `lib/arena-card-face.ts`：从牌库与帧生成只读卡面数值；不参与战斗结算。
- `public/art-assets/arena-2d/item-atlas.png`：12 张原始机制族插画。
