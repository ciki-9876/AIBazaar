# 2026-10-03：Laya 与本地 F9 专用模型

## 用户问题与约束

用户询问开放 Laya 或共同制作本地类 Jev 小模型，期望取消运行调用费用。后续明确同时支持 Windows 客户端与浏览器。未确定所有功能必须离线、最低硬件、交涉范围，也未选择模型或批准训练。

## 调研与建议

[完整方案](../../../F9_LOCAL_DECISION_MODEL_PROPOSAL_2026-10-03.md)重新核对 Laya 0.3.24、开放许可和领域微调案例，建议先用开放基础训练 F9，再视两端性能考虑蒸馏轻量策略网络。基础模型的业务零样本准确率不足以证明游戏能力；GPU毫秒数字与普通浏览器、CPU和渲染共存不能混用。

快模型可取消该层API费用；制作、硬件及维护不归零。开放谈判若也要本地运行，须另外验证本地生成式模型；若仅小策略网络＋对白模板，则不等于原先要求的大模型实时博弈。不能无声替换体验。

提出个人观察／动态候选契约、角色目标条件化、人工／模拟／教师／失败轨迹数据、分组留出、校准和闭环验证。样本数、参数规模、频率及性能门槛均为助手实验建议，没有训练或性能证据。
