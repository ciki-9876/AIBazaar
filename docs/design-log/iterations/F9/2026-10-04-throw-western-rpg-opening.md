# 2026-10-04：甩牌现代西方奇幻 RPG 开场

## 来源与决定

- 用户要求现代西方奇幻剧本、像素横版、可控主角、不跳跃、进入建筑、NPC 对话与战斗。
- [ADR-0043](../../decisions/ADR-0043-throw-western-pixel-rpg-opening.md)接替上一版具体包装。[新版剧本](../../../F9_THROW_WESTERN_MAGICIAN_RPG_V1_2026-10-04.md)把用户确定的主线与助手人物、对白、后续幕明确分开。
- [《水银疗养院》官方 Steam 页](https://store.steampowered.com/app/1689080/Mercury_Abbey/)介绍复古像素、美漫式插画、场景光影与拟人动物。本项目借鉴光影、轮廓和横版空间，使用原创人类角色及全新场景。

## 已实现

- `apps/throw/src/lib/adventure/magician-world.ts`：确定性的行动、交互、剧情与任务门槛，独立 `magician-adventure-v1`。
- `apps/throw/src/app/adventure/`：街道、工作室、剧院、角色四帧行走与静立、点击地点步行、键盘／触屏行动、就近交互、对话选择、地图、启程结尾。页面固定在一个视口，聚焦不再造成原生场景滚动。
- `throw-table.tsx`：可注入挑战种子、真实对手、名字、人物素材与返回回调；既有独立练习不依赖冒险层。战前布局与单遗物在本次旅程中保留。
- 首页及 `/adventure` 进入冒险；`/wandeng/throw` 保留练习。`scripts/products.mjs`增加新素材路径，生产包实际包含资产。
- 三张1672×941场景、主角四帧图集与三 NPC 图集均来自内置 image_gen；精修第二帧静立。五张实际使用的 PNG 与初始／精修提示词在 `public/art-assets/throw/western-rpg/`。两张带光晕的独立静立草稿未使用。
- 正式资格赛失败／平局不推进；导师完整练习可完成基础教学且对白明确胜负；退出不发奖。种子按冒险种子与递增对局编号确定，同一次完整输入可复现。

## 验证证据

首轮全仓450项测试通过，含7项冒险流程与确定性测试、既有甩牌规则和黄金回放。甩牌独立类型和 lint 检查通过；三个生产项目构建通过。后续最终检查结果追加在本节末，不把中途检查当最终完整验收。

浏览器实际操作已验证开场三段对白 → 主角步行到门口 → 进入工作室 → 步行到导师 → 对话 → 进入整备 → 开始真实甩牌对战。发现并修复聚焦导致场景隐藏容器滚动的问题。浏览器结果与完整流程模型测试分别记录，不以单元测试冒充人工完整夺冠。

开发服务重启在 `http://localhost:4175/`；首页返回200，初始叙事正常服务端呈现。没有停止其他产品服务。

最终检查：全仓 `npm test` 450／450；甩牌独立 `npm run test:throw:cards` 59／59。全仓 lint、类型、产品边界与确定性检查通过；甩牌独立类型和 lint 通过。三个生产项目完整构建通过，最后的结束界面和触屏调整后再次完成甩牌构建，四条路由均生成。

浏览器完整首章验证：导师练习实际战败，返回后呈现对应教学对白并收到邀请；正式挑战没有出牌而战败时不发参赛证；按同一牌序重试，用现有剧毒构筑、实际点选并甩牌获胜后才获得参赛证。返回剧院、走出建筑、步行至巴士、确认启程，进入第一幕完成界面。全过程没有注入隐藏状态或用剧情代替战斗结果；整备构筑在导师练习与正式挑战间保留。

桌面1280×720、较低屏幕1024×600以及竖屏390×844均核对页面尺寸；场景、完成页、开场对白、路线地图保持在视口内。实际页面高度等于视口高度，场景隐藏容器滚动偏移为0；临时浏览器尺寸覆盖已恢复。最近一次浏览器控制台没有 error／warn。

## 尚未实现与假设

后四幕只是剧本与路线占位，没有完整60–90分钟赛季、冒险保存、商店经济、器具数值养成或世界冠军实装。首次通关、自制牌与 AI 未接入。初始 NPC 对手沿用现有预设，未完成教学难度和资格战平衡。

温馨气氛、被正确报幕的爽感、行走对原有事件节奏的影响与动画长期观感待用户试玩。生成图集是原型，不能认定已经达到逐像素手工校对的最终动画品质。
