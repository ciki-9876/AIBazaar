# F9 战场减遮挡与结算飘字

日期：2026-09-26。用户指出桌面 UI 底板过大、冷却读秒冗余，并要求伤害与修复飘字；授权本会话改动直接发布。

承接：[统一战术桌](2026-09-26-arena-tactical-table.md)。本记录取代该版本的常驻大型路线面板、装备读秒底板和桌面事件短句表现；历史结算与复盘规则不变。

## 决定

- A-08／MC-01 的即时战况以物件、命中位置、数值变化为第一层。详细原因通过点击装备、增幅器和复盘查看。
- 装备冷却使用 26 像素小圆环；冻结、疾速、迟滞、缺弹由小图标表示。移除长冷却条、常驻剩余秒数和被动标签。
- 屏障改为图标加当前值，增幅器使用小按钮，持续效果用图标加层数。移除重复路名、最大值、运转文案、大面积底板与“已破／暴露”文字；破路由屏障缺口与淡化图标表达。
- 战斗默认简洁：名称按关注显示，详细模式可显示名称与桌外事件明细；布阵时保留名称便于认识和比较物件。状态细则留在详情中。
- 伤害、修复和治疗在实际受影响表面飘字，使用正负号、颜色与图标区分。重击字号更大；不添加无事实依据的暴击提示。

## 已实现事实

- 飘字读取已结算屏障吸收、宿主实际损失和有效修复／治疗。屏障与宿主的溢出分开呈现；同帧同位置同类型合并。施加灼烧／侵蚀层数、减伤、无效修复和超出剩余生命的伤害均不冒充扣血。
- 飘字横向位置与投射物命中共用槽位坐标，目标表面区分屏障和宿主。持续伤害保留火焰／液滴图标。
- 飘字弹出、上浮和消失只依赖回放时钟，暂停、倍速、倒回和结算收尾保持一致。减少动态抑制位移与弹跳，保留数值及淡出。
- 没有更改模拟、阵容验证、卡牌数值、档案格式和冒险存档。

## 验证证据

- 144 项测试通过；覆盖溢出分流、叠层不误报、无效修复、全局实际收益对账、不修改帧、回看姿态与收尾消失。
- 50 组原有对照模拟逐帧哈希一致。TypeScript、lint、生产静态构建通过。
- 浏览器验证暂停后飘字位置不变，倒回起点无未来飘字，结算收尾后无残留；减少动态和增幅器详情可用，错误日志为空。
- 实际浏览器检查灼烧、侵蚀、直击、破屏、修复、治疗同时发生的画面，及桌面、全屏、800×900 窄窗；桌上无旧事件卡片或装备信息底板。

## 假设与边界

- 减少底板并突出飘字会让战斗更有冲击力，同时保留基本读局能力；仍待用户试玩验证。
- 飘字寿命 1.35 秒、冷却环 26 像素为本次表现参数，不是战斗数值。高频极端阵容的数字密度仍可按试玩调整。
- 本次属于独立 `/arena` 的表现迭代，不代表正式冒险已接入 3D。
