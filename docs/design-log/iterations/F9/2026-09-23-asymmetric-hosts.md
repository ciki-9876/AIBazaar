# 2026-09-23 · 蜷卧者与异常投影

## 用户决定
采用敌我不对称宿主：敌方为横跨三路、头尾不明的蜷卧者；我方为横向拉长的个人投影。共同使用原有宿主生命，不引入三套局部生命。投影是战术视图表现，不据此宣布主角已异化。

本记录取代 [护命匣切片](./2026-09-23-host-case.md) 的宿主包装。用户否决护命匣（体积不能覆盖三路）和电梯门（遭遇发生在电梯外的房间，且门与屏障概念重叠）。中途门方案未交付、未发布，历史资产保留但运行时不加载。

## 实现
- Blender生成连续躯体、藏在褶皱下的折叠肢体；我方为不同资产的拉长影子。宽度约10.2，对应10.65宽桌面。不是三个独立敌人。
- 实际本体伤害的来源位置驱动局部收缩与伤痕；敌方归零塌伏，我方投影受击处形成透明裂口、归零淡出；减少动态关闭呼吸与抽动，保留状态提示。
- 同路攻击保留发射槽位横坐标，跨路效果才平移到目标路。两格武器以占格中心为发射点。屏障保持全宽，通过透明度和光线衰减表达损伤，归零才消失。
- 攻击终点根据已模拟的实际命中事件选取屏障或本体，避免飞行途中因其他攻击破路突然拐弯。屏障溢出仍在同一真实事件里驱动本体受击。
- 弹弓为粗糙石子；弩为木箭杆、金属箭头、尾羽；支援为脉冲环；刀仍是即时命中，不虚构飞行物。
- 仅切片的Duel快照设置：弩0.5秒、弹弓0.75秒、支援1.25秒。预览、模拟、回放和结算共享配置。是便于观察的风格化时间，不是现实单位速度；正常冒险参数未改。
- 暂停可逐帧前进0.25秒，速度循环1×→2×→0.25×。暂停标识移到边缘，不遮挡弹道。

## 验证事实
- npm test：121项通过（新增槽位不汇聚、两格中心、跨路偏移、武器真实到达时间验证）。
- TypeScript、lint、build通过。构建仍有大于500kB分块提示。
- Agent实际操作：敌阵→上阵缓冲垫→开战→暂停逐帧→继续至胜利。16.25秒检查弩箭，18.25秒检查石子；桌面和640px截图检查；浏览器错误日志为空。
- 相同资源对照：缓冲垫中路，我方损伤26、减伤20；缓冲垫左路，我方损伤50、减伤0。两者仍24秒胜利。该结论不代表所有卡组的速度平衡完成。
