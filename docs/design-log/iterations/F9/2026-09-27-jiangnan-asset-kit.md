# 江南构件集：听雨庭首版

日期：2026-09-27。决定见 [ADR-0021](../../decisions/ADR-0021-themed-kits-and-jiangnan-sample.md)。

## 产出

- `/art/pavilion`：可旋转、缩放和平移的实时三维样板；三套氛围及庭院／月门／飞檐视角。暂停雨景不影响观察操作。
- `/survival`：新第三层使用同一构件集的雨夜版本；木箱继续使用原有物资和翻找规则。保留迷雾、自动攻击、饥渴、返程与单向楼层。
- GM：听雨庭入口、庭院中央两个检查点；中央检查点仅调整调试起点及生活值，不关闭迷雾或战斗。
- 曲面瓦顶和瓦垄、重檐、斗拱、花格、月门、纸灯、帘幡、荷叶与竹木。外围继续生成地面与远景建筑，通过暗色地表和雾过渡。

## 复用方式

`lib/survival-pavilion.ts` 定义短布局配方、保存清单、稳定实例 ID、配色及装饰选择。同一清单产生导航障碍和场景构件，减少视觉与碰撞分别维护的漂移。

`app/survival/pavilion-assets.ts` 是共享构件工厂；`pavilion.ts` 接入雨景及原电梯传送门。样板页和真实楼层调用同一份构件代码。几何按材质合批，雨幕为一组线段；样板静态全景不揭示真实游戏中的未探索区域。

## 验证范围

自动验证包括：三套配方实例身份与碰撞一致；箱子、怪物入口、守卫、中央庭院及应急补给可往返；月门可穿过、实体墙和池水不能穿过；新存档重放一致；损坏的清单被拒绝；旧沙岩快照不会被中国风覆盖。

浏览器检查覆盖三个氛围、近景结构和实际游戏迷雾。进一步的手机 GPU 性能、长期循环和大量随机布局仍未验证。本版不包含通用拓扑生成器和建筑室内。

完成检查：`npm test` 233/233，`npm run lint`、`npx tsc --noEmit`、`npm run build` 均通过。浏览器确认三个氛围、月门／飞檐视角和两个游戏检查点；样板最终渲染无控制台错误。实景截图保存在 `outputs/survival-opening/jiangnan-*.png`。窄屏检查未完成，不据此宣称移动端已验收。
