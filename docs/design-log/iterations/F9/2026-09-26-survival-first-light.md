# 返程终端演出与第一次开灯

- 日期：2026-09-26 开始，2026-09-27 完成验证。
- 依据：[ADR-0016](../../decisions/ADR-0016-lift-host-and-first-light.md)。
- 范围：独立 `/survival` 及共享生存 UI；原 `/survival/waterworks` 继续可用。

## 设计事实与实现

用户指定 17 步返程。首房核心来自实际箱子，有限三怪各掉一份材料；结算读取真实背包、安全容器与装备。能源核心（电容）只能投喂一次，三份 X 保留。画面、音乐与台词由同一剧情阶段驱动；暂停停止剧情和声音。减少动态模式保留顺序，用渐暗代替快速闪烁并取消镜头震动。

电梯初始主灯关闭；屏幕、面板弱照明。投喂后先显示 0→1 进度和感谢台词，再点亮大灯，保持现实轿厢尺寸。地面返程线使用可通行路径、逐帧同步角色起点。菜单、装备、行囊、心声、小地图、终端统一到暗铁旧金暖纸色板；设置中可以查看组件图鉴并重播返程。

旧版修复、赠送电容和强制相邻任务不再接在首次返程后。后续 [18–34 步设计](../../../F9_SURVIVAL_AFTER_LIGHTS_DESIGN_2026-09-26.md)单独作为未实装提案。

## 验证证据

- 自动化全量 205 / 205 通过。新增覆盖实际首房结算、完整演出顺序、150 tick 闪烁、60 tick 停顿、错误/重复投喂原子性、核心消耗与材料保留、感谢后才开灯、序列化恢复、物理轿厢范围及返回寻路。原 fog、拾取、真实背包、相邻和 60/144 Hz 投影测试保留。
- TypeScript、生存相关检查、最终全仓库 lint 与生产构建通过。
- 浏览器实测：从设置重播返程，看到左屏机器人与真实黑孔；点击 3D 黑孔进入双栏基地界面；拖入 X 被拒收、库存不变；实际拖入核心后普通包从 4 变为 3，只留下三份 X；随后关闭升级界面、出现感谢与大灯亮起。
- 正常入口重新经过苏醒、开门、装备电筒、翻箱和三怪战斗；拾取最后一份材料后剩余提示消失，地面虚线随角色移动改变起点与路线。
- 界面图鉴已分别在窄窗和桌面宽度查看；窄窗使用单列布局，桌面使用双栏。屏幕镜头调整过距离以完整容纳实体屏。

## 尚待真实体验判断

恐怖强度、五秒闪烁和近距离屏幕的舒适度、合成音乐/雷声的主观质量、对话读完所需时间，应以用户试玩评价为准。当前不是配音版本；机器人通过气泡和短电子音表达。

原型不持久化刷新存档；设置重播明确重置试玩。首次强制带齐教学掉落仅用于确保指定结算，普通房间仍可自行提前撤离。长期死亡返程、跨局升级经济与空间扩建未在本轮扩展。
