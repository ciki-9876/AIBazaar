# 2026-09-27：护幕、心灯与可读的战斗反馈

后续视觉修订：[精细像素美术](./2026-09-27-wandeng-pixel-art.md)替换图形媒介与字体，本记录中的状态语义、弹道和飘字约束继续有效。

## 用户决定

用户要求修复飘字被棋盘边界裁切、同路弹道汇聚到屏障中心的问题，并为彩色数值增加半透明效果图标、强化屏障图案、区分卡牌品质、设计宿主形象。

本轮只改变展示。50 张机制牌、10 种增幅器、三路九格、原战斗结算和回放继续遵循 [ADR-0017](../../decisions/ADR-0017-wandeng-arena-baseline.md)。不修改卡牌强度、赎回经济、实例身份或存档。

## 采用的表达与历史边界

- **恢复既有包装**：屏障是物灵联结形成的“护幕”，出处为[归物师核心 v0](../../../F9_WANDENG_SOULS_CORE_DESIGN_V0_2026-09-26.md)的战斗包装。本次增加缝线、织纹、灯结与横跨路线的帘状轮廓。剩余生命控制亮面宽度；低完整度出现裂缝，破幕后织物消散。仍显示屏障数值，不引入额外资源。
- **本轮助手提出并实装、审美待验收**：宿主表现为“心灯”，每方一盏灯，联结光带延伸到三路。灯光随真实生命减弱，低生命显露裂纹，归零熄灭。三个命中区域属于同一宿主，不是三份独立生命。
- **用户明确的新要求**：数字背后增加剑、火焰、骷髅、治疗心形、修复盾牌五种半透明标识。数字保持银、橙、深绿、亮绿、黄的效果语义，效果数量仍可扩展换行，独立冷却不变。这局部取代 [ADR-0006](../../decisions/ADR-0006-integrated-colored-numbers.md) 的无图标约束以及[上一轮 UI](./2026-09-27-wandeng-cozy-ui.md)的纯数字方案。
- **语义不偷换**：骷髅对应既有侵蚀机制；没有把降低屏障上限改成持续扣血毒伤。卡面展示基础输出或施加层数，战斗飘字展示真实结算量。
- **品质不只依靠色点**：普通灰纸框、稀有蓝釉框、史诗紫色压纹、传说金箔边和炫彩干涉膜形成五档材质。边缘厚度、内框与纸层阴影加强触感；只有炫彩附带缓慢流光，减少动态设置禁用装饰动画。数值颜色不跟随品质改变。

## 战斗的可观察性约束

1. 同路攻击的命中横坐标必须等于发射卡的横坐标；一至三格卡、敌我方向均适用。弹道携带的附加控制目标不能把直接伤害改画成打牌。
2. 命中尚存护幕；破幕当次仍命中实际承伤的护幕，后续伤害穿至宿主。一次破幕产生的护幕损失与生命溢出分别显示。原规则明确跨路的卡仍跨路。
3. 飘字不随棋盘边界消失，只按原回放时间和生命周期移动、淡出。它们脱离棋盘滚动裁切；弹道仍受水平方向的战桌范围限制。窄屏离屏路线不产生覆盖其他 UI 的飘字，已经发出的数字可以越过棋盘边缘。

这些修正验证的是 A-08 的因果可读性，不是新增战斗规则。

## 证据与限制

- 218 项测试通过，包括本轮增加的三组几何回归：双向同路与多尺寸、跨路/支援、破幕与生命溢出。全项目 lint、TypeScript 检查及生产构建通过；构建仍有既存的大包体积提示。
- 实机旧回放 4.5 秒确认同路弹道与发射卡横坐标一致；10.5 秒确认破幕与宿主生命 103/190，护幕损失 50、溢出生命伤害 87 分别呈现。
- 1440×1000 和 390×844 布局检查：窄屏棋盘保留内部横滚，独立效果层不撑宽文档。共享 `/arena/2d` 能完成原阵容战斗并显示原宿主与复盘。
- 越界核验：共享战桌上边界位于屏幕 y=255.5 时，生命损失数字顶端已到 y=228.4，仍在视口内并保持原回放透明度；不再在经过棋盘边界时截断。
- 实机图位于 `outputs/wandeng-qa/soul-battle-board.png`、`soul-card-rarities.png`。
