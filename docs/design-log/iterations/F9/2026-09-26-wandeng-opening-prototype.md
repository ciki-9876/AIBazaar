# 2026-09-26：归物师开场与终局送达原型

## 用户事实与决定

玩家败后扣钱赎回、不丢物；不预定收件需求，终局统一送整套物品；主角背景四格漫画；实装进入、介绍、师傅对战教学、来信、启程、事件卡片与阶段 BOSS。见 [ADR-0014](../../decisions/ADR-0014-wandeng-ransom-and-opening.md)。

## 原型实现

独立 `/wandeng` 路线贯通四格漫画、教学实际摆牌、现有引擎自动对战、三街区九个选择节点、三位 BOSS、最后送达。原子经济、保留成长的敌方实例转移、本地书签接入。新增六幅故事插画和十二件纸纹彩铅物品，美术与 HTML 信息分离。

完整范围、操作、数字和代码入口见 [系统原型记录](../../../F9_WANDENG_PROTOTYPE_2026-09-26.md)。旧归家 v0 与 ADR-0012 保留，明确追加后续决定指针。

## 设计假设

只失路费能保住对伙伴的培养感；统一终局送达能让战力成长和温情收束各得其所。旅途的爽感来自真实数值增长、组合强化与越来越强的守关人，不依赖剧情强制掉落。以上仍需玩家体验，不能用自动测试替代。

师傅垫付、收入优先还款、BOSS 未胜后追加一次街边整备，是本轮为保证恢复路径采用的补充规则。成本为失败压力可能偏弱，正式平衡时需验证。

## 证据

- 七项新规则测试通过，覆盖全部用户规则、原子失败、存档重放与三位 BOSS 真正可通关。
- 类型检查、lint 和生产构建通过。
- 初次全项目测试 189 项、187 通过，两项电梯开场测试失败；该模块被另一开发流程更新后，最终重跑 196 / 196 全部通过。本轮未修改电梯实现。
- 浏览器完整走通四格漫画、实际摆钟教学、来信启程、九次免费修缮、三位 BOSS 和十件物品终局统一送达。放映机从 75 直伤成长到 129，实际通过三位 BOSS；第二、第三位 BOSS 获得的实例保留 1 / 2 级。
- 最终 BOSS 战中刷新后从书签恢复，结算路费从 38 到 48，没有重复领奖。标题返回、另开旅途确认、终局不能继续战斗均完成实际检查。
- 窄屏 390×844 验证标题、漫画和教学；棋盘局部横向滚动，不造成整个页面溢出，可实际放置座钟。默认视口已恢复，浏览器控制台无错误/警告。
- 实机截图保存于 `outputs/wandeng-qa/`，不能据此宣称用户美术验收通过。

## 尚未验证

未做真实用户试玩，不声称美术已获接受、剧情节奏已确认或完整长局平衡已成立。图鉴与局外解锁未实装；原型固定首发种子，后续可在保持确定性的基础上扩展随机旅途。
