# 3D 箱庭探索 demo · 2026-09-23

## 需求与决定
用户要求将电梯外逐节点探索改为一个个 3D 箱庭房间，先制作 demo。
本轮提供独立 `/art/rooms`，正式冒险和存档不变。采用固定斜俯视剖面、物件点击交互与房门移动；暂不引入角色行走、寻路、自由镜头。此选择是本轮原型方案，尚待用户验收。

## 可玩内容
电梯前厅 → 储物间 → 低压泵房 → 守卫房间 → 沿原路归返。

- 储物间：点击工具箱，开盖后获得补漏胶与未鉴定缓冲垫，仅发放一次。
- 泵房：直接点击三段管道旋转，连通后恢复供压。基础 8 步；补漏胶可消耗一次增加 4 步，不是通关前提。重置不退还已消耗工具。
- 供压恢复后房门打开，获得单次鉴定仪；行囊中可将缓冲垫鉴定成稀有皮质缓冲垫。
- 守卫房间：调查装备台进入现有真实 3D 战斗切片，鉴定的卡牌进入备用卡列表，可布阵、自动战斗、领取卷簧弩并返回原房间。
- 已搜索、供压、战利品和行囊状态在往返中保留。回到电梯显示本次带回物品。

## 运行
在项目根目录运行 `npm run dev -- --port 4173`，访问 http://localhost:4173/art/rooms 。当前本地服务已运行。

- `npx tsc --noEmit`：通过。

## 范围与后续
这是压缩成四个空间的探索形式原型，不是既有六节点新手流程的替换。管道玩法简化为三段转向；未接正式精力、经济、随机楼层、存档、鉴定仪式动画和全部教学。
复用已有装备与核心 GLB，房间为程序化块面美术；房间布局暂时同尺寸，缺少专业纹理与完整音景。战斗采用已有独立切片，战利品在本 demo 中仅供带回展示，不开放下一场配装。
后续先验收镜头与物件操作，再决定房间尺度差异、分支/隐藏物、移动模式；不在本轮扩建关卡系统。
