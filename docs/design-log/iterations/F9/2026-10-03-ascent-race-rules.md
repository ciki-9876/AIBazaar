# 2026年10月3日 百层竞速与阶段上升规则

## 用户要求

用户明确与AI竞争抢先到100层的大目标，比较升级电梯解锁楼层与消耗通行证选择跨层距离两个脑洞。要求结合真实选手博弈讨论，没有选择具体方案或授权实装。

## 分析与建议

[完整提案](../../../F9_ASCENT_RACE_RULES_PROPOSAL_2026-10-03.md)比较清晰成长、刷取效率竞争、领先滚雪球、跳过资源和选手错层等问题。建议通行资源决定实际前进，升级保留为长期能力；共享资源目标与少量必经节点承载交涉和晋级。限制低层囤票、保留有代价的重复取得途径、全体共同时间与公开胜负为建议边界，未实装。

目标见[ADR-0026](../../decisions/ADR-0026-race-to-floor-100.md)，承接[ADR-0025](../../decisions/ADR-0025-llm-contestants-and-elimination-experience.md)。小赛段验证优先于直接扩展100层内容。
