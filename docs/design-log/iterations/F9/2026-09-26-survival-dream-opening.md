# 生存版：梦中荒原开场

日期：2026-09-26。依据：[ADR-0013](../../decisions/ADR-0013-dream-wasteland-opening.md)。

## 目标与用户决定

完成用户明确描述的 20 步开场：进入 → 睁眼 → 发现电梯 → 困惑气泡 → 拿手机 → 无信号收回 → 想开门 → 右侧按 E → 运镜俯视且只余门 → 碎石荒原 → 捡并装备电筒 → 翻箱 → 怪声 → 惊觉气泡 → 三怪边缘出现 → 装备栏与双光束 → 物品自动攻击的惊讶 → X 材料掉落 → 想回家 → 回到电梯。

## 已实现与复用

- `/survival` 为新开场；原水处理站完整试玩保留在 `/survival/waterworks`。
- 沿用冥河庭院方向的分段光影、轮廓、暗绿和旧金配色，复用真实比例轿厢、黑烟、广告屏、开关门及出入运镜。
- 睁眼、手持 3D 手机、无信号屏幕、内心气泡、右墙空间按键引导；战斗前不显示常驻 HUD。
- 小型确定性荒原、低矮碎石边界、杂草、单独的跨界门；复用路径移动、箱子翻找、真实占格装备、自动结算伤害与掉落拾取。
- 怪声先于怪物；只产生三只虫形怪物。装备栏在遭遇时弹出，手机冷光、电筒暖光各自攻击，不是定时播放的假击杀。
- 结束后回到第一人称轿厢，实体广告屏显示实际带回的 X 材料数量。回家前掉在地上但没拾取的材料不会被算作带回。
- Esc 暂停、静音、减少动态、重新体验。切走窗口暂停，以免错过台词；减少动态关闭眨眼反复收拢和装备栏滑入。

## 证据与待验证

自动检查：182 项测试通过，其中 6 项为本段新增，覆盖阶段顺序、提前交互拒绝、三怪只生成一次、真实双光束与唯一掉落、自然搜刮与返程、序列化复现、教学边界以及普通房间规则不被覆盖。规范检查、类型检查和生产构建通过；构建仍有大包体提示，未把首屏载入与低端设备性能当作已优化完成。

实机观察：已从入口进入、查看手持无信号手机、按右侧提示开门，进入无 HUD 荒原并看到独立门；拾取并装备电筒，翻箱触发虫形怪物与真实光束，收集掉落，再返回轿厢。屏幕阅读文本和左墙实体屏均显示带回 3 份 X 材料。确认鼠标进入、地面点击、E 交互、Esc 暂停与重播可用。怪声通过事件和合成音频代码核对，尚未作听感验收；窄窗口生成位置有回退处理，但未完成全分辨率实机覆盖。

实机截图位于仓库忽略的 `outputs/survival-opening/`：`01-right-panel.png`、`02-wasteland-door.png`、`03-encounter.png`、`05-materials-home.png`。截图是检查时的真实渲染，不是概念图。

待用户验收：开场台词停留时间、怪声的惊吓程度、暗处物品发现率、是否容易记住返程方向。角色仍使用当前简化模型，音效为程序合成占位，未把美术与演出首版当作最终成片。

## 后续边界

当前停在第一次回电梯。X 材料用途已表达，但命名、升级成本、设施功能、跨次出勤存档和后续剧情没有在本轮擅自扩展。旧两次出勤提案保留历史，后续按新叙事再决定如何复用。
