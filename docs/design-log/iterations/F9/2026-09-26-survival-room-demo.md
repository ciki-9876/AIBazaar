# 2026-09-26：新版房间战斗单场切片

状态：已实现可运行实验；流程与规则检查通过，玩家体验待验证。

## 事实与授权

用户在纯单机、走位搜刮、自动道具战斗的讨论后，要求开始新版房间战斗 demo。继承 [ADR-0001](../../decisions/ADR-0001-elevator-survival-extraction.md) 的普通背包失败全失、安全容器保留、不依赖弹药时限约束，以及 [ADR-0002](../../decisions/ADR-0002-single-player-ascent-and-rivals.md) 的纯单机定位。此请求没有确认完整成长经济、竞争者行为或共同逃生故事。

## 本版实现决定（实验范围）

- 独立 `/survival`：一间有遮挡与绕行的水处理站，用俯斜视角 3D 呈现即时战斗。
- 操作集中于移动、停留搜刮、背包取舍与返回电梯；武器自动运行，拾取立即增强战斗力。
- 普通怪物持续补入，房间资源点和可选 BOSS 有限；击杀小怪不产资源。这样先验证「离开门口寻找东西」，尚未验证用户提出的层间资源效率循环。
- 拾取装备占普通背包，死亡损失；放进安全容器后停止战斗效果。基础钉枪作为本次切片初始能力，不是战利品。此范围限定不替其他版本决定装备损失方案。
- 开包与离开窗口暂停。食水和医疗按阈值自动使用实际持有的物品；生活消耗和搜索疲劳形成长留压力。
- 返程需真正移动到电梯并完成可打断的短引导；失败和成功显示不同保留物。

详细操作、可执行边界和规则见[试玩说明](../../../F9_SURVIVAL_ROOM_DEMO_2026-09-26.md)。

## 机制组合

MC-03 的实时搜刮变体：电梯出发 → 路线选择与持续走位 → 停留搜索承担接近风险 → 装备增强与容量占用 → 继续深入或返程 → 撤离兑现 / 失败保全。

沿用 A-01 的确定性、A-07 的原子结算、A-08 的可观察自动战斗、A-09 的风险回收。位置取舍发生在场景距离、遮挡与路线中，不是三路卡牌占格。

## 假设与未解决问题

- 假设：范围不同的武器足以让路线和走位有差异。风险：两个装备叠加后可能只剩站桩。
- 假设：有限物资与持续威胁可形成主动撤离。风险：所有资源拿完后没有继续停留价值，这不能证明完整楼层刷取成立。
- 假设：保护装备意味着暂时放弃战斗力。风险：暂停整理可能鼓励频繁切换而非真正承诺，需要玩家试玩。
- 假设：三项生活数值共同影响远征。风险：仅水更早见底，其余数值可能冗余；本版没有因此确认最终需要保留三项。
- 房间使用外围通风口且排除贴脸刷新，尚非围绕玩家动态生成范围；需在更大场景中验证。
- AI 竞争者、多楼层、资源效率成长、局外建造、精神状态与故事动机均未实现，也未被本轮否定。

## 证据与验收边界

- 规则检查覆盖相同输入复现、序列化续算、移动碰撞、绕路、搜索只结算一次、满包不吞物、容量失败原子性、保护装备停止发动、死亡损失与安全容器、撤离打断、BOSS 单次奖励、刷怪预警、真实补给消耗。
- 全仓 `npm test`：155 项通过；`npm run lint`、`npx tsc --noEmit`、`npm run build` 通过。构建保留现有大包提示，未阻止生成 `/survival`。
- 浏览器已操作验证拾取两件自动装备、波次持续运行、安全容器存取、自动装备状态改变、暂停、绕行返回电梯与完整撤离结算。1280×800、800×900 窗口检查通过。
- 一次浏览器样本中，两件装备齐全后在电梯入口附近停留，至 4 分 11 秒撤离时仍为满生命；说明当前配置的入口站桩压力偏低。该样本不代表所有路线和驻守者战斗，下一轮需比较空装、单装、双装的走位收益与怪物接近压力。
- 第二次浏览器样本中，两件装备齐全进入东侧深处后唤醒并击败驻守者，生命降至 43，现场出现并搜取单件净水机芯；随后拾取急救包，自动消耗后生命恢复到 88、背包占用不增加。证明可选目标、有限奖励与真实补给的链路可运行。没有躲避的样本不能用于衡量玩家操作上限。
- 工程通过只证明规则执行和界面可操作；不证明平衡、长期动机、沉浸感或用户偏好已获认可。
