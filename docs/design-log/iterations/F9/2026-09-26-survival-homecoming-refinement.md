# 2026-09-26：荒原体验修正与返程教学

## 决策与事实

用户要求方块手、荒原迷雾与手电视野、黑雾边界、材料即时拾取、所有拾取飘字、稳定 3D UI、低亮度技能，并授权继续设计返程后的引导。规则与假设分别记录在 [ADR-0015](../../decisions/ADR-0015-wasteland-fog-and-first-lift-repair.md)，对应 [MC-03](../../01_DESIGN_DNA.md#mc-03-电梯楼层机制组合) 的搜刮—回收—成长闭环。

本轮让第一次带回资源形成可操作的结果：终端识别未知材料、修复供能、打开一次性应急舱、获得电容、调整真实相邻关系、选择保护物资、带着原装备再次出发。第二次出勤复用水处理站，不再从默认钉枪配置重置。

## 实现边界

模拟仍为固定 30 Hz、确定性身份与序列化。镜头、角色与 UI 共用前后帧插值和同一相机投影，屏幕坐标不取整；视觉插值不反馈到寻路、碰撞、视野或伤害。物品飘字来自实际转移事件，不能凭打开容器或触碰满背包重复发放。

荒原仍是小型、有限三怪的教学例外；实际碰撞边界保持，画面以渐隐黑雾遮挡。黑雾不替代实体遮挡判断，电筒不会穿墙揭示怪物。

## 待验证假设

给一个有明确来源的电容是否能让玩家自然理解相邻机制；修复 1 X 是否比一次消耗全部材料更有保留与保护的取舍；第二次出门再展示小地图与行囊是否减少开场信息压力。上述均待用户评价。
