# 迭代：先用一把刀理解战斗，再让战利品改变下一步

日期：2026-09-20。用户明确修订前三间节奏。本记录取代[上一版首次出勤](./2026-09-20-first-floor.md)中新开局的先搜刮、三张初始牌和数字阀门方案；历史记录与旧档保持原样。

## 决定

单刀首战 → 两件实体+鉴定仪 → 转化钉枪并上阵 → 用留下的缓冲垫操作图形管道 → 敌情与守卫 → 归返。引导期不开放提前撤离或主动回收。初始补给资源保留，减少的是装备与工具，不是出勤所需资源。

## 可迁移机制组合

先给最小可用解，建立可观察的战斗基线；再发放两种去向明确的战利品，一件进入战斗能力、一件进入环境交互。下一间立即兑现未转化实体的用途。以真实出手/命中事件暂停解释，把规则绑定到发生中的证据，而不是进门先展示说明书。

## 事实与证据

20个种子自然取得同一组教学战利品；单刀首战13.25秒胜利，宿主无伤。两把武器可完成守卫战。管道成功让精力80→87，工具保留。真实UI完成拾取、扫描、装备、旋转、提交和布阵返回；桌面/窄窗截图见[实现与验收](../../../F9_GUIDED_OPENING_2026-09-20.md)。

## 假设、取舍与待验证

假设：先经历单刀、再看新增武器，比起始塞三张卡更容易感知成长。假设：把实体用途兑现到下一间，比孤立物品说明更易理解。两者均缺独立玩家证据。

选择可旋转的连通机关而非三消或QTE：操作与热管道包装一致，无需另一套补充规则或反应时限。代价是首趟选择较少、机关简单。完整自由鉴定在引导之后恢复；本轮不把简单教学当成长期机关深度。

首趟回家、后续系统逐步解锁尚待与用户对齐。本轮不是全部新手引导终点。
