# 2026-09-27：归物师奶油纸与旧物收藏册 UI

后续修订：[护幕、心灯与战斗反馈](./2026-09-27-wandeng-soul-battle-feedback.md)按用户新要求为数字增加半透明图标，以五档边框材质强化品质，并补齐战斗图形。以下保留本轮历史实现和验证结果；纯数字和仅色点品质方案被局部取代。

## 用户决定与范围

用户提供物品制作图鉴参考，要求将 UI 改成该风格。参考中的可执行视觉特征是奶油黄纸底、暖棕圆润文字、连成一排的圆形分类、橙色当前标签、带柔和阴影的白边物品卡、右侧详情和虚线分隔。

本轮替代 `/wandeng` 原有偏灰绿、书法标题和薄线框的界面外观。保留此前的旧物手绘插画与漫画内容，没有决定改成动物卡牌，也没有重新设计游戏系统。原 50 张卡、10 种增幅器、三路九格及确定性战斗继续按 [ADR-0017](../../decisions/ADR-0017-wandeng-arena-baseline.md)。

## 已实装的呈现决策

- 标题、旅途、教学/叙事面板、卡牌、战桌、回放和弹窗共用奶油纸、暖棕文字、橙色操作重点、圆润白框与胶囊按钮。
- 图鉴改为左物品格、右详情。顶部按原八种定位筛选，加全部入口；名称/机制检索与分类取交集。选择物品联动占格、冷却、稀有度、基础数值、原始规则、故事与可展开细则。
- 图鉴勾选仅代表本次行囊内拥有，稀有度用独立色点/标签；不增加收藏解锁、收藏奖励或最爱系统。
- 卡底保留可换行的纯类型色核心数字，数量不受占格限制。暖色界面不改银色直伤、橙色灼烧、深绿侵蚀、亮绿治疗、黄色修屏的含义；独立冷却继续可见。
- 灯笼与心形底纹为代码绘制的原创装饰。手绘物品图的边缘柔化融入卡底；没有复制参考游戏的图标或物品资产。
- 窄屏采用三列图鉴、下置详情；三路战场保留足够卡面宽度，在战桌内横滚。系统减少动态偏好禁用装饰动画和位移过渡。

## 实现文件

- `app/wandeng/wandeng-cozy.css`：局部主题及响应式收藏册布局。
- `app/wandeng/page.tsx`：加载主题。
- `app/wandeng/wandeng-experience.tsx`：图形化常驻导航入口。
- `app/wandeng/wandeng-battle.tsx`：收藏册交互和弹窗关闭图标。

没有修改战斗引擎、卡池、存档或局内经济。图鉴筛选和选中状态只在弹窗中存在。

## 证据与边界

- 原有 206 项测试通过，生产构建通过；万灯城文件的定向 lint 通过。全项目 lint 在另一处 `app/survival/base-upgrade.tsx:38` 报 TS2554，本轮未改该文件。构建仍有原有大包体积提示。
- 实机核查 50 张图鉴、分类和检索交集、无结果恢复、自动展示第一条匹配详情、选中联动、Escape 关闭。
- 现有旅途读取成功；1/2/3 格对阵、同一卡的直伤与侵蚀数值、独立冷却和全部 10 项增幅器入口可读；回放仍读取原对局输入。
- 请求 1440×1000 和 390×844 视口进行布局检查，窄屏页面无横向溢出。浏览器缩放可能使实际 CSS 可用宽度更小。
