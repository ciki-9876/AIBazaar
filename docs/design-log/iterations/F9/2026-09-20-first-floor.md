# 迭代：首次出勤先完成一次短远征

- 日期：2026-09-20
- 影响：A-03、A-06、A-08、MC-03
- 决策依据：用户认可首次首页后，明确授权按已讨论的第二段节奏实装。
- 实现与验收：[第一层交付](../../../F9_FIRST_FLOOR_2026-09-20.md)

## 体验问题与假设

旧第一层9—11节点，首战前已经出现工具与机关，首次完整归返较晚。假设：缩短首趟、先见一次战斗再兑现工具用途，能让玩家先掌握“出去并带回来”，为回家转化提供具体对象。五间是本轮设计选择，不是测量出的最佳房间数。

## 决定与机制组合

新开局1F：少量可拾取实体→普通战观察→耐用工具恢复精力→守卫前室查看敌情→守卫战与事件证据→返回电梯。先让消耗产生恢复需求，再由背包实体兑现用途；保留本体使后续转化有真实落点。把商人、精英、多类机关和随机封锁战留在后续常规楼层。其他目的地仍可展开选择。

此记录限定并取代2026-09-18物品文档中“所有新楼层9—11节点”的1F部分；历史文档保留，旧存档路线保留。其余楼层不变。

## 已确认事实与证据

20个种子初始阵容自然流程均能完成并保留工具；正常UI种子10909走完首趟，生命次数12、返家精力76。前室敌情与开战相同，构筑往返不扣路费。97项工程测试通过。完整证据见交付文档。

## 未验证与边界

独立新玩家能否自然理解物品用途、战斗证据和归返仍待观察；没有统计宣称。首趟刻意减少选择，代价是随机性和购买决策减少。第二次出勤、首次回家引导、完整系统解锁尚未设计定稿；本轮不认定整个新手引导结束。
