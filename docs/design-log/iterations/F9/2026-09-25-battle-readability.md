# 2026-09-25 · 战斗空间与可读性实装

## 决策

用户接受按“镜头与屏障位置 → 棋盘画幅与三路关系 → 生命、冷却、命中反馈 → 拖放手感与核心演出”的顺序完成迭代。

本记录接续[评审与提案](./2026-09-25-battle-readability-review.md)，将其中批准的表现方向落到独立原型。此前屏障位于双方装备之间的空间实现被取代；历史记录保留。

## 已实现事实

- 第一人称进入房间，高位固定视角读棋盘；布阵与战斗不改变观察轴。
- 各自屏障位于各自装备后、核心前；三段覆盖连续核心。投射物、反馈、HUD 使用同一表现坐标来源。
- 关联路线、核心生命、屏障状态、冷却与真实命中结果直接可见；细节按需查看。
- 完整占格预览、失败原因、取消和落地确认。详情固定在棋盘外，恢复暂停前状态。
- 核心局部受击和持续伤痕由真实事件驱动；不改变战斗模拟契约。

## 证据与验证边界

130 项工程测试、lint、类型检查与构建通过。实际浏览器走通完整流程，并检查 1280×720 桌面与 800×900 窄窗；测试了不合法放置、取消、移动、交换和播放状态恢复。参考对局仍为 24 秒、我方损失 26、实际减伤 20。

以上为 Agent 定向 UI 复测，尚无独立新玩家证据。更高可读性是否减少理解错误仍为待验证假设。手机和低端硬件未验收；用户尚未验收这一版视觉与手感。
