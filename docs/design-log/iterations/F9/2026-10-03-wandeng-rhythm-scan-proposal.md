# 2026-10-03：归物师节奏线对决细化提案

后续：用户认可方向，补充「每圈首次扫到卡立即触发并重置冷却」并授权开发。见[ADR-0030](../../decisions/ADR-0030-wandeng-rhythm-first-entry-demo.md)与[实装规格](./2026-10-03-wandeng-rhythm-demo.md)。本文保留历史提案；新版取代格中心固定发动／速度间隔绑定的建议，每圈九次不再是一般不变量。

## 范围、事实与状态

用户选择继续探索双方节奏线：连续扫过各自卡牌区，按节奏线触发间隔发动当前位置卡牌，以节奏线和双方生命承载观看焦点；三路与屏障可以移除。见 [ADR-0028](../../decisions/ADR-0028-wandeng-rhythm-scan-direction.md)。

用户没有逐项批准下列规则，也没有要求本轮开发。现行训练场仍是三路、护幕、独立冷却，旧规则、原50卡、六张训练卡及回放保持其版本语义。[上一轮候选](./2026-10-03-wandeng-combat-attention-proposal.md)保留历史状态。

## 体验假设

玩家为物灵编排一段合奏，观察准备、出手、兑现和恢复。固定行动顺序为下一次爆发提供期待，位置成为时间上的安排。温馨世界可以把线包装为心灯发出的共鸣光，不要求玩家按键打拍子。

这是假设，不能由单屏布局检查或静态效果图证明。目标仍是看懂主要胜法、主要威胁、辅助贡献，并能在失败后调整。

## 1. 第一版建议规则

| 项目 | 未批准的助手建议 | 理由 |
| --- | --- | --- |
| 场地 | 双方各一条固定九格横列 | 保留1/2/3格的空间取舍，去掉三路防线；九格沿用容量而非新测量 |
| 扫描 | 左到右，视觉连续移动；每拍走一格，在格中心发动 | 不让1格牌因采样相位永久漏触发 |
| 周期 | 初始每拍1秒，一圈9秒 | 用户例子用于演示，不是已测数值；首拍可以在开场半拍后到达首格中心 |
| 回卷 | 扫完右端后回到左端，无额外结算或空拍 | 第十拍重新发动首格；首尾不算物理相邻 |
| 空格 | 占用一拍但不发动 | 空置不能把整圈压短，防止少放牌免费提高发动频率 |
| 尺寸 | 每个占格有一次发动机会 | 1格每圈1次、2格2次、3格3次；不能额外再无条件乘尺寸伤害 |
| 卡牌冷却 | 不再普遍使用各卡独立秒表 | 扫描决定发动，避免线到了还等另一套计时器 |
| 双方 | 初版同速同相位，上下两线对齐 | 同一竖向区域成为焦点；同步不等于按我方先执行 |
| 胜负 | 只保留双方生命；本拍共同结算后判定，双零可平局 | 避免隐性先手顺序；具体生命和判负制度尚待讨论 |

扫描的视觉位置可以插值；逻辑按固定拍点和格中心确定当前物品。不能通过渲染帧率或浮点边界决定发动哪张牌。未来若变化节奏间隔，也应联动下一格的移动时间，先保留每格被扫到的保证；独立改变移动速度与发动频率属于另一种待验证机制。

示意沿用六张物品的尺寸，**只说明占格和顺序，不说明旧牌效已迁移**：

```text
占格：[ A ][ B ][ B ][ C ][ C ][ C ][ D ][ E ][ F ]
拍号：  1    2    3    4    5    6    7    8    9
发动：  A    B    B    C    C    C    D    E    F
```

## 2. 多格牌的机会成本

九格填满时，每方每圈总共九次扫描发动，与实际卡数无关。3格牌用掉三次机会，也占掉两件其他1格牌可能提供的不同功能，不能同时默认获得3倍单次效果。

大卡可以每拍重复同一效果，例如茶壶连续两次攻击；也可以明示分段，例如大型放映机的三个占格依次装片、聚光、投射。分段必须有可见进展，不能让前两拍变成不明原因的无效等待。整圈效果预算、暴发时间与支援位损失需要共同评估。

首版尽量让所有上阵牌都有扫描发动效果，被动作为附加条款。纯被动牌占用扫描拍却不行动可能形成额外取舍，但会制造冷场，不适合作为主池的默认结构。

## 3. 一拍的因果边界

建议顺序：读取本拍开始的双方状态 → 选中各自当前卡 → 应用已存的强化与有限附加效果 → 共同结算伤害、治疗和本拍状态损失 → 更新受击储能与后续拍的准备 → 判定胜负 → 展示本拍主要因果。

同拍对方攻击不会抢先阻止已经选中的我方发动；新获得的受击能量用于后续拍。治疗参与本拍结算，生命上限、实际伤害与吸取分配需在执行规格中另行明确，不能依赖动画播放次序。

每方每拍只有扫描卡能发起完整发动。被动可记账或给当前发动附加效果，但不能无上限让远处卡牌完整出手。初版建议每件支援物每拍最多贡献一次，支援不再次触发支援；防止火柴响应邻居、邻居再响应火柴的循环。

附加灼烧、增伤和修补在同一个动作中展示贡献。它们仍需在回放中保留真实来源，不应为合并画面而隐藏结算。额外完整发动、分裂扫描线和多层连锁暂列后续候选，不能混入此基线后再宣称单焦点已成立。

## 4. 数值、状态和防御

- 卡面仍允许同时显示多种彩色核心数值，沿用粗体和效果图标。战中弱化未扫描卡的细节，指向或暂停可读全文。
- 支援优先写成“接下来两次发动”或“本圈后续物品”，避免每件牌额外管理4秒、6秒等临时到期时钟。哪些发动消费增益必须明确，例如仅攻击发动。
- 灼烧与毒在公共拍点跳伤，同类先合计展示；新附加的状态从下一拍开始结算，避免发动当拍重复跳伤。持续时间、衰减、清除规则为后续设计，不自动继承旧公式。
- 删除护幕后，修幕不再有合法目标。可重设计为治疗、下一拍减伤或一次性抵挡；不建议另设多条可补充护盾血条来重复原有观看问题。
- 同拍多个实际命中应有限聚合受击通知，避免“每次受伤储能”被弹道数量而非有效威胁放大。具体通知口径要随新规则批准，不静默改变旧训练牌。

## 5. 构筑为什么仍有深度

1. **爆发前置**：储能物在输出大卡之前，给后两次攻击供能；大卡连续发动可以把一次准备兑现为清楚的一段暴发。
2. **续航排序**：治疗放在预计承伤之后，攻击或减伤放在对手暴发对应的拍附近。敌方顺序公开，交换位置能改变对局，而非只更换数值。
3. **分段成长**：大型物品连续完成准备与释放，玩家围绕它的关键拍安排增益、净化和其他输出；局内培养改变整圈表现。

物品之间可以按实际左右紧贴判相邻，跨越空格不算相邻；首尾不因回卷变成相邻。时间上的“下一次发动”与空间上的“相邻”必须分开描述。敌我对齐的列仅用于观察对应拍，不重新引入独立路线或列屏障。

现有手炉、茶壶、针线团可作为新体系的形象例子：手炉受击积攒暖意，扫描时强化后续攻击；茶壶占2格，连续回敬两次并恢复生命；针线团扫描时治疗。**这涉及修幕与冷却重设计，只是提案，不是保留旧效果的开发承诺。**梳妆镜与风铃尤其不能直接删除原目标字段后继续沿用原卡文。

## 6. 值得后续探索的节奏操控

方向、停留、回响及快慢可成为新构筑轴，但每种都应保持一个扫描焦点、公开预告和有限次数。例如停留一拍重复当前卡，同时延迟后续卡；反向使同样的队列形成另一种准备与兑现关系。不能先加入多条独立扫描线来追求强度。

初版先保持双方同速，避免变速再次制造注意力分裂。提高速度不能无限叠加压缩到不可观察；可以考虑将过量加速转换为单次效果成长，但具体阈值与换算均未设计。

## 7. 表现与体验验证

建议双方横列上下排布，心灯与生命位于中间；同步线提示当前拍，下一张预亮，其他卡保持低动态。当前卡出手、支援的短促指向、心灯一次合计反馈形成有限动作链。声音只辅助节奏，静音也能理解。

最重要的风险是固定循环变成机械播片，或最优顺序永远不变。应以公开敌阵、暴发时点和短暂防御让位置形成应对；再观察玩家是否愿意看下一圈。治疗拖延、大卡重复强度和纯被动冷场都需真实对局验证。

首个候选实验：固定九格、同步1秒拍、少量扫描有效的新牌，只覆盖直接攻击、治疗、储能和有限增益；与旧训练场独立比较。观察首次观看是否能预告下一次关键输出、指出支援来源，以及失败后是否主动重排。完整毒火控制与50卡迁移不应先于这些验证。

本轮仅阅读相关设计资料并记录提案，没有新规则实现、运行测试或新版本试玩。上述数字均为演示占位，没有平衡认证。
