# 2026-10-03：归物师战斗关注点与观看体验候选

## 用户反馈与本轮范围

用户在单屏对战布局调整后指出：信息多而乱，关注点反复切换，没有重点；自动战斗依赖观看，如果观感不好，玩法价值会受损。用户要求大胆脑暴，允许讨论现有框架之外的方案。

这是一次实际体验反馈，不是独立玩家群体研究。单屏布局的浏览器边界检查只证明完整取景，不证明信息能被理解或观看有趣。

本轮仅提出候选。没有选择新规则，没有修改引擎、卡池、存档或回放，也没有撤销此前[恢复原战斗基线的决定](../../decisions/ADR-0017-wandeng-arena-baseline.md)。

## 现行事实

- 双方各三路九格，六道独立护幕，两个核心；卡牌有独立周期与邻接、跨路、持续效果、控制等机制。
- 当前训练阵容有十三张实际物品，包含多格卡；不能把十八个最大占位位置说成十八张实际卡。
- 用户六牌存在可解释的因果：A储能分配给相邻B，B攻击实际损失修复本路护幕；D受到本路护幕伤害通知后推进左路冷却；F周期发动可触发邻接E追加灼烧。参见[六牌记录](./2026-09-27-wandeng-six-keepsakes-training.md)。
- 卡牌项目的收集、局内数值养成和归物叙事与电梯项目独立。本轮不引入另一产品的百层竞速或模型选手提案。

## 助手设计解释，尚待验证

当前问题可能包含三层：并行防线导致注意力分裂；效果缺乏主次；频繁小收益与关键联动都成为独立视觉事件。增加像素精度、缩小界面或逐事件放大镜头均不能单独证明这些问题已解决。

自动战斗可以承担“验证自己的构筑”和期待关键联动的功能。玩家不一定需要实时读完全部日志，但应能判断主要胜法、眼前威胁和关键联动的兑现。

## 五个候选方向

1. **工坊与台前分开**：构筑和暂停时展示完整卡牌；战中以双方物灵形态为固定焦点，主输出负责动作，辅助贡献通过可辨认的协作动作和因果提示呈现。基础版本只改变表现，合并展示必须来自真实事件；风险是过度隐藏支援导致黑箱。
2. **一条主战场，后方九格工坊**：保留占格、邻接和组合，在规则上收束为单一交锋面，放弃三道同时失守的独立防线。风险是失去路线取舍，需要以有限后勤容量、组合机会成本等重新承载深度；不可直接套用旧三路卡文。
3. **有拍子的自动对决**：共享行动节奏，一拍一个发起者、完整连锁、结果反馈，再交给下一拍；冷却转成公开的拍数与就绪次序。候选可展示临近行动的少量预告。并发、持续伤害、控制和行动机会成本都需重新定义；这是真实规则分支，不能仅排序旧回放动画后冒充新结算。
4. **有限主动干预**：自动构筑承担持续运转，玩家只在清楚预告的危险或爆发窗口作少量选择，例如唤醒一件物品、保护伙伴或改变本段策略。风险是额外操作负担与固定最优使用时机；次数、资源和窗口均未定，不宜先在现有高密度界面上叠加。
5. **BOSS是可读的灵魂难题**：敌人有少数公开动作和阶段弱点，构筑回答一个具体挑战，而非每场面对另一套同样繁复的自动机器。可采用封存、风雨、遗忘等物灵领域包装。新规则只为候选，风险是内容制作成本、固定谜底与通用卡组的关系。

## 推荐实验，未获用户选择

先比较“固定台前焦点、显示真实主要因果”的表现版本与“单一交锋面、节拍连锁”的规则版本。前者提供保持旧结算的对照；后者验证更深的重构是否更值得观看。九格工坊可承载构筑，三路并行是否保留应由试玩决定。

手炉蓄能→茶壶强化攻击→护幕回补是一段候选演示。每秒小修补可以累计显示，关键释放保留独立反馈；不能为了戏剧化伪造连锁关系或延迟玩家需要的受伤警告。

## 待验证标准

- 开战前后，玩家能否说出本阵容的主要胜法与对方主要威胁。
- 联动发生后，玩家能否指出谁提供了帮助，帮助改变了什么。
- 玩家能否期待下一次关键行动，而非只被动追逐随机亮起的卡。
- 失败后能否提出具体构筑调整；只看见胜负和巨大伤害并不足以证明理解。
- 熟悉当前阵容与第一次看见阵容的玩家应分别观察；没有据此制定已验证的量化阈值。

后续若选择节拍、单战场或主动干预，应另立规则决策和独立版本，不改写旧实验。
