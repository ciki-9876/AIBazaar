# 无人值守室：第一人称单房间切片

## 已决定的范围
用户在《邪恶冥刻》风格与 3C 调研后批准单房间切片。先验证入口观察、近看物件、俯看棋盘的连续关系，保留 F9 三路屏障和自动战斗。没有批准把正式冒险全部换成第一人称。

选择受控第一人称：点击物件移动至预设观察点，开柜、取物、坐到装备台、起身与离开。没有自由 WASD 行走、自由鼠标环视或角色全身模型。棋盘视角为可读性提高俯视角度，仍使用透视镜头和同一张实际桌面。

## 实现事实
独立 `/art/chamber`。房间、柜子与战斗装备放在同一持续挂载的 Three.js 场景，视角切换不重新加载战斗页面。真实战斗与动画复用已有引擎和模型；不是以录像或预定胜利代替计算。

旧楼值守室采用磨损木面、污渍墙面、暗绿护墙、暖色吊灯、冷色门缝。3D 渲染高度最高 600 像素并近邻放大，UI 保持原分辨率。尘粒、缓慢灯光波动、柜门和出口门动画服务于场景，减少动态选项缩短镜头过渡并关闭装饰运动。支持可选合成环境低鸣与命中声音。

柜中皮质缓冲垫与棋盘使用相同的 Blender 模型；取得后可拖动或点击上阵。锁格、失败、上下阵复用现有原子动作。敌方中路卷簧弩、我方弹弓与猎隙刃沿用独立战斗切片配置，未改经济或平衡。

获胜→揭晓→领取→起身→走向出口→离开。领取前不能结束房间。正式冒险、既有箱庭和存档不变。

## 假设与证据
假设：在同一房间中靠近桌面，比箱庭切换成独立战斗页面更能维持空间感和压迫感。该假设尚未经过独立玩家测试。

工程与定向 UI 复测证据：1440×900、800×900 截图；实操取物、拖动中路、点击布阵、查看详情暂停和恢复、倍速、胜利、夺取与离开。实际战斗显示缓冲垫减伤 20、投影损伤 26，与原切片一致。旧 `/art/slice` 仍正常呈现原正交桌面。浏览器错误日志为空。

## 美术与交付边界
这是第一人称方向首版，不声称达到《邪恶冥刻》完整成品的美术、演出和音景水准。程序化房间表面仍需进一步手工细化；没有新人物/手部动画，没有自由走动，未重做全部道具。原卡牌数值、描述、存档与奖励身份约束保持。
