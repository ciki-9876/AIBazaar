# F9 核心战斗的 2D 卡牌桌

日期：2026-09-26。状态：已实现，待用户视觉与玩法体验验收。

## 事实与决定

用户暂时接受可扩展数值区方向，并要求将卡牌、桌面及当前 F9 核心战斗实装为 2D 版本。承接 [ADR-0003](../../decisions/ADR-0003-independent-2d-card-direction.md)、[ADR-0004](../../decisions/ADR-0004-collectible-card-showcase.md)、[ADR-0006](../../decisions/ADR-0006-integrated-colored-numbers.md)、[ADR-0007](../../decisions/ADR-0007-flexible-core-stat-layout.md)。本记录将此前“仅静态方案、尚未实装”的状态推进为可玩原型，不覆盖历史决策，也不代表最终美术验收。

独立入口为 `/arena/2d`。保留 MC-01 的“公开敌阵 → 三路九格布阵 → 自动战斗 → 事件复盘 → 调整再战”组合，复用已有确定性模拟与 v1 对局档案。占格、同名数量限制、伤害、灼烧、侵蚀、屏障和增幅器规则不变；2D 表现不引入另一套胜负结算。

## 呈现规则

- 桌面采用靛蓝街机屏幕和克制的背景扫描线；战场使用平面卡牌，按真实占格扩展宽度。
- 50 张实验牌与 10 种增幅器可用。初始示例同时包含 1／2／3 格与伤害、侵蚀、修复、充能、灼烧联动，亦可清空自行布阵。
- 普通灰、稀有蓝、史诗紫、传说金、炫彩用于本入口的展示名称与卡框；原始稀有度整数、身份、数值和存档不变。
- 卡牌顶部显示名称与定位；下部显示规则与独立冷却；底部只显示彩色核心数字，没有效果标签或图标。数值是列表、按可用宽度换行，数量不绑定占格。字号不因 1／2／3 格而变化。详细卡面保留全文，桌上小卡与牌库有摘要取舍。
- 直伤银、灼烧橙、侵蚀深绿、修屏黄、治疗亮绿。侵蚀沿用现有机制，不因视觉颜色而改成新毒伤规则。灼烧／侵蚀卡面数值指基础施加层数，实际伤害飘字取引擎已结算损失。
- 条件、百分比、充能、控制和再生等规则数字留在描述中；不会伪造成固定伤害或治疗量。已知形态、储能、成长和升阶可从当前帧更新核心数值；命中时判断的条件由描述解释，卡面基础值不是结算预测。
- 详情用薄卡侧边、CSS 透视和轻微悬停倾斜表现收藏卡；仅炫彩卡有持续流光。它是 2D 界面中的立体视觉，不是独立可导出的 3D 卡牌模型。
- 战斗显示双方生命、各路屏障／持续效果、冷却、实际命中、真实触发连线及结算飘字。弹药耗尽显示“待装填”。回放时间驱动位移、飘字、命中反馈；装饰流光不参与结算。减少动态可关闭流光和弹道移动。

## 验证证据

- 自动检查覆盖同一张 1 格牌同时输出直伤与侵蚀、连珠每发数值、下一次第三发攻击、独占条件、修复阈值与形态切换，以及 50 张牌的读取不修改战斗帧或输入。
- 浏览器实测：清空／示例、搜索、非法跨路放置、三格完整占位、移牌、收藏卡详情、增幅器装备、真实对战、暂停、回到开局与逐帧前进、战后各路数据、本地档案重建。
- 实际拖动牌库卡牌进入空格，再拖动三格卡换路，前后 UID 一致。2D 页面无 canvas，原 3D 战术桌入口仍能加载。
- 1440×1000 桌面和 800×900 窄窗检查；窄窗通过牌库抽屉和桌面横向滚动保留操作入口。工程检查与测试结果见 [交付说明](../../../F9_ARENA_2D_2026-09-26.md)。

## 假设与边界

假设平面排列和直接嵌入卡面的数字能改善读局。上述工程与定向操作检查不能证明新玩家理解速度或卡池平衡；仍需实际试玩。

当前 12 张机制族插画由 imagegen 生成并复用，尚非 50 张独立原画，见 [图集与提示词](../../../art/F9_2D_ITEM_ATLAS_PROMPT_2026-09-26.md)。五种效果可扩展布局不等于当前卡池已经存在“五种效果同时输出”的牌；未为验证视觉而给真实卡牌添加效果。

本轮仅落实战斗、布阵和复盘，尚未决定独立卡牌游戏的商店、获取、长线成长与世界观。旧 `/arena` 入口继续可用；另一会话的电梯玩法不受影响。
