# F9：首战战利品 → 工具解谜 → 鉴定（2026-09-20）

状态：已实现，工程及 Agent 定向 UI 复测通过，独立新玩家验证待执行。

## 体验问题与假设

旧暂停框与目标太远；三路没有先建立空间概念；首胜缺少有形收获；第二间同时介绍物品、鉴定、布阵，压缩了学习节奏。

假设：先用首战武器奖励介绍布阵，再让实体参与机关，最后获得鉴定仪转化保留下来的工具，会让每一步的产物推动下一步，避免玩家同时学多套规则。

## 已接受的决定

1. 弹弓初始单武器；刀变为即时命中、3秒/10伤害/破路+6。弹道与即时共用现有结算器，差别是结算时刻。
2. 七步战斗教学，三路全景先于屏障；贴近目标并连线。第一次精力消费前讲解精力。
3. 每次胜利从真实敌方输出卡池取一个实例副本，经揭晓、领取进入背包。首敌只有猎隙刃，所以保证获得。满包保留待领，不自动折金币。
4. 背包首胜开启；任何后续场景可打开。战斗中只暂停并编辑下场布局，当前快照保持不变。
5. 第二间只给缓冲垫与补漏胶。第三间工具参与接管，成功消耗补漏胶、保留缓冲垫，获得鉴定仪与一次电荷；之后才教鉴定。
6. 鉴定与背包整理不推动节点，继续按钮才扣下一段路费。原子结算、固定横向格与旧存档继续保留。
