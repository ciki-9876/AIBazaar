# 巡回器具师联赛：主线、收集与成长骨架

## 事实与决定

用户选择巡回器具师联赛，要求完整游戏骨架；随后选择 60–90 分钟一局，以及保留图鉴/解锁选择、每局重新培养卡牌数值。接受范围见 [ADR-0010](../../decisions/ADR-0010-circuit-league-and-run-boundaries.md)。

现有 `/arena/2d` 已有三路战斗、卡面与自由组卡；没有本文描述的完整市场、赛季、旅途、局内成长和局外解锁。动物仅为美术实验，不成为正式卡牌内容约束。

## 本轮产物

[联赛核心设计 v0](../../../F9_CIRCUIT_LEAGUE_CORE_DESIGN_V0_2026-09-26.md) 作为后续讨论与实装的系统入口，补齐：

- 4 城 15 场计划赛的阶段节奏、地方考题、两次劲敌交锋与冠军目标。
- 每城两次旅途选择、持续货架、定向寻货、资格关与三败退赛。
- 核心/屏障战后恢复，用败绩承担赛季容错，避免残血拖垮养成。
- 卡牌调校与互斥改装、低频拆装转移；个人专长、局外收藏分工。
- 奖金和调校额度的最小经济、领取幂等、确定性生成、稳定实例与存档边界。
- 两城七战的先行验证切片，完整目标仍为用户选择的 60–90 分钟。

以上具体结构是助手提案，不伪装为用户已经验收的规则。新调校数值与现有引擎 level/quality 公式不同，文档明确禁止静默复用或叠加。

## 核心假设与取舍

1. 保证每场首次完成可投资一次器具，旅途机会负责选择方向，可以同时提供稳定成长与不同局的差异。
2. 高稀有牌改变机制，旧牌的投入保有价值；低频有损转移为中途转向留出口。需要验证两者能否共存。
3. 每场恢复、三败退赛可让玩家在失败后继续构筑；代价是跨场生存压力降低。
4. 地方会馆考查能力而不锁定唯一克制卡，才能同时维持强敌递进和个人战斗风格。
5. 局外的作品记录与新选择需要承担长期收集动机，不能偷加永久数值补足。

## 本轮暂不采用的方案

这些是助手的范围建议，不是用户永久否决：无限刷同一比赛、重复牌强制合成、同时叠等级/品质/升星/随机洗练、开放世界走路、额外基地经营、默认真人匹配、首版突然死亡。原始候选与旧电梯机制保留为历史，不删除。

## 证据与下一步

证据只有用户选择、现有规则与代码阅读，以及文档中的预算算术；没有新模拟、运行测试或试玩。下一步用七战切片检查养旧/换新、战败恢复、构筑可达性和实际用时，再决定完整十五战经济与数值。未改运行代码，无需以 npm 测试冒充设计有效性验证。
