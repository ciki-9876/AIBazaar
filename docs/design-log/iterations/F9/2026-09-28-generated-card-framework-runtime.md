## 规范解释及冲突处理

- 词库的创意谓词范围比数据合同中的两种谓词更宽；本版严格执行数据合同的 `barrier_state/stat_compare`，其他字段拒绝，未凭文案猜规则。
- 规范要求路线持续伤害一次受伤通知，同时要求幕／核心损失可区分：采用同一事件的多目标列表及独立损失字段，来源信用再按实际损失比例拆分，避免一次溢出被当成两次命中。
- 基础能力数值到期与反应治疗的同刻关系已在开发说明冻结：到期优先；同批响应在正式死亡裁决前允许挽救，未发出的自然周期不由零血一方补发。回放嵌入规则版本，不影响旧调度器。
- 多个修改攻击力效果不能因来自同一能力而被误判为同源刷新，状态键包含来源实例、能力及效果ID。
- 10毫秒内核与旧0.25秒训练对局隔离。当前只提供只读插值接口；没有宣称旧页面已经切为100Hz。

## 证据与限制

四张文档样例通过同一编译器。固定示例对局29.25秒结束，玩家剩41血；6310毫秒在途保存再恢复，与连续运行的完整最终快照相同。示例胜负仅证明执行，不是平衡证据。完整输入与报告在 `outputs/card-framework/`，生成脚本可复现。

专项覆盖：非法／未知定义拒绝、请求边界不提升、预算发布阻断、ATK加减与到期、状态刷新、充能冻结、选择器去重及均分、弹道快照、显示读取不改模拟、持续伤害单次接触及归因、A→B→A与充能回环、延迟持续伤害保留路径、护幕保护／修复／同刻到期、多来源资格、腐化同时死亡、工程上限报错及原子失败、中途恢复和篡改拒绝。

最终检查：全项目272项测试通过，其中新框架12项、六牌训练场11项；lint与TypeScript通过。训练场路由生产构建和桌面／窄屏浏览器验证已在[训练场记录](./2026-09-27-wandeng-six-keepsakes-training.md)完成。新框架为独立模块，未再改动页面路由；仍需后续战桌适配和设备性能验证。
