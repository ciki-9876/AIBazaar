# 电梯环境元素怪物与杀戮模式设计扩展

日期：2026-10-05，讨论开始于10月4日。性质：用户设计方向明确，助手详细方案待验证；无代码实施。

## 用户明确的方向

挑战拓展加入灼热等持续环境压力、元素伤害与附着反应、buff与debuff和护盾、伤害防御生命移速抗性，以及更丰富的怪物战斗行为。元素结构可参考原神，但元素与反应类型要原创。

新增杀戮模式默认关闭且头顶绿灯；快捷键开启后攻击能伤其他参赛者且头顶红灯，AI选手具备同样能力。延续自动技能割草、少文本、道具配装和主要商店获取、有限补给、共享据点与共同暂停。

## 助手候选机制

[详细设计](../../../F9_COMBAT_ENVIRONMENT_ELEMENTS_MONSTERS_AND_KILLING_MODE_DESIGN_2026-10-05.md)提出蚀振磁织四元素、六种对称反应、单目标单附着与频率限制、八环境、十四怪物和三BOSS方向。环境、空间、行为、元素、机制、属性和杀戮许可分层，普通楼层最多三个可见危险条件。

候选杀戮模式控制攻击者对外许可，绿灯不提供受击免疫；默认K、0.6秒启动预警、即时关闭、授权代号和残留效果撤销。范围传播、引爆、反射和召唤保留来源，防止绿灯间接伤人。返梯保护只在合法提交后生效，多票门禁继续成立。AI使用同一执行规则，角色策略与社交反应没有硬编码批准。

候选续航允许防护、吸血和有限恢复缓解热害，但恢复不补食水，食水为零时自动回血停止，饥渴穿透盾与防御。所有成长来自安装道具；电力继续采用此前候选强化预算，基础攻击与反应在空电时有效。具体数值、类型和顺序均为原型建议。
