# 2026-09-23 · 战斗物件、核心与屏障动态升级

## 决定与边界
用户要求升级当前战场四件原型与双方核心、屏障的动画和特效。承接[不对称宿主](./2026-09-23-asymmetric-hosts.md)，仍是独立 `/art/slice` 切片。覆盖场上弹弓、猎隙刃、卷簧弩、补漏胶，同时覆盖可上阵的皮质缓冲垫。复用现有 Blender 几何，在 Three.js 中驱动部件与实时特效；没有生成新模型文件、引入付费服务或改变伤害规则。

## 已实现
- 弹弓：固定叉端的弹性拉伸、弹丸随皮兜后移、发动回弹和后坐、石子短尾迹。
- 卷簧弩：卷簧绕自身中心旋转、弦拉伸、弩臂蓄力、出箭后短暂空轨、后坐；实体弩箭保留原有真实飞行时间。
- 猎隙刃：抬起挥斩；即时命中处显示短弧刀光，不产生虚构的飞行刀。
- 补漏胶：喷嘴动作、成串液滴输送、实际修复位置的波纹与碎光。满屏障的零收益不会出现修复成功效果。修复改道遵循实际结算目标。
- 缓冲垫：真实减伤触发压缩回弹与物件响应光环，和屏障受击位置同时反馈；修复使用冷色脉冲，与胶液区分。
- 屏障：保持三路全宽；透光格纹、局部冲击波、随剩余生命出现裂纹；破路时按敌我颜色碎裂。略增高以适配俯视角可读性。
- 蜷卧者：受击处更明显地收缩、暗色碎屑、局部着色；归零时逐渐塌伏并变暗。
- 我方投影：受击处冷色碎片和波纹，原有透明裂口保留；归零淡出。
- 同一溢出事件同时表现屏障接触与核心伤害，不编造第二次攻击。
- 最后命中后留出 1.4 秒表现尾段，仍可暂停、变速、逐帧；实际战斗时间和结果不增加。未结算飞行物在战斗终止后撤去，不能制造结算外命中。
- 特效使用回放时钟、固定轨迹和限量实例池；重播重新取样，减少动态关闭飞散、挥斩和冲击扫描，保留状态。窄窗也保留减少动态入口。

## 验证证据
- `npm test`：124 项通过，新增事件无副作用、溢出双表面反馈、零收益修复过滤、修复目标与动画回退验证。
- TypeScript、lint、构建通过；仍有既有的大分块提示。
- Agent 实际 UI：从敌情进入、装备中路缓冲垫、开战、暂停逐帧、2×播放至胜利、重播、0.25×结尾、640px 窄窗与减少动态开关。新加载版本控制台无错误。
- 中路缓冲垫案例仍在 24 秒获胜：投影损伤 26，蜷卧者损伤 82，实际减伤 20。没有为了特效改战斗数值。

## 主要实现文件
`app/art/slice/scene.tsx`：物件／核心动作、弹道；`effects.ts`：屏障着色器、碎片、波纹与刀光；`page.tsx`：表现尾段与逐帧控制；`slice.css`：窄窗动态开关；`lib/battle-slice-fx.ts` 与测试：从实际结算生成表现事件。

本地访问 http://localhost:4173/art/slice 。需要重启时运行 `npm run dev -- --host 127.0.0.1 --port 4173`。
