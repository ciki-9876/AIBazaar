# 2026-09-26：无覆盖界面的阴暗电梯

## 用户事实与本轮决定

用户要求 3D 开门引导、门缝淡黑烟、按钮对面左墙电子广告屏，以及更阴暗恐怖的场景。电梯内信息转为空间物件的决定与范围解释见 [ADR-0011](../../decisions/ADR-0011-diegetic-lift-and-darkness.md)。本轮推进[现实小轿厢版本](./2026-09-26-survival-passenger-lift.md)，不改变其尺度和出入场玩法。

## 已实装

- 电梯内撤去标题、二维开门按钮、入场字幕和撤离成功弹窗。门前细线双门图标与小型 E 标记都在 3D 空间中；可点击门或按 E 开门。拖动环顾与点击分开判断，屏幕阅读器仍可调用开门。
- 中缝、侧缝和门槛增加程序黑烟，门后增加遮光面，闭合状态不透出外部亮色；开门后遮蔽随门扇运动淡出。不开新随机序列、不改生成世界。
- 左墙安装约 0.48×0.67 米电子屏，广告为虚构住区宣传、楼宇线画、固定扫描线和绿色反光。屏幕独立命名，可供后续系统入口迭代；当前不能操作系统菜单。
- 撤离成功后屏幕显示实际保住的物资价值、击倒数和出勤时间，明确标注再次开门重开试玩、当前不保存跨局物资。
- 降低轿厢环境光，以弱顶灯聚光和广告屏侧光保留空间轮廓；房间光照也稍降，但保留战斗读取。无灯光频闪。减少动态时提示呼吸与烟流静止。

## 浏览器证据

- 初始画面没有可见二维界面；从门图标处拖动环顾没有误开门，点击图标正常出发。运镜阶段也没有标题或字幕，战斗开始后 HUD 正常显示。
- 实际返程时，第一次撤离被受伤打断；第二次成功。原返程风险仍在，成功后关闭门、回到人眼视角，无结算覆盖层。
- 左墙实体屏显示本次实际结果：保住价值 26、击倒 55、出勤 136 秒。环顾可读，E 可重新开始并进入出门运镜。
- 闭门时门缝无明亮外景泄露；门和开门图标可辨认。电子屏固定扫描纹理未闪烁。浏览器无错误日志。
- 截图保存在 `outputs/survival-dark-lift/door.png`、`advertisement.png`、`extracted-screen.png`，均为实机截图。
- `npm test`：176/176 通过；`npm run lint`、`npx tsc --noEmit`、`npm run build` 通过。构建仍提示既有大分块。

## 尚未证明与边界

本轮没有用户恐怖氛围验收、引导发现率测试或低端设备性能专项测试。广告措辞不是已定世界观，电子屏不是完整电梯操作系统。房间战斗 HUD、主动暂停和死亡结算保留；后续如果房间也要去掉 UI，需要另行确定生命、生活数值与格子构筑的信息承载方式。
