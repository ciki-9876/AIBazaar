# 非像素材质方向：从空间原型到表面质感

## 决定与范围

用户认为像素化第一人称版本仍有白盒感，要求恢复非像素风格，并先讨论渲染/材质升级方案。

**已决定**：停止把降低渲染分辨率、近邻放大作为目标美术风格。此决定取代[第一人称切片记录](./2026-09-24-first-person-chamber.md)中的像素化方向；历史实验保留。用户没有在本轮否决第一人称操作，也没有要求回退所有空间与镜头工作。

**本轮仅调研与方案记录**：未改场景、材质、玩法和存档，未发布。下述材质路线、制作范围与质量预算为提案。

## 核查事实

- 实际检查 `/art/chamber` 与 `/art/rooms` 的浏览器画面。前者暗部压得较重，墙纹明显重复，装备仍有规则几何感；后者原本即为非像素渲染，纯色墙地面与规则边缘呈现模型样板感。这些为本轮视觉判断，非独立玩家测试。
- `app/art/slice/chamber.ts`：墙、木、地面使用 256² 程序化颜色纹理；材质粗糙度统一 0.91，未提供法线和粗糙度贴图。提高统一粗糙度不能补出表面结构。
- `scripts/art-battle/build-slice.py`：装备材质主要由纯色、统一金属度/粗糙度构成；已有倒角，但没有成套表面贴图。
- 当前 Three.js 场景已有 ACES 色调映射与阴影。相关场景未配置环境反射贴图及屏幕空间环境遮蔽，不应把现状描述为完全没有灯光或阴影。
- 像素化会减少细节显示，无法替代物件自身的形体、材质、磨损与光照设计。

## 提案：有使用痕迹的旧楼实物

方向为清晰、克制的风格化写实：现实中熟悉的漆面、木料、皮革、金属与橡胶，搭配异常生物；构图和轮廓保持易读。

### 三层细节

1. 大尺度：材质分区、褪色区域、漆层脱落、木板拼接、皮垫压痕。
2. 中尺度：木纹方向、划痕、接缝、螺钉、缝线、锈从连接处扩散。
3. 小尺度：金属微划痕、皮革颗粒、橡胶细纹；仅在近景和斜光下明显。

磨损按用途与位置分布：握柄被磨亮、凹槽积灰、金属边缘露底、墙脚受潮。不同物件不得统一覆盖相同强度的噪声。

| 对象 | 主要材质表现 |
| --- | --- |
| 卷簧弩 | 氧化钢弹簧、木托纹理、握持区抛光、螺钉/接合缝、少量油迹 |
| 弹弓 | 木柄磨损、橡皮带拉伸细纹、布带纤维，保持朴素轮廓 |
| 猎隙刃 | 刃口较亮、刀身方向性划痕、握柄旧包裹，避免全刀同一金属反射 |
| 缓冲垫 | 不均匀压陷、缝线/边缘、皮纹和局部磨亮 |
| 墙与地面 | 粉化涂料、局部裂缝/缺角、砖缝积灰与地面接触阴影 |
| 敌方核心 | 干燥褶皱与局部湿润反光分区；大轮廓、破损与命中区域保持可读 |
| 屏障 | 保留清楚的通透界面与局部命中波纹；污痕不遮挡敌阵 |

### 制作与渲染

- Blender 处理可见轮廓、接缝、倒角差异及近景道具细节；法线贴图只补细节，不代替轮廓。
- 资产展开 UV，把程序材质/细模信息烘焙成颜色、法线、粗糙度、金属度及必要的遮蔽贴图，按 glTF 支持的材质结构导出。必须在浏览器验收，不能只检查 Blender 渲染图。
- 普通表面复用平铺材质，主要道具加专属磨损遮罩；近景主要道具可先用 2K，普通表面先用 1K，都是待性能验证的起点。
- 恢复正常分辨率、纹理过滤与抗锯齿；UI 保持清晰。
- 定向斜光照出凹凸，弱环境反射帮助金属读出形体；以局部照明组织亮暗，保留暗处结构。静态房间优先烘焙遮蔽/间接光；动态物件使用实时阴影并评估轻量接触遮蔽，避免双重压黑。
- 检查贴图色彩空间；发光仅用于合理光源和战斗反馈。轻微辉光、暗角属于最后调色环节。

## 首次验证范围与顺序（建议）

先做一个浏览器可交互的材质标杆：同一张装备台、卷簧弩、缓冲垫以及相邻墙地面。沿用已有空间与战斗，不同时扩建房间或玩法。

1. 恢复非像素输出，保留同机位旧版截图。
2. 建立中性光材质检查与游戏内灯光对照，先完成上述标杆。
3. 在近景、正常战斗距离和低光下比较纹理尺度、材质区分、阴影与可读性。
4. 标杆达成后复用到其余武器、核心和房间。

## 验收标准与待验证项

- 不依赖物件颜色，也能看出金属、木头、皮革/橡胶的反光差异。
- 近景可见具有方向与用途的磨损；正常战斗距离保留材质分区，无闪烁碎噪。
- 物件与桌面有接触关系；暗部仍能看见轮廓和结构。
- 法线不能伪装修复近景明显方正的轮廓，必要时必须改模型。
- 在同机位/同分辨率保留前后对照，在浏览器而非离线渲染图验收。
- 记录帧时间、纹理显存与加载体积后再确定质量档；当前没有性能承诺或新跑分。
- 假设：以上改动能显著减少白盒感，尚需用户对材质标杆进行视觉验收。

## 技术依据

- [Three.js MeshStandardMaterial](https://threejs.org/docs/pages/MeshStandardMaterial.html)：金属/粗糙度流程，环境反射、法线与粗糙度贴图。
- [Khronos glTF Blender exporter 文档](https://github.com/KhronosGroup/glTF-Blender-IO/blob/main/docs/blender_docs/scene_gltf2.rst)：可导出的材质结构、图像贴图和法线烘焙。
