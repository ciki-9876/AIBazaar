# 2026-10-05：甩牌SVG制作切片

## 事实与决定

用户确认现行柔和报刊插画风格“就这么定了”，要求尝试SVG与其他量产方法。承接[ADR-0046](../../decisions/ADR-0046-throw-editorial-illustration.md)，不改变风格目标、RPG剧情、左右舞台或战斗规则。矢量母版／骨骼／烘焙图集的混合生产链为助手建议，尚未由用户选定。

## 实施

- 20份原创SVG：8件道具、主角、两配色家族及道具／人物图集；主体全为可编辑路径。8件道具全部复用进原子场景；SVG主角复用到场景、肖像和主线战斗。
- 主角同一部件造型形成16姿势，身份不会像逐帧生成一样变化；仍按现行8／8帧播放，不能宣称已实现专用运行时骨骼动画。
- `/art/vector`切换同灯光工作室并放大比较；`/art/vector/play`保留真实主线行走、进入建筑、对话与进入战斗。首页仍为已选定原版。
- 未重画3位NPC、装饰与装备图标；这是一轮生产方法试验，不是全量替换。
- 首次过大SVG固有尺寸已缩至800×512道具和1600×512角色；母版继续可编辑，输出画布仍960×540等固定分辨率。

## 工程检查

全仓498项测试通过；全仓lint／typecheck通过；产品边界检查通过；throw构建6条路由通过。没有变更确定性规则或数据模型，旧回放保持。

## 浏览器证据

1280×900对照页：SVG加载成功、同灯光正常WebGL、实际主角步行帧2；切换回原版成功。放大倍率与角色／配色切换由实际按钮操作确认。390×844中魔术桌4倍曾挤宽对照列，修改为可收缩网格后，两列162.5px且页面无横向溢出。

可玩试演实际走过开场3页、从街区220步行至工作室门485、进入工作室210、步行至795与导师对话3页、进入练习布阵和真实对战。1280×720对战无页面溢出，玩家左侧的角色标记为vector、右侧导师仍raster。单选♥Q显示12伤害，实际手牌起点(90,524)→敌人目标(943.1328,324)；对局结束统计命中1次，导师320→308，玩家0，48秒真实失败。返场导师明确“这一场是我赢了”，未伪造胜利。本轮不是通关验证。浏览器控制台没有素材载入错误。

20份SVG独立XML解析通过，无重复ID、嵌入位图、脚本或foreignObject；道具／人物8／16帧源矩形、图集固有尺寸与清单一致。
