# 2026-09-27：温馨氛围下的精细像素美术替换

## 用户决定与边界

用户明确“整体氛围感不变（温馨可爱），但美术素材以及字体全部替换为超高精度的像素画”。这是 `/wandeng` 的展示层替换，不是战斗系统重做。

本轮局部取代[奶油纸 UI](./2026-09-27-wandeng-cozy-ui.md)的圆润字体、手绘插画和光滑控件，以及[护幕与心灯](./2026-09-27-wandeng-soul-battle-feedback.md)的曲线图形。其读数层次、效果语义、五档品质、护幕包装和一方一宿主继续成立。[ADR-0017](../../decisions/ADR-0017-wandeng-arena-baseline.md)的 50 卡、10 增幅器、三路九格、确定性结算与历史回放不变。

## 已实装

- 使用内置 image_gen 重绘 12 件旧物和 6 幅叙事画面。保留主角、师傅、旧物及情节身份，使用细密像素簇、阶梯轮廓、材料分层色阶和局部像素高光。保留暖灯、黄铜、奶油底、草木绿与旧物被珍惜的气氛。
- 新素材接入标题、序章、教学、来信、启程、旅途窗口、全部卡牌引用、行囊、图鉴、战斗和终局。物品使用真实透明背景和独立裁切矩形；不对整页套模糊/马赛克滤镜。
- 所有万灯城文字指定本地 GNU Unifont，包括中文、数值、规则、控件和回放。正文与卡面以 16px 为主要字号，大标题和主要数字放大；取消伪粗体与旧书法/圆润字形。素材目录记录字体授权位置。
- 原界面图标替换为整格像素路径。五种数值背景符号、心灯、护幕、路线状态、增幅器标识和冷却等展示继续读取真实状态。共享战桌通过可选图标渲染入口接入，不改变其他主题默认外观。
- 控件、图鉴格和五档品质框使用分层像素边缘、硬阴影、稀疏底纹；炫彩保留离散步进的局部流光。减少动态偏好停用装饰动画。
- 窄屏标题和路线纵向排列，事件小图留出独立位置；三路战桌继续在内部横滚。

## 主要文件与素材来源

- `public/art-assets/wandeng/pixel/`：两张正式 PNG、素材说明和 `generation.json` 完整生成提示词。使用内置 image_gen，无外部 CLI 调用。
- `app/wandeng/wandeng-pixel.css`：像素主题、字体、材质、响应式布局。
- `app/wandeng/wandeng-pixel-icons.tsx`：原创像素图标。
- `app/wandeng/wandeng-symbols.tsx`：像素护幕、心灯和效果标识。
- `app/wandeng/wandeng-cards.tsx`：图集裁切和一格卡品质行；`wandeng-battle.tsx`、`wandeng-experience.tsx`、`page.tsx` 接入主题与图标。
- `app/arena/flat-table.tsx`：可选图标入口，原几何和效果层不变。

## 证据

- 228 项测试通过；全项目 lint、TypeScript 检查、生产构建通过。构建保留既有大包体积提示。
- 字库覆盖检查：`app/wandeng/*.tsx` 使用的全部非 ASCII 字符在本地字体 cmap 中存在。浏览器字体检查返回已加载，界面采用 `Wandeng Pixel`。
- 实机检查标题、旧旅途继续、图鉴五档品质、一至三格卡与对决手记。修正图集裁切范围后，卡面不再带入相邻物品片段。
- 旧回放破幕时仍显示敌方生命 103/190、一个破损护幕及 −50 护幕损失、−87 溢出生命伤害；该回放界面检测到 29 个像素图标、0 个旧 Lucide 图标。
- 1440×1000 与 390×844 布局检查；窄屏文档宽度 375px，小于视口 390px，图鉴宽度 337px，棋盘内部滚动。
- 实机证据保存到 `outputs/wandeng-qa/pixel-*.png`。

## 仍待验证

高精度和温馨感的审美结果待用户评价；目前有功能和视觉检查，没有独立玩家偏好研究。原 50 张机制牌仍复用 12 类物品造型，此次完整替换既有素材集合，未扩充 50 张独立卡图。浏览器非整数缩放会影响像素边缘的均匀程度。
