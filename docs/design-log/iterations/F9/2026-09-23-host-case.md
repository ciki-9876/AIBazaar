# 2026-09-23 · 宿主改为护命匣（切片迭代）

## 决定与范围
用户同意按静态画面、装备、攻击链、胜利的顺序打磨，并授权放弃人物模型，改用符合背景且适合受击的宿主包装。本次先落实非人物宿主与静态层次；不代表全部高质量美术目标完成。

“护命匣”为暂定名称与叙事提案：幸存者使用旧世界应急屏障设备维持交战防护，三路屏障连接匣体。设备停机表示本场战败，不把战斗耐久混同探索生命。尚未确认为全局世界观名词，仅在独立切片显示。

## 实现事实
- 去掉简化守卫人物，敌我各有一个装甲匣、可见核心、保护架、散热片、提手、供能线路。
- 真实 healthLoss 驱动短暂震动、核心闪亮和火花；剩余耐久低于40%时装甲松脱，归零核心熄灭、装甲进一步张开。表现不反向修改战斗数据。
- 屏障破路后的弹道朝向真实匣体；直接命中环定位匣体，溢出伤害仍在屏障命中，同时驱动匣体反馈。
- 压暗背景、取消重复地砖与卷帘背景、收紧镜头；保留完整三路和可操作格位。
- 减少动态关闭匣体震动和火花；重播由战斗时间与帧数据重建。

## 证据
工程：119项测试通过，lint、TypeScript、build通过。构建仍有超过500kB分块提示。
UI：实际完成查看敌阵→缓冲垫中路上阵→完整战斗→夺取卷簧弩→领取；结果我方损伤26、敌方82、实际减伤20，与原切片一致。桌面和640×900截图检查通过，浏览器错误日志为空。这是Agent复测，不是独立玩家测试；没有完成目标设备帧率测量。
