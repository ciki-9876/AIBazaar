# 2026-10-03：甩扑克牌对战 DEMO

## 已决定与已实现

用户明确新分支实验六条甩牌规则，见 [ADR-0027](../../decisions/ADR-0027-throw-card-duel-experiment.md)。分支 `codex/throw-card-duel`，独立入口 `/wandeng/throw`，万灯城主页面增加“甩牌试验场”链接。

- 自由装卸最多三件旧物，提供单张、对子、顺子／同花三套预设，对手流派和牌序种子可选。
- 双方独立 52 张牌堆，5 张初始手牌，10 张容量，按模拟冷却抽牌；满手暂停，空位出现后恢复，耗尽牌堆后按独立命名随机流洗新牌堆。
- 点选切换、拖动框选、Shift 框选追加；按钮和空格均发射真实选择，另有全选、清空、推荐组合。
- 选择区显示实际“点数 + 牌型 + 道具”伤害；最高五牌组合加成一次，其余牌仅增加基础点数。A 可接 2–5。
- 发射后卡牌进入飞行队列，0.45 秒命中本体；同 tick 致命命中同时结算。暂停冻结抽牌、AI、飞行与伤害。
- 对手公开手牌，提前一秒标明组合与伤害。结局可调整道具、同种子再试。
- 纸纹、低亮绿桌垫、现有像素旧物与字体；双方手牌和一次中心对决取代多路交互。桌面与窄屏使用各自手牌排列。

## 工程边界

新内核位于 `lib/cards/throw-*`，新 UI 位于 `app/wandeng/throw/`，产品路由位于 `apps/cards/app/wandeng/throw/`。既有保存、战斗与回放规则未迁移。失败出牌命令不消耗手牌；模拟显式使用种子与固定 50ms tick，不引入环境时间或随机性。试验没有持久存档，刷新回到战前准备。构建生成的嵌套依赖目录排除在 Git 与 lint 外，检查仍覆盖产品源代码。

## 验证证据

- 11 项新增规则测试：对子 2=6、所有牌型、A 低顺子、十牌单次加成、道具与槽位、满手暂停／恢复、原子失败、命中延时、同时击败、治疗上限、跨牌堆稳定身份、种子重演及 AI 预告。
- 全仓测试 316 项通过，保留黄金回放；双产品生产构建成功。
- 全仓 lint、TypeScript、产品边界、确定性及依赖检查通过；双产品生产构建分别生成 3／9 个静态路由。
- 浏览器实测：无道具对子 2 预览 6，空格发射后敌方生命 320→314；A 的按钮发射再使其降至 300。拖框选中三张，10 张全选、满手停抽、再次发射、对手预告、结局和规则说明已观察。
- 1280×720、1366×768、1920×1080 与 390×844 下，文档与视口同宽高；窄屏满手 10 张和发射按钮无越界。像素字体已加载，页面无控制台错误。截图位于 `outputs/throw-qa/`。
