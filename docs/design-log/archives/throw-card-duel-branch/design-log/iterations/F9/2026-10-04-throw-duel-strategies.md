# 2026-10-04：甩牌节奏、位置构筑与九套策略

## 决定与实现边界

接续[上一轮](./2026-10-03-throw-duel-relics-and-motion.md)，按用户要求将抽牌调为3秒、解决框选与整理冲突、增强组合演出、扩展伤害及位置构筑。用户随后指出电脑也须遵守单选／框选，已统一约束。决策与规则详见[ADR-0029](../../decisions/ADR-0029-throw-duel-rhythm-layout-and-strategies.md)。

独立分支 `codex/throw-card-duel`，入口 `/wandeng/throw`、本地服务 `http://localhost:4174/wandeng/throw`。仅甩牌版本升至v3，不更换原50卡三路战斗、存档或主线。新物品和遗物数值属于可试玩试验值。

## 已实现的体验链

九套起手方案／自行选择23旧物 → 在十格行囊摆放1–3格物件 → 携带最多1件遗物（10种） → 上下对战，每3秒一张 → 单选或一次框选 → 多来源预告 → 原位实体飞牌 → 心灯命中、烧／毒／护盾／反击／吸血／成长／控制 → 本体状态与集中共鸣演出。

空隙、贴邻、双邻与左右端点影响实际效果；移动失败不覆盖或丢失。理线盒用按钮按点数／花色排序或收拢选牌，成功改变顺序才消耗3秒冷却；牌面起拖与空白起拖都框选。电脑不再从整手牌抽出散落的最优牌组，只比较连续区间或单张，保留1秒预告。

共鸣演出在桌面中心显示组合名、直伤、触发旧物与效果带，高阶组合加光环、冲击线、星粒和更强命中飘字。飞行区分火／毒／高阶尾迹，音效区分烧、毒、盾、成长、控制与高阶组合。常驻状态只保留心灯边小标签；暂停和减少动态仍有效。没有给每个持续扣血重新弹大庆祝画面。

- 全仓lint、类型、产品边界、确定性与依赖检查通过；双产品生产构建成功。卡牌产品类型检查通过。
- 浏览器种子3电脑手牌为「♦2、♠3、♣7、♦3、♦5」，实际预告选中连续「♠3、♣7、♦3」，不能跳过7只出两个3。截图 `outputs/throw-qa/throw-v3-ai-contiguous.png`。
