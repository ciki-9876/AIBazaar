# ADR-0028：甩牌对决的上下布局、选牌约束与唯一遗物

- 日期：2026-10-03。
- 状态：用户要求已实现；三个新增遗物的具体规则为助手首版设计，待试玩。
- 范围：独立 `/wandeng/throw`、`throw-duel-v2`。
- 局部取代：[ADR-0027](./ADR-0027-throw-card-duel-experiment.md) 的累计点击、Shift 追加框选、全选／推荐和旧飞行动画。
- 证据：[本轮迭代](../iterations/F9/2026-10-03-throw-duel-relics-and-motion.md)。

## 用户决定

双方上下对置，真实扑克从自己的手牌位置飞向对手本体。点击只能单选；多选依靠一次框选，不能逐张点击不同位置累加。保留主动出手、自动抽牌、满手停抽和原扑克组合计分。

三件道具外增加一个遗物槽，只能携带一件，可不携带。用户指定两种效果：拖动整理手牌、冷却 3 秒；容量增加 2。要求另设计三种效果。

选中牌上方预告本次会触发的效果，多个并排显示；实际触发时对应物品发光／跳动、显示效果名并播放音效。像素素材和字体保留，空间运动采用连续插值。

## 助手包装与首版数值

| 遗物 | 行为 | 来源 |
| --- | --- | --- |
| 三息理线盒 | 拖动手牌改变顺序；成功后冷却 3 秒 | 用户规则 |
| 双层旧邮匣 | 容量 +2，最多 12 张；仍满手停抽 | 用户规则 |
| 接力闹钟 | 每第三次成功甩牌立即抽 1 张，不重置普通抽牌计时 | 助手试验值，支持快甩 |
| 余响八音盒 | 每次受击积攒 3 点，最多 12；下一次成功出手加等量伤害后清空 | 助手试验值，支持反击 |
| 红心补缝毯 | 每实际抽到红心牌回复 3 点生命，不超过上限 | 助手试验值，支持抽牌续航 |

一次受击指一次甩牌批次命中，不按批内卡牌数重复计算。理线盒只重排稳定身份，不修改点数、花色或倍率；无效整理不消耗冷却。携带时卡牌上起拖用于整理，空白起拖用于框选；其他遗物下可直接拖框。所有框选替换当前选择。

满生命时治疗预告显示“满生命”，实际回复仍为零。抽牌加速在实际自动抽牌时展示“催信速递”；容量是持续效果，不伪造每张牌的伤害触发。

## 体验假设与边界

整理使视觉相邻与组合对应，但三秒冷却可能增加找牌压力。唯一遗物使整理、容量、快甩、反击和续航竞争，是否形成有效选择仍需玩家比较。

反馈分两层：手牌上方解释“本次将发生什么”，心灯旁解释“刚刚真实发生什么”；实体飞行把选牌和伤害相连。这可能降低注意力切换，工程测试不能证明好玩或所有设备恒定 60 帧。

旧 50 卡、三路、护幕和万灯城旅途保留。规则版本只升级甩牌实验；无新增存档迁移。音频、屏幕坐标、动画时间留在表现适配器，模拟使用显式种子和固定 tick。
