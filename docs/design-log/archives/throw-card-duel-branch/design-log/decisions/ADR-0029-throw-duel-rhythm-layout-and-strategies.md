# ADR-0029：三秒抽牌、统一选牌与十格构筑

- 日期：2026-10-04。
- 状态：用户的节奏、交互与策略拓展要求已实装；新物品、遗物及数值为助手实验方案，待玩家验证。
- 范围：独立 `/wandeng/throw`，规则版本 `throw-duel-v3`。
- 局部取代：[ADR-0028](./ADR-0028-throw-duel-relics-and-selection.md) 的牌面拖动整理、三件固定道具及旧自动抽牌速度。旧记录保留当时决定。
- 证据：[本轮实现与验证](../iterations/F9/2026-10-04-throw-duel-strategies.md)。

## 用户决定

自动抽牌统一为每3秒一张，满手时停计时。拖动已用于框选，整理不能再抢占同一手势。点击只能单选；这一约束同样适用于电脑，不能跨格选择离散的牌凑组合。用户要求更强的组合演出、丰富伤害与赢法、基于背包位置的道具联动，并讨论与原故事的结合。

## 交互与信息组合

玩家点击替换为单选，拖动从牌面或空白开始均框选并替换上次选择。电脑只能选择单张或手牌序列中的连续区间；跨过其他牌时必须一起甩出。电脑仍提前1秒公开意图，禁止从全手牌抽取最优组合的离散牌集合。

理线盒采用“按点数／按花色／收拢所选”按钮。成功改变顺序才消耗3秒冷却，失败及无变化不消耗。稳定身份、点数和花色不变；排序、选牌、发射与额外抽牌不重置普通抽牌计时。收拢保留选中牌的相对顺序。

预触发标签贴近所选牌，多个换行；飞牌保留每张实际起点，烧／毒／高阶组合有不同尾迹。桌面中心短暂显示组合名、直伤、旧物及效果带，命中侧显示加粗伤害，心灯边显示护盾与持续状态。暂停同时冻结模拟和动画。演出集中于一处，不以增加常驻窗口制造热闹；是否改善注意力仍需试玩。

## 助手首版规则

战前十格横向行囊容纳1–3格旧物，另有一个可空的遗物槽。点击装入，选择旧物后点击空格移动，或用左右移／取下按钮。失败移动原子拒绝，无覆盖、自动交换或丢失。物品边缘贴合才算相邻，空格中断联动；最左与最右分别支持守灯与接牌。共23物品、10遗物、9预设，完整可执行数据见 `lib/cards/throw-loadout.ts`。

| 机制 | 本轮数值与执行语义 |
| --- | --- |
| 护盾 | 挡直伤、灼烧，上限160；直伤溢出扣生命 |
| 灼烧 | 每秒扣当前层数，结算后减1，上限60；小炉每批3／至少两张红牌5，相邻风扇+50%，煤球再+2 |
| 剧毒 | 每秒绕盾扣当前层数，不衰减，上限40；药匣每张梅花3，相邻线盒+50%，药匙再+2；红心净化各移除4烧／毒 |
| 吸血 | 本批直伤实际生命损失的25%回复；护盾、超杀、反击和持续伤害不产生吸血，不复活已死亡施法者 |
| 护盾反击／盾击 | 针盒被直伤命中反击4，贴邻护盾物品为10；铜镜反射护盾吸收量35%；反击不会再触发反击。盾击在发射时取当前护盾40%快照，不消耗护盾 |
| 成长 | 同一纯花色连续出手力量+4；种子每第三批至少三牌再+4；力量上限40，从后续批次开始增伤 |
| 迟缓／穿透 | 至少两张黑牌：座钟命中暂停普通抽牌1.5秒，重复只刷新；细针让本批35%直伤绕盾。怀表施放迟缓时+12盾，冷却6秒 |
| 位置增幅 | 双邻接线盒使两侧邻居的甩牌伤害／烧／毒／盾／治疗／成长+25%；取整。增幅预告只计实际可容纳收益，不把满生命治疗计作增幅 |

九个起手方案：快甩接力、双响对子、星光蓄爆、余烬燃爆、青苔侵蚀、护灯反击、回甘续航、续曲成长、止雨穿幕。组合倍率仍由原扑克计分决定，一批只有最强组合享受倍率，其他牌按点数。最多120秒与320生命保留。

## 假设、拒绝方案与边界

拒绝“有整理遗物就把牌面拖动改成整理”，因为玩家无法统一预判拖动行为。拒绝电脑离散最优选牌，因为它会获得玩家无法执行的操作优势。未引入手动战斗中移动行囊，避免重新制造并行注意力负担。

烧／毒／盾与净化尝试建立不同进攻窗口，位置预算让强组件竞争空间。九套方案不等于九套已平衡或同强度的赢法；剧毒持久、单张成长、反击压制高频出手均需玩家验证。没有将新规则写入原50卡三路战斗或旧存档。

故事结合只在实验说明中试用“记忆灵符／旧物赋予效果”的命名。完整旅途改造仍是[提案](../../F9_WANDENG_THROW_STORY_PROPOSAL_2026-10-04.md)，不视为用户批准更换主线战斗。
