# ADR-0047：共鸣的夏日像素与手绘叙事美术试演

日期：2026-10-04。

**状态：用户要求同时开发两个可试玩方案，最终表现形式尚未选定。**

## 用户约束

- 图1至图3明确来自《SUMMERHOUSE》；图4来自《火山的女儿》。
- 方案1制作温馨可爱的像素主场景与可操控主角，横向操作可以参考甩牌分支。
- 方案2采用背景、角色立绘与对话叙事。
- 两个方案中的战斗美术也须全面替换，而非只展示故事插画。

本决定承接 [ADR-0044](./ADR-0044-resonance-outline-authoring.md) 的「先完成大纲，再确定表现形式」。两个入口是对照实验，没有推翻这一顺序，也没有选定最终画风。

## 本轮助手细则

两个方案共用阿弦与「雨停驿站」作为比较样本。像素版采用大色块的湖畔驿站、4帧步行、左右行走、点击前往、就近交互、对话期间停止行走。参照甩牌已验证的固定步长控制方法，在共鸣内部独立实现；没有跨产品导入。

手绘版采用暖色木屋、透明主角立绘、三段示例对话与两种开场选择。这些对白用于美术试演，不覆盖共同维护的 `outline.json`，不构成新主线批准。

两套战斗使用原有 `rhythm-healing-v3` 输入和模拟：九格编排、每圈首扫、装备歌曲、独立冷却心魔、多目标、回放和确定性结果。更换全部11种共鸣器具、6种心魔、宿主、场地背景、品质边框、数值图标、血条、音符、弹道与命中形状；普通首页仍保留原外观，首页新增试演入口。

## 证据与待验证项

原创素材使用内置 imagegen 生成，选用素材及提示词存放在 `public/art-assets/wandeng/presentation-v1/`。场景尺度以门、石路与人物脚底对齐检查。详见[调研、素材与实机记录](../../F9_RESONANCE_ART_DEMOS_2026-10-04.md)。本轮仅证明可操作的比较原型；最终美术取舍、长时间舒适度、后续场景扩展与动画精修仍待用户试玩。
