## 用户提出的方向（事实）

**第一轮**：

1. 卡牌效果已经有了数值成长，角色血量也应该成长，敌人血量也要越来越高。要说明在这个世界里血量代表什么。
2. 正式演出时，玩家一开始看不到敌人的卡组和道具，要通过日程里的日常玩法逐渐获取情报。
3. 生活玩法的收益收束为五类：钱（核心）、人物经验、故事（次要）、收藏品、其他（补充）。
4. 叙事节奏按城市设计：每座城市是一个成长里程碑，加一段难忘的故事。

**第二轮**：

1. 血量包装为「**气场**」（「台风」是多义词，容易让玩家困惑）。视觉上仍然是标准的血条。
2. 不要「每座城市重新开始」：玩家难以理解成长倒退，改为常规的累积成长。
3. 护盾不需要上限。
4. 每座城市的气场上限，要结合这个阶段能达到的理论成长上下限来评估。
5. 房租和伙食要展开：付不起房租会怎样？吃喝有什么作用，不吃不喝有什么后果？
6. 每座城市的主线，始终围绕挑战并战胜这座城市的强敌来写，而且每座城市的主线套路要有足够差异；八卦和怪谈作为支线。
7. 对第一轮待确认点的回答：
   - 成员之间的台龄差异：同意；
   - 情报制：同意，并且街头演出也要有部分迷雾；
   - 假情报：可以有，但玩家发现不对之后，必须告诉他「可能会出现假情报」，否则玩家会以为是 bug；
   - 新增米尔布鲁克：同意；
   - 改写手册原则：同意。
8. 调研知名文学作品，借鉴相似的大纲。

**第三轮**：

1. 心情只影响「愿不愿意登台」，作用太小（伙食 → 心情已经是两层系统）。罢演是心情最低一档的结果；另外按心情给气场百分比加成或减益。
2. 住处的规格也给全员气场百分比加成：保底住处没有加成，房租越贵加成越高；和心情加成相加。
3. 做饭吃饭包装成小玩法，另出方案：见[厨房提案](../../F9_THROW_KITCHEN_2026-10-10.md)。
4. 除第 3 条外，其余设计可以开始落地开发。

## 决定

| # | 决定 | 依据 |
|---|---|---|
| 1 | 血量在世界观里叫**气场** = **底子**（每人自己的台龄）+ **名气**（剧团共享）。只涨不跌，不按城市重置。界面仍是标准血条 | 用户第二轮 1、2 |
| 2 | **护盾不设上限** | 用户第二轮 3。实测中 160 的上限几乎从不生效，对现有内容没有影响 |
| 3 | 落幕伤害和所有「半血」判断都按自己的气场上限缩放；道具和变种的数值不缩放 | 气场成长是为了抵消数值膨胀 |
| 4 | 练习场全公开；**街头演出部分迷雾**（打法和大件道具可见）；**正式演出全迷雾**，靠情报揭开；情报分未知、传闻、确认三档 | 用户第二轮 7 |
| 5 | 假情报只来自便宜的来源；用「情报有误」印章、结算核对、报刊亭对白、每周的更正启事，在世界观内告诉玩家 | 用户第二轮 7 |
| 6 | 五类收益；**钱买东西和机会，时间买成长**；气场和台龄不能用钱买 | 用户第一、二轮 |
| 7 | 房租买住处（决定剧团规模和舒适度），欠租分三步变得不方便，永不失去成员和道具；伙食只影响心情，心情不改对局数值 | 用户第二轮 5（细节待确认） |
| 8 | 叙事按城市组织，全程一年、六站，新增米尔布鲁克 | 用户第一、二轮 |
| 9 | 每座城市的主线围绕强敌，套路各不相同：守门人、爬梯子、谍战、团队赛、诱惑、终局考试；八卦和怪谈是支线（镇志） | 用户第二轮 6，参照见故事参照文档 |
| 10 | 气场上限 =（底子 + 名气）×（1 + 住处加成 + 心情加成）。心情五档：兴奋 +8%、愉快 +4%、平常 0、低落 −8%、罢演（不登台；伊莱最低为低落）。住处：保底 0，其余 +3%、+6%、+10% | 用户第三轮 1、2 |
| 11 | 手册原则补充为「钱买东西、机会和状态；时间买成长」。状态加成要每周持续付钱维持，上限 +18%；底子和名气只能花时段挣 | 用户第三轮 1、2 与第二轮原则的协调 |

## 证据：气场曲线

用变种的获取目标，模拟三档玩家（下限、中位、上限）和同城对手，反推维持基准时长需要多少气场。基准是格雷维克，43 秒。方法和完整数据见设计文档 1.2。

| 城市 | 需要的气场：下限 / 中位 / 上限（含改装估算） | 推荐值 |
|---|---|---|
| 布里奇波特 | 328 / 331 / 336 | 340 |
| 韦斯特港 | 354 / 373 / 452 | 370 |
| 米尔布鲁克 | 368 / 397 / 507 | 395 |
| 奥罗拉 | 373 / 406 / 557 | 420 |
| 世界大剧院 | 403 / 468 / 627 | 460 |

- 第一轮提议的 594 贴着理论上限走。实测在世界大剧院，中位玩家的对局要 55 秒，47% 拖进落幕。**已否决**。
- 推荐曲线下，强敌对决 44–47 秒，中位玩家拖进落幕的比例为 21–28%。

## 未采纳的替代方案

| 方案 | 结论 |
|---|---|
| 「台风」这个名字 | 用户否决：多义词 |
| 「镇定 + 人气」，人气按城市重置 | 用户否决：成长倒退难以理解 |
| 护盾上限按气场的 50% 缩放 | 用户决定不设上限 |
| 气场曲线 320 → 594（按理论上限） | 实测否决 |
| 钱可以买训练、换经验 | 会形成「刷钱 → 买血」的最优解 |
| 情报只有「未知 / 确认」两档 | 用户选择保留假情报，加告知设计 |
| 不加城市，韦斯特港延长到 6 周 | 用户选择新增米尔布鲁克 |
| 伙食直接给对局加成 | 会变成用钱买数值；改为只影响心情 |

## 风险

| 风险 | 对策 |
|---|---|
| 护盾无上限后，新的护盾道具或金级改装可能让护盾无限堆高 | 削盾、穿透、剧毒、落幕四种克制；每加一件护盾道具，都跑「三件护盾核心」的回归测试 |
| 曲线的测量用的是代理 AI 和预设箱子，改装是估算 | 实装时做成正式工具，并让剧情模拟的玩家方带同城水平的牌匣 |
| ♣A、♦A 的传奇单张就能大幅提高胜率（小样本） | 正式复测；成立的话下调，或推迟投放 |
| 情报迷雾让新玩家不知道怎么构筑 | 布里奇波特是情报教学关，朱诺的情报很容易拿到 |
| 日程拉长城市时长，内容量跟不上 | 城市大纲第 4 节的最低内容清单 |
| 已实装的布里奇波特要包上日程层 | 已有的对决和奖励不变，存档迁移 |
