## 用户提出的方向（事实）

1. 卡牌效果已经有了数值成长，角色血量也应该成长，敌人血量也要越来越高。要说明在这个世界里血量代表什么、为什么能成长。
2. 正式演出时，玩家一开始看不到敌人的卡组和道具，要通过日程里的日常玩法（看报、打听）逐渐获取指定敌人的情报。
3. 生活玩法的收益收束为五类：钱（核心）、人物经验、故事（次要）、收藏品、其他（补充）。
4. 叙事节奏按城市设计：每座城市是主角成长的一个里程碑，加一段难忘的故事。可以在一座城市停留更久，只要内容量跟得上。

## 提议

| # | 提议 | 修订谁 |
|---|---|---|
| 1 | 血量改名为**台风** = **镇定**（每人自己的台龄）+ **人气**（剧团在当前城市的观众支持）。台风上限从 320 涨到约 594；对手按台龄和主场配置。落幕伤害和护盾上限按台风缩放；道具数值不缩放 | ADR-0057 决定 4：天生的规则仍然平等，台龄是挣来的差异 |
| 2 | 正式演出隐藏敌人配置，情报按单位揭开，分「未知 / 传闻 / 确认」三档。传闻的真假写在内容里，是确定的。练习和街头演出仍然全部公开 | ADR-0054 |
| 3 | 五类收益按价值占比约为：钱 45%、人物经验 25%、收藏品 15%、故事 10%、其他 5%。**钱买东西和机会，时间买成长**：台风、台龄、好感都不能用钱买 | 手册 07 原则 1 |
| 4 | 叙事按城市组织，全程一年。新增米尔布鲁克（秋，剧团之城，斯坦的故事）。主线约 37 小时，总计约 47 小时 | 故事大纲的结构与时长预算 |

## 理由

- **台风**：
  - 卡牌数值膨胀（变种、改装、天赋）只能用对手同步变强来抵消；
  - 「镇定 + 人气」让成长在这个世界里讲得通；
  - 人气按城市重置，正好接上「每座城市都是重新开始」。
- **情报**：
  - 让日程里的日常玩法直接服务于对局，看报、喝酒不再只是氛围；
  - 敌人预览的价值从「免费送」变成「挣来的」。
- **五类收益**：每种生活玩法的奖励都有明确的去处；收益之间不互相替代。
- **城市**：日程玩法让玩家「住下来」，叙事单位必须跟着变成城市。

## 未采纳的替代方案

- **血量直接按等级涨，不做包装**：数值上一样，但用户明确要求在世界观里讲清楚。
- **只有角色血量成长、敌人不变**：会让后期对局越来越长，并且越来越容易。
- **钱可以买训练、换经验**：会形成「刷钱 → 买血」的最优解，日程的时段取舍也会失效。
- **情报只有「未知 / 确认」两档**：更简单，挫败感更低；作为备选，留给用户决定。
- **不加城市，把剧团联赛并进韦斯特港，延长到 6 周**：作为备选，留给用户决定。

## 风险

| 风险 | 对策 |
|---|---|
| 台风成长后，规则层的「半血」「满血」判断和落幕伤害需要全部改为按比例 | 规则版本升级；剧情模拟按城市曲线验收：对局 55–70 秒 |
| 情报迷雾让新玩家不知道怎么构筑 | 布里奇波特是情报教学关；朱诺的情报很容易拿到 |
| 假传闻带来挫败感 | 假传闻只出现在便宜的来源（报纸、酒馆）；贵的来源都是确认的 |
| 日程拉长城市时长，内容量跟不上 | 城市大纲第 4 节的最低内容清单；新鲜内容用完时有自然的离开提示 |
| 已实装的布里奇波特要包上日程层 | 已有的对决和奖励不变，存档迁移 |
