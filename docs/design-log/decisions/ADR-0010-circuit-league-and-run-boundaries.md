# ADR-0010：巡回器具师联赛与单局成长边界

叙事选择已由 [ADR-0012：万灯城的物灵与归家](./ADR-0012-wandeng-souls-and-homecoming.md) 局部取代（Superseded in part）。60–90 分钟局长、局外图鉴/新选择与每局数值重养继续有效。以下保留当时决定与理由。

- 状态：已接受，仅限下述「决定」中的世界观与体验边界。
- 日期：2026-09-26
- 影响的设计 DNA：A-02、A-08、新增 A-10、MC-01、新增 MC-04。
- 相关迭代：[联赛核心骨架](../iterations/F9/2026-09-26-circuit-league-core.md)。
- 相关系统：[核心设计 v0](../../F9_CIRCUIT_LEAGUE_CORE_DESIGN_V0_2026-09-26.md)。

## 背景与问题

独立卡牌方向此前开放世界观，后集中讨论旧物灵异魔幻与巡回成长冒险。用户现在明确选择方向 3「巡回器具师联赛」，并要求完善主线关卡、卡牌收集与成长，形成完整游戏骨架。

需区分一局成长和长期收集，明确局长，避免把已做的动物美术样本、电梯规则或助手的关卡提案误记为用户决定。

## 选项

- 叙事：旧物魔幻、巡回联赛或二者融合。联赛更直接承接用户希望的旅行挑战与主角成长；旧物的主线和融合没有被选择。
- 局长：15–25、30–45 或 60–90 分钟。更长局长能让收集与投资经历多个阶段，代价是内容量、保存与节奏要求更高。
- 局外：保留卡牌数值与长期实力，或保留图鉴与新选择并重置数值。后者让每局成长依靠当局选择，同时需要足够丰富的发现与作品记录承载收藏感。

## 决定

1. 采用巡回器具师联赛为当前独立 2D 卡牌方向的叙事框架，不默认融合旧物灵异主线。
2. 目标单局 60–90 分钟，留出旅途事件与培养空间。
3. 局外保留收藏图鉴并解锁新选择；卡牌数值每局重新培养。
4. 保留用户既有核心目标：卡牌收集、局内数值养成、持续挑战强敌、收集物品与玩家自身成长，每次游玩有主角式成长体验。

四城十五战、败绩制度、调校等级、专长、市场、具体价格、PVE 与制作切片均为助手在系统文档中的新提案，尚未被用户逐项接受。

## 理由

这是用户对世界观和两个澄清问题的明确选择。设计解释是：巡回赛给予每局清楚的出发与终点，局内成长产生一段作品成名过程，局外图鉴延续发现与履历，不依赖永久攻击生命累积。

## 影响

- 用 MC-04 独立描述「旅途获取 → 当局培养 → 连续挑战 → 局外记录与新选择」；不把旧 MC-02 实体转化和 MC-03 电梯撤离闭环强加回来。
- 更新当前状态与玩家体验入口；早期候选保持原文，新增链接注明选择已发生。
- 运行代码、三路战斗、存档和成长系数未在本轮变更。后续实装数值养成必须显式版本化，不能把旧 level/quality 与新调校重复叠加。
- 不影响另一条电梯生存任务，不替卡牌模式确认最终单机/多人定位。

## 证据与待验证

用户原文：「我选方向3：巡回器具师联赛」。澄清回答为「60–90 分钟：更多旅途事件与培养空间」与「收藏图鉴、解锁新选择；卡牌数值每局重新培养」。

这些是方向选择，尚无联赛原型、经济模拟或玩家试玩证据。完整骨架中的占位数字与制作范围分别标为提案与验证切片。
