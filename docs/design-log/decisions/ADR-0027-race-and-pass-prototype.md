# ADR-0027：综艺竞速与通行证首版

- 日期：2026-10-03。
- 状态：用户授权两个系统的设计与开发；首版已实现，助手所选数值待试玩验收。
- 影响：MC-03的目标、阶段压力和风险回收，A-08的资源与空间决策。
- 细则与接口：[实现文档](../../F9_RACE_AND_PASSES_IMPLEMENTATION_2026-10-03.md)。

## 决定及其理由

采用通行证决定实际爬升距离，电梯成长决定单次跨度。普通怪仍掉脑浆；通行终端承担另一条资源线，避免杀弱怪同时解决所有成长与晋级。未把每次上楼同时锁在等级和票两道收费后。

每十层为不能跳过的审查点：击败驻守者，在电梯提交2张当前段票；余票转经验，发下一段2张。以公开的12分钟资格期限作为首版紧迫感，探索、返程、救援和电梯停留计时，暂停与界面思考停止全体。晋级后不允许在旧审查点无限拖延下一段计时。

死亡救援保留已登记票；普通背包仍可追回。死亡与本季资格注销有不同后果和演出。先到100层决定最终胜者，不能由主持人或大模型独立宣布相反结果。

第三层首次返程之后揭晓节目，复用现有教学、终端、资产包、像素界面与升级演出。选手排名和广播来自权威事件；AI未接入时明示未入场。全体遵守共同来源、成本、tick和原子交易，接口已实现，真实AI相遇仍在另一个分支。

## 历史关系

实现[ADR-0026](./ADR-0026-race-to-floor-100.md)的长期目标，具体规则按本记录局部接替其待定状态，原记录保持为当时讨论。第三层之后通行证跨层替代[ADR-0020](./ADR-0020-survival-needs-guidance-and-ascent.md)中升级作为唯一开层途径；前三层教学与单向上楼、[ADR-0023](./ADR-0023-survival-sight-brains-and-recovery.md)的死亡追回规则保留。

## 假设与证据

跨度3／5／7／9、上限10张、12分钟、3秒与8秒登记、15秒冷却、审查2张、余票5经验均为首版调试值。代码测试验证合法动作、兼容和结果一致；实机确认可操作路径与演出，没有证明竞争趣味、接触率或百层平衡。只有三名未入场占位，未编造AI进度。

需要观察：刷慢终端是否支配策略、跨层是否真正放弃有价值的准备、12分钟是否过紧、十层是否能有效会合、落后是否有合理追赶机会。后续逐段审查挑战和淘汰配额不在本次决定内。
