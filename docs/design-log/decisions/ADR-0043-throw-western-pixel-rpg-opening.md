# ADR-0043：现代西方奇幻与横版魔术师 RPG

日期：2026-10-04。

**状态：用户指定题材、参考与角色行动；初始街区切片已实装；完整夺冠主线仍为设计稿。**

## 用户决定

上一版魔术师故事的中国风不符合扑克牌调性。改为现代西方奇幻，保持个人英雄从落寞故乡逐步赢得世界冠军的主线。游戏采用像素横版 RPG，玩家控制主角移动，不需要跳跃；能够进入建筑、与 NPC 对话并进入既有甩牌战斗。美术调研参考《水银疗养院》。

本决定局部接替[ADR-0041](./ADR-0041-throw-magician-personal-championship.md)的具体地名、人物与表现包装，不撤销个人夺冠目标；历史剧本不改写。

## 本轮创作与实现

[新版剧本](../../F9_THROW_WESTERN_MAGICIAN_RPG_V1_2026-10-04.md)采用格雷维克、伊莱·维尔、现代巡回赛事、电灯与 Art Deco 剧院。人物与地名是助手暂定创作，公开评价与舞台待遇带来的爽感仍为体验假设。

`apps/throw` 首页改为可控角色的街区；原 `/wandeng/throw` 继续作为独立练习场。三个原创场景、主角四帧角色图集与三 NPC 图集由内置 image_gen 生成，最近邻呈现，保留透明背景。NPC 是原创人类，艺术参考不代表照搬原作拟人动物、场景或叙事。

执行组合：横向行动 → 靠近交互 → 场景／对话选择 → 道具布阵 → 主动甩牌 → 确认真实结果 → 返回场景 → 更新资格任务 → 巴士收尾。点击地点会实际步行，进门与交谈仍需在范围内触发。对话、地图与失焦停住行动。

导师的完成条件是完整打完一场练习，胜负产生不同对白；中途退出不给教学进度。正式资格赛必须实际胜利，失败／平局不发参赛证；同一结果只确认一次。该任务区别是本轮原型细则，不是战斗倍率变化。

## 规则与范围

冒险层为 `magician-adventure-v1`，种子、方向、步数与战斗编号明确；交互失败不消耗或部分推进。战后回到指定原图与位置，已选择的道具构筑在本次旅程内保留。没有冒险存档或全局永久属性增长。

战斗保持 `throw-duel-v3` 的规则、随机流与原有数值，不加入剧情必胜、掌声倍率或强制终结牌型。使用现有构筑、道具、单遗物、伤害与音效。后四幕、完整章节存档和跨局收集尚未开发。本轮不发布外网，不改其他产品存档。

本轮对设计原子的影响是为主动选择与清晰提交增加可行动的场景入口，详见[设计 DNA](../01_DESIGN_DNA.md)新记录。场景观看、走路时长与正式赛季节奏仍需试玩。
