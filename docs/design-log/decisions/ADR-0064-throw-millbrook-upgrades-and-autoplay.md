# ADR-0064：米尔布鲁克、按机制改装与可观察自动出牌

- 日期：2026-10-12；项目：甩牌；对决 v16，冒险 v10。
- 状态：已决定并实装；[证据与限制](../iterations/F9/2026-10-12-throw-millbrook-upgrades-and-autoplay.md)。
- 局部取代 [ADR-0061](ADR-0061-throw-recovery-and-westport-troupe.md) 的统一百分比改装、最多两件金级与第三幕终点。扩展 [ADR-0063](ADR-0063-throw-team-preparation-and-intermission.md) 的独立队员备战为三人联赛；五秒保护、公共池独占、阶段重置保持。

## 事实

用户要求完成第四幕，银/金级强化道具自身机制，金级消耗同款且不设数量上限，说明直接展示新数值；自动出牌应根据手牌、道具与遗物选择动作。原统一倍率不能表达抽牌频率、穿透与净化，原金级配额不符合新成本。重复购入不能自动把公用原件变成多个可装备实例，否则会破坏独占分配。

## 决定

1. 所有26件道具的字段表 `ITEM_TUNING` 是实际效果与描述的共同依据。银级通常约提升25%，金级多为翻倍（穿透、百分比和时长各自校准）；抽牌闹钟从每4次→3次→2次出手抽1张。触发张数、家族门槛、格数、禁手不改。数值先强化，再计算相邻增幅及家族效果。
2. 银级£12后才可金级；金级£28加一件同款道具材料，材料来自第三幕起的重复购买并存入 `spareItems`。费用、材料和级别单次原子提交；失败全不消费。没有金级总数上限。原收藏每种一件的身份不改。
3. 描述按字段替换，不能追加通用buff段。例：飞牌修缮箱直伤8→10→16，穿幕细针穿透30→40→60%，清露净化4→5→8层。工坊显示当前和两级结果；背包、布阵详情与战斗预览使用相同实际数字。
4. 自动出牌默认关闭，玩家随时切回手动。枚举手中所有合法连续范围，用真实道具/相邻/遗物/人物/改装预览，估算盾抵扣、削盾、实际治疗缺口、持续状态余量、净化与反弹风险，并按禁手成本估价。只能使用公开当前状态，不看牌堆。使用已有合法整理和角色手法，整理遵守20秒冷却。选牌先高亮600ms再发出，暂停及禁手使用同一规则tick；自动时不接受手动出手。
5. 第四幕落实[米尔布鲁克内容清单](../../F9_THROW_MILLBROOK_2026-10-12.md)：三人联赛、后台调查、公开重赛、斯坦回归、决赛、四条镇志支线、可租住处/商店/新人物/音乐。第五幕只留邀请。队员配置可切换，成员及顺序可选，公共收藏与伙伴本命变种都进入同一个独占池。
6. v9冒险存档迁移到v10时补空同款材料与新旗标，保留旧进度、钱、已改装道具和个人箱元数据。对决v16独立版本，不重写历史黄金回放。

## 假设与证据边界

自动策略是确定性的短期价值评估，不是保证最优的搜索器；未证明长期经济、真人决赛难度或音乐审美。首轮自动模拟暴露公共池相撞导致伙伴空箱，默认朱诺组合/斯坦护盾使三人各有用途；首轮气场285/290/310替代320/330/350，避免新三人赛直接成为决赛。前后固定种子证据单列，不以脚本强胜伪装难度。
