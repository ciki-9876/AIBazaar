# ADR-0010：现实尺度的初始电梯与出门运镜

日期：2026-09-26。范围：独立 `/survival`。状态：用户方向已决定；首个轿厢及镜头流程已实装，扩容经济尚未决定。

## 用户决定

1. 电梯内采用第一或第三人称，以增加身处其中的感觉；进入房间时运镜过渡到俯视。
2. 初始内部结构与空间大小以现实电梯为依据，游戏发展后才逐步升级为更大、不可思议的空间。
3. 延续此前已确认的冥河庭院手绘风格，与房间中的工业物件一致。

此决定取代[维修营地首版](../iterations/F9/2026-09-26-survival-service-lift.md)作为开局空间的安排。旧版本作为历史与后期扩容候选资产保留。

## 本轮选择及依据

- 选择第一人称，眼高 1.62 米；站在轿厢内可拖动或按方向键环顾。眼高、视角和演出时长为原型配置，不是用户指定数值。
- 以 [Schindler 1000 官方规划表第 15 页](https://www.schindler.qa/content/dam/website/mena/docs/schindler-1000-elevator.pdf/_jcr_content/renditions/original./schindler-1000-elevator.pdf)中的 630 kg / 8 人配置为尺寸参考：轿厢 1100×1400×2139 mm；选 C2 中分门、900 mm 宽、2000 mm 高。现实中有不同轿厢规格，本版选择这一具体参照，而非假设所有电梯相同。
- 初始仅有双扇滑门、门槛导轨、侧壁按钮面板、楼层显示、后扶手、通风孔、完整顶板和顶灯。保留房间的青绿旧漆、象牙色面板、黄铜及细墨线；不放床和工作台。
- 初次出发：1.2 秒开门 → 1.8 秒走出 2.4 米 → 1.6 秒抬高到俯视。位置与阶段由固定模拟步驱动，可暂停和序列化。首次入场期间不推进战斗计时、生活消耗或刷怪，结束后同时启动。
- 回程继续使用俯视，以便判断门口威胁；必须整个人进入轿厢，才可开始原有 2.2 秒撤离。门在读条时保持打开，移动或受伤仍打断；成功后切回舱内视角并关门。不会因为接近电梯而自动停战或恢复。
- 俯视时剖切顶板和高墙，保留低墙与门框定位。近距离恢复完整结构。视觉剖切不移除碰撞。

## 扩容方向与未定项

用户已决定由现实小空间成长为超常空间。建议依次验证「普通乘客轿厢 → 可展开的储物／工具设施 → 可生活的维修营地 → 突破外部体积的空间」。具体阶段数量、尺寸、解锁资源、永久保留与设施功能均为待设计项，不能把这条建议当成已完成的成长系统。

原 6.9×6.8 米营地保留在 `elevator-expanded.ts` 与 `survival-lift-expanded.ts`；当前不加载，不提供假解锁按钮。本次不新增局外存档、建造资源或升级费用。

## 体验假设

现实起点建立身体尺度与熟悉感，后续扩容才形成可感知的成长。进入危险楼层时，镜头逐步交出战场信息；返程则保留可读性到撤离完成。仍需玩家验证小门洞是否难以点击、开局演出是否过长、第一人称是否比第三人称更合适。

实现与检查见[本轮记录](../iterations/F9/2026-09-26-survival-passenger-lift.md)。
