- 建立在 [ADR-0052](./ADR-0052-throw-v6-vector-stage-and-tempo.md)（v6 节奏：白热、三张组合、默认整理）之上，补充 [ADR-0050](./ADR-0050-throw-curtain-call-and-card-variants.md)。规则版本从 `throw-duel-v6` 升到 `throw-duel-v7`。v6 的阶段补牌、牌堆随机流、牌匣上限、稀有度结构、每张牌一张专属传奇都不变；冒险存档仍是 `magician-adventure-v4`，不需要迁移。

## 背景（事实）

[评估](../../F9_THROW_CARDS_RELICS_REVIEW_2026-10-09.md)在 v5 上测出四个问题。v6 节奏上线后在 v6 上重测，结论不变，部分更严重：

| 问题 | v5 | v6 |
|---|---|---|
| 一张指定的牌每局被甩出的概率 | 40% | 38% |
| 同一张牌在落幕后被甩出的概率 | 2.7% | **1.3%**（对局更短） |
| 稀有度倒挂：最强稀有（衬里）的提升 | +11.7，比 5 种史诗强 | +13.5 |
| 专属遗物在本流派的排名 | 快甩第 3、护灯第 5、回甘第 3 | 快甩第 3、**护灯第 4、余烬第 2**、回甘第 3 |
| 万金油遗物 | 接力闹钟、余响拿下 3 套的最佳 | **接力闹钟一件拿下 3 套**（护灯、回甘、青苔） |
| 死遗物 | 双层旧邮匣、折光铜镜 | 双层旧邮匣（6 套都等于不带） |

## 决定

### 1. 三条线的分工

- **遗物 = 规则**：每局都在，决定这一局怎么打。专属遗物必须是本流派的前两名；任何遗物都不能是 3 套以上卡组的最佳；没有死遗物。
- **道具 = 引擎**：稳定产出。
- **变种 = 高光**：任何时候打出都要有价值；「落幕」只能当加成，不能是唯一条件。

### 2. 遗物

| 遗物 | v6 | v7 |
|---|---|---|
| 接力闹钟 | 每出手 3 次抽 1 张 | **不再抽牌**：连续甩出单张时，从第 2 张起每张直伤 +1；出多张就清零 |
| 余响八音盒 | 每次受击 +3，上限 12 | 只在生命低于一半时积累，+3，上限 9（翻盘件） |
| 红心补缝毯 | 被单张命中治疗 4 | 被单张命中治疗 2，巡演箱里**每件治疗道具再 +1**；溢出生命上限的治疗一半转为护盾 |
| 灶心煤球 | 施加灼烧 +2 | 保留 +2；**对手净化你点的火时只能净化一半** |
| 浸露药匙 | 施加剧毒 +2 | 施加剧毒 +1；**你下的剧毒每 3 秒才退 1 层**（原 2 秒） |
| 折光铜镜 | 2 张及以上反射 35% | 2 张反射 40%，3 张及以上 70%；单张仍不反射 |
| 双层旧邮匣 | 手牌上限 +2 | 保留；出牌时手牌 ≥ 9 张：直伤 +8 |

v6 删除的三息理线盒不恢复；星光仍不带遗物。

### 3. 变种

| 改动 | 内容 |
|---|---|
| 稀有附魔按点数分段 | 2–8 是小牌，效果完整；9 及以上只有象征性的效果。磨边 4/1、衬里 4/1、薄荷 5/2、火漆 2/1、苔痕 2/1。描银不变 |
| 透甲 | 甩出时直伤 +4；单张时 50% 穿透（原 15% 穿透） |
| 谢幕 | 甩出时护盾 +4、治疗 3；落幕期间 ×3（原只在落幕） |
| ♠5、♥Q、♣5 | 平时有基础效果，落幕期间加强 |

### 4. 冒险数据

第二幕的稀有变种奖励和商品从大牌移到小牌，例如 ♥9 薄荷 → ♥8、♠K 磨边 → ♠4；朱诺牌匣里的 4 张磨边从 K 移到 3，霍布斯的苔痕从 ♣9 移到 ♣8。已经拿到的旧变种仍然有效，只是按新规则结算；id 不变，存档不用迁移。

## 被否决的方案（证据）

前 6 条在 v5 上测试，后 5 条在 v6 上测试。

| 方案 | 为什么不要 |
|---|---|
| 补缝毯：「着火时治疗打八折」 | 直接削弱声明过的克制「余烬克回甘」（71% → 47%） |
| 煤球：「对手每次烫手，借火 +3」 | 回甘一出红心就净化，很少烫到 3 层；余烬均值跌到 25% |
| 药匙：「毒发阈值从 5 张降到 4（或 3）」 | 青苔克护灯降到 56–57%，低于 60% 的验收线 |
| 接力闹钟：只算单张、连续单张、或手牌 ≤ 4 时抽牌 | 只要还能抽牌，护灯就最爱它 |
| 铜镜对单张也反射 15–25% | 护灯只多 +3 个百分点，却要推翻「单张不被铜镜反射」 |
| 全局抽牌节流（3 / 4 / 6 秒） | 六套卡组均值变化都在 ±1 个百分点内 |
| v6 上：接力连击上限 +2 | 快甩均值 63–66%，余烬克快甩、星光克快甩跌破 60% |
| v6 上：补缝毯固定回血 2 或 3 | 回甘均值 28–34%，跌破 35% 下限 |
| v6 上：补缝毯固定回血 4（v6 原值）+ 溢出转盾 | 补缝毯成了快甩、护灯、星光三套的最佳遗物 |
| v6 上：药匙只有慢退、没有 +1 | 青苔均值从 57% 降到 47% |
| v6 上：余响只记 2 张以上的命中 | 余响对所有卡组都只比不带高 1–2 个百分点，成了死遗物 |

## 结果（自动对局，v6 → v7）

- **克制环**（200 种子对称矩阵）：11 条声明全部成立，最低 65%（星光克快甩）。六套均值 40–62%（v6：39–62%）；变化最大的是回甘 39 → 44、星光 57 → 55、快甩 45 → 48。
- **遗物**（每格 120 局）：护灯、余烬、回甘、青苔的专属遗物排第 1；没有遗物是 3 套以上卡组的最佳；双层旧邮匣比不带高 13 个百分点（快甩）。**快甩的接力闹钟排第 2–4**，比不带高 11 个百分点，和前几名的差距在误差内。
- **变种**（每格 60 局）：稀有放在小牌上 +5～+8，放在大牌上 +1～+4（描银两边都是 +6）；史诗里镀金 +11.5、连环 +11.2、谢幕 +7.5（v6：+0.7 级别），透甲全场 +3、在快甩上 +8；百搭、共鸣全场 +1～+2。
- **落幕牌**：概率没变（一张牌在落幕后被甩出约 1.3%），但现在任何时候打出都有基础效果。
- **第二幕难度**：曲线基本不变。默认巡演箱打艾格尼丝 55 → 65%、霍布斯 60 → 70%、派克 18 → 25%、朱诺 75 → 70%；护盾巡演箱打霍布斯、姐妹各高约 20 个百分点（铜镜加强）。

## 影响

- 规则版本 `throw-duel-v7`。牌堆随机流、阶段补牌间隔不变；冒险存档 `magician-adventure-v4` 不变。
- 所有遗物、变种的规则文字已同步；对决界面在理牌状态旁新增遗物状态（接力、余响、满匣、补缝回血量），预览分项和规则弹窗已同步。

## 待验证

- 快甩的专属遗物仍不够有吸引力（第 2–4 名之间浮动）。
- 百搭、共鸣在本流派里也只有约 +7，没达到史诗的目标（+8～+12）。
- 回甘对快甩 96%、星光对回甘 98%，都是 v6 原有的硬克制，本轮没有动。
- 代理玩家不是人：真人试玩时最先看接力连击的手感，以及余响「半血以下才积累」是否看得懂。
