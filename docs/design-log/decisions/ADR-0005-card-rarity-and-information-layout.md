## 背景与问题

上一版以满幅插画和炫彩材质为主，仅放置名称和示意关键词。用户要求补齐普通至传说的四档外观，并用附图明确名称、定位、描述、主属性数字及冷却的布局。

## 选项与决定

不继续沿用只有底部卡名与关键词的外观，选择能承载规则和数值的卡面结构。最高级炫彩保留，新增普通（灰）、稀有（蓝）、史诗（紫）、传说（金）的视觉等级。

### 用户已明确的信息结构

1. 顶部放卡牌名称与定位词缀。
2. 卡面下部留出效果描述区。
3. 冷却位于描述区内，但使用显眼、独立的位置，不能混入描述正文。
4. 最底部用数值贴片展示伤害、治疗与用户明确列出的屏障修复等直接输出。
5. 相邻卡牌冷却 -1 等特殊机制数值留在描述区，不作为底部输出贴片。

| 输出类型 | 用户要求颜色 |
| --- | --- |
| 直伤 | 银色 |
| 灼烧伤害 | 橙色 |
| 毒伤 | 深绿色 |
| 治疗 | 亮绿色 |
| 屏障修复 | 黄色 |

### 本轮执行选择与假设

- 稀有度色主要作用于边框；输出贴片色保持固定，避免同一颜色在同一位置表达不同语义。
- 贴片增加小图标与短标签，作为颜色之外的识别手段；此为设计建议，待用户验收。
- 三种尺寸统一用稀有蓝边比较布局，另用同一张火花电池比较四档外框。尺寸和稀有度互相独立，不因三张尺寸样例而遗漏第四档稀有度。
- 冷却采用描述区右上角的时钟胶囊；窄卡描述换行，宽卡利用横向空间。
- 三种尺寸仍暂按等高、横向宽度 1:2:3 的布局规格设计。生成图透视和边缘不作为精确像素标准。

## 理由与影响

名称与定位用于辨认和初筛，描述承担条件与特殊机制，底部输出数值用于快速比较，独立冷却位置用于读取发动节奏。把稀有度和输出类型分别编码到边框与贴片，可减少金色品质、黄色修复以及绿色伤害／治疗之间的混淆。

这一信息结构细化 A-08：可观察自动战斗需要玩家先在卡面区分效果条件、输出类型与冷却，而不是把所有数字放进同一属性行。

## 证据与待验证问题

- 用户事实：本轮明确陈述与标注图片；图中占位方块只是布局参考，不是最终材质。
- 已交付：1 至 3 格信息布局图、四档稀有度对照图，均为静态概念。
- 视觉检查：三种尺寸与四档颜色齐全，顶部名称／定位、描述、冷却与底部贴片分开；特殊机制 -1 只在描述区；五类输出颜色均有示范。
- 示意数字：火花电池 3.0 秒／直伤 8，汽水连发器 4.0 秒／直伤 12、灼烧 5、毒伤 3，午夜放映机 6.0 秒／治疗 20、修复 15。它们仅用于视觉排版，不代表正式卡池、真实行为或平衡结论。
- 未决定：持续伤害数字的每秒／每次／总量口径、成长与临时增益的展示、长描述折叠、多于三类输出在 1 格卡上的适配。不能从本概念图推导这些规则。
- 待验证：用户视觉验收、真实战场小尺寸辨认、流光与数字叠加、动态冷却呈现。
