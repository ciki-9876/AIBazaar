# ADR-0023：可追回的死亡背包、脑浆与怪物视野

日期：2026-09-28。状态：用户规则已实施，数值与演出待试玩验收。仅适用于 `/survival`，不改变独立卡牌战斗。

## 背景与问题

用户要求失败先有倒下、渐黑与救援叙述；普通背包留在死亡地点，而非永久删除。怪物要依靠视野追击，不再始终知道玩家位置。升级材料需要具体身份、品质和堆叠。并要求修复对话、拖拽、暂停层级，强化升级反馈。

## 已决定的规则

- 精神力归零：角色倒下，屏幕渐黑，显示「你撑不住了，安泊将你拖回了电梯」。普通背包原子移入死亡地点的一个背包容器，装备与安全容器保留。重进同层可翻找追回，重复拾取不会复制。上升导致低层永久不可访问的原规则仍生效，因此留在低层的背包也不能再追回。
- X 材料改称脑浆，描述为「打爆怪物掉落脑浆很合理，升级电脑需要脑浆也很合理」。低质、普通、精良、极品四品质，同品质每格最多 20 份，不同品质分组。每份保留稳定身份，堆叠、支付、保护、死亡与结算不丢失单位记录。
- 所有击杀均掉落脑浆，可接近即拾取。更高楼层提高基础品质，怪物等级提高升品质的概率；使用战斗的确定性随机序列。
- 领地怪按区域生成，失去目标后返回出生区域；突袭怪在玩家附近生成，出现时仍须至少相距 5 米，失去目标后原地停留。二者都遵守既有同时存在数量预算。
- 怪物只有视距内无遮挡时才发现玩家。视野丢失后寻路至最后目击位置，持续 3 秒；重新看到玩家会刷新计时，否则取消追击，不读取玩家的隐藏位置。
- 世界遮挡物具有低／高两个视野高度类别。低柜、箱子、矮墙、水池等不挡视野；建筑、墙、高架、泵机、树和竹丛挡视野。两种高度都保留原有移动碰撞。月门只在门柱处遮挡，开口仍能通行和看见。
- 电筒只增加光明视野，不增加跟随角色的实体灯光。净水瓶仅主动使用。
- 初始普通背包改为 4×4、16 格，装备栏保持十格；每个基础格为正方形。
- 电梯内首次饱食≤50 或饮水<50，安泊仅赠送一次面包与水。满背包时保留待领资格，整笔发放成立才记为已赠送。

## 实施参数（助手初值，非已证明的平衡结论）

| 脑浆品质 | 每份升级经验 |
| --- | ---: |
| 低质 | 5 |
| 普通 | 15 |
| 精良 | 40 |
| 极品 | 100 |

- 当前居所 1→2 消耗 30 脑浆经验与机械零件×2，接通第三层。按背包顺序消耗完整材料单位；多支付的经验存入电梯，不浪费。首次能源核心投喂维持独立配方。
- 基础品质为楼层减一，最多极品。默认怪物等级：爬行者1、突进者2、重型3、驻守者4；每多一级增加20%升一品质概率，上限90%。数量分别1、2、3、6份。
- 默认视距普通怪12米、驻守者10米；首次三怪教学视距24米以覆盖镜头边缘入场。丢失视野计时90帧，固定30Hz。
- 倒下到返回约4.8秒；升级演出约6秒，包含能量汇入、结构转动、奖励揭晓与合成音效。减少动态时缩短并去掉旋转与粒子。演出不重复扣费。

## 选择与理由

采用可回收背包，保留失败压力，同时提供再次出门的具体目标。拒绝免费复制关键物资的补救包；首次荒原失败也找回真实背包。保护容器仍有意义，因为追回有战斗与单向上楼风险。

采用共用视野规则与独立移动碰撞，而不是所有障碍都挡光或怪物透墙追踪；路线和地形因此能用于脱战。主题包为资产声明视野高度，避免每层另写规则。

升级演出属于呈现层；支付、材料身份和地图随机仍由确定性规则驱动。暂停使用浏览器原生顶层模态层，同时释放拖拽捕获，避免透明遮罩吃掉点击。
