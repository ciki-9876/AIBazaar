# ADR-0041 甩牌魔术师个人夺冠主线

日期：2026-10-04。

**状态：用户已选择题材和成长主线；详细剧本为助手草案；未实装剧情或新冒险规则。**

## 用户决定

用户接受流浪魔术方向，并指定个人英雄主义爽文：主角是出生于落寞魔术之乡的魔术师，开场被嘲讽，随后从乡村、小镇、城市、大城市一路成长，最终拿下世界冠军。用户要求参考网络爽文套路并整理更详细的剧本。

这一决定接替 [ADR-0038](./ADR-0038-throw-workbench-and-world-candidates.md) 中五个世界观尚未选定的状态。此前魔术团候选的“寻找散伙同伴并重新开幕”不再作为终局主目标；主角个人夺冠成为主线，故乡和巡演班底可以作为支撑。旧候选保留历史原义。

## 助手草案

[详细剧本](../../F9_THROW_MAGICIAN_HERO_STORY_V0_2026-10-04.md)包含六格开场、17个关键场景、故乡衰落原因、比赛晋级、主要人物、关键对白与冠军返乡结局。折光乡、林烁、陶师傅、艾禾、费奇、洛岚、季衡、阿斯特均为暂名，未获用户逐项确认。

助手建议主角从开场就有多年练成的手法、明确野心和愿意改造道具的主动性，靠不断发展的个人构筑扬名。嘲讽者与世界冠军分开，前者回收最初的评价，后者通过全力对决证明最终胜利的份量。高手认可、第一张海报、后台名牌与各地转播逐步提高社会身份；这些是设计假设，不是已验证玩家情绪。

## 规则与研究边界

本轮没有改变三秒抽牌、单选／连续框选、牌型、十格、单遗物、战斗数值、保存或回放。真实魔术、巡演箱与赛事保护是叙事草案，不增加掌声资源、隐藏天赋倍率或强制牌型。夺冠演出只能在真实胜利后触发，不允许剧情把失败改成胜利。

已查阅四部作品的官方或授权简介及部分开篇，作品事实和套路归纳在正文中分别标记并给出来源。74分钟为60–90分钟目标内的预算，不是实测。冒险失败、复赛和重复赛季等仍为未选择的系统建议。
