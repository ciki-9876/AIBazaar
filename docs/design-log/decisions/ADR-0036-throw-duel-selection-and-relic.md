# ADR-0036：甩牌选牌与单遗物槽

**状态：用户要求已实现；助手提出的遗物规则和数值仍待试玩。**

点击始终只选择一张牌；拖动手牌执行一次连续框选并替换原选区。主动出手使用按钮或空格。拖动牌面不兼任整理，以免相同手势有两种结果。

行囊之外保留一个可空遗物槽。理线盒通过明确按钮整理手牌；只有成功改变顺序才进入三秒冷却。容量遗物增加两张上限。其余遗物提供抽牌、反击和续航的候选流派。选牌预览解释将触发的物品效果，命中反馈展示实际造成的效果。

此决定承接并局部取代甩牌初版的累计点击与牌面拖动整理。稳定牌 UID、点数与花色；失败移动、无效整理或失败出牌不能消耗冷却或手牌。模型只读取可执行选区，不能选择玩家无法框出的离散手牌。原始用户需求、助手首版包装及体验假设见[分支 ADR-0028](../archives/throw-card-duel-branch/design-log/decisions/ADR-0028-throw-duel-relics-and-selection.md)与[实现记录](../archives/throw-card-duel-branch/design-log/iterations/F9/2026-10-03-throw-duel-relics-and-motion.md)。
