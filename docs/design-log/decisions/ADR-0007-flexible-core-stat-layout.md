# ADR-0007：核心效果数量独立于占格尺寸

- 日期：2026-09-26
- 状态：用户明确否决固定数值角位，并要求一张卡可同时拥有多种核心效果；自动换行和向上增高为本轮修正方案，待验收。
- 局部取代：[ADR-0006](./ADR-0006-integrated-colored-numbers.md)的固定角位／底边位置方案；保留数字字色语义与无数值标签方向。
- 影响的设计 DNA：A-08 的可观察性；占格尺寸不能被表现层误用为核心效果数量上限。
- 范围：独立卡牌外观和信息布局，不改变卡池、效果结算或存档。

## 问题与用户约束

上一版分别给 1、2、3 格样例安排单个、三个和两个数值，并用固定角位承托。用户指出一张卡可能同时具有直伤、灼烧、毒、护盾、治疗等核心效果，布局不能把数值区域限制死。

已明确约束：卡片尺寸不决定可拥有的效果种类或核心数值数量。1 格卡同样需要能显示多种效果，不能因为卡面角位不足而隐去或禁止合法效果。

## 方案与本轮选择

移除固定角位与专属凹槽，把输出作为有顺序、可重复排布的数值列表。存在多少核心效果就排多少个数值，不预留空效果槽；数字本身的颜色继续表达类型，不增加数值旁文字或图标。

本轮视觉方案使用统一字号与间距，按实际可用宽度排列，空间不足时整项换行。一个数字不拆开，换行后的区域向上增高，先减少插画露出，为独立冷却和机制文字保留空间。卡片外部高度不变，不以不断缩小字号或横向拉大数字来适配尺寸。

本轮展示五项只是验证案例，不定义五项硬上限、固定五列或固定两行。未来新增效果不应要求重画专属角位；超过可读空间时需要另行验证展示上限或展开方式，不能声称有限卡面支持无限信息。

## 静态验证案例

三张卡统一展示同一个有序列表：银灰 128、橙色 24、深绿 16、黄色 36、亮绿 48。顺序暂用于对照，不是用户已确认的正式排序规则；颜色沿用前序对应关系。

- 1 格：第一行三项，第二行两项；独立冷却与机制文字保留，数值区增高。
- 2 格：五项单行，整组居中。
- 3 格：五项单行，整组居中，字号和间距不因宽度变大而扩大。

卡名延用三个视觉样例，定位临时统一为“复合 · 联动”。它们仅用于多效果排版验证；所有数值均非正式规则。示例增加三位数，用于暴露数字宽度压力。
