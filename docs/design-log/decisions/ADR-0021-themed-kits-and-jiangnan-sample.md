# ADR-0021：主题构件集与中国风样板

日期：2026-09-27。状态：资产包方向由用户采纳；听雨庭首版已实装，具体审美和关卡节奏待试玩验收。

## 用户决定

采纳“主题资产包”方案。资产应尽量复用，在符合主题的前提下，通过装饰、配色形成不同效果。先制作中国风样板。

## 执行解释

- 跨主题仍需不同的大轮廓和空间组织：中国庭院采用主殿、侧廊、月门、荷池。沙漠、魔法世界等不能仅把这套庭院换色。
- 同主题共享几何构件，变换材质、陈设和光线。首版江南构件集包含建筑、月洞门、粉墙、荷池、树、竹、立灯等八类实例；建筑内部共享曲面瓦顶、瓦垄、飞檐、斗拱、花格和灯笼。
- 三个氛围配方是本次制作假设：雨夜听荷（青瓦旧朱漆和雨幕）、朱灯夜宴（绛红金饰、多灯与帘幔）、月下荒祠（褪色木作、白幡、稀疏枝叶）。游戏默认雨夜；另外两套在样板页比较。三者不改变碰撞、物资身份或战斗规则。
- 楼层保存版本化构件清单、布局、主题配方和种子。已访问的快照不因资产生成规则更新而重排；颜色配方不参与玩法随机序列。
- 首版是手工策划布局配合可复用程序构件，不宣称已经完成通用自动关卡生成器。新布局需检查物资、守卫和返程可达，以及入口和应急补给不被建筑封死。

## 覆盖范围

局部取代 [ADR-0020](./ADR-0020-survival-needs-guidance-and-ascent.md) 的“新第三层默认沙岩起点”：尚未到达第三层的新旅程进入听雨庭；已访问沙岩第三层的存档保留原地图和搜刮状态。升级成本、单向上升和新手引导不变。

## 成本与未验证问题

首次主题资产的造型仍需美术投入。后续变化只修改短配方及摆放参数，运行时不调用模型，也无需逐物体重写代码。当前没有精确 token 节省比例的测量，不承诺任意主题能够零成本复用。

需用户评价：是否足够阴暗、是否仍能辨认主题、三个变体是否有明确差异。建筑当前作为室外关卡的障碍和视线遮挡物，未制作可进入的室内；声音、主题专属怪物和独立战利品尚未扩展。
