# ADR-0014：归物师以路费赎回伙伴，终局统一送达

- 日期：2026-09-26。
- 状态：用户明确规则已接受；原型已实装，叙事细节、数字与恢复节奏待试玩验收。
- 局部取代：[ADR-0012](./ADR-0012-wandeng-souls-and-homecoming.md) 的玩家战败掉物规则，以及核心 v0 的指定委托、途中赠予和追索提案；保留物灵世界观、两派与温情目标。
- 系统入口：[原型说明](../../F9_WANDENG_PROTOTYPE_2026-09-26.md)。影响 A-11 / MC-05。

## 用户决定

1. 对方战败愿意交物；玩家战败支付路费赎回，玩家物品完整保留。利益派偏好钱，使这种不对称有叙事依据。
2. 单局的最终叙事是向物品关爱机构送上一套修复好的物品。不预先指定品类，不在途中赠送，不把送达变成反复交易战力的系统。
3. 采用先前修复学徒与音乐盒的主角背景，以漫画开篇。
4. 实装标题进入、主角介绍、师傅教学、收到来信、启程，再进入卡片窗口选事件、阶段 BOSS 的循环。

## 本次原型采用的补充方案

- 接收机构暂称「万灯归物所」，师傅为许师傅，接信人为林姨；四格漫画。名字与对白是助手创作，不视为用户最终定名。
- 三个街区，每区三个事件节点后打一位守关人；教学一战，正式 BOSS 三战，第二节点可选额外对决。
- 对方败后按种子从真实上阵实例中取一件，保留 UID 和成长；胜利额外给路费。无指定剧情掉落。
- 败后路费不足由师傅垫付，后续收入先偿还；BOSS 未胜退回最后一个街边节点，可免费修缮或帮工后重试，避免构筑不足且缺钱时停滞。
- 接引时已完成基础修复，修缮等级表示进一步培养；不要求终局将每件升满。
- 同一局的路口内容、掉落与战斗可重现。固定首发种子方便这轮美术与开场验收。

以上数字与补充规则只服务原型验证。完整游戏的 60–90 分钟目标和局外图鉴/新选择、局内重养仍有效，本次不冒充完整长局与局外进度系统。

## 为什么这样改

本轮把经营风险集中到路费，把培养过的伙伴留给玩家，避免随机丢牌破坏温情与长期培养。送达放在终局，让整局的收集成长先完整兑现，再统一完成情感收束。利益派不因商业行为自动成为恶人，挑战是双方接受的交换规则。

被否决/不沿用：玩家战败随机掉牌、途中寻找指定接收人并送牌、归家换社区增益、围绕必掉剧情物品的任务；均保留在旧记录中作为历史提案，不继续驱动当前原型。

## 证据与待验证

证据：用户四条修订、确定性端到端测试、真实浏览器流程。自动测试能证明规则一致，不能证明温情成立或经济平衡。仍需用户体验：开场对白长度、教学是否清楚、事件三选一是否有吸引力、败后重试是否过于宽松、终局送别是否成立。
