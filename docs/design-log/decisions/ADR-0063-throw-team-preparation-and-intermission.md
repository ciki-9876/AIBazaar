# ADR-0063：有结果的筛选、独立队员配置与中场报幕

- 日期：2026-10-11。
- 项目：甩牌，对决 v15；冒险存档 v9 的可选布阵元数据扩展。
- 状态：已决定并实现，最终验证见[迭代记录](../iterations/F9/2026-10-11-throw-team-preparation-and-intermission.md)。
- 局部取代：[ADR-0062](./ADR-0062-throw-readable-recovery-and-local-leases.md) 的允许筛空、[ADR-0061](./ADR-0061-throw-recovery-and-westport-troupe.md) 的瞬时换人且阶段不重置。落实 [ADR-0057](./ADR-0057-throw-troupe-gauntlet-identity.md) 每人独立十格和公共收藏独占分配。

## 事实与原因

用户要求筛选的每一步始终有道具可展示、敌人待出牌明显高亮，并指出双人赛必须能为每位队员编辑道具、遗物和牌匣。此前标签从全目录取值；伙伴配置固定套预设，界面只编辑首发；替补直接出现并继承全局阶段时间。这三处都把可操作的完整规则留在了界面之外。

## 决定

1. 标签取当前匹配结果的真实打法和全部效果。添加任何可见新标签都至少保留一件物品，选中标签仍可取消；“全部”和清空均能拓宽结果。切换商品/收藏分类时清空筛选，防止旧分类的条件造成空集。不借颜色推断效果。
2. 敌人待甩卡牌不再变暗，向上抬起、金色宽边与脉冲发光，并加“待甩”标记；其他牌减弱。减少动态效果时保留静态高亮与文字。
3. 换人使用确定性的 5000ms 中场休息。规则拒绝出牌、整理和手法，停止伤害、补牌和战斗计时器的消耗；单一 tick 推进报幕，暂停/说明界面仍可停住它。关幕、双方肖像、接棒姓名、读秒和合成报幕音读取同一个状态。
4. 绝对 tick 不回退，保留事件、牌 UID 和整队账本顺序；增加 `roundStartTick` / `round`，休息结束时新场阶段从 0 开始。白热、落幕、阶段补牌和禁手、落幕附魔、自然状态时钟都使用新场时间。存活者气场、盾、状态层数、手牌、力量等保留，临时状态和冷却保留真实剩余时间。在途飞牌仍取消，不能打中新登场者。最终整队退场直接结算，无额外休息。
5. 双人备战有首发/第二棒切换页，各自独立十格、遗物、52 牌位与变种装配；启动时按两份完整配置注入规则，伙伴不凭空获得公共池之外的道具。公共道具、遗物、具体变种各独占；白牌始终免费。已分给另一人的物件不在本人的可选池，移交须先取下再切换装备。
6. 可选 `loadout.members[performer]` 保存伙伴配置，原来单只箱子的存档继续有效；嵌套配置逐项校验，复用旧存储键。进入比赛时根据真实拥有池过滤历史配置，并保留合法格位，不能影响冒险进度或给出不存在的资产。

## 待试玩假设

5 秒报幕能帮助读懂换人，但其频率和对残局耐心的影响仍需真人反馈。公共收藏的独占分配可能让默认首发拿走太多道具；暂不擅自重排玩家首发，备战页明确显示双方装配数和移交方法。
