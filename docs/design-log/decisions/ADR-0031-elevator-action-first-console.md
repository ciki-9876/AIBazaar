# ADR-0031：电梯首页围绕出发决策，减少常驻文字

- 日期：2026-10-04。
- 状态：用户批准一轮交互优化，并明确同屏不能堆放过多文本；已实现，理解效率待试玩。
- 影响：A-06信息逐步揭示、A-08可观察性、MC-03电梯准备与出发。
- 证据：[本轮迭代](../iterations/F9/2026-10-04-elevator-console-clarity.md)。

## 问题与用户决定

截图评审指出：没有通行证时，首页仍以升级投喂为主要操作；当前楼层和电梯等级容易混淆；选层藏在标签后；倒计时没有表达系统内暂停。用户授权按建议优化，但要求限制一个界面的文字量。

## 本轮采用的表达

首页采用出发与成长两区。当前楼层用F，等级用Lv.；展示近期赛段路线、真实可选目的地及票数。零票时主行动为免费重进当前层找票；有票时先选择目的地，再通过主按钮确认上升。审查层用驻守者／通行证两项状态与审查入口表达准备情况。

菜单内明确显示暂停；完整行囊、仓库与赛况保留原入口，首页提供快捷入口。升级区只显示脑浆／零件两条进度、仓库／跨度奖励及可投入材料，保留点击和拖入黑孔。选择材料后才展开本次消耗、实际增加经验和不可撤回提示；不用大段物品风味描述覆盖出发决策。

**首版布局细则**：桌面两列，窄屏上下排列；材料来源通过小仓库图标和悬停说明表达。跨层后的永久关闭提醒在选中目的地后显示，确认上升仍是独立动作。尺寸与信息揭示位置是本轮实现选择，尚未证明新玩家能快速理解。

## 规则与历史关系

局部接替[ADR-0027](./ADR-0027-race-and-pass-prototype.md)和[ADR-0029](./ADR-0029-elevator-warehouse-and-incremental-feeding.md)的首页呈现；保留两份历史记录。通行费、跨度、资格条件、时间推进、投喂配方与盈余、物品身份、存档及回放规则均保持原义。消耗预览调用现行纯投喂规则，不另写一套计算公式；首页出发通过现有开门／选层动作执行。

## 假设与验证边界

假设：把资源、路线和主行动放在一起，并按选择显示必要解释，能减少寻找入口与规则误读。工程检查和实际操作已验证主要路径，不能据此声称可读性和策略理解已经通过新玩家验收。
