# ADR-0008：手绘工业生存、大房间探索与十格装备

日期：2026-09-26。范围：独立 `/survival`。状态：用户方向已接受；本版实现与数值待体验验收。

## 背景与问题

用户选择 `/art/showcase` 的冥河庭院风格，希望移入实际游戏，但保留已有水处理站、电梯、机械物资设定。用户明确提出非人类怪物、至少十倍面积的房间、MOBA 迷雾与左下小地图、更丰富特效，以及自动攻击下继续保留 Bazaar 十格、1–3 格装备和相邻机制。

旧试玩将武器放在普通背包里就自动生效，无法表达装备空间、顺序和相邻取舍；小房间全景也不需要探索记忆。本决定推进[旧切片](../iterations/F9/2026-09-26-survival-room-demo.md)，不改写其历史，也不改变独立 2D 卡牌方向。

## 选项与决定

- **表现**：复用冥河庭院的分段明暗、墨色轮廓、手绘表面、象牙／青绿／暗红配色。继续制作水罐、泵机、检修管道、货架和电梯；未将工业题材改为希腊遗迹。普通怪物采用六足虫、漂浮触须体与甲壳兽；人类形体留给玩家和未来 AI 竞争者。后者本轮未实现。
- **规模与生成**：从 28×24 扩为 96×80，面积 7,680，为原来的约 11.43 倍。16 个 24×20 模块从三种机械布局配方按种子选择并镜像，所有配方保留连通的十字和边界通道。运行时不调用模型逐件生成大场景。详见[生成方案](../../../F9_SURVIVAL_WORLD_GENERATION_2026-09-26.md)。
- **信息**：12 米暂定视野，机器遮挡；未探索区域隐藏，已探索地形离开视野后变暗，敌人和物资实时提示只出现在当前视野内。看见机器近侧后显示其整体轮廓，不因此穿透它看见敌人。小地图同样不显示视野外敌人。
- **装备**：十格单行，装备占 1–3 连续格。保留独立八格运输背包和一格安全容器。仅已装备武器／模块生效；拾取装备优先装入连续空位，否则放入运输背包，均放不下则留在原地。整理期间暂停，可选装备后点起始格、卸入背包、保护或重新装备。
- **相邻**：按物品占用区间的左右边缘紧贴判定。暂定增幅电容使左右相邻武器伤害各 +25%；冷却模块使频率各 +20%。空格切断连接。实际伤害／间隔由同一规则提供给战斗和界面；移动装备不会重置已有冷却。
- **损失**：本切片失败时已装备物品与普通背包一起丢失，安全容器保留；成功撤离保留三者。该损失范围是本轮实现选择，尚待玩家确认体验。没有跨局仓库或存档，重开仍重置。

## 理由、被替代选项与影响

不采用“普通包里有武器就攻击”的旧切片近似：装备空间必须参与战斗构筑。运输空间与战斗空间分开，可以让搜刮收益、当场战力和保全形成不同取舍；这不是用户已指定的唯一背包架构，而是为本轮可试玩而选择的实现。

不通过把旧场景整体放大十倍获得规模：移动尺度、武器范围和单个物件尺寸保留，新增路线、遮挡和资源位置。模块化节省后续场景制作与文本生成量，但重复感仍需测试；三种配方不是最终内容量。

不将探索记忆等同于持续侦察：地形可以记住，敌人位置不被实时泄露。技能的拖尾、光束、弧电、切割轨迹与命中粒子从实际结算事件产生；粒子不反过来决定伤害。

## 证据状态

规则自动验证包括种子与序列化复现、16 个种子的所有资源／刷怪点连通、十格原子操作、真实相邻伤害、视野遮挡与记忆、激光贯穿及失败损失。浏览器实测拾取线圈和锯环、地图逐步展开，以及把电容从第三格移到第八格后钉枪 29→23、线圈 28→22、锯环 32→40。

这些证据证明功能连通，不证明规模、视野半径、敌群压力或暂停整理已平衡。下一轮重点检查：大房间是否产生有效路线选择；玩家是否能从十格栏读出增幅关系；加强特效后是否仍能识别敌人预警。
