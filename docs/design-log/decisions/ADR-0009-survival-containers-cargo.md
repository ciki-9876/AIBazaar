# ADR-0009：容器翻找与真实背包格子

日期：2026-09-26。范围：独立 `/survival`。状态：用户要求已接受；具体时长、容量形状为本轮实验配置。

## 背景与问题

用户认可上一版，要求物资不再全部散落地面，加入翻找更久、一次获得多件物品的箱柜，并让背包可以真正管理格子。此前八格运输包只有容量计数，不能表达物品形状与碎片空间。此次推进 [ADR-0008](./ADR-0008-survival-art-fog-equipment.md)，保留十格战斗装备、相邻规则和安全容器。

## 决定与理由

- 地面散件停留 0.8 秒；设备箱 3 秒；补给柜 5 秒。精力低于 25 时均乘 1.7，移动中断尚未完成的搜索。容器在场景中有实际体积、碰撞和开盖／开门状态。
- 容器预先拥有多件稳定身份物资，一次翻找尝试收取全部。装备优先装入十格栏，其余进入普通背包；放不下的物品留在原容器，之后无需重复长读条。已搜空容器保留为场景物体，不重生物资。
- 普通背包采用 4 列 × 2 行的八格空间。1–3 格物品占连续格，可以拖放或点选放置；两格物品可旋转，三格物品不能竖放进两行。自动整理确定性地寻找合法布局。
- 放置、卸下、取回安全容器都检查真实空间，不只比较总容量。无合法位置时整个动作失败，不移动其他物品或消耗资源。容器允许一次获得部分物品是明确的成功结算：得到的物品与原容器剩余物品在同一步更新，不能丢失或重复。
- 整理背包继续暂停。普通背包装备不生效；安全容器仍为一格，失败保留，且不自动使用其中补给。

长搜索换取成批物资，使玩家有理由观察敌群间隙再停下；空间管理让“能带多少”和“怎样装下”都可见。没有将所有资源都改成长搜索，也没有在满包时删除或重新抽取奖励。

## 影响与假设

对 A-02：容量决策增加形状和排列维度，战斗相邻仍由独立十格装备栏承担。对 MC-03：探索 → 选择快速散件或较慢箱柜 → 暴露于威胁中翻找 → 整理与取舍 → 继续或返程。当前容器掉落固定可复现；增加随机稀有掉落、工具开锁和受击打断需另立规则。

**待验证假设**：3／5 秒停留会创造有效风险，而非单纯等待；八格二维背包比一维容量更有趣；暂停整理不会让自动战斗频繁中断。现有自动测试不能证明这些体验成立。

## 电梯美术的独立状态

用户要求先出设计方案。已提出“移动维修营地”，保留床、桌面、操作台、屏幕，门与楼层牌为视觉中心；本轮只有[概念图与布局方案](../../art/F9_ELEVATOR_REBUILD_PROPOSAL_2026-09-26.md)，未替换实机电梯，不能视为用户接受最终外观或新增基地规则。
