# ADR-0013：梦中醒来、物品觉醒与第一次返程

日期：2026-09-26。状态：用户明确指定 20 步流程；首版实装，体验待用户验收。

## 背景与问题

核心玩法、美术和视角已转为第一人称电梯、俯视自动战斗。此前[两次短出勤的迁移提案](../../F9_SURVIVAL_ONBOARDING_PROPOSAL_2026-09-26.md)仍偏系统教学。用户这次明确以“梦境困惑—日常物品异常—恐惧返程”定义开场，并要求先完成到回电梯为止。

## 决定与理由

1. 进入游戏后睁眼，在现实尺度电梯内通过内心气泡建立困惑；拿出无信号手机、收回，再提示开门。按 E 的空间提示移至右侧按钮。
2. 保留第一人称出门并拉升俯视的入场。荒原里只显示独立门框，不显示轿厢外壳，表达跨越异世界的门。
3. 首场使用只有碎石和杂草的小荒原；先拾取电筒并明确装备，再翻找箱子。此时不展示常驻战斗界面。
4. 箱子翻找完成，先怪声、再“什么声音！”，随后三只非人类怪物从画面边缘进入。此时才让十格装备栏弹出，并由手机、电筒的真实自动光束攻击产生伤害。
5. 玩家发现物品异常，击杀获得暂名 X 材料；该材料用途为未来升级电梯。最后以危险感驱动主动回到电梯，结束本段。

顺序的意义：先让手机作为熟悉的生活用品出现，再由它攻击怪物，才有“物品觉醒”的惊讶。先让玩家走出，再让玩家主动回家，电梯才有安全感，而不只是关卡菜单。

## 取代关系与未采用内容

- 本轮取代前一版迁移提案作为首段实装依据；旧方案保留供后续教学参考。
- 局部取代 [ADR-0011](./ADR-0011-diegetic-lift-and-darkness.md) 的门前开门提示和房间进入即显示 HUD：新开场移至右侧按钮，首次怪物出现才显示装备栏。
- 大房间、迷雾、无限刷怪、生活数值、相邻装备与格子运输包仍保留于水处理站试玩；这次小型有限遭遇只作为教学例外，不全局修改长期规则。
- 本段不接入管道、竞争者、鉴定、升级消费或第二次出勤。没有把 X 材料设为已有金币的别名。

## 实现选择与待验证数值

手机占 1 格、电筒占 2 格；箱子翻找 3 秒并给水和食物；三只爬虫各 65 生命，各掉 1 份 X 材料。上述是首版暂定参数，不是用户确认的平衡值。怪声到登场的短镜头暂时停住移动；进入战斗即恢复走位。战前无攻击、生活值不衰减、不会追加波次。

荒原可行走范围 36×32，边缘用低矮碎石带标识。显示器比例只决定首次登场位置，位置量化后作为明确的模拟输入；同状态与输入仍确定性复现。角色、装备、容器和掉落均有稳定身份，重复触发不会复制物品或敌人。

## 证据边界

复用现有移动、寻路、真实伤害、容器、装备占格、入场和撤离逻辑；首段额外控制顺序与信息解锁。验收证据见[本轮记录](../iterations/F9/2026-09-26-survival-dream-opening.md)。当前仅保留本次运行内的带回结果；刷新重播，未宣称已接通跨次出勤存档和升级系统。
