# ADR-0030：首扫保底与独立共鸣线 demo

- 日期：2026-10-03。
- 状态：用户批准规则方向并授权开发；独立 demo 已实装，观看体验与数值平衡待试玩。
- 关联：A-02 有限空间位置决策、A-08 可观察自动战斗、MC-01 战斗组合。
- 承接：[ADR-0028](./ADR-0028-wandeng-rhythm-scan-direction.md)及[节奏线细化提案](../iterations/F9/2026-10-03-wandeng-rhythm-scan-proposal.md)。
- 实现规格与证据：[本轮实装记录](../iterations/F9/2026-10-03-wandeng-rhythm-demo.md)。

## 用户决定

用户指出扫描速度和触发间隔自由组合可能让小卡每圈恰好漏过触发点，明确采用「每轮节奏线首次扫到卡牌则会立即触发并重置冷却」，认可其余设计，要求开发 demo。

因此，新版每圈第一次进入某个卡牌实例立即发动，不等线的剩余冷却；发动后从此刻重新计算线的触发间隔。停留期间，间隔到期仍发动当前卡。进入新卡与冷却到期重合只发动一次。每圈重置首扫标记，空格仍占扫描时间。

此决定在新版取代0028提案中的格中心固定触发、扫描速度与触发间隔必须绑定的建议。双方初版同速同相位，但不同尺寸顺序会使各自冷却重置时刻不同，不再保证每次发动完全同步。

## 实施范围

新增 `/wandeng/rhythm`：双方各九格、1/2/3格卡、两盏心灯与生命、单条共鸣线、共同结算、有限支援、公共状态跳伤。提供11张新规则物灵、四套预设、排位与参数调整、自动对战及回放。

新卡采用独立 `rhythm-*` 身份和 `rhythm-scan-v1` 规则。形象可以复用旧物，但修幕、三路与原独立冷却不被伪装成原效保留。旧50卡、旧六牌训练场、旅途存档及历史回放继续使用其原版本。本轮不决定将整个旅途正式迁移，也不接入AI自制卡。

300生命、9秒扫描、1秒触发间隔、状态衰减、单次防护及11卡数字为助手首版调校参数；批准开发不等于这些数字已通过平衡验证。

## 设计后果与尚待验证

首扫保底保证小卡不漏，但小卡停留时间短于触发间隔时，继续加长间隔不会减少其每圈一次的保底发动。大卡能否多次发动取决于停留时间和间隔；「填满九格即每圈九次发动」只在默认9秒／1秒及对齐布局下成立，不能作为一般规则。

排序、防御时机、下一次攻击强化与大卡分段提供构筑空间。固定循环是否令人期待、双方不同时发动是否仍好看、小卡密排是否过强、治疗是否拖延，仍需要用户试玩。类型与回放测试、单屏验证不是玩法成立的证据。

停留、反向、变速卡、额外回响保持后续设计方向；本轮只有战前参数调整，未添加这些卡牌机制。
