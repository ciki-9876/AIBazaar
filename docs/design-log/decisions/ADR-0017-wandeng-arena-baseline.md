# ADR-0017：归物师换二维表现，保留 50 卡与每路增幅器的战斗基线

- 日期：2026-09-27（讨论始于 09-26）。
- 状态：用户明确指定基线；恢复接入已实装。
- 局部取代：09-26 归物师原型中缩小卡池、没有增幅器整备、简化战场与省略复盘的实现。保留 [ADR-0014](ADR-0014-wandeng-ransom-and-opening.md) 的叙事、赎回和终局送达决定。
- 影响：A-08 可观察战斗、MC-01 战斗循环、MC-05 归物旅途。

## 用户事实与决定

用户指出：3D 换成 2D、换美术风格不等于重做战斗。明确选择“后来的 3D 对战桌：50 张牌、每路增幅器”，不选择更早的天气/地形/英雄版本。

基线证据：[独立对战实验场](../iterations/F9/2026-09-25-arena-duel-lab.md)、[统一战术桌](../iterations/F9/2026-09-26-arena-tactical-table.md)、[已有 2D 迁移](../iterations/F9/2026-09-26-arena-2d.md)。

## 必须保持的不变量

- 使用原 `arena-catalog` 的 50 卡、10 增幅器和原 `simulateArenaDuel`。保留卡牌 ID、实例 UID、占格、相邻、同列、目标优先级、冷却、弹药、控制、成长、持续状态、触发及事件排序。
- 双方三路，每路三格；每路独立屏障、独立增幅器位置，三路共用一条生命。物品不能跨路；每种卡至多两张。增幅器不占卡格，只作用于本路，破屏后永久失效；拆解/修理的对象仍是增幅器。
- 战前读敌阵、布阵与增幅器选择；自动战斗可观察；时间轴、事件回看、实际收益复盘及历史输入保存。
- 主题名称与美术可以替换，卡面数值和描述必须指向真实行为。

## 实装范围与边界

`/wandeng` 共用 `FlatTable`、`ArenaReview` 与原呈现辅助函数，仅传入纸纹卡面和旧物名称。完整卡池接入接引/旧物摊，新增图鉴、双方增幅器、公开敌阵、整备、战斗控制及回放手记。

旅途敌人生命、成长等级、每章阵容和经济是故事原型配置，不冒充原实验场默认双方 300 生命/90 屏障；其值也不修改任何卡或增幅器规则。原 `/arena` 自由布阵和反制实验仍保留。

旧书签的既有对局不注入新增幅器、不更换上阵卡；旧的已打开接引/商店选项保持原样。新增历史记录保存完整输入，导入只读回放不能发奖或覆盖旅途。
