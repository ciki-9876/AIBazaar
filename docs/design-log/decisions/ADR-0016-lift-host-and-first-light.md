# ADR-0016：电梯终端人格、第一次投喂与开灯

- 日期：2026-09-26
- 范围：独立电梯生存试玩；不改变竞技场或万灯城。
- 状态：用户指定返程 17 步已实装，演出与主观体验待用户验收；后续 18–34 步仅为提案。
- 取代关系：局部取代 [ADR-0015](./ADR-0015-wasteland-fog-and-first-lift-repair.md) 的 1 X 修复、应急电容领取及返程强制相邻教学。其迷雾、接触拾取、方块手、插值与低亮战斗效果保留。

## 背景与问题

上版返程立即进入功能教学，缺少电梯自身的戏剧性与情绪转折。用户明确要求：暗轿厢、屏幕恐吓转可爱机器人、真实结算、将电容喂入黑孔、升一级开灯，并统一 UI 到场景艺术语言。

## 决定

1. 开局主灯关闭，环境主光在舱内为零，只有左屏与右面板弱照明；一级照明由剧情中真实投喂触发。
2. 返程为固定顺序：缓气 → 右看左看 → 五秒渐快闪烁 → 黑屏靠近 → 雷声与抽象恶魔 → 求饶 → 淡出恶魔与温暖音乐 → 机器人玩笑 → AI 疑问 → 威胁前半句 → 两秒停顿 → 后半句 → 沉默 → 实际结算 → 索要核心 → 黑孔 → 拖拽 → 0→1 → 感谢 → 开灯。
3. 用户所述「能源核心」与「电容」本轮统一为 **能源核心（电容）**，来自首房箱子。它与战斗装备「增幅电容」是不同物品。这个命名统一属于实现解释，可再改名。
4. 首房实际带回电筒、3 份 X 材料和 1 核心；手机为原有物品，不计本次战利品。首次返程要求先收齐有限教学掉落，有明确剩余提示；此特例不延伸到普通房间。
5. 黑孔仅接受普通背包中真实拥有的核心，错误物品、错误阶段与重复动作均不消耗。X 材料保留。投喂可用拖拽或选择后点击完成。
6. 升级演示填满进度后进入感谢台词，台词结束才开灯。电梯仍保持现实尺寸；没有暗中扩容、回复生命或消耗生活值。
7. 击杀完成后的地面引路线依据可通行路径连接玩家与电梯，每帧起点取角色插值位置。它帮助首次返程，不替代后续自主探索。
8. 冥河庭院 UI 系统使用冷铁底、墨线、旧金边、暖纸心声、克制磷光；实体屏与 2D 升级屏共用画面，设置可访问组件图鉴。

## 放弃或推迟

- 不保留旧版 1 X 修复，避免同一任务出现两种收费。
- 相邻、保护和长期空间升级在下一段重新安排；保留底层组件与自由试玩，不在本段重复强制教学。
- 不伪造结算道具，不从装备栏拿能源核心，不允许普通材料冒充核心。
- 后续引导方案见[开灯之后](../../F9_SURVIVAL_AFTER_LIGHTS_DESIGN_2026-09-26.md)，尚未实装。

## 理由、影响与证据

先让电梯作为一个具有意图的对象被认识，再让一次资源投入产生可见改变。第一次成长是一盏灯，而不是一串数值。开场箱内补给被核心替换；普通多物品箱柜规则不变。

剧情时序、库存原子性、重复投喂保护、存取序列化一致性、相机物理范围与返回路线有自动化覆盖。浏览器演出及拖拽验证见[本轮记录](../iterations/F9/2026-09-26-survival-first-light.md)。这些证明流程可执行，不证明惊吓、音乐和节奏已达到用户预期。

原型仍只在当前运行内保留跨出勤物资，刷新会重置。设置提供明确标注「重置试玩」的返程重播，由实际开场规则生成已完成首房的检查点，方便逐段评价。
