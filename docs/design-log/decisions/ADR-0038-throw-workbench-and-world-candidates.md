# ADR-0038：甩牌布阵界面与世界观候选

日期：2026-10-04。

**状态：用户指定的布阵交互与文案收束已实装；界面实际操作待验收；五个新世界观为未选择提案。**

## 事实与用户决定

用户认为甩牌核心玩法已经成立，本轮要求探索风格差异较大的世界观，并明确以下体验修订：扑克花色为红／黑；删除准备页左侧宣传说明；扩大布阵区域并复用电梯拖放；删除文案里的无用提示；遗物在独立格子中打开选择弹窗，选中查看效果，按装备按钮生效。

## 本轮执行

1. 准备页变为整张装配桌：预设 → 十格布阵与单遗物槽 → 道具目录 → 对手和开始对战。目录独立滚动，布阵与开始按钮保持可见；较矮桌面窗口收紧布阵高度。
2. 指针拖放由共享中立组件承接，电梯和甩牌使用同一个捕获、阈值、落点预览、取消和点击抑制流程。各自的合法安放仍由本项目规则判断；不互相导入产品代码。
3. 目录道具可拖入指定格，已放置道具可移动；落点显示整件占格预览，非法放置保持原布局。点击和左／右移动按钮作为键盘与非拖放入口保留。
4. 遗物选择使用草稿状态，选中只改变弹窗预览。装备或卸下提交，关闭／取消不提交；遗物位于十格之外，不计入道具容量。
5. 能力文案保留触发条件、效果与数字，去掉开发口吻、重复全局规则和装饰性故事。共有规则集中在玩法说明里，明确相邻、取整、上限、护盾、持续伤害和反击边界。
6. 牌角、中央和飞行牌使用相同红／黑花色标记；生命、模拟时间和演出保持现行规则。

主动选择、牌型倍率、三秒抽牌、十格空间关系、物品数值、遗物数值和 `throw-duel-v3` 均保持 [ADR-0037](./ADR-0037-throw-duel-rhythm-and-loadouts.md)。此记录细化 [ADR-0036](./ADR-0036-throw-duel-selection-and-relic.md) 的遗物操作流程，不重写其历史。

## 叙事提案与假设

[五个世界观方向](../../F9_THROW_WORLD_DIRECTIONS_2026-10-04.md)为魔术团、命运怪盗、百鬼邮路、星海快递、失眠图书馆。用户尚未选择，未实装新主线或人物。

助手建议魔术团优先验证，因为掷牌、机关、旧物素材和组合演出在同一场景内成立；命运怪盗作为更鲜明的形象候选。当前暖色纸纹是素材延续，不代表用户已经要求所有新题材必须温馨。四花色不预先锁定为四种伤害，避免收窄构筑空间。

## 证据边界

代码检查和规则回归能验证规则未改变、失败安放原子性与项目隔离，不能证明拖动流畅、摆放好懂或题材有吸引力。浏览器自动操作被网址协议安全策略拒绝，本轮没有实际拖拽／遗物弹窗／窄窗的浏览器验收证据。详见[本轮记录](../iterations/F9/2026-10-04-throw-workbench-and-worlds.md)。
