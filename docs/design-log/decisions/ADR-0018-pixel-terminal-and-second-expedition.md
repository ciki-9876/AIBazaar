# ADR-0018：像素终端与第二次自主出勤

- 日期：2026-09-27
- 状态：用户明确要求落地；实现与规则验证已进行，节奏及美术待用户体验。
- 范围：独立 `/survival`；不修改万灯城或卡牌战斗。
- 局部取代 [ADR-0016](./ADR-0016-lift-host-and-first-light.md) 的旧界面表现和“18–34 仅提案”；其首房身份、投喂成本与演出顺序保留。

## 用户决定

1. 恶魔改成像素黑色圆脸、红眼、龇牙；使用内置 ImageGen，透明原图直接纳入游戏。
2. 界面与中文使用细像素表达。投喂仅保留物品、投喂目标、等级与真实进度；不重复解释。
3. 电梯屏幕通向机器人系统，行囊仍是单独功能。自身独白固定在画面下方。
4. 开灯必须看见顶灯灯罩亮起，并从灯具处向舱内照明。
5. [18–34 提案](../../F9_SURVIVAL_AFTER_LIGHTS_DESIGN_2026-09-26.md) 进入实施。

## 执行方案与规则

18–23 为开灯后的安静、家与离开的疑问、可选保护和维保廊出发。保护认可真实安全容器任意物品，允许明确跳过。

24–30 使用固定种子维保廊，近门有安静区域、散件及含净水和增幅模块的工具柜。前两波为相同爬行生物，出生前预警；第一波后显露生活值。净水仍只在真实阈值消耗。十格装备的双侧增幅由实际相邻规则判定，任何合法位置有效。整理时暂停世界，允许暂后，不替玩家摆牌。

31–34 用已翻空的箱子、鞋印和驻守声响暗示其他人。继续搜刮和提前返回均有效。结算分开列出实际持有、安全容器、途中使用与未带回。最后两项未来建设只作未接通预览，不收费，不承诺已建造。

同一维保廊再次出勤保留柜内剩余物品、物品 UID、怪物、迷雾和教学标记，不重新生成奖励。普通包及装备仍随失败丢失，安全容器保留；本轮不暗中引入免费复活或补装规则。

原型增加独立 v4 本地检查点，首页可继续。读取时校验版本、物品身份、容量、装备位置和关键状态；旧版本不直接套用。重播按钮明确重置试玩，并由实际开场规则构造检查点。

## 表现与资源

采用 GNU Unifont 原生 16 像素中文及整数倍标题，预先加载再绘制 Canvas；没有把普通字体简单模糊或像素化。物品为带材质层次的 32 像素代码图标，细阶边框延续冷铁、旧铜、磷光色板。字体 OFL 许可及来源随资产提供。

恶魔源提示词：[资产清单](../../../public/art-assets/survival/manifest.json)。字体许可见仓库 `public/fonts/unifont/LICENSE.txt`。

## 证据与风险

规则测试覆盖保护或跳过、真实多件搜刮、任意双侧邻接、提前返回后复入不重生、消耗归类和检查点校验。浏览器检查像素字体、真实保护拖拽、顶灯灯罩与供能弹窗。自动验证不代表恐怖程度、阅读负担或探索节奏已获认可。

长期升级价格、正式死亡救济和跨设备存档仍未设计；两个未来选项明确为预览。本地检查点依赖浏览器存储，不等同正式长期存档系统。
