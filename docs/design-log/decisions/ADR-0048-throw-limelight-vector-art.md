# ADR-0048：甩牌美术重构——「聚光与丝绒」全矢量舞台

日期：2026-10-08。

**状态：用户要求“抛弃已有的一切，对美术做一轮重构，让美术足够丝滑、精细”；新美术已实装并替换旧表现。浏览器自动化在 1280×720、1600×900、390×844 下验证了冒险、布阵、对决与飞牌；真人长期观感、低端设备帧率尚未验证。**

## 用户决定

抛弃此前全部甩牌美术：像素 V2、报刊插画 V1、SVG 试验页、所有位图图集，以及只为旧 `Art` 图标服务的万灯城遗留代码。目标是“丝滑”与“精细”。

本决定取代 [ADR-0045](./ADR-0045-throw-atomic-pixel-scenes.md) 与 [ADR-0046](./ADR-0046-throw-editorial-illustration.md) 的全部表现部分，以及 2026-10-05 的 [SVG 试验](../iterations/F9/2026-10-05-throw-vector-art-trial.md)。现代西方奇幻、个人夺冠、横版行走、就近交互、真实战斗返场、资格门槛（[ADR-0043](./ADR-0043-throw-western-pixel-rpg-opening.md)）不变。历史记录保留原文。

## 助手实施细则（可再讨论）

- **方向**：魔术师的世界就是剧场。夜孔雀蓝为底，骨白纸牌，漆红丝绒，铜绿为魔法与交互色，黄铜只用于细线装饰。刻意避开旧版的奶油纸、赤陶与报纸版式。拉丁数字与标题用 Didone 字体栈，中文用系统黑体与宋体栈；不打包字体文件。
- **全部由代码绘制**：`apps/throw/src/app/stage/`。项目不再发布任何位图，`products.mjs` 中 throw 的资源清单为空。
- **丝滑**：角色是 SVG 骨骼（髋、膝、肩、肘、头、衣摆、围巾），每个显示帧按相位连续求值，取代 8 帧序列。步态相位取自实际行走距离，所以鞋底不会打滑。眨眼、呼吸、出牌挥臂与受击后仰是时间包络。规则仍按 20 ms 步进；表现层每帧把主角与镜头指数逼近规则位置，因此在任何刷新率下都平滑。全页只有一个共享 `requestAnimationFrame` 时钟。
- **精细**：三个场景都是手绘分层矢量（三层视差、动态吊灯与街灯、光束浮尘、走马灯、霓虹闪烁、雨痕、钟摆），任意缩放都清晰。52 张牌面采用标准点阵，人头牌为徽章式，A 带装饰环；牌背是黄铜格纹。23 件道具与 10 件遗物各有单线图标，按家族着色。
- **尺度**：成人在场景中按 0.8 绘制（154 世界单位），门高约为人高的 1.35 倍。世界坐标、热点、地图尺寸不变。
- **签名元素**：跟随主角的聚光。它的亮度随剧情进度提升（未训练 0.12 → 完成练习 0.45 → 拿到参赛证 1.0），是纯表现，不进规则。
- **对决**：左右舞台、台口幕布、帷幔与台面；人物按舞台高度自适应（容器查询），道具徽章放在台面上。飞牌沿抬升的二次曲线飞行，带翻转与拖影，从实际手牌位置出发，命中实际角色区域。
- **减少动态效果**：在 `prefers-reduced-motion` 下，场景动画停止，飞牌改为直线、无旋转。

## 规则边界

`throw-duel-v3`、`magician-adventure-v1`、随机流、数值、抽牌节奏、连续框选、十格布阵、单遗物、AI、存档与回放均未改动。表现层读取规则状态，从不写回。删除的万灯城遗留模块（`arena-*`、`wandeng-game`、`cards/combat` 等）在 throw 项目中已无规则调用。
