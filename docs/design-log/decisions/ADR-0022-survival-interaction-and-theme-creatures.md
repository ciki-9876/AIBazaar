# ADR-0022：探索交互、对话节奏与主题鬼怪

> 局部 Superseded by [ADR-0023](./ADR-0023-survival-sight-brains-and-recovery.md)，2026-09-28。旧决定保留供回溯；当前死亡追回、脑浆、视野、背包容量与净水使用以新记录为准。

日期：2026-09-27。状态：用户要求已实施；具体上限、美术与动机提案等待试玩评价。

## 用户决定

- 限制怪物同时存在的数量；拾取提示、照明、伤害与拾取飘字更清晰。
- 可用物品支持主动使用，所有物品遵循统一特性；保护格不用锁图标。
- 主题包同时包含怪物外形，三层用中国题材非人类鬼怪。
- 对话可点击跳过，气泡提供图标与默认关闭的自动播放开关；电梯模型点击不能误触返程。
- 系统首页改为电梯页，始终展示升级条件与奖励；机器人气泡和暗纹保持像素风格。
- 恶魔改为无肌理纯黑、红色空眼窝、龇牙。

## 本轮实施假设

- 初始教学保留三只；二层并存上限 16，三层 22，旧独立实验房 24。驻守 BOSS 与预定刷出的怪均计入预算；满额不积攒新的大波次，空位在后续波次补充。旧待刷队列也不能突破并存上限，已有旧存档超额活怪不被凭空删除。
- 主动补给与已有低值自动补给共用效果定义；保护格暂停生效，满值不消耗。第一顿面包发放时饱食最多 55，修复原有“满值却必须吃”的不一致；吃完饮水依然为 60。见 [物品规范](../../F9_SURVIVAL_ITEM_TRAITS_2026-09-27.md)。
- 对话默认手动；等待只阻止台词定时跳转，野外移动、战斗和饥渴继续。点击台词不自动提交结算、投喂、升级或吃东西。单向上升仍必须明确确认；限时弱引导保持原有时长，可提前点掉。
- 随身灯在所有主题使用相同基础参数，电筒增加照明与视野；环境仍保持各自氛围。
- 中国主题含灯魇、丧鸢、铜餮、祠守四种非人形外观，保留现有敌人战斗分类与数值。荒原、维保廊、沙岩目前共享基础骨架并区分甲壳色；跨主题造型将继续扩充。
- 目前最高仍为居所等级 2。完成后常驻本次已投入条件、已获得奖励及“更高等级尚未开放”，不伪造第四层或新的支付承诺。
