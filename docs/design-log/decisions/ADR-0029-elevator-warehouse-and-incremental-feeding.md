# ADR-0029：电梯仓库、分次投喂与物品销毁

- 日期：2026-10-03。
- 状态：用户要求已实装；扩容速度和操作细则是本轮默认值，待试玩验收。
- 影响的设计 DNA：A-02有限空间、A-07原子结算、A-09远征回收、MC-03电梯成长循环。
- 相关迭代：[仓库与交互优化](../iterations/F9/2026-10-03-warehouse-and-interaction-polish.md)。

## 用户决定

电梯系统新增初始4×6格仓库，随等级扩容。升级保留黑孔“投喂”，允许随时贡献下一级所需材料并累计进度。玩家可以永久销毁物品来腾格子。

## 本轮采用的默认细则

仓库保持4列，每升一级增加一行：居所1–5对应24／28／32／36／40格。只能在电梯内存取；行囊和仓库支持拖动、交换、旋转、同品质堆叠与快捷存取。仓库物品和已投喂进度不随外勤倒下丢失，继续跨楼层和存档保留。

首次能源核心投喂、开灯及第二层教学保持。其后脑浆经验和机械零件分别累计，不要求同时集齐。保留原配方：1→2需30经验，其后40／70／100经验，各需2零件。黑孔只接受当前尚缺的材料数量，不吞掉整叠盈余；单份高品质脑浆超过本级所需的经验保留。材料齐全且教学允许时自动升级，接入原升级演出和仓库扩容奖励。安全容器材料需先移到行囊，已贡献材料不退回。

销毁采用“销毁→确认销毁／取消”的两步操作。删除整件或整叠及其全部单位身份，不产生可追回背包，也不返还资源。未完成吃面包教学时，开场赠送面包受保护，避免把教学唯一必需品删掉。

## 机制组合与理由

外勤收集 → 返程 → 留作构筑／存入仓库／投喂成长／销毁腾位 → 升级扩容与提高跨层能力 → 再出勤。仓库把“下一次可能用到”的储备与当前背包风险分开；投喂把几次短探索变成可见的长期进度，同时提前放弃材料的其他用途；销毁是有限空间决策的最后出口。

**设计假设**：可保存的小额贡献能改善升级等待感，仓库能减少无意义丢弃。无限仓库会消解整理取舍；本轮选择有限扩容而未采用无限列表。尚未证明每级4格或现有配方是合理平衡。

## 历史关系与兼容

局部接替[ADR-0023](./ADR-0023-survival-sight-brains-and-recovery.md)与[ADR-0027](./ADR-0027-race-and-pass-prototype.md)中的一次性交齐升级交互；保留脑浆品质、20份堆叠、死亡背包、通行证支付与单向上楼。旧升级动作保留兼容，新界面使用累计投喂。新存档封套为`f9-survival/8`，仍读取6／7及既有支持的旧存档；存储键、历史RNG和回放夹具不变。

## 证据与待验证

规则测试验证满仓及失败交换不会部分丢物、堆叠身份保留、分次消耗与经验盈余、旧存档迁移、倒下保留仓库和进度、永久销毁不产生追回物。实际浏览器操作验证行囊↔仓库拖动、快捷存取、销毁取消，以及15/30经验、1/2零件补齐后升级与24→28格扩容。

仍需用户试玩确认：仓库扩容速度、分次投喂是否使材料风险过低、整叠销毁是否需另加单份销毁，以及长期储备与竞速停留时间的平衡。本轮未调整升级配方或接入AI分支。
