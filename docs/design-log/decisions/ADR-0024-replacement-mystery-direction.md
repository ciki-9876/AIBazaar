# ADR-0024：采纳“我被取代了”的主线方向

日期：2026-09-30。状态：用户接受题材方向；底层设定、压力系统、角色与具体剧情仍为待讨论提案，未实装。

## 用户已确认的边界

- 认同“另一个我在现实中取代了我，我通过电梯寻找归途”的悬疑方向。
- 要有持续攀爬动机，可以来自紧迫感，也可以来自对悬疑与真相的追索。
- 创作者必须有内部自洽的替身原理，即使不向玩家完整解释。
- 冲突应触及真实生活、关系与人物成长；用户提出“好好先生先带来欣慰，后暴露更大问题”作为例子，并未锁定家庭构成或剧情。
- 题材必须进入实际玩法，不能只作为刷资源之外的剧情包装。

## 本轮推演的状态

[框架提案](../../F9_REPLACEMENT_FRAMEWORK_PROPOSAL_2026-09-30.md) 建议以跨现实修复设施、逐渐接管人生选择的替身、章节行动窗口及可操作的现实干预串联探索。所有这些具体方案均属助手建议，不能视作已获用户批准。

本轮不修改战斗、生活数值、死亡回收、装备、地图、存档或开场流程。没有新增试玩证据，不运行玩法测试。
