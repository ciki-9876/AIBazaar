# ADR-0058：甩牌牌匣去掉稀有度上限，改由收集来约束

- 状态：已接受（用户决定；上限已移除；养成深度为提案）
- 日期：2026-10-10
- 影响的设计 DNA：A-10 局外保留发现与选择
- 取代 [ADR-0050](./ADR-0050-throw-curtain-call-and-card-variants.md) 中「一副牌最多稀有 8 / 史诗 4 / 传奇 3」这一条；变种本身、稀有度结构、每张牌一张专属传奇都不变。
- 设计文档：[牌匣：去掉上限之后的收集养成](../../F9_THROW_DECKCASE_COLLECTION_2026-10-10.md)

## 用户决定

牌匣不再设稀有、史诗、传奇的张数上限。牌匣作为收集养成玩法的一部分，需要更多可玩深度。

## 实装

- `validDeckBook` 只检查每个变种是否真实存在、是否装在它对应的那张牌上，不再计数；`DECK_LIMITS` 已删除。
- 牌匣界面改为显示「已装」的各稀有度张数，不再锁住已满的稀有度。
- 规则版本不变：所有原本合法的牌匣，结算结果完全不变；只是原本不合法的牌匣现在也合法了。存档不变。

## 证据

不同牌匣对白牌的六套预设（每格 12 个种子）：

| 牌匣 | 各预设平均胜率 |
|---|---|
| 白牌 | 43–57% |
| 第二幕现有的 14 张 | 51–65% |
| 52 张全是传奇 | 85–100% |
| 52 张全镀金 | 87–98% |

## 后果与护栏

- 强度上限交给获取节奏：按幕规划玩家能拿到的变种数量，对手同步成长。
- 竞技模式和联赛提供「公平规矩」，可以选择恢复旧的上限。
- 剧情模拟里的玩家方要带上同幕水平的牌匣，否则会低估玩家。
- 养成深度（磨合、工坊改刻、套组、签名、调性）见设计文档，等用户挑选。
