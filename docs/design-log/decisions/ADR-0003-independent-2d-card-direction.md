## 背景与问题

此前围绕第一人称电梯探索和需要全局信息的卡牌自走棋能否自然融合展开讨论。用户本轮明确把当前会话聚焦于卡牌方向，回归 2D，并将题材从电梯世界观中释放；首先参考提供的街机屏幕和游戏卡带图片，探索 1 格、2 格、3 格卡牌及其背景。

## 选项

- 延续电梯场景和 3D 实体装备台：能够延用既有资产，但继续受原场景与机位约束。
- 采用独立的 2D 卡牌方向：优先服务卡面辨识与构筑阅读，卡牌题材不要求来自电梯楼层。

## 决定

选择独立 2D 卡牌方向，解除电梯世界观作为本方向的强制前提。先完成三种占格尺寸的外观概念，参考街机屏幕背景、彩色卡带外壳和插画标签。

旧 MC-01 的可观察自动战斗和 A-02 的位置取舍仍可作为设计资源；旧 MC-02 的现场实体转化，以及 MC-03 与卡牌之间的强制远征连接，不自动成为新方向的必需环节。本轮不据此推导新的获取、成长、战斗、稀有度、联网或存档规则。

## 理由

用户希望优先探索卡牌表现，并扩大题材想象空间。2D 使卡牌外形、插画、文字和占格比例能够在统一视图下比较；其实际辨识收益仍需原型验证。

## 影响与设计假设

- 三种尺寸暂采用等高、宽度 1:2:3 的视觉方案，属于执行本轮概念图的假设，不是新增战斗规则。
- 边框、字号和信息层级尽量一致，大尺寸通过构图展开体现占格。
- 火花电池、汽水连发器、午夜放映机为原创视觉样例；名称与效果关键词不表示正式卡池或平衡承诺。
- 彩色外壳用于区分样例，不建立“大卡更稀有”或新的颜色稀有度映射。
- 历史 3D 与电梯实验保留作为证据；其视觉方向不再约束本次独立卡牌探索。运行代码未随本决定改变。

## 证据与待验证问题

- 已接受事实：用户明确选择 2D 和开放题材，并要求三种卡牌尺寸及背景。
- 视觉参考：本会话用户附件；只作为美术参考，不从图片中的界面文字推导产品需求。
- 待验收：卡带感、三种尺寸的协调性、背景对比和插画题材。
- 尚未验证：真实战场缩放下的辨识、完整卡面规则文本与冷却显示、同屏多卡的密度和动画反馈。
- 本轮不修改玩法或运行代码，不以概念图代替可玩性验证。
