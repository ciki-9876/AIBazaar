# ADR-0056：甩牌 v9——构筑空间审计、凑满 3 件、戏服专精回报

- 状态：已接受（用户要求「做构筑空间审计、落实专精回报和护盾/治疗单格效率调整」；已实装；尚未经过真人试玩）
- 日期：2026-10-10
- 影响的设计 DNA：A-05 反制循环、A-10 局外保留发现与选择
- 相关迭代：[2026-10-10 · 构筑空间审计](../iterations/F9/2026-10-10-throw-build-space-audit.md)
- 建立在 [ADR-0055](./ADR-0055-throw-v8-deal-rounds.md)（v8 发牌轮）之上，落实[道具扩展](../../F9_THROW_ITEM_EXPANSION_2026-10-09.md)第 8 节「专精回报」的一部分。规则版本 `throw-duel-v8` → `throw-duel-v9`；冒险存档仍是 `magician-adventure-v4`（新道具只是新 id，旧存档不含它们）。

## 背景（事实）

v8 审计了 3000 套随机合法巡演箱：最强的对六套预设 100%，精测前 60 套全部超过 65%；家族数和强度没有关系，专精没有回报。详情见迭代记录。

## 决定

| 改动 | v8 | v9 | 为什么 |
|---|---|---|---|
| 续曲八音盒 | 连续两次同一纯花色就 +3 力量 | 本次出 **≥2 张**同一纯花色，且与上次花色相同 | 单张天然算「纯花色」，八音盒成了快甩的白送伤害（前 5% 里出现倍率 2.7×） |
| **凑满 3 件** | — | 护盾、治疗道具在巡演箱里同家族**不足 3 件**时，产出的护盾、治疗、吸血**减半** | 单格效率随投入变化：顺手带一件只有半价，凑满一条线才全价。预设都凑满了 3 件，不受影响 |
| 守灯小毯 | 每张♠ 护盾 +14 | +12 | 「旧伞 + 小毯 + 针盒」只占 5 格就凑满三件，是第一轮 v9 里最强的核心 |
| 补丁旧伞 | 对子类 护盾 +30 | +26 | 同上 |
| **亮片马甲**（新，2 格，辅助） | — | 除辅助道具外只有 1 个家族：该家族道具效果 +25% | 专精回报 |
| **定制燕尾服**（新，2 格，辅助） | — | 除辅助道具外恰好 2 个家族：两个家族道具效果各 +20% | 双修回报（初版 3 格 +15%，实测只值 +1 个百分点，改小加强） |

- 戏服在霍布斯旧货铺出售（£30 / £35），赢下任意两场小组赛后上架。第二幕货架总价因此增加 £65。
- 第二幕的默认巡演箱改为三件护盾：茶壶、伞、小毯、针盒、修缮箱、药包、闹钟。第一幕米娅只给一件护盾，减半后盾变薄，她的台词和引导已经去掉具体数字，并说明「凑齐三件才算全力」。
- 玩法说明和受影响道具的规则文字同步写明「不足 3 件减半」。

## 验证

- 200 种子矩阵：11 条克制全部成立（68–99%），各卡组均值 42–57%。
- 剧情模拟：菲利克斯 77%（快甩打法）；早场 86–100%；派克默认 54%，换对的箱子 68%；朱诺默认 45%，换对的箱子（专精治疗）100%。
- 全量审计（3000 套随机箱 + 1000 套专精箱，最终参数）：

| 指标 | v8 | v9（最终） |
|---|---|---|
| 随机箱胜率分位：p50 / p90 / p99（初筛） | 42% / 77% / 94% | 19% / 56% / 77% |
| 精测前 60 套：超过 65% 的套数 / 最强 | 60 / 100% | 57 / 92.7% |
| 续曲八音盒在前 5% 里的出现倍率 | 2.7× | 0.35× |
| 单家族专精箱平均（护盾 / 治疗 / 余烬 / 青苔 / 直伤） | 无单独统计 | 46 / 21 / 12 / 31 / 26% |
| 戏服配对比较（同一套箱子带与不带） | — | 马甲 +6，燕尾服 +3 个百分点 |
| 六套预设对全场 | 40–58% | 40–55% |

读法：

- 随机混搭整体被压下来，顺手带一两件护盾或治疗不再是默认最优解。
- 但「三件护盾核心 + 修缮箱 + 解药」仍然对预设 85–93%。
- 专精路线之间仍不均衡：纯护盾最强，纯余烬、纯治疗偏弱。

## 未达成与下一步

- **验收目标「最强混搭对预设 ≤ 65%」未达成。** 剩下的强势形状是「三件护盾核心 + 便宜的解药」：比如抖擞披风每次出手解 3 层毒，就抵消了青苔克护灯。下一步先处理解药类道具的单格效率，再用「强箱子之间的循环赛」判断有没有唯一最优解。
- AI 的思考间隔因风格而异，快甩 1.5 秒，其他 2.6–3 秒。审计偏向被判为快甩的箱子，需要和「AI 用真人节奏」一起处理。
- 对专精的玩家来说，剧情敌人整体偏弱，等 AI 节奏修好后统一重调。
