# ADR-0032：上下阵地与心灯命中反馈

- 日期：2026-10-04。
- 状态：用户要求已实装；视觉可操作性已检查，观看体验待用户试玩。
- 关联：A-08 可观察自动战斗、MC-01 战斗组合。
- 承接：[ADR-0030](./ADR-0030-wandeng-rhythm-first-entry-demo.md)。
- 调研与证据：[本轮记录](../iterations/F9/2026-10-04-wandeng-rhythm-combat-visuals.md)。

## 用户决定

用户要求共鸣线对战改回上下结构，突出核心及血条，强化受伤和治疗反馈；指出现有触发表现、弹道和飘字难以辨认，并要求参考 The Bazaar。

战场从上到下为对手心灯与生命、对手卡牌区、简短共鸣提示、我方卡牌区、我方心灯与生命。此呈现修订局部取代0030首版将两方心灯并列放在中央的视觉安排，规则不变。

## 呈现选择

核心及长血条作为固定视觉锚点。实际发动卡牌高亮；攻击从该卡飞向对方心灯，治疗从该卡回到本方心灯。弹道有深色轮廓、彩色拖尾和亮色弹头，命中带冲击环、核心闪光、血条变化与粗体数字。伤害使用暖色反馈，治疗使用绿色反馈；大伤害加强冲击，低生命和熄灭有独立状态。

为了让血量变化与弹道命中衔接，展示层统一滞后12逻辑步（300毫秒）读取核心状态，并在模拟结束后保留同长演出尾段。时间轴、暂停和跳转都由回放tick计算视觉状态；模拟没有等待弹道，也没有改变同时结算、首扫、支援、卡牌数字、胜负、回放版本或种子。

短窗口减少品质文字、待机文字和页面框架占用，优先保留卡牌插画、类型数字、扫描线与生命。品质仍由边框材质区分，完整效果可暂停查看。尊重减少动态设置。

## 假设与边界

“发动 → 飞行 → 命中 → 生命反馈”可能降低追踪负担，但浏览器截图与规则回归只能证明实现和一致性，不能证明观看更有趣。没有移植 The Bazaar 的美术，也没有声称其使用本原型的300毫秒、伤害阈值或节奏线规则。

本轮只改 `/wandeng/rhythm` 展示；旧三路训练场、50卡旅途及其回放继续保持原义。
