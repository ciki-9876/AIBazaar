# ADR-0060：快抽手法、可执行教学与可观察的构筑和收获

- 状态：**已接受；本轮实现，整体验收见迭代记录**。
- 日期：2026-10-11
- 影响的设计 DNA：A-01 确定性、A-06 信息逐步揭示、A-07 失败原子性、A-08 可观察战斗。
- 迭代记录：[快抽、布阵与冒险反馈](../iterations/F9/2026-10-11-throw-quick-draw-and-feedback.md)。
- 版本：对决 `throw-duel-v12`；冒险 `magician-adventure-v7`。
- 局部修订：[ADR-0057](./ADR-0057-throw-troupe-gauntlet-identity.md) 中伊莱的初始手法「假洗」改为「快抽」；其他角色的天赋、手法和既有朱诺入团剧情保留。其他历史决定不改写。

## 背景与问题

玩家的实际截图暴露了三种信息断裂：教学要求甩黑桃但手里没有黑桃；选牌后出现说明使手牌区变高、舞台跟着移动；结算只给命中和时长，看不出构筑实际做了什么。布阵中旧标签混用了打法与效果，交换需要先逐件卸下；支线、收获和章后管理入口也缺少明确承接。

本轮目标是让「看懂当前条件 → 做出一个可执行动作 → 看到真实结果 → 调整构筑或继续探索」连起来。手法、奖励和引导都必须服从真实规则状态。

## 选项与取舍

| 问题 | 未采用 | 采用与代价 |
|---|---|---|
| 主动补牌 | 人人获得独立通用技能 | 伊莱初始手法快抽替换假洗，保留每人一个手法的身份差异；会改变伊莱的出牌节奏 |
| 固定教程 | 只找一个当前恰好有黑桃的种子 | 资格赛显式固定首副牌，提示再检查实时手牌和道具；需要独立的教程配置 |
| 战报 | 对屏幕最近的飘字求和 | 规则层维护整场统计，显示实际产出；需要明确过量、挡伤和重复触发的口径 |
| 可搭配标识 | 同家族、同颜色就标记 | 逐条确认共同触发、状态供给或相邻增幅；新增道具必须同步维护机制关系 |
| 获得弹窗 | 玩家点「领取」时再次发奖 | 规则先完成原子交易，弹窗呈现已获得的增量；确认只关闭展示 |
| 复杂信息增多 | 让底部容器随内容长高 | 每个视口档位固定高度，各信息区预留位置、局部滚动；窄屏采用不同固定布局 |

## 决定

### 1. 伊莱的快抽

- 伊莱从开始就具有手法「快抽」，立即从自己的牌堆抽 **5 张**，冷却 **15 秒**。这些数值来自用户要求。
- 非满手时可用，空位不足 5 个时只补到上限；满手、冷却中、对局结束时拒绝，手牌、冷却、统计和事件都保持不变。
- 不重置正常发牌轮的进度。跨牌堆周期继续使用既有确定性洗牌流，不额外消耗随机数。
- AI 只有身份为伊莱时才获得此手法；至少留有 5 个空位时会使用。朱诺、罗茜、斯坦仍使用各自手法。
- 玩家手法统一放在手牌左侧的大圆按钮中，展示名称、可用状态与剩余冷却；键盘仍为 `Q`。它不是双方默认的额外能力。

### 2. 教学只要求当前可执行的动作

- 仅抒情剧院资格赛调用 `applyQualifierOpening`：双方首副 **52 张**全部固定顺序，玩家初始有 **3 张黑桃**；保留原牌的身份与变种。普通对局牌序不受影响。
- 「现在甩一张黑桃」只有玩家正在着火、没有护盾、装备守灯小毯且手里确有黑桃时才出现。已经带盾则跳过裸身着火步骤，进入闷火观察。
- 指令必须由当前条件守卫。固定开局不能替代这个守卫，因为玩家可能已经用掉教学牌。
- 教学气泡与普通对白共用关键文本的安全高亮，涵盖角色、地点、任务、花色、道具和关键机制；不在文案里嵌入 HTML。

### 3. 战后统计是整场实际结果

`ThrowDuel.stats[side]` 是规则状态的一部分，与最多 240 条的表现事件列表独立。统计重开时清零、序列化时保留，不触碰随机流。

| 统计 | 口径 |
|---|---|
| 出牌 | 有效出手次数、命中次数、总牌张数、每种牌型次数；各花色/点数/变种分别累计，同一张再次甩出再次计数 |
| 直伤、灼烧、剧毒、反射 | 对手**实际损失的气场**，不包含护盾吸收和过量伤害；反射独立于出牌直伤 |
| 护盾 | 实际新增的护盾，包括红心遗物把过量治疗转出的护盾；扇面格挡的减伤不是产盾 |
| 治疗 | 实际恢复的气场，经过焦灼/重创衰减和上限裁切 |
| 道具和遗物触发 | 同一道具一次出手产生多个效果只算一次激活；受击反应另计。吸血从发牌到命中是同一次激活，不能记两次 |
| 手法 | 成功使用的次数，失败尝试不计 |
| 落幕 | 环境伤害，记录为本人 `curtainDamageTaken`，不归功于对方输出 |

结算窗口放大、主体可滚动，只保留「退出」和「重来」：分别返回场景、回到整理巡演箱。战报提供构筑复盘信息，不把名义预览数当成实际成绩。

### 4. 布阵、分类与搭配信息

- 进入布阵默认选中背包当前展示的首件道具。详情框固定高度，正文内部滚动；操作栏保持可达。
- 每件道具和遗物严格显示两枚带底板装饰的标签：**打法/触发条件**与**主要效果类型**。分类来自实际机制，例如「单张 / 穿透」「火势 / 直伤」，不能用效果家族代替触发条件。
- 选中一个道具后，在可与之配合的道具右上角显示「可搭配」，并提供具体原因：共同触发、供给状态与消费状态、有效相邻增幅。仅同色、同家族或相互冲突不够。
- 鼓风只配实际灼烧产出，毒增幅只配实际剧毒产出；双邻罗盘说明两侧条件；戏服推荐还要检查当前布阵的家族条件。推荐不保证能直接放入，也不保证此刻已经触发。
- 拖放支持场内互换位置、背包与场上一换一、背包内改变展示顺序。大小不同也先模拟完整结果；越界或碰到第三件则整次拒绝，不卸下一半。
- 牌匣扩大展示，并以**实际拥有且合法的变种**筛选牌位，包含已收集但未装备的变种。筛选只影响展示，保持 52 个牌位和既有装备规则。

### 5. 冒险的目标、收获与管理入口

- 主线和支线同时展示：主线金色、支线蓝色，路径标记统一为卷轴。姐妹早场都已获胜、后续赌约尚未获胜时显示前往醉鹅旅店的支线；目标随地图指向比阿、旅店或可达出口，完成后消失。由已有胜场推导，旧档不必重打。
- 佩蒂格鲁移到桌子右侧，避开招募看板。酒馆招募采用独立拟真看板，展示人物与条件并调用现有原子招募流程；不增加新的车轮战机制。
- NPC 头像在右侧并面向左，玩家头像在左侧；只调整框内构图、放大上半身，保持头像框和对白布局稳定。
- 获得道具、遗物、卡牌变种或金钱时，用统一独立弹窗、亮光与粒子反馈。内容来自一次交易的真实收据；同次交易合并，连续交易排队。物品等取真实新增，普通金钱取正增量；战斗奖励显示本场实际收到的总额，避免同次周日房租结算吞掉收获展示。重复奖励、失败购买和读入旧存档不伪造收获；点击确认不再次发奖。
- **第一章结束后解锁背包**，统一管理卡牌、道具、遗物和布阵，并给出可跳过的简短引导。`flags.departed || act > 1` 作为解锁依据，直接进入第二章也开放；`backpackGuided` 只记录引导是否读过。
- 冒险存档升到 v7。v6 迁移仅为新旗标补 `false`，保留已获财产、胜场、剧团和时钟；继续支持既有旧版本的迁移链，不改变存储键。

### 6. 底部操作区保持稳定

同一视口下，无选择、单选、多选、效果众多、冷却、10/12 张满手和不满足出牌规矩时，手牌区高度一致。预留效果提示、排序工具、手法按钮、牌面与出牌预览位置；内容超出时在对应说明区滚动。窄屏重排为自己的固定布局，不能靠选牌状态增减整块高度。

## 证据与待验证问题

- 已完成的定向规则证据：全部卡牌测试 **95/95**，包括 40 种子的六流派克制回归、快抽原子性与确定性、超过事件上限的统计、资格赛跨种子固定首副牌。
- 构筑专项 **7/7**：分类完整性、不同尺寸交换的原子性、实际增幅、搭配对称性与家族条件、按真实拥有变种筛选。
- 冒险专项 **59/59**：包括新加的 **8 项**支线可达/独立、章后解锁/一次性引导、v6 迁移、收获增量、周日收入与支出分开、招募原子性、首胜后重来保留奖励验证。
- 已观察到真实拖拽的三类结果：等尺寸交换成功、撞第三件的异尺寸交换拒绝、末端有空间时异尺寸替换成功。
- 尚不能据此断言：快抽已经达到长期平衡、所有视口都易读，或奖励动画的情绪反馈已经获得玩家认可。完整构建、跨界面走通、固定高度比较和玩家试玩另在本轮迭代记录补证据。
