# ADR-0004：保留街机背景，改用立体展示的炫彩收藏卡

- 日期：2026-09-26
- 状态：背景接受、卡面改用新参考风格、展示为 3D、最高级卡有流光已由用户明确；新概念图待视觉验收。
- 前序：[ADR-0003](./ADR-0003-independent-2d-card-direction.md)。仅细化本方向的卡面与展示方式，不推翻独立卡牌、开放题材和 2D 玩法方向。
- 相关产物：[图片、提示词与验证边界](../../art/F9_HOLOGRAPHIC_CARDS_2026-09-26.md)。
- 影响：A-08 的信息可读性与卡面展示层；没有战斗规则变更。

## 背景与问题

用户接受前一版 CRT 街机背景，但要求卡牌改用两张新附件所示的收藏卡风格：薄卡片、插画铺满卡面、立体倾斜展示，最高级炫彩卡有流光，并再次设计 1 至 3 格各一张。

## 选项与决定

不再沿用前一版厚塑料卡带外壳，选择薄实体收藏卡。保留深靛蓝 CRT 背景、暗色圆角屏幕边框和低对比几何图案。卡面以满幅插画、窄边框、下部文字区为基础；展示时使用轻微透视、可见薄边与投影，最高级材质使用虹彩镀膜与流动高光。

本次继续使用火花电池、汽水连发器、午夜放映机三个临时样例以比较外观，三张均展示最高级材质。这是本轮执行假设，不建立尺寸与稀有度对应关系；其他稀有度外观仍未决定。

## 理由与影响

薄边框和满幅插画提高图像占比，倾斜与反光提供收藏展示感。3D 仅用于卡片展示的要求，不自动延伸为 3D 战场或回归电梯世界观。普通状态、完整卡面数值与流光动画参数留待后续设计。

## 事实、假设与验证边界

- 用户事实：保留背景、更换卡面参考、3D 展示、最高级流光、三种占格尺寸。
- 已交付：单张横向三卡静态概念图；以反光带、虹彩边框和高光表现流光的一帧。不是可旋转模型或已实现动画。
- 设计假设：卡片等高、横向宽度随占格扩大；参考中的角色、骰子规则、数值和其他界面不成为本项目需求。
- 视觉检查：三种尺寸齐全，卡带机械结构已移除，背景保留，卡名正确，卡片有倾斜与镀膜反射。
- 待验证：最终用户验收，实际尺寸下的可读性，流光随时间／角度变化时是否遮字或造成干扰。
- 未改运行代码、正式卡池、存档和数值；不运行代码测试。
