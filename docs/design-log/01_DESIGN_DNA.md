## 2026-10-09：甩牌的节奏与可观察性增补

用户决定以同伴 SVG 舞台继续正式开发，旧剪纸／像素资料归档。对决 v6 采用「开场 → 超过 30 秒白热 → 60 秒落幕」的阶段压力，基础补牌从 3 秒逐步变为 2 秒、1.5 秒；三张顺子／同花降低组合门槛，默认 20 秒整理让每个构筑拥有相同的基础手牌操作。入门先教单张，再通过真实资格赛胜利开放其他构筑。见 [ADR-0052](./decisions/ADR-0052-throw-v6-vector-stage-and-tempo.md)。这些是本项目当前决定，尚未证明是所有卡牌游戏的通用数值。

可迁移的组合为「实际构筑 → 可执行出牌方向 → 同源预览与命中 → 事件反馈 → 胜负兑现」。构筑产生明确的单张／对子／花色选择，策略提示帮助玩家开始行动，喝彩只认可一次真实的大生命伤害，胜利鼓掌和彩带承接规则结果。表现层只读取事件与胜负，避免视觉奖励和真实结算分离。这补充 A-08 可观察战斗；前提仍是 A-01 的确定性规则与 A-07 的失败原子性。

A-06 信息逐步揭示在场景中分为两层：普通名称随交互范围出现，当前任务图标持续指向实际可达目标；到达后用亮黄关键名词与固定左右头像说明谁在说话、下一步去哪里。其可迁移原则是让当前目标可见、局部说明就近出现；图标不可超前泄露未开放角色，也不可在任务完成后继续指向旧目标。工程与试玩证据见 [本轮迭代](./iterations/F9/2026-10-09-throw-v6-stage-and-tempo.md)。

窄屏必须保留关键操作的可用性反馈，不能为了空间只留整理按钮而隐藏冷却。阶段视觉应由同一规则判定驱动，在减少动态效果模式仍有静态文字；新对局同时重置规则会话和教程／声音会话，不能让旧局的出手标记或延迟声音进入下一局。这些约束用于保护可观察性与一致的行动结果，数值仍由本项目的实际规则决定。

## 如何理解 DNA

设计 DNA 有两个层级：

1. **设计原子（Design Atoms）**：可以独立复用的规则、关系、反馈或决策模式。
2. **设计机制组合（Mechanism Compositions）**：为了形成一段完整玩法循环，把多个设计原子按特定顺序和因果关系组合起来的结构。

设计原子回答“这个局部设计是什么”；机制组合回答“哪些局部设计为什么要一起工作，以及它们如何让玩家持续做决定”。新游戏可以替换主题、内容和数值，但如果要复用 AIBazaar 的体验，应优先理解机制组合的因果结构，而不是复制名词。

## 设计原子的通用字段

记录一个设计原子时，至少回答：

| 字段 | 要回答的问题 |
| --- | --- |
| 玩家需要 | 玩家当下想达成什么？ |
| 玩家动作 | 玩家实际选择或操作什么？ |
| 状态/资源 | 哪些状态被消耗、保留或改变？ |
| 反馈 | 玩家如何知道选择产生了什么结果？ |
| 决策张力 | 为什么不能同时选择所有好处？ |
| 奖励/代价 | 短期收益、长期收益和失败代价是什么？ |
| 变化轴 | 哪些参数或内容变化会产生新局面？ |
| 不变量 | 哪些规则不能被轻易破坏？ |
| 证据 | 这是已验证事实、设计决定，还是待验证假设？ |

## 当前设计原子

以下是当前可以跨内容复用的原子。它们不是完整玩法，必须放回机制组合中理解。

### A-01 确定性局面

2026-09-28 结构化框架增补：新卡行为、描述、蓝图指纹和运行定义使用同一结构。独立规则版本保存完整定义、队列、因果、随机和特殊状态；中途恢复与连续运行比对，不能仅存种子。未知机制拒绝、未校准预算阻断发布，语义合法与平衡已证实分开。见[首个执行内核及限制](./iterations/F9/2026-09-28-generated-card-framework-runtime.md)。

2026-09-27 训练实验增补：新卡与调校必须使用显式规则版本、稳定ID与完整回放输入，不能覆盖原50卡或改写旧对局。新训练版本的控制选目标读取双方同阶段快照，并以换边核验消除顺序偏差；旧版本不静默迁移。见[六牌训练场](./iterations/F9/2026-09-27-wandeng-six-keepsakes-training.md)。

同一世界种子、楼层蓝图、天气、卡牌状态和行动序列应得到同一结果。确定性让玩家可以学习因果、复盘失败，也让 Agent 能够稳定测试和解释结果。

### A-02 有限空间中的位置决策

玩家不是只选“带什么”，还要决定“放在哪里”。当前战斗使用 3 条路线、每条 3 个位置；位置会影响阻挡、目标接触和卡牌效果。

2026-09-26 生存变体进一步将普通运输包实现为 4×2 格：物品形状、旋转与碎片空位共同决定能否放入。该取舍独立于十格战斗栏的相邻增益；失败放置不自动挪动其他物品。见 [ADR-0009](./decisions/ADR-0009-survival-containers-cargo.md)。

### A-03 同一实体的双重价值

一个实体既可以作为现场资源/工具，也可以转化为卡牌成长材料。保留、转换和立即使用之间形成机会成本，避免所有物品只有单一最优用途。

### A-04 单向识别与成长

实体通过识别或转换成为卡牌；卡牌再通过等级、品质、效果和构筑进入战斗。单向转换保持成长路径可解释，并让“现在使用还是带回家”成为明确决策。

### A-05 反制循环

速度突破、腐蚀成长、防御反击等角色不是孤立强度，而是互相克制的关系。构筑价值来自读局、预判和调整，而不是简单堆最高数值。

2026-10-09 甩牌增补：甩牌项目以花色锁定状态，用闷火、净化、焦灼／烫手、毒发四条机制构成「盾克火、疗克毒、火克疗、毒克盾」，再用削盾、扇面格挡、重创与压轴接入快甩、蓄爆两套节奏打法。克制关系必须来自规则，并由平衡回归测试保护，不靠数值表。见 [ADR-0049](./decisions/ADR-0049-throw-counter-wheel-and-chapter-one.md)。

2026-10-09 甩牌 v5 增补：「落幕」从第 60 秒起对双方造成逐秒递增的普通伤害，让只求存活的护盾和回血流能把「活得久」兑现成胜利；它对双方对称，不改变克制方向。见 [ADR-0050](./decisions/ADR-0050-throw-curtain-call-and-card-variants.md)。

2026-10-09 甩牌第二幕增补：克制要能在流程里兑现，靠的是「情报 → 购买 → 改构筑 → 对决」的循环。对手档案只记录亲眼观察到的数据；旧货铺按赢过的对手上架货品。已知风险：同时覆盖两个克制者的混搭构筑（护盾 + 回血）会让克制环失效，需要做构筑空间审计。见 [ADR-0051](./decisions/ADR-0051-throw-act-two-bridgeport.md)。

### A-06 信息逐步揭示

出发前看到需求和风险，现场通过观察、搜索和工具获得更多信息，回家后识别结果，再进入构筑和战斗。信息获得本身也是行动和资源管理的一部分。

### A-07 原子结算

失败行动不能只扣掉部分资源，也不能留下半完成状态。一次现场行为要么按规则完整结算，要么恢复到行动前状态。这既是技术约束，也是让玩家敢于试错的体验保障。

### A-08 可观察的自动战斗

2026-09-27 可读性修订：核心数值与飘字必须加粗；桌面/卡纸压低亮度，把明度与轮廓对比优先留给弹道、命中和读数。温馨像素风不能以削弱战斗可辨识性为代价。此约束局部取代上一版统一细字重，见[展示调整与首轮组牌实验](./iterations/F9/2026-09-27-wandeng-readability-and-first-deck.md)。

2026-09-27 像素美术修订：用户要求保持温馨可爱氛围，全部现有美术素材及字体替换为精细像素风。此媒介变化不撤销可扩展效果数字、独立冷却、品质分层、垂直弹道和真实结算反馈。新素材、字库与整格图形已接入，审美待验收；见[本轮实现与验证](./iterations/F9/2026-09-27-wandeng-pixel-art.md)。

2026-09-27 后续修订：按用户新要求，在彩色数字背后增加半透明效果图标，仍支持多项同时存在；品质通过独立边框与材质表达。用户要求同路弹道保持发射横坐标并命中该列护幕，不能汇聚到路线中心；跨路效果仍依照真实规则。屏障采用既有“联结护幕”包装，宿主心灯为本轮已实装但待审美验收的视觉提案。数字图标与品质材质局部取代下方的纯数字、仅色点方案。见[本轮决定、观察与限制](./iterations/F9/2026-09-27-wandeng-soul-battle-feedback.md)。

2026-09-27 展示层修订：用户新参考采用奶油纸、暖棕字和白边物品卡，图鉴使用分类格与详情栏。战斗卡面的纯类型色数字可扩展、冷却独立、三路占格及原引擎继续有效；稀有度另用色点/标签，避免与效果颜色混淆。这次局部取代此前界面外观，不取消既有玩法与可观察性约束。见 [收藏册 UI 决策与证据](./iterations/F9/2026-09-27-wandeng-cozy-ui.md)。

战斗可以自动推进，但玩家必须能从位置、卡牌角色、天气/地形、冷却和结果摘要中理解“为什么赢/输”。自动不等于黑箱。

2026-09-26 生存方向后续：A-02 的位置取舍再次通过十格装备表达，1–3 格尺寸和左右紧贴的相邻支援实际影响输出；A-08 的可观察性同时要求“只显示当前视野敌人”与读懂技能范围。大地图的探索记忆保留地形，不提供持续敌情。见 [ADR-0008](./decisions/ADR-0008-survival-art-fog-equipment.md)。这不把独立 2D 卡牌重新绑定到电梯。

### A-09 远征风险与回收

玩家离开安全的家，携带有限资源进入楼层；更深的探索带来更高收益和更高损失风险。回收、撤退、救援和下一次准备让风险具有可管理性，而非纯随机惩罚。

2026-09-26 电梯实时搜打撤新方向的已确认约束：失败丢失普通背包全部物品，安全容器保留；不以弹药耗尽作为主要远征时限。新模式的已装备道具损失范围及具体生活数值未定。这是新方向的设计约束，未替换现有冒险实现；同层深入、向上推进和竞争者的组合方案仍为提案，见 [ADR-0001](./decisions/ADR-0001-elevator-survival-extraction.md)。

同日后续决定：新电梯方向定位为纯单机。世界中的竞争者不必由真人承担；是否采用统一效率成长、怎样保留 AI 竞争与上升动机仍在讨论，见 [ADR-0002](./decisions/ADR-0002-single-player-ascent-and-rivals.md)。此定位不改写既有卡牌模式或确定性要求。

### A-10 每局重新培养，局外保留发现与选择

后续适用范围：此边界随 [ADR-0012](./decisions/ADR-0012-wandeng-souls-and-homecoming.md) 继续用于归物师方向。原实例已修复或归家不会在故事中被反复损坏；新一局如何重养、物灵身份如何延续见新系统提案。

独立卡牌联赛的稳定边界：玩家在一局中获得卡牌、投入成长，并用它们连续挑战强敌；局外保留图鉴与新选择，卡牌数值在下一局重新培养。收藏记录和可选内容延续发现，单局实例承载这一次的投资与作品经历。二者不能混为永久攻击、生命或满级实例继承。

玩家需要同时看到「这张器具因本局选择变强」和「这次旅途留下了什么」。具体调校、改装、个人专长、获取概率与失败损失仍在系统提案中，不属于已验证 DNA。此原子仅适用于独立卡牌方向，不取代电梯方向的回收规则。证据为用户明确选择，见 [ADR-0010](./decisions/ADR-0010-circuit-league-and-run-boundaries.md)。

### A-11 物品具有经历，归属是核心目标

**现行增补（ADR-0014）**：玩家败后保持全部实例，以路费承担失败代价；只有对方败后才发生随机物品转移。培养与同行贯穿整局，送达仅发生于终局，且不受指定物品需求限制。以下的途中归家/随机失散/追索讨论保留为旧提案，不再作为当前默认规则。

此原子适用于独立归物师方向。用户明确物品有灵魂，玩家修复后帮助它们进入真正需要或喜欢它们的人的生活，也从商品化流转中夺回物品。收集的对象因此拥有经历与可能的去向，而不仅是匿名输出组件。

需要保护：修复、持有、同行、失散和赠予应关联同一实例身份；获得一件物品不等于已经完成归家。用户给定的对决血量包装与随机掉落会影响实例归属，必须与战斗展示和保存一致。

具体的物品意愿、接收人匹配、离队回报、单次掉落数量及追索是待验证设计，见 [ADR-0012](./decisions/ADR-0012-wandeng-souls-and-homecoming.md)，不能把助手提案误写为已验证原则。

## 设计机制组合

机制组合不是“机制清单”，而是一个有方向的循环。每个组合都必须描述：入口状态 → 玩家决定 → 机制处理 → 输出状态 → 为什么交给下一段 → 失败或恢复路径。

### MC-05 归物委托中的收集、修复、同行与归家

**现行版本：MC-05 v1，用户规则已接受、原型已实装**。依据 [ADR-0014](./decisions/ADR-0014-wandeng-ransom-and-opening.md)：

```text
音乐盒四格序章 → 师傅指导布阵与真实对决 → 来信启程
  → 路口三选一：接引 / 修缮 / 帮工 / 交易 / 对决
  → 获得物品、局内成长、路费变化 → 自由调整三路九格
  → 阶段守关人：胜利接回物品并前进；失败付费赎回全部伙伴
  → 不足额由师傅垫付，收入先还款；未胜时追加街边整备后重试
  → 最后一位守关人获胜 → 全部同行与储备物品统一送达
```

组合理由：收集与培养不中途被送物削弱；经济而非丢牌承接失败压力；终局送别为完整旅途收束。不变量：确定性随机、真实实例转移、原子扣款与成长、结算不可重复、送达后禁止继续战斗。师傅垫付和追加整备为助手补充方案；具体数值、时长与情感效果待试玩。见 [本轮证据](./iterations/F9/2026-09-26-wandeng-opening-prototype.md)。

**下方为 MC-05 v0 历史提案**，其中指定需求、途中赠予、玩家随机失物及追索已由上述 v1 取代；保留以说明取舍。

**状态**：世界观、关爱派目标与灵魂对决掉落由用户提出；完整协作流程为本轮工作方案，待试玩。接替 MC-04 的当前独立卡牌叙事流程，保留后者历史知识。

```text
接到居民与物品的归物需求
  → 寻找、接引或通过正式对决获得物品
  → 修复灵魂、理解愿望、培养数值与能力
  → 编排小队，与逐渐强大的物灵者对决
  → 承担随机失散，选择追索、补位或继续
  → 在合适时机赠予真正需要/喜欢的人，或继续照顾
  → 物品进入新生活，关系网络帮助下一段旅程
  → 委托结算留下经历、图鉴与新选择
```

| 环节 | 玩家决定 / 输入 | 输出与交接原因 |
| --- | --- | --- |
| 接引 | 需求、声音、流通线索；去哪里寻找 | 新实例和愿望，给培养与归家提供上下文 |
| 修复与同行 | 有限修护与阵容空间；集中培养或补齐能力 | 数值与机制成长，让物品经历在战斗中兑现 |
| 灵魂对决 | 上阵实例与可见敌人；接受风险并编排 | 胜败、成长证据和可能的实例转移，影响后续选择 |
| 归家 / 追索 | 愿望、接收人、当前战力、失物线索 | 安置与阵容调整，或付出机会找回伙伴 |
| 回应与结算 | 实际完成的帮助与未尽事项 | 物品去向、有限社区支持和局外记录，使下一次相遇有长期意义 |

**组合理由**：数值培养为共同经历创造力量，共同经历使赠予具有情感价值；归家改变阵容和关系网络，让新的收集再次有空间。掉落加入风险，但不得靠伪造随机必掉、复制已归家物或重复领奖维持故事。

**不变量**：确定性随机、稳定实例归属、原子转移、战内与跨战状态分离；界面继续用生命值等战斗术语；旧联赛售卖、拆解和培养转移不自动继承。

**可调旋钮**：单局长度、故事/战斗比例、掉落数量与候选范围、追索代价、修缮速度、归家时机、社区支持和备用容量。

**证据与风险**：只有用户设定和设计推演，无新原型。重点验证强制失物是否压过温情、归家是否被当作兑换资源、故事是否卡在随机掉落。见 [核心设计](../F9_WANDENG_SOULS_CORE_DESIGN_V0_2026-09-26.md) 和 [本轮迭代](./iterations/F9/2026-09-26-wandeng-souls-reframe.md)。

### MC-04 巡回联赛中的收集与单局成长

后续状态：叙事和具体流程已由 [ADR-0012](./decisions/ADR-0012-wandeng-souls-and-homecoming.md) 与 MC-05 推进为温情归物委托。以下保留联赛方案，不再是当前默认关卡结构。

**范围与状态**：独立 2D 卡牌方向；叙事、核心体验、60–90 分钟局长目标与局外边界已接受。下面是这些目标的机制关系，具体节点、成本、失败制度与数字仍以 [核心设计 v0](../F9_CIRCUIT_LEAGUE_CORE_DESIGN_V0_2026-09-26.md) 的提案状态为准。

**一句话定义**：以一届巡回赛为边界，让旅途收集提供新选择，让当局投资形成招牌构筑，再用连续强敌验证并修正它，最后将发现与作品记录留给下一次出发。

```text
局外图鉴与已解锁选择
  → 从新的当局起点出发
  → 旅途中收集器具与物品
  → 选择培养已有器具、补充新器具、发展自身能力
  → 编排三路构筑并挑战更强对手
  → 从结果判断下一次获取与培养需求
  → 完成或结束本届巡回赛
  → 保留发现与新选择，下一局重新培养数值
```

| 环节 | 输入 / 玩家决定 | 输出与交接理由 |
| --- | --- | --- |
| 出发 | 已解锁选择；选择本次起点 | 形成可发展的初始方案，不携带上局满级实力 |
| 收集 | 对手需求、当前器具；寻找新机会 | 新器具与培养可能性，使旅途改变构筑 |
| 投资 | 有限机会与资源；养旧、换新或成长自身 | 当局强度与协同，投入须通过战斗兑现 |
| 挑战与复盘 | 实例成长与位置；调整可解释的战斗方案 | 产生胜败与短板，决定下一轮收集/培养优先级 |
| 结算 | 本季实际取得的发现与经历 | 图鉴与新选择延续长期目标，不把数值滚存为默认优势 |

**组合理由**：只有收集容易退化成一直换牌，只有数值升级又会让旅途新发现失去价值；让新机制、已有投资与强敌考题彼此反馈，才能让每局形成不同作品。局外保留发现使失败也有记录，数值重置为下一局保留重新成长的空间。

**不变量**：稳定设计与实例身份、原子结算、同输入可复现、战内临时状态与单局永久培养分离；美术样本不限定卡牌主题；不能把局外解锁偷换成永久数值。

**可调旋钮**：站数、比赛与旅途比例、供给定向程度、调校速度、替换回收、容错、个人成长节点、解锁节奏。

**失败与证据边界**：确定要有单局结束与新的数值培养；三败退赛、战后恢复和重赛不重复领奖是本轮方案，不是已接受结论。已有三路原型支持战斗环节，完整收集成长循环尚无试玩证据。关联 [本轮迭代](./iterations/F9/2026-09-26-circuit-league-core.md)。

### MC-01 战斗机制组合

2026-09-27 独立实验支路：[六牌训练场](./iterations/F9/2026-09-27-wandeng-six-keepsakes-training.md)将“玩家提案→明确触发语义→原始／调校对照→公开锁定对手→可回放试打”闭环落地。用户授权调数字，不等于允许改卡效或临时重选对手；固定样本结论与完整平衡认证必须分开。

**一句话定义**：在确定性的 3×3 三路线空间中，通过位置、卡牌冷却、角色反制、天气/地形和可观察的自动结算，把“出战前构筑”转化为“战中读局与复盘”。

**循环结构**：

```text
卡组/资源准备
  → 观察敌方、天气与地形
  → 在三路线九格中安排单位与卡牌
  → 自动推进：冷却、移动/接触、攻击、效果和反制
  → 产生伤害、阻挡、关键事件与结果摘要
  → 复盘有效贡献和失败原因
  → 调整卡组、位置或下一次远征计划
```

| 环节 | 输入 | 机制原子 | 输出 | 为什么交给下一环 |
| --- | --- | --- | --- | --- |
| 准备 | 已识别卡牌、资源、敌方信息 | 单向成长、角色反制 | 可出战卡组 | 将远征所得转化为可比较的战斗方案 |
| 布局 | 卡组、敌方、天气/地形 | 有限空间位置决策、确定性局面 | 三路线九格状态 | 让“带什么”与“放哪里”共同决定方案 |
| 自动推进 | 布局、冷却、单位状态 | 自动战斗、反制循环 | 可复现的过程与结果 | 在不要求逐帧操作的情况下制造因果反馈 |
| 复盘 | 过程日志、结果摘要 | 可观察自动战斗 | 有效贡献、损失、失败原因 | 把一次战斗转化为下一次构筑知识 |

**为什么这样组合**：

- 只有卡牌强度，没有位置，玩家会退化成比较数值；加入九格布局后，构筑必须落实为局面判断。
- 只有位置，没有反制，最佳布局容易固定；角色克制和天气/地形使同一套卡组在不同局面中需要调整。
- 只有自动战斗，没有可观察反馈，玩家无法学习；结果摘要和可复现过程把自动推进变成可解释的决策反馈。
- 确定性把失败从“运气不好”转为“我可以改变准备、布局或路线”。

**不变量**：

- 同一输入、种子和行动序列产生同一结果。
- 位置、天气/地形、卡牌效果的语义必须能在结果中被观察到。
- 失败结算不能留下部分扣除或不一致状态。
- 角色反制是关系结构，不应被单一数值升级完全抹平。

**可调旋钮**：路线数量、格子容量、冷却长度、天气权重、阻挡规则、反制倍率、敌方预览程度、结果摘要粒度。

**当前证据与风险**：战斗/天气文档、Demo 1.8 和相关测试支持“三路线、天气/地形分离、自动结算、反制构筑”的方向；不同原型的数字、难度曲线和“自动战斗是否足够好玩”仍需独立试玩验证。参见 [战斗天气设计](../COMBAT_WEATHER_DESIGN_2026-09-08.md)、[Demo 1.8](../DEMO_1_8.md)。

### MC-02 卡牌机制组合

**一句话定义**：把现场实体、识别/转换、卡牌成长和战斗构筑串成一条有机会成本的成长链，使每次远征都同时回答“现在拿什么解决问题”和“以后培养什么战斗能力”。

**循环结构**：

```text
查看楼层需求与工具需求
  → 选择保留、现场消耗或带回的实体
  → 搜索/交易/现场机制获得实体
  → 现场使用，或带回家进行识别与单向转换
  → 形成/强化卡牌：品质、等级、效果、角色
  → 加入三路线战斗构筑并自动战斗
  → 根据有效贡献、损失和下一层需求调整取舍
```

| 环节 | 输入 | 机制原子 | 输出 | 为什么交给下一环 |
| --- | --- | --- | --- | --- |
| 需求判断 | 楼层目标、已知风险 | 信息逐步揭示 | 工具/实体优先级 | 让出发准备有上下文，而非盲目收集 |
| 现场取舍 | 容量、实体、工具 | 同一实体双重价值、机会成本 | 保留/消耗/转换选择 | 让现场收益与长期成长竞争有限空间 |
| 识别转换 | 带回实体、识别条件 | 单向识别与成长 | 稳定身份的卡牌 | 将探索结果转为长期可复用能力 |
| 构筑战斗 | 卡牌、角色、敌方局面 | 反制循环、有限空间 | 具体卡组与布局 | 让成长必须经过局面判断才能兑现 |
| 结果回流 | 战斗贡献、损耗、下一需求 | 可观察自动战斗、确定性 | 新的取舍依据 | 让每一局结果改变下一局计划 |

**为什么这样组合**：

- 同一实体有“现场解决问题”和“回家成长卡牌”两种用途，才能产生有意义的库存压力。
- 识别是安全的延迟价值，现场使用是即时价值；两者之间的取舍把远征和战斗连接起来。
- 卡牌不只提供数值，还承担角色、位置和反制语义，成长因此不会脱离战斗结构。
- 战斗结果回流到下一次准备，形成“探索 → 成长 → 构筑 → 验证 → 再探索”的闭环。

**不变量**：实体与卡牌的稳定 UID 和关系必须可追踪；转换方向和消耗必须明确；行动失败必须原子结算；相同实体不能因 UI 路径不同产生不一致价值。

**可调旋钮**：实体容量、工具消耗、识别成本、品质分布、成长速度、卡牌角色比例、即时收益与长期收益的差距、稀有资源的出现位置。

**当前证据与风险**：F9 卡牌/物品和字段工作文档已明确双重价值、UID、单向转换、三层取舍与现场循环；“现场使用是否足以和卡牌成长竞争”“成长是否会被单一最优路线垄断”仍未充分验证。参见 [F9 卡牌与物品](../F9_CARD_ITEMS_2026-09-18.md)、[F9 卡牌语言](../F9_CARD_LANGUAGE_2026-09-20.md)。

### MC-03 电梯楼层机制组合

**一句话定义**：用电梯/基地作为安全准备与回收中心，用确定性的多楼层路线把探索、现场工作、资源风险、撤退和成长串成可重复的远征循环。

**循环结构**：

```text
回到家/电梯基地
  → 查看楼层蓝图、需求与风险
  → 选择卡组、工具、容量和远征目标
  → 进入确定性的楼层路线
  → 观察、搜索、交易、现场机制与战斗
  → 获得实体/信息/救援对象，承担资源与时间风险
  → 撤退、返回、识别、结算损失与成长
  → 根据结果升级基地或调整下一次楼层计划
```

| 环节 | 输入 | 机制原子 | 输出 | 为什么交给下一环 |
| --- | --- | --- | --- | --- |
| 家中准备 | 上局结果、库存、卡组 | 信息逐步揭示、同一实体双重价值 | 本次远征方案 | 安全空间允许比较取舍 |
| 楼层选择 | 确定性蓝图、目标、风险 | 确定性局面、远征风险 | 路线与目标 | 让深度、收益和风险成为主动选择 |
| 现场工作 | 工具、实体、容量、节点 | 原子结算、信息逐步揭示 | 资源、线索、战斗前置优势 | 使探索行为直接改变后续局面 |
| 风险处理 | 伤害、配额、救援对象、时间 | 远征风险与回收 | 继续、撤退、救援或损失 | 让玩家管理风险而不是只接受惩罚 |
| 回收成长 | 带回实体、结果、基地状态 | 单向成长、资源回流 | 新卡牌、基地进展、下一次目标 | 把一次远征变成长期进度和新决策 |

**为什么这样组合**：

- 没有家/电梯，探索、成长和失败没有清晰的节奏边界；基地提供准备、回收和反思空间。
- 没有楼层蓝图和路线，远征会变成无上下文的随机收集；确定性楼层让玩家可以计划和复盘。
- 没有现场工作，楼层只是战斗入口；工具、搜索、交易和微型机制让玩家在战斗前就开始塑造局面。
- 没有撤退/救援/损失，风险只有“赢或输”；回收机制让深入探索成为可管理的赌注。

**不变量**：世界、楼层蓝图和路线生成可复现；准备、现场、回家和结算的状态边界清晰；资源、配额、库存和救援状态原子更新；失败仍能解释损失来源。

**可调旋钮**：楼层数量和深度、节点密度、工具容量、配额/时间、撤退成本、救援成本、回家收益、基地升级速度、信息揭示程度。

**当前证据与风险**：电梯设计、PRD v0.4 和 F9 现场/回家文档已经形成“基地—楼层—现场—回收”的结构；部分模块仍是原型或未完全接通，完整远征节奏、深层风险的可玩性和新玩家理解成本需要测试。参见 [电梯设计](../ELEVATOR_DESIGN.md)、[F9 现场工作 UX](../F9_FIELD_WORK_UX_2026-09-20.md)、[F9 回家](../F9_HOME_ARRIVAL_2026-09-20.md)。

### 历史融合闭环

```text
电梯/楼层组合提供问题、风险和实体
  ↓
卡牌组合把实体转为即时解决方案或长期成长
  ↓
战斗组合验证构筑、位置和反制判断
  ↓
战斗结果改变下一次楼层准备与实体取舍
```

因此，AIBazaar 的核心不是“卡牌 + 战斗 + 电梯”三个名词相加，而是：**玩家在确定性远征中获得有双重价值的实体，经过取舍转为构筑，再用可观察的局面战斗验证判断，结果回流到下一次远征**。


### MC-03 的首次出勤变体（2026-09-20）

新开局1F：单刀首战（真实出手/命中暂停聚焦）→两件实体与鉴定仪→一件转化并上阵→另一件操作图形机关→敌情前室→守卫→回家。前一步的产物必须在下一步产生可操作价值，既让战斗能力发生可见增长，也让保留实体有当场用途。引导期暂不开放提前撤离/主动回收。机关使用后的工具可带回；格子和自动战斗不变。

这是已授权并实现的节奏实验，独立玩家理解效果尚未验证。当前[迭代与证据](./iterations/F9/2026-09-20-guided-opening.md)取代[先搜刮版本](./iterations/F9/2026-09-20-first-floor.md)的新开局安排；历史存档不重排。

### MC-01 / MC-02 / MC-03 的首胜与后置鉴定修订（2026-09-20）

当前首次出勤改为：弹弓首战→敌方武器战利品→手动布阵→两件实体→机关使用→鉴定仪奖励→保留实体转化→守卫→回家，取代上一节先鉴定再机关的安排。

- 战斗原子：即时武器发动帧命中，弹道武器到达后命中；二者仍共用三路屏障与自动战斗规则。
- 奖励原子：胜利产出真实敌方输出卡的副本；揭晓与领取是两个显式动作，满包保留待领，不能重抽或重复领取。
- 准备原子：全局背包可随时访问，战斗中编辑的是下一场阵容，当前对局快照不可变。
- 节奏原子：首次消耗前讲解资源；先让实体产生现场收益，再授予转化能力，让转换具有经历基础。
- 前置与产物：首胜武器供布阵；第二间工具供机关；机关成功给鉴定仪与一次电荷；未消耗的缓冲垫供鉴定。每一步都有可用输入，旧存档原子身份保留。

已实现与定向复测，不等于独立新玩家理解已验证。长期武器积累速度仍需观察。[决策、假设与证据](./iterations/F9/2026-09-20-guided-rewards.md)。
