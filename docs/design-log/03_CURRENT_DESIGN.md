# 当前设计状态

本文件是当前状态的导航快照，不替代历史记录。状态标签含义：

- **已实现**：代码和可运行原型已具备，仍可能需要平衡。
- **已决定**：设计方向已接受，但实现或接通可能未完成。
- **提案**：有合理设计意图，但尚未成为承诺规则。
- **未验证**：实现或提案存在，但可玩性假设缺乏足够试玩证据。

## 当前闭环

**已决定 / 部分已实现 / 未验证**：准备 → 确定性楼层探索 → 现场工作/搜索/交易 → 获得或消耗实体 → 回家识别与转换 → 卡牌构筑 → 三路线自动战斗 → 观察结果并调整下一次准备。

## 已接受的不变量

- 世界、楼层、天气、卡牌、实体、保存和回放保持稳定身份与可复现序列。
- 失败行动不应部分消耗库存、资源或配额。
- 用户可见描述必须与实际执行规则一致。
- 自动战斗必须提供足够信息，让玩家能把结果归因到准备、布局或反制。
- 设计变更必须能够追溯到决策、迭代或测试证据。
