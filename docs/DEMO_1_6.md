# Demo 1.6：行装、鉴定与图鉴

行装与构筑拆为上阵构筑、背包、安全容器、仓库、卡牌图鉴五个子页。仓库仅在基地可访问。物品容器格缩小至 72×88 像素，保持水平占格；战斗格不变。

点击卡牌在右侧查看详情。上阵按钮按顺序寻找同一路连续且已解锁的空格；下阵自动收入背包。空间不足不改变原状态。容器之间仍支持拖拽整理，上阵区不接受拖拽。详情绑定页面和子页，离开后不显示残留浮层。

鉴定台独立展示待鉴定实体，并标注背包、仓库或安全容器来源。选取时播放 620 毫秒拖尾入台动画，点击鉴定后每 650 毫秒呼吸一次，从灰色逐级升至实际稀有度。结果在按钮生效时确定并保存，切页或刷新不重新抽取；完成后卡牌仍留在原容器。未鉴定实体不计入图鉴拥有状态。

图鉴展示全部现有卡牌，按当前上阵和各容器内卡牌标记已拥有及数量，不作为历史收集记录。

游戏和弹窗内滚动区域隐藏原生滚动条，使用自绘轨道与滑块，支持滚轮、触摸、拖动滑块、点击轨道及键盘操作。
