# 《最后一张王牌》剧团生活：英伦小镇的日常与风土人情（脑洞）

- 日期：2026-10-10
- 状态：**提案**（脑洞清单；选中的条目先写 ADR 再做）
- 方向：用户希望剧团玩法往「角色模拟」拓展，让玩家真的生活在这个英式魔术世界里，体验风土人情和日常生活。
- 背景：二十世纪五十年代的英国。巡演艺人住寄宿房，下午喝茶，周末去酒馆，冬天排圣诞默剧，夏天去海边码头剧场。
- 前提：
  - [ADR-0057](./design-log/decisions/ADR-0057-throw-troupe-gauntlet-identity.md)：角色之间没有属性差异。所以生活玩法**不产出战斗数值**，只影响「谁、何时、能不能、解锁什么」。
  - 规则确定性，全部矢量美术。
  - 主线仍是伊莱个人夺冠。

---

## 0. 三条原则

1. **时间是唯一稀缺的东西。** 一周七天，每天三段（上午、下午、晚上）。做了这件，就没做那件。这样不需要体力条，也不需要刷。
2. **小事要有灵魂。** 每件日常都是一个角色的一句话、一个习惯、一个笑话，而不是进度条。参照 [文案风格指南](./F9_THROW_VOICE_GUIDE_2026-10-09.md)：英式冷幽默，克制，带一点温情。
3. **生活和舞台互相喂。** 生活解锁对局里的东西（手法升级、专属变种、新规矩的演出、谁愿意上场），对局给生活带来回响（报纸、名声、谁来敬酒）。

## 1. 生活的骨架

### 1.1 一周日程（必需的底座）

| 时段 | 能做的事（举例） |
|---|---|
| 上午 | 排练（练手法、改装道具）、逛集市、送信办事、去报刊亭看八卦 |
| 下午 | **下午茶**（和一名成员或镇民约茶）、街头演出、去码头或公园 |
| 晚上 | 正式演出或比赛、酒馆、寄宿房里的晚饭聊天、早点睡 |

- 正式比赛排在固定的晚上（「周四剧院」已经现成）。
- 错过的事下周还有，但人和事会变：罗茜的炖菜只在周五做。

### 1.2 一年的节庆（季节换皮 + 限时活动）

| 时节 | 风土人情 | 玩法钩子 |
|---|---|---|
| 春 · 园艺展 | 镇上的花卉和蔬菜比赛，艾格尼丝是评委 | 青苔流的主场；帮她看护参赛的南瓜 |
| 夏 · 海边档期 | 码头剧场、炸鱼薯条、沙滩上的潘趣和朱迪木偶戏 | 海边连演一周：每晚一场，观众是游客，口味天天变 |
| 秋 · 篝火之夜（11 月 5 日） | 烟花、篝火、烤土豆 | 余烬流的节日；♦5「十一月五日」这张传奇牌在这一晚有专属剧情 |
| 冬 · 圣诞默剧季 | 英国剧团冬天的饭碗：每家剧院都排一出默剧 | **剧团大型活动**（见 3.1） |
| 一年到头 | 雨、雾（浓得像豌豆汤）、排队、公交晚点 | 天气只改氛围和对白，不改数值 |

## 2. 剧团的家：寄宿房

巡演艺人住「digs」：剧场附近的寄宿房，由一位规矩很多的房东太太管着。这里是剧团生活的中心舞台。

| 元素 | 内容 |
|---|---|
| **房东太太** | 每座城市一位，各有规矩：晚上十点锁门；不许在楼梯上练飞牌；早饭只有周日有培根。违规不扣数值，但会触发笑话和小支线 |
| **房间分配** | 两人一间。谁和谁住，会影响他们之间的关系（见 2.2） |
| **晚饭桌** | 每晚一段几句话的群聊小剧场，由当天发生的事拼出来：谁赢了、谁出了丑、谁收到家信 |
| **墙上的东西** | 节目单、剧团合照、剪报、明信片；收集品会被贴在这里 |
| **账本** | 房租、伙食、给成员的薪水（演出费）。不是生存压力，而是「这个月请不请得起新人」的取舍 |

### 2.1 成员的小日子

- **习惯与嗜好**：朱诺每天早上去码头喂海鸥；罗茜周五炖菜；巴兹尔每天做报纸上的填字游戏；斯坦每天……上厕所。
- **喜好**：茶怎么泡、爱吃什么点心、怕什么天气。送对了礼，好感涨；送错了，有专门的吐槽对白。
- **家信与私事**：成员会收到信。有的是好消息（妹妹订婚），有的是麻烦（家里铺子要关门）。私事会变成个人支线，完成后解锁手法升级或专属变种。
- **心情**：只影响对白语气，以及他愿不愿意参加某些演出。比如罗茜刚输给你，三天不想上台。**不影响战斗数值**（决定 4）。

### 2.2 成员之间的关系

- 两两之间有关系：搭档、拌嘴、暗恋、竞争。来源是同住、同台、一起做事。
- 关系好的两人，在车轮战里接力时有专属的换人台词和援护动画；关系差的，会在后台吵架，那一周有一个人拒绝登台。
- 例：艾达和比阿是姐妹，天生绑定；朱诺和菲利克斯是街头和剧院的老对头，同住会出事。

## 3. 风土人情玩法

### 3.1 圣诞默剧季 ★（剧团的年度大戏）

- 英国默剧有固定的类型角色：男扮女装的「默剧贵妇」、反派、王子（传统上由女演员反串）、马的前后两条腿。
- 玩家给成员**分配角色**；每个角色对应一场带规矩的对决。比如「马的后腿」只能出单张，而且出手比前腿晚 1 秒。
- 连演 12 晚，观众会喊台词（「他就在你身后！」），这是表演赛的掌声玩法（见[可玩性脑洞](./F9_THROW_PLAYABILITY_IDEAS_2026-10-09.md) 1.2）。
- 默剧季的收入是剧团一年最大的一笔。

### 3.2 下午茶

- 约一名成员或镇民喝茶。挑茶叶、挑点心、先倒奶还是先倒茶（英国人真的会为这个吵）。选择决定对方的反应。
- 下午茶是好感的主要来源，也是获取八卦和支线的入口。
- 里德的茶「永远是热的」，第一幕就有现成的人设。

### 3.3 酒馆之夜

| 活动 | 玩法 |
|---|---|
| 飞镖 | 一个计时点按小游戏；赢了酒馆老板请一轮，好感 +全场 |
| 酒馆问答 | 一周一次，问题来自你在这座城市见过的东西：地图、人物、对手档案 |
| 讲故事 | 用你的战绩讲一个夸张的故事；听众信不信，取决于报纸有没有登过 |
| 招募告示板 | 酒馆招募的入口（第 2 阶段已做） |

### 3.4 镇上的差事

- 送信、找猫、帮报刊亭多德太太理报纸、帮米娅送零件。每件差事都是一段步行和一段对话，有时还有一场带规矩的对决。
- 差事带你认识镇民，他们以后会出现在观众席和剪报里。

### 3.5 交通与巡演路线

- 城市之间坐斯坦的巴士或火车。火车有时刻表，赶不上就多住一晚，也就多一个晚上的日程。
- 路上有随机的小事：同车厢的乘客认出你来、巴士在乡下抛锚，于是开一场即兴街头演出。随机事件由种子决定。

### 3.6 留下来的东西

- **剪贴簿**：报纸剪报、节目单、门票根。
- **剧团合照**：每场大演出后拍一张，站位和表情取决于当时的关系和心情。
- **明信片**：每座城市一套风景。
- **菜谱本**：成员教你的家乡菜，比如罗茜的炖菜、比阿的司康。

这些都贴在寄宿房的墙上，是一份可以翻阅的剧团编年史。

## 4. 与对局和养成的连接

| 生活里做的事 | 带来的东西（不是属性） |
|---|---|
| 好感升级 | 招募 → 手法升级 → 专属变种 → 个人剧情 |
| 成员关系 | 车轮战里的接力台词、援护动画；关系太差时，那一周有人罢演 |
| 节庆 | 限时演出和规矩、节庆专属变种牌、默剧季收入 |
| 下午茶和酒馆 | 八卦（对手档案）、支线、差事 |
| 账本 | 能不能请新人、能不能修道具、能不能换更好的寄宿房 |
| 演出和比赛 | 剪报、名声、谁来敬酒、晚饭桌上的话题 |

## 5. 优先级建议

| 优先 | 条目 | 理由 |
|---|---|---|
| 1 | 一周日程（上午、下午、晚上） | 一切生活玩法的底座；同时解决「探索没内容」和「输了没代价」 |
| 2 | 寄宿房 + 晚饭桌小剧场 + 成员习惯和喜好 | 剧团的「家」；用很少的系统撑起大量角色感 |
| 3 | 下午茶（好感主来源） | 和第 2 阶段的好感直接接上 |
| 4 | 剪贴簿、合照、明信片 | 成本低，长期留存 |
| 5 | 圣诞默剧季 | 年度大戏，工作量大，放在剧团系统成熟以后 |
| 之后 | 成员关系、家信支线、节庆、交通事件、酒馆小游戏 | — |

## 6. 风险

- **时长膨胀**：日程会让每座城市变长。对策：一座城市 2–3 周，每周的必做事项不超过 2 件，其余都是可选。
- **变成数值养成**：好感、心情、关系很容易滑向刷数值。对策：没有数值奖励（决定 4）；好感只解锁内容；心情只改对白和意愿。
- **文案量**：生活模拟靠大量小对白撑起来。对策：晚饭桌小剧场由模板拼接，用当天的事件填空；每个角色先写 20 句高质量的习惯台词。
- **和主线节奏冲突**：主线比赛有固定日期，日程让它自然出现；但不能让日程挡住主线，主线比赛总是可以去。
