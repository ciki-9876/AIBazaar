## 2. 世界、人物与主线

### 世界的基本规则

器具师是能把日常器具、机械装置、自然材料与少量奇异遗物组成协同系统的人。力量来源统一包装为「共鸣工艺」：器具可以储能、周期发动，并在邻接或特定条件下互相影响。它允许纸灯、钟表、药泵、折伞与重炮同场存在，不限定为纯机械枪械，也不自动恢复另一候选的灵异主线。

卡牌是参赛器具的可操作档案与战斗表示。玩家实际购买、改装的是器具，图鉴收录的是其设计与使用记录；不会出现把真人或有人格的伙伴当作强化耗材的默认设定。

比赛中，双方使用三路防护场保护同一个比赛核心。击破核心会触发安全停机。治疗恢复核心稳定度，修屏修复路线屏障；两者仍是不同机制。牌不会被攻击摧毁，器具自动运行，玩家在赛前完成编排。

### 一届赛事的主线

主角是小镇工坊出身的年轻器具师，带着一件自选的起步作品和有限预算参赛。目标是拿到四枚地区资格章、进入中央冠军赛，让自己的作品获得正式认可。获胜后得到个人工坊署名权与作品展示机会；不把拯救世界、巨额债务或必然黑幕塞进首版。

三个贯穿角色即可承载首版主线：

- **同行劲敌**：同届参赛者，第一城第二场相遇，决赛半决赛再战。两次都可正常获胜或失败；对话读取真实胜负。其改良方向提前可见，不临时复制玩家弱点。
- **巡回导师**：在城际行程点评玩家的作品，介绍培养选择；只在有明确成长或构筑变化时评价，不逐局重复长篇教学。
- **卫冕冠军**：通过各城报道、示范战记录与器具档案逐步建立实力预期，决赛阵容提前公开。其强处是成熟的联动与应变，不靠玩家永远拿不到的隐藏数值。

每城有一个小故事，结构为「认识地方问题 → 选择怎样帮忙或学习 → 获得一件有来历的收获 → 在会馆战验证」。例：修复港口的信号装置，可以选择领奖金、留下零件或接受修屏指导。支线服务构筑，不另建长线任务清单。

多次游玩表现为参加新的赛季、提交新的参赛作品。履历保留，熟人可以记得以前的成绩；本季卡牌与调校重新获得。首轮才播放完整出发故事，此后用简短开场承接。

## 3. 一局的结构与节奏

```text
选择起步作品与旅途方向
  → 城市：看会馆情报、逛市场
  → 旅途选择 A → 地区公开赛 → 收获与培养
  → 旅途选择 B → 主场挑战者 → 收获与培养
  → 最后整备 → 会馆主 → 资格章与个人专长
  → 下一城（以上共四城）
  → 中央八强赛 → 劲敌半决赛 → 冠军决赛
  → 本季作品档案、图鉴与新选择解锁
```

下表是**目标时间预算，不是实测数据**。额外重赛、首次阅读和主动复盘可能超过目标局长，因此必须支持节点自动保存与随时退出续玩。

| 阶段 | 计划比赛 | 主要任务 | 目标时间 |
| --- | ---: | --- | ---: |
| 出发 | 0 | 起步套件三选一、读第一城情报 | 2 分钟 |
| 第 1 城 | 3 | 学会完整闭环，完成首次明确强化 | 13–17 分钟 |
| 第 2 城 | 3 | 找到主力与协同关系 | 13–17 分钟 |
| 第 3 城 | 3 | 接受反制考验，补齐短板 | 13–17 分钟 |
| 第 4 城 | 3 | 完成招牌作品，为冠军准备 | 13–17 分钟 |
| 中央决赛 | 3 | 用三套可见阵容检验成熟构筑 | 12–18 分钟 |
| 结算 | 0 | 看关键成长与作品记录 | 2 分钟 |
| 合计 | 15 | 不含额外重赛 | 68–90 分钟 |

每城两次旅途选择，共八次；每次从三个可见机会中选一个，未选机会关闭。没有倒计时催玩家读牌。固定比赛与保证的成长构成下限，旅途选择改变本局方向。

首轮城市顺序固定。熟悉后允许交换中间两城，敌人强度按访问次序取预设档，不按玩家当前战力动态追涨。港口作为第一城、电气街作为第四城，先保证教学与终盘节奏；更大路线网留待验证。

### 四城与决赛的差异

名称和角色均为工作名。

| 站点 | 地方气质 / 收藏来源 | 会馆考题 | 公平的应对空间 | 叙事推进 |
| --- | --- | --- | --- | --- |
| 潮汐港 | 航标、修理铺、运输器具；修屏与反击较常见 | 对手一条路很稳，另一路薄弱；读局后决定突破方向 | 集中火力、侵蚀、换路、以更快节奏突破均可，不要求指定牌 | 无名新人完成第一次值得被记住的胜利 |
| 钟摆城 | 钟表街、校准师；充能、节奏、精密器具 | 对手依靠一组位置联动，威胁出现在明确的发动窗口 | 提前破路使增幅器失效、控制关键节奏、护住己方核心 | 玩家开始有自己的招牌组合 |
| 青穹园 | 温室、药房、园艺工坊；灼烧、侵蚀与恢复 | 敌方收益随时间积累，拖延会付出代价 | 加快突破、有限净化、维持屏障、以更强后程争胜 | 发现自己不是所有局面都能靠同一招解决 |
| 霓电街 | 夜间市集、实验室；爆发、弹药与过载 | 扛过第一轮压力，并保留持续作战能力 | 分配防线、恢复、控制、抢先爆发或针对弹药空窗 | 外界开始讨论玩家的作品；完成决赛整备 |
| 中央联赛 | 各地选手汇聚，出售跨流派补件 | 八强考查一处短板；劲敌展示成长；冠军混合两种已见机制 | 全阵容预览、储备换牌与既有培养；不突然加入免疫所有主力的规则 | 招牌作品获得最终验证 |

地方特色是供给倾向，不是强制流派。每城市场仍提供通用输出、防护或调校入口；不设计某城完全免疫灼烧、侵蚀等整种构筑的关卡。

第一、第二场是常规赛，第三场会馆主是资格关。无需再计算地区积分：完成两场常规赛即可挑战会馆主，必须获胜才能拿该城资格章。

### 关卡生成边界

每站由阶段号、城市、市场货架、两组三选一路途事件、三套敌方阵容及其奖励组成。赛季开始时锁定种子和内容版本；中途选择产生的分支按节点 ID 独立生成，读档不会刷新货架或敌人。

到城就展示会馆主的完整静态阵容、主要机制与奖励；临场前展示每个对手的完整阵容。未知感来自旅途中未遇到的机会，不能来自开战后才告知的致命规则。敌阵在该节点生成后固定，换牌和布阵不会触发暗中反制。

## 4. 每场比赛如何连接养成

1. 查看敌阵与自己的短板；可以免费重新布阵、在储备与场上之间换牌。
2. 使用现有三路九格自动战斗。牌横向占 1–3 格且不跨路；同名牌最多两张上场。独立卡牌方向从完整九格开始，不继承旧冒险的四格开局。
3. 结算展示胜负、最早失守路线、关键联动，以及本场贡献较大的器具。不能只按直伤评 MVP，控制、屏障维持和有效治疗须有各自贡献记录。
4. 在该比赛节点首次完成战斗后，取得基础奖金和 2 点调校额度，胜利另有奖金；重赛不重复发放。
5. 玩家选择把调校投入主力还是补件，再决定下一次收集或培养机会。

战斗核心与三路屏障、弹药、战内灼烧/侵蚀、冻结、工序、临阵升阶等状态在新比赛前恢复或清空；局内永久成长不清空。屏障在一场内破裂后不能重建，下一场恢复。比赛后恢复核心稳定度不代表把战内治疗与修屏合并。

**赛程预览不提供无代价的正式对手结果计算器。** 基础试验靶可以检查效果是否发动，不发奖励、不推进成长。已结束比赛允许在独立副本中改阵复盘，不写回赛季。否则确定性自动战斗容易变成无成本穷举答案。

## 5. 失败、和局与退出

推荐初版采用**本季第三次败绩退赛**，不用跨战残血做第二套消耗压力。

| 情况 | 赛程处理 | 奖励与保留 |
| --- | --- | --- |
| 常规赛胜利 | 前进到下一节点 | 首次基础奖励 + 一次胜利奖金 |
| 常规赛失败 | 败绩 +1；未达到三败则继续赛程 | 首次基础奖金和调校仍给；无胜利奖金 |
| 会馆主 / 决赛失败 | 败绩 +1；未达到三败则回整备并重赛同一敌阵 | 节点基础奖励只发一次；胜利奖金在首次获胜时发一次 |
| 第三次败绩 | 本季结束，不再开始重赛 | 先结算本场可记录的发现与履历，不携带数值进入下一局 |
| 主动退赛 | 正常结束并标记退赛 | 已实际获得的图鉴记录保留，不伪造赛季成绩 |
| 中途退出应用 | 不视为退赛 | 保存已提交节点；未完成的战斗按已锁定输入继续或重放 |

初版超时沿用战斗引擎的和局结果。赛程层将和局记为一次未晋级的败绩：常规赛向前，资格关需重赛。赛前明示，双方同归于尽同样处理。首轮先不新增突然死亡机制；如纯防守导致频繁和局，再单独验证裁定方案。

资格关失利后，可免费重排和更换储备牌，并继续使用本城**剩余**货架、尚未购买的调校和改装服务。不能刷新旅途、重复打工或反复领取调校。每局最多增加两场重赛；不存在无限刷资源后再晋级。

这一方案的取舍：败局仍能成长，避免滚雪球式落后；胜局有经济优势和荣誉回报，故意失败不增加可得奖励。全恢复会降低跨战生存压力，本方案把重点放在构筑、投资与应对上。

## 6. 收集系统：能找新东西，也能主动找需要的东西

### 三类可收集对象

| 类别 | 作用 | 空间 / 成长约束 |
| --- | --- | --- |
| 器具卡 | 战斗主体，包含输出、恢复、控制、支援等多种效果 | 占 1–3 格；可调校与改装；多种核心数值不受占格数量限制 |
| 路线增幅器 | 强化一条路线的特点 | 每路一件、不占九格；破屏失效；首版只替换、不另建等级树 |
| 旅途用品 | 一次性提供调校、交易或事件收益 | 使用后消耗；不占战斗格；首版不加入战中主动操作道具 |

图鉴登记稳定的设计 ID；局内每个实际副本有自己的实例 ID 和成长记录。一个设计可以有不同局内培养结果，不能覆盖成同一张收藏数据。

### 获取来源及职责

- **起步套件**：三选一，各含一件明确核心和两件可用辅助，覆盖 5–6 格；组合保证有输出和最基本的承伤能力。配套不是固定唯一解，开场市场负责第一个取舍。
- **地方市场**：持续可访问的本城货架，买与不买、养旧与换新在这里发生。
- **旅途委托**：用本次机会选择新器具、通用资金或培养，让物件有出处。
- **会馆纪念品**：获胜后从三件地区增幅器候选中取一件，获得当地身份与可改变布局的收获；不是必然更高稀有的主力替换。
- **稀有发现**：部分旅途节点提供特殊器具或本局稀有改装；来自有限机会，不另做付费或局外数值抽取。

首版沿用五档视觉：普通灰、稀有蓝、史诗紫、传说金、最高级炫彩。**固定稀有度、占格、局内调校等级是三件事。** 普通三格与炫彩一格都成立；调校不把普通牌染成传说。最高级卡仍是低频、辨识度高的牌，并非每局必须拿到的通行证。高稀有度可提供独特机制，但不能统治所有位置和局面。

### 定向供给与储备

每城入城时选择一个寻货意向，例如火力、防护、节奏或持续效果；选项是宽标签，不是指定某张卡。四个商品位暂定为：两个当地池、一个意向池、一个全局池。首次货架保证至少有一项当前可购买的通用输出或防护补件；不保证刚好破解会馆主。候选缺货时按预先规定的通用池回退。

每城最多两次付费刷新，只替换未购商品；价格和剩余次数可见。货架不随每场比赛免费重置。购买后退出重进不能刷新。

储备器具暂定六件，按件数计算，不把运输格子拼图带进本方向。上场仍按九格约束，且同名最多两张。每种设计局内最多保有两个实例；多余同名获取可以当场折价为奖金。备用增幅器暂定三件。

储备满时在领取/购买界面选择替换或放弃；先完成整笔可行性检查，才扣钱、转移或出售。不能先扣钱再发现放不下。不上场的物品不触发战斗或场间被动；明确例外必须写进物品规则。

重复牌不强制三合一。它可以保留为第二副本、替换或出售；收集同名不是数值成长的必经门槛。这样玩家投资的牌不会因为迟迟抽不到重复件而停止成长。

## 7. 卡牌成长：养出招牌，而不是只换更贵的牌

建议把首版成长收敛为**调校等级 + 一次改装选择**，暂不同时引入升星、品质、觉醒、附魔和随机词条洗练。

### 7.1 调校等级

- 每次计划比赛节点首次完成后获得 2 点调校额度；共最多 30 点，其中决赛结束获得的 2 点仅用于作品结算，不能倒用在最后一战。可在整备时使用或存下；旅途、工坊还能提供少量额外额度。
- 一张卡从调校 0 升至 5；每级成本暂按占格数：1 / 2 / 3 格分别消耗 1 / 2 / 3 点。满九格全部升至 5 需要 45 点，高于固定赛程供给；玩家需要集中培养或用旅途/奖金补充。五级上限与成本均为实验值，不代表已通过平衡。
- 按格计费是为了避免大卡以与小卡相同成本放大整条路线的基础输出；仍需用真实牌效校准，不能由占格直接推断一张牌的实际强度或效果数量。
- 通用示例规则：允许成长的伤害、治疗、修屏数值，按基础值每级增加 20%，达到调校 5 时为基础值的 2 倍。多输出牌可有多个成长字段，不因此被删成单效果。
- **不能把所有数字统一乘倍数。** 灼烧/侵蚀层数、充能、控制时长、弹药、被动减伤、触发次数和阈值逐牌制作调校表。沿用确定性累积余量等已有语义时要明示；不能令冻结、装填和额外触发无限增长。
- 调校不会自动缩短冷却或扩展占格。每次升级在确认前显示所有实际变化；无效升级不得扣额度。

为什么每场都给调校：玩家每打完一场，都能做一次培养选择，包括立即投入辅助或存下以强化大器具。为何不让上场就自动涨数值：否则仅仅使用某张牌就获得复利，早期牌和优势阵容会自动滚大，主动收集与替换的空间变窄。

### 7.2 改装与专精

调校达到 3 后开放一个改装位。每张适用卡至少准备两个手工设计、互斥的改装方向；未有合格改装的卡不进入这轮正式卡池。改装不随机洗词条，不改变设计 ID、固定稀有度或占格。

例子仅说明结构，均不是当前可执行牌效：一件带直伤和灼烧的器具，可以选「增加灼烧投入」或「对燃烧目标提高直伤」；治疗器具可以选「有效治疗更高」或「溢出部分转为受限的本路修屏」。后者确实新增第二种核心输出时，卡面须同时显示，不能用尺寸限制它。

每城工坊出售一次改装服务，可用于一张达到门槛的卡；也可在旅途中放弃其他奖励换取。首版全局永久冷却减免合计不超过基础冷却的 20%，最终冷却按 0.25 秒向上对齐。战中充能和疾速仍遵守独立触发上限，不能因改装绕过保护。

### 7.3 养旧与换新的实际取舍

保留旧牌得到已经投入的数值和改装收益；新牌提供不同机制、占格或触发关系，不靠商店自带更高调校等级碾压旧牌。新购牌从调校 0 开始。

每城提供一次付费「拆装转移」：放弃一个旧实例，将其**实际消费调校点的一半、向下取整**返为通用额度；旧改装不转移，折扣或返还过的点数不重复计入回收基数。完成后旧牌移除并按出售规则结算一次，不额外复制资源。该操作消耗工坊服务次数与奖金，确认界面同时列出损失和新余额。未消费的调校额度本来就属于玩家，不参与折算。

这是低频转向出口，不是无损洗阵。若试玩发现玩家被沉没成本完全锁死，应提高回收或降低转向成本；若大家每城都换最高稀有牌，则收集供给和稀有度预算有问题。

### 7.4 一张普通牌的成长样例

纯算术示例：起步直伤 12 的射钉匣，调校 2 时为 16.8，调校 5 时为 24；如果还选择一项 +4 直伤的改装，则为 28。上述改装未实现，数值不代表战斗收益预测。

它还需要面对弹药、装填、攻击路与敌方防护的问题。一个摆轮或弹链柜的取得可能比继续把它从 24 调到 28 更有价值。成长数值应清楚，但不能抹平构筑。

### 与当前引擎的明确差异

当前原型通用系数为 `1 + level × 0.12 + quality × 0.15`，部分控制采用单独时长公式；支持 level 0–20、quality 0–5。本文的调校 0–5 和每级 20% 是**新赛季成长提案**，不能直接用旧字段冒充相同语义。

接入时必须新增有版本的调校规则或显式映射与迁移，不在同一计算里重复乘旧等级、品质和新调校。联赛首版不开放独立品质养成。战内临阵升阶与永久调校分开序列化，战内工序不能刷成跨战永久奖励。

## 8. 玩家自身成长

卡牌成长回答「我把哪件器具培养成核心」，个人成长回答「我成为哪类器具师」。不再做一棵可无限刷等级的通用攻击树。

### 基础成长与个人专长

- 每枚资格章附带固定的比赛核心容量提升。初始核心 300，每章 +30，是待测起点；三路基础屏障各固定 90，不跟随核心增长再乘一次。个别器具和增幅器仍可改动本路屏障。
- 每枚资格章给一次个人专长三选一，最多四个。专长在该节点获得，不能额外刷经验；已选专长唯一且不重复出现。
- 候选覆盖三类：经营（交易或转向便利）、培养（局内更多有效调校）、战斗风格（对某种编排给有上限的帮助）。不同类在前两城提供机会，最后一城避免出现来不及兑现的长线经营专长。
- 首版只做约 12 个清楚的专长。晚期若只剩无效选项，按固定规则换为可立即生效的通用专长，生成结果落入存档。

待测样例：购买首件器具减价；每城首次调校辅助牌返还有限额度；一条配置了三件单格器具的路线获得一次开场修屏；每场首次由己方造成破屏后，让指定邻路推进一次受限冷却。经济专长不能通过买卖循环刷钱，触发牌和路线要写明，强度须与占格代价一起测。

这些专长与固定容量提升全部属于本局。长期玩家不会因为更早刷出永久攻击/生命就默认压过新玩家。

## 9. 最小经济：一种钱，一种培养额度

首版只保留「奖金」与「调校额度」两项可累积资源。资格章是赛程记录，败绩是容错状态，图鉴发现是局外档案，不再额外包装成可消费货币。

以下是**用于首轮预算检验的占位价格**，不是卡牌强度评价；高稀有卡定价后还要逐牌检验。

| 项目 | v0 占位 |
| --- | ---: |
| 初始奖金 | 10 |
| 每计划比赛首次基础奖金 | 4 |
| 首次获胜奖金 | 额外 2 |
| 每城两个旅途机会 | 各在器具 / 培养 / 资金等机会中选择，不全拿 |
| 选择资金的标准旅途收益 | 5 |
| 普通 / 稀有 / 史诗 / 传说 / 炫彩器具参考价格 | 4 / 6 / 8 / 11 / 14 |
| 额外调校额度 | 3，每城最多买 2 点 |
| 一次改装服务 | 6，每城最多 1 次 |
| 一次拆装转移 | 3，每城最多 1 次 |
| 第一次 / 第二次刷新 | 2 / 4，每城合计最多两次 |
| 出售 | 实例取得时登记的基础回收价，不超过常规标价 25%，向下取整 |

出售不返调校投入，只有有次数限制的拆装转移会返。折扣后的购买成本如果低于基础回收价，则该实例回收价下调至购买成本，禁止折扣套利；赠品使用内容表的回收价。

零旅途奖金、全胜完成 15 场，名义收入为 `10 + 15 × (4 + 2) = 100`。**其中决赛获胜后的 6 已无战斗购买价值**；进入最后一场前最多从前 14 场取得 84，加开局 10，共 94。不能把终局奖励当成可用于打冠军的钱。

此预算要同时容纳数次购卡、几次改装与少量额外培养，故旅途拿钱有意义，但不应逼迫八次都选钱。每城市场公布后可持续使用，玩家可以先比赛再花本城所得，无须开城一次性付清。

中央赛场有一个一次生成、不可刷新的补给货架，两次赛间整备都访问同一货架。最多购买 2 点调校、1 次改装、1 次拆装转移；价格同地区工坊。不会在打冠军前强制清空旧牌、强制发高级牌或免费重置所有投资。

## 10. 局外收藏与重玩

### 保留与重置

| 局外保留 | 新一局重置 |
| --- | --- |
| 实际获得过的器具设计与增幅器图鉴 | 当前持有器具及其调校、改装 |
| 已解锁起步套件、器具设计、事件与难度选择 | 奖金、培养额度、旅途用品 |
| 会馆/劲敌/冠军档案与作品履历 | 个人专长、资格章、当前败绩 |
| 最佳作品快照、称号与外观收藏 | 商店、路线机会、敌方阶段与本季状态 |

“见过”和“获得过”分开记：只看敌方不算获得；局内取得后即计入发现，不要求带着它夺冠。售出不会抹掉图鉴。作品快照可以在独立练习模式重放或分享配置，不把那张满级实例直接带入新赛季。

### 解锁内容，而不是解锁更高攻击

首轮建议先开放约 24 张经过筛选的基础设计，覆盖所有核心效果和基本应对；其余从现有实验牌中分批开放。内容解锁奖励新机制与新的起步选择，不使用永久数值加成。

解锁条件以具体体验为主，例如完成一次装填联动、让一件普通器具参与地区夺章、在一次赛季内使用过治疗与修屏两种体系。每个条件给一个小内容包；不用“重复获胜 100 次”作为核心内容入口。解锁条件与当前进度可查。

第一次完成一城即有一项有意义的解锁，首次通关仍能继续发现内容。所有基础生存与反制手段必须首轮可用，高难度也不以指定未解锁牌作硬门槛。

新设计加入相应地方/意向池；检验扩池是否稀释构筑可达性。暂不同时增加自选删牌池系统，先用地方供给与寻货意向验证。收藏完整度不等于胜率增益承诺。

新解锁在**下一局**加入供给；本季开局保存可用内容集合，中途达成图鉴条件不会重写已生成货架或改变后续随机流。复盘、练习和重复领取不推进同一条件多次。

### 重玩变化来源

起步作品、旅途机会、地方供给、互斥改装、个人专长和同阶段敌方变体共同生成新经历。城市主线和会馆身份保持可辨识，关卡不能随机到失去旅行目的。

通关后开放更高联赛组别作为可选难度：增强敌方编排与数值预算，增加已公开的组合考题。先不叠大量永久规则词缀。默认模式仍维持同一公平成长起点。

## 11. 怎样让玩家感到自己是主角

不要把“主角感”完全交给对白，首先保证三件事情能在游戏中发生：

1. **我的选择有来历**：起步作品由玩家选；旅途收获记得在哪座城、因为什么得到。
2. **我的培养能兑现**：对比起步与当前的具体数值和有效联动；早期普通牌有机会进入决赛，但不强迫每局都保留。
3. **世界承认我的实际表现**：报道引用真正达成的胜利、破屏或独特组合；没有达成就不用相应文本。

第一城重点是首次调校后可见的变化；第二城让玩家能说出“这局我靠什么”；第三城给一次可读的短板与补救机会；第四城展示招牌器具；决赛用早期劲敌对照成长。

失败结算也记录这局做成的作品、最强的一次联动和还差什么，但不会把退赛写成冠军。奖励成长过程，同时保留夺冠价值。

## 12. 首版内容与制作边界

### 先做一段能闭环的短联赛

现有 `/arena/2d` 证明了战斗、展示和自由组卡的技术基础；它尚不能证明市场、旅途或数值养成有趣。下一步优先做**两城 + 一场决赛，7 场计划比赛，约 25–35 分钟的验证版本**。这只是开发切片，完整目标仍是用户选择的 60–90 分钟。

切片应包含：

- 三套起步方案、24 张筛选器具、4–6 种增幅器。
- 两座城各两组三选一事件；从至少 8 个手工事件模板生成不同供给。
- 每城市场、奖金、调校 0–5、主力卡的二选一改装、拆装转移。
- 两次个人专长选择、三败退赛、核心/屏障战后恢复。
- 图鉴登记、少量内容解锁、作品结算、继续存档。
- 每个会馆与决赛各至少两套固定敌阵变体，覆盖至少三种可通关构筑。

切片每张可出现的器具都应完成真实调校表与至少两个合格改装方向；没完成的牌留在自由试验场，不进入联赛切片卡池。不能售卖一个到门槛却什么都不发生的“完整功能”。

先验证“市场取舍 → 投资器具 → 赢或输 → 修正构筑”是否成立，再扩到四城十五战。暂不增加自由行走城镇、基地经营、材料配方树、全语音长剧情或真人匹配。

### 接到现有 demo 的功能边界

| 部分 | 已有基础 | 需要新增 |
| --- | --- | --- |
| 战斗 | `lib/arena-engine.ts` 确定性模拟、三路与增幅器 | 赛季成长效果输入、版本边界与逐牌校准 |
| 卡牌 | `lib/arena-catalog.ts` 实验牌；2D 卡面 | 调校表、改装、来源与养成对比，不硬限制多效果数量 |
| 对手 | `lib/arena-challenge.ts` 固定挑战 | 城市/阶段敌阵库，公开情报与公平预算 |
| 赛季 | 暂无完整赛程 | 赛季状态机、节点、商店、事件、奖品、败绩与晋级 |
| 收藏 | 战斗档案可作为技术参考 | 设计图鉴、解锁条件、个人作品档案 |
| 页面 | `/arena/2d` 自由试验场 | 独立的联赛入口、地图/城市/整备/结算；保留试验场作为验证工具 |

首版建议以确定性 PVE 选手完成全部旅程，因其可承载关卡考题与重复出现的劲敌。**PVE 是本文实施建议，用户未对卡牌方向确认最终单机或多人定位**；不能引用另一条电梯方向的单机决定替代这里的选择。

### 状态与结算约束

将赛季状态、局内卡牌实例、局外档案、战斗临时状态分开。赛季保存规则版本、种子、当前节点、奖励领取记录、货架与刷新序列、资源、库存、布阵、调校/改装、专长和败绩。每个节点奖励与图鉴解锁有稳定 ID。

比赛节点第一次结算和后来第一次获胜分别记录领取状态，以覆盖资格关「先败后胜」；第三败之后的战斗回放不会重新开启赛程。内容池快照与成长字段保留版本，旧联赛存档不能被新解锁或更新的价格表静默改写。

购买、出售、转移、改装和奖励领取必须是一次完整的校验与提交；失败时不消耗任何钱、物品、次数或额度。重开页面、连点、重放战斗不能重复领奖。赛季种子与节点随机流分离，避免看一段演出就改变后续商品。

战斗输入冻结后才开始模拟。回放同时持有牌基础版本与当时成长快照；今后改平衡不会静默改变旧比赛的解释。高分和成就来源于正式赛季提交，不来自任意复盘副本。

## 13. 验证标准与主要风险

以下是下一轮试玩的**观察目标，不是已有成绩**：

| 假设 | 如何观察 | 失败信号 |
| --- | --- | --- |
| 旅途有收集与培养的取舍 | 记录玩家选择、原因与后续使用；不同构筑都要观察 | 无论阵容如何总选同一类奖励 |
| 旧牌值得养，新牌也值得拿 | 同时观察早期牌留到终盘与中途有效转型的局 | 必须全换高稀有，或从第一城起再也不想看新牌 |
| 玩家感到自己变强 | 第二城后能说明一条成立的联动与一件重点培养器具 | 只能说“所有数字都变大了”，无法指出自己的选择 |
| 关卡考验构筑而不锁答案 | 至少三种不同主轴通过相同会馆；记录多种补救途径 | 某张牌成为必购税，或某流派完全不能过一城 |
| 失败后仍可学习和恢复 | 首败后观察调整是否改变后续结果 | 第一败后几乎必退赛，或故意失败获得额外成长 |
| 节奏适合目标局长 | 分别统计读牌、整备、自动战斗、复盘与重赛时间 | 主流程长期超过 90 分钟，或大量时间只是点确认 |
| 局外解锁只增加选择 | 比较基础池与全解锁池的可达构筑和供给缺口 | 初始卡池缺少必要手段，扩池反而经常断构筑 |

重点风险：三路本身已经有布局复杂度，再叠多个养成货币和随机词条会分散注意；因此首版收敛资源与成长轴。另一方面，等级上限和稀有牌预算若过紧，会缺少后半程跃升感，需要通过真实战斗测，而不是靠增加更多升级按钮弥补。
