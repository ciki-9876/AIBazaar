# F9 电梯生存完整流程设计 SPEC 草案

后续状态：用户已授权按本SPEC完成除AI以外的全量开发。当前执行规则及验收见[执行规格](./F9_ELEVATOR_FULL_FLOW_IMPLEMENTATION_2026-10-04.md)与[ADR-0039](./design-log/decisions/ADR-0039-elevator-complete-season-with-finite-rescue.md)。下文保留草案0.1形成时的提案状态，不追改历史。

日期：2026年10月4日。版本：草案 0.1。适用：电梯生存产品。

本稿将前三层教学、四层集结、五层开赛、私人爬楼、共享据点、金票晋级和资源死亡连成完整流程。玩家在私人楼层准备自己的生存能力，在据点面对真实选手竞争；失败应能追溯到物资、行动和争夺结果。

**状态说明**：用户提出的流程与约束作为本轮设计输入；为消除漏洞而补充的规则均标为建议，尚未获得逐项确认。本轮只交付设计文档，没有改变可执行规则、AI 分支、存档或回放。文中参数为调试建议，不代表已经证明平衡。

## 1 设计目标与用户约束

| 来源 | 规则 |
| --- | --- |
| 用户要求 | 通关第三层、获得第一张通行证后结束引导。 |
| 用户要求 | 第四层是所有本次参赛者共同出现的准备房间；自由走动、没有攻击，等待广播介绍规则后开门。 |
| 用户要求 | 第五层开始正赛。非据点楼层各自探索，不发生玩家与 AI 的遭遇。 |
| 用户要求 | 每十层一个共享据点，玩家与 AI 可因实际进度先后进入。 |
| 用户要求 | 据点面积比普通房间大50%。 |
| 用户要求 | 据点提供剩余参赛人数减 X 的黄金通行证；没有金票不能前往据点下一层。 |
| 用户要求 | 可以拾取多张金票，但最多携带一张回电梯；增加把物品扔在脚下的操作。 |
| 用户要求 | 玩家暂停或退出后，AI 也停止行动。 |
| 用户要求 | 正赛通过有限物资与精力损耗产生死亡，取消限时注销资格等硬性淘汰。 |
| 延续用户偏好 | 同屏少文本；详细规则集中在广播、按需说明和规则回看。 |

保留现有“通行证支付爬升距离、电梯升级决定单次跨度、上升后低层关闭”的路线基础。建议区分普通通行证与黄金通行证，分别承担爬楼和据点资格，避免一种票同时承担所有收费。

## 2 必须修正的漏洞

| 问题 | 后果 | 本稿建议 |
| --- | --- | --- |
| 金票不足等于恰好死亡 X 人 | 战斗、饥渴和囤票都可能造成额外死亡，配额不能保证死亡人数 | 改为最多 N减X 个晋级资格，至少 X 人无法通过；实际死亡可能更多。 |
| 不断按当前存活人数重算金票 | 已取得的票可能突然失效，或死亡反而增减出新票 | 冻结据点名册与发行量；发行后不重算、不补发。 |
| 前一据点尚未结束，领先者已抵达后一据点 | 后一据点最终有多少参赛者尚未确定 | 推荐上一据点结算后冻结下一段名册；允许领先者先爬楼，但下一据点金票等名册冻结后发行。另保留固定名额表方案供选择。 |
| 每次只带一张，但可以反复返程 | 同一人可把整个金票池搬到仓库 | 第一次合法带回即兑换本人资格；每人每据点只兑一次，已晋级者不能再拾取本点金票。 |
| 倒下免费补满精力、饥渴 | 自杀成为恢复资源的最优方式，不能自然死亡 | 正赛取消免费重置，救援消耗预存真实物资；没有救援储备则永久死亡。 |
| 电梯停留不消耗，房间重进重置 | 无票选手可以无限存活或无限刷补给 | 正赛电梯也消耗食水，同层状态持久化，补给与可兑现掉落有限。 |
| 只扩地图却不改争夺布局 | 变成多跑50%的路，先到者可能在单入口包场 | 按可通行面积扩容，分散争夺点和入口，保持角色尺寸、视距、速度。 |

用户希望的资源淘汰成立，需要整个经济闭环都有限。只修改“精力归零”这一处，不能解决无限恢复和无限刷物资。

## 3 完整流程

引导一至三层 → 第四层安全集结与广播 → 各自电梯 → 第五层同步开赛 → 私人楼层搜集与成长 → 共享据点争夺金票 → 带回一张兑换资格 → 下一私人楼层 → 重复至百层终局。

| 阶段 | 进入条件 | 玩家可以做什么 | 结束条件 |
| --- | --- | --- | --- |
| 引导 | 新开局 | 学习移动、搜索、装备、补给、返程、投喂与选层 | 完成第三层目标并实际取得首张通行证。 |
| 四层集结 | 用首张票完成3F到4F的移动 | 观察全部参赛者、走动、听广播、回看规则 | 广播完成，大门开放，各选手返回本人的电梯并准备。 |
| 开赛 | 玩家确认出发，所有参赛电梯已就绪 | 进入各自5F房间 | 同一比赛 tick 激活全体正赛。 |
| 私人爬楼 | 正赛存活，拥有本段资格 | 搜刮、战斗、吃喝、升级、选择停留或跨层 | 实际抵达本段据点；或死亡。 |
| 据点争夺 | 实际抵达10F、20F等 | 搜刮、争夺、撤离、扔下、取得金票 | 带回一张本点金票并兑换资格；或失去晋级机会、死亡。 |
| 下一赛段 | 已兑换本点资格 | 从kF前往k加1F，开始新的私人探索 | 抵达下一据点。 |
| 百层终局 | 有效抵达100F | 争夺终局资格，带回终局金票 | 首个合法兑换终局金票者获胜；全体死亡则无人获胜。 |

### 第三层引导结束

“通关”建议以明确任务记录判定：第三层关键目标完成、第一张通行证实际登记、完成一次返程确认。单纯走进第三层不算完成。

首张票是稳定身份的一次性奖励。重复返程、读档或再次击败旧目标都不重新发票。引导期可保留原免费救回机制；进入正赛之前必须明确告知其即将改变。

### 第四层准备房间

所有正式参赛者在赛季初始化时进入同一个准备房间，拥有固定身份和自己的电梯入口。这里的“同场”应能看见真实角色、名字和行动，不能用一张名单替代实际集结。

用户指定的无攻击规则同时禁止攻击伤害、敌对碰撞推挤、抢夺和补给消耗。建议身体碰撞在此弱化，防止 AI 堵住玩家通道。准备房间不能刷可带入正赛的补给，不能交易首张票，也没有假倒计时死亡风险。

建议进入后自由走动20秒再广播。首次广播分六段，共约60至90秒：目标、普通通行证、私人楼层、共享据点、金票与单人兑换、补给和死亡。字幕最多两行，玩家可以继续走动；一整页条款留在规则回看中。

广播结束后开门，各选手真实走回自己的电梯。玩家可自由决定何时准备好；准备阶段不偷跑正赛。首次须完成规则确认，重开可跳过已看过的广播。4F到5F是全体的赛制入场移动，不消耗第二张普通票。

### 第五层开赛

建议以“玩家确认出发且全部参赛电梯就绪”为全局开赛条件。全体同 tick 激活，但出门、探索、取票和返程由各自真实行为产生，不直接写入领先楼层。

正赛开始时冻结参赛名单与初始配置。AI 的物资预算按公开规则生成，不能在运行中补满状态或凭空补票。玩家保留教学积累；AI 的等价准备预算是调试建议，需要验证是否让玩家的教学收益仍有价值。

建议赛前为全体初始化一次相同的精力与食水状态，避免教学剩余伤害成为玩家不知道的开赛劣势。这属于固定赛季起始预算，仅初始化一次，必须保存已发放标记；不是返程、升层或死亡后的恢复。装备与库存仍按各自真实准备记录保留。

5F必须提供可达的首份普通通行证来源。取得它可以有搜索和风险成本，但不能要求先拥有另一张票。首段应可在不升级的情况下合法抵达10F。

## 4 普通通行证与私人楼层

以下是本稿推荐的具体支付规则，尚待确认：

| 行动 | 支付与限制 |
| --- | --- |
| 3F到4F | 消耗教学获得的一张普通票；失败不扣票。 |
| 4F到5F | 开赛入场免费，全体同规则。 |
| 正赛普通爬升 | 每上升一层消耗一张普通票；支付距离与电梯跨度分别检查。 |
| 同层重进 | 免费，复用原房间状态，不刷新资源、怪物奖励或状态值。 |
| 跨层 | 可以在跨度内跳层，支付完整距离；跳过的补给和低层永久错过。 |
| 越过据点 | 禁止；无论跨度和普通票多少，都须实际进入据点并获得资格。 |
| kF到k加1F | 使用已兑换的本点金票资格，不再多收一张普通票。 |
| 普通票余额 | 建议跨段保留，上限沿用10张；不再收旧版审查2票、不发免费下一段2票、不把余票转经验。 |

普通票是登记账户资源，不占物品格；金票是可以争夺和扔下的实体。普通票与金票不能互相转换，升级不能直接生成晋级资格。

私人楼层的房间实例按“赛季、楼层、选手”隔离。每名选手使用相同难度与资源预算规则，持久化自己的箱子、掉落、怪物、迷雾和背包遗落。不同选手不在私人楼层相遇，也不互相抢走这些来源。

建议私人地图用共同内容模板与独立物品身份，先减少随机运气对到达速度的影响，再试验地图差异。私人楼层并不意味着 AI 停止模拟：AI 必须实际走路、搜索、战斗、耗用补给、返程并支付票。

普通票来源与食水来源必须有限。生成校验至少证明每个基础路线能找到下一步所需的票，票源不在必须先付票才能进入的区域。玩家主动跳过物资或用完资源导致的困局可以成立，地图生成造成的无解开局不能成立。

## 5 据点空间与竞争

10F至90F是晋级据点，100F另按终局处理。每个据点只有一份权威房间状态；玩家未在场时也持续推进 AI 的行走、战斗、拾取和资源变化。

**面积定义建议**：据点可通行探索面积等于同档普通房间的1.5倍。若长宽同比增加，各乘约1.225；不能把两个边都乘1.5，否则面积会变成2.25倍。门外装饰、封闭区域和电梯舱不计入探索面积。

建议采用多个外围电梯入口、中央与侧翼争夺区、可绕行通路。不同入口到最近有效争夺点的最短路径应接近；金票分布不能全部压在一个宝箱、单个驻守者或单一狭窄入口后。角色、拾取范围、速度和视距不随地图放大。

先到者能先拿资源、探路、占据位置，这是真实竞争收益。后到者看到房间真实现状；不会为玩家重置已打开的箱子，不会临时让 AI 等玩家，也不保证到达时仍有金票可拿。

用户尚未明确据点是否允许选手互相攻击。**本稿建议允许，但仅限共享据点**，使囤多张金票有实际风险。武器默认攻击怪物；攻击选手须有明确敌对目标，避免自动武器把中立接触变成无意宣战。AI 可以依法主动敌对，规则与玩家相同。联盟和自由谈判不作为首个切片的必需功能。

据点驻守者可以保护部分资源或通路，但不再是所有人额外提交资格的第二道审查。是否必须共同击败它应由具体地图任务决定，不能偷偷恢复旧版“杀驻守者加2票”的收费。

## 6 金票配额与异步名册

### 配额能够承诺什么

本点正式参赛名册人数记为 N，资源名额减少量记为 X。建议常规据点使用：

`实际 X = min(配置 X, max(0, N减1))`

`金票发行量 G = N减实际 X`

N为0时不发行，赛季无后续参赛者；N为1时X为0，避免唯一存活者被负配额淘汰。发行后不能因死亡或到达人数变化临时增减。金票不可以销毁，死亡时也不会消失。

正确承诺是**最多 G 个本点晋级资格，至少实际 X 个本点名册成员无法晋级**。如果所有票都成功兑换，恰有 G 个兑换者；他们之后仍可能死亡。若仍有金票留在无人能够取得的房间中，晋级人数可能更少。不能承诺恰好死 X 人或恰好剩 G 个活人。

### 推荐的名册冻结方式

“当前剩余参赛者”建议改成“本段正式名册中的存活选手”。为避免异步到达造成重复计数，本稿采用以下方案：

1. 第一段的参赛范围在5F开赛时确定，包含全部正式参赛者；第一名选手实际抵达10F时，以这一范围内仍存活的选手冻结本点名册和N。
2. 本段金票池一次发行 G 张，登记唯一身份；不要求名册中的选手全部抵达才能争夺。配置X须为非负整数，常规点在N大于1时建议至少为1。
3. 当前据点所有金票兑换完成，或名册中已经没有存活且尚未晋级的选手时，该点配额结算。后一个条件可使死亡导致的无人认领金票不永久卡住赛季。
4. 下一段的参赛范围只包含上一据点已晋级者。下一点同时满足“上一据点已结算”和“至少一名合法选手已实际抵达”时，以范围内仍存活的选手冻结名册和发行量。N统计整个合法参赛范围，不是房内人数。
5. 已晋级者可立即去k加1F探索，不要求等待其他人离开上一据点。可以提前抵达下一据点并争夺普通物资；**下一据点金票在其名册冻结后才投放**。已实际抵达的事实保存下来，不因暂时撤离而遗失。
6. 晚到者始终是名册中的真实选手，不按“已进房的人数”缩减配额；名册外选手不能兑换本点票。

这会带来明确取舍：领先者能够提前准备和占位，但如果上一据点尚未完成结算，下一据点暂时没有金票。界面显示“上段资格结算中”，不得把真实等待伪装为模型延迟。若领先者等待过久，应通过物资布局和赛段名额方案调整，不能用隐藏淘汰倒计时解决。名册冻结后的死亡仍可能使实际晋级人数减少；不能保证最后都由活人现场争走全部名额。

另一种方案是赛前固定每个据点的晋级名额表，允许领先者立即争夺任意后续据点。它更适合完全连续竞速，但无法再承诺每点都按当时实际存活人数减 X。**两者需要用户选择，本稿以名册冻结方案作为可执行建议，不把这一新增等待规则视为已批准。**

### 资源不足与死亡分开记录

所有金票兑换后，未获得资格的选手已无合法上升路线，可标为“无晋级名额”。这只是资源资格结果，不是系统立即杀死或补扣精力。他们可以消耗现存补给、继续在可达房间行动，最终按死亡规则结束。

临时拿不到金票不等于配额已经结算：尚未兑换的票可能在地上、持有人背包或遗落物中，仍可以争夺。只有权威状态能够宣布名额已用尽。

## 7 金票拾取与兑换

金票是绑定赛季和据点的实体，每张占一格、不能堆叠，可以同时持有多张。它只能放在普通行囊中，禁止塞进安全容器、装备槽、仓库、投喂口或销毁系统；不能在电梯中远程转交。

建议首次合法返程时按以下顺序执行一个完整事务：

1. 检查选手存活、本点资格未兑换、位于本人的电梯撤离区。
2. 在进入受保护电梯舱的门槛检查全部随身容器，仅允许0或1张本点金票；多于1张时禁止进入保护区和撤离并提示“多余金票需扔下”。不能先躲进安全舱囤住多张再慢慢处理，不自动选择、销毁或复制多出的票。
3. 0张允许普通撤离与整理，但没有晋级资格。
4. 1张则完成实际撤离，消耗该票唯一身份并登记本人本点资格。
5. 开放k加1F的单次入场权限；不能再次兑换，不刷新补给。

兑换后本人不能再拾取本点金票；若仍返回本点取普通资源，仍受此约束。这防止一张一张搬运，也防止晋级者靠无限重进继续占票。禁止把尚未兑换的金票先存进电梯，再去拿第二张。

持多张票不会直接增加普通精力损耗倍率；首版先用背包占格、争夺风险和撤离限制产生代价，避免再增加一条难懂的负重规则。选手可以通过“扔下”转移金票，接收者必须现场拾取，所有权必须真实转移。

多名选手同 tick 拾同一张票时，只能一人成功。建议按实际完成拾取的 tick 排序；同 tick 用赛季种子、票身份、竞争选手身份与当前tick产生稳定裁决，不能固定玩家优先或按数组位置奖励 AI。裁决方式需纳入回放。

## 8 扔下物品

新增“扔下”与既有“销毁”必须分开：扔下会产生可拾取实体，销毁会永久删除；金票只允许前者。

| 场景 | 建议规则 |
| --- | --- |
| 房间中扔下 | 默认一份，支持明确数量；同一物品身份从行囊移到脚下的可通行地面。 |
| 地面无法放置 | 选择脚下最近的合法点；没有合法点则失败，物品完整留在原容器。 |
| 电梯舱内 | 普通物品建议使用仓储；禁止在保护区扔金票绕过兑换扫描。超过一张时须走回房间扔下。 |
| 玩家脚下已有物品 | 可以形成并列地面实体，不合并身份、不覆盖旧物品。 |
| 重新拾取 | 使用主动交互；刚扔下不会被自动拾取循环吞回。 |
| 别人拾取 | 据点内其他存活选手可以拾取；私人房间的物品只属于该房间实例。 |
| 跨层与保存 | 世界中的掉落持久化；低层关闭后不能通过重新生成追回。 |

拆堆仅移动指定单位的身份。操作失败不减少数量、不生成地面实体、不改变原有保护状态。首版应让点击与键盘都能扔下，减少精确拖动带来的操作负担。

## 9 精力恢复与永久死亡

### 当前实现的无限生存来源

当前房间的 `player.hp` 在有楼层的探索中显示为精神力，归零后触发倒下。救回时它被设置为100，食物与水至少恢复到60；装备、安全容器和登记票保留。与此同时，持续怪物可继续产生脑浆，可重复签发器还能继续发普通票。

因此本稿把“精力 S”定义为现有精神力条对应的同一生存状态，不新增一个隐藏生命条，也不使用当前旧 demo 中另一个 energy 字段作为第二套死亡指标。未来统一命名属于实现迁移工作。

### 推荐采用消耗真实补给的救援

引导期保留免费救回；从5F正赛开始，正常返程、开门、升层、兑换金票和演出均不补满精力或食水。

正赛恢复来自消耗品和明确休息。休息可以在有食物与水时恢复精力，但会继续消耗营养和饮水，不能凭空生产补给。食水耗尽后的状态下，不允许休息恢复抵消饥渴伤害。急救包的主动与自动使用继续消耗实际物品。

建议救援储备使用现有物品：电梯仓库中的急救包一份、口粮或面包一份、净水一份。出门前可设为救援预留，仍占原仓库格；预留单位不能同时拿出使用或投喂。可救援次数由真实库存推导，不新增凭空刷新的一条生命数。

| 事件 | 后果 |
| --- | --- |
| S大于0并正常撤离 | 回电梯，保留当前S与食水；普通物资带回，不免费恢复。 |
| S归零且存在完整救援储备 | 一次性消耗全部三份预留物资；普通行囊留在倒下位置，包括所有未兑换金票；装备与安全容器保留；被救回电梯。 |
| 救回恢复 | 建议S恢复到45，食水各按已消耗的食物和净水恢复45、上限100；不额外加到60或100。45来自现有消耗品效果，适合程度待测试。 |
| S归零但储备不完整 | 永久死亡，本季不能再次行动；没有免费补包、自动补足或以后再赊账救援。 |
| 已兑换资格后死亡 | 资格不返还为金票，不补发名额；死者不能进入下一段名册或复活。 |
| 据点中永久死亡 | 随身物资进入真实遗落物；金票保持原身份留在共享房间，可被其他选手取得。 |

救援是否成立在S归零的权威结算中检查，原子消耗；不能只扣急救包后发现缺水，再部分失败。救援期间全体比赛继续推进，除非玩家主动暂停；镜头演出不能让 AI 单方面停下，也不能加速任何一方。

普通行囊追回延续旧风险；永久死亡后所有随身物资，包括装备和安全容器，应转入尸体遗落物，私人仓库不跨房间转给别人。安全容器保护的是一次可救援的倒下，不保护本季永久死亡。

尚未兑换的金票必须落在共享房间的公共可达区域。若倒下位置在电梯门槛或本人独占的舱内，金票释放到门外最近的公共合法点，不能因救援或死亡被永久锁进别人不能进入的舱室。

此方案保留“安泊救回”的已有情感和追回循环，同时让失败消耗真实长期物资。代价是储备教学、较长失败过程和医疗资源平衡。另一方案是**正赛S归零直接永久死亡**，逻辑更简单、竞争更残酷，但首个据点容易变成突然的单次失败；它作为待选替代方案保留。

## 10 有限经济与停留消耗

正赛所有存活选手在房间、电梯、旅行、搜刮、撤离和救援过程中持续消耗食水。暂停菜单、物品管理、失焦暂停和退出停止整个比赛时钟；四层准备属于开赛前，不消耗正赛资源。

本稿不设置“待满几分钟就死”的判定。食水按相同规则消耗，归零后真实损耗S；急救、休息和补给必须有真实资源来源。这些成本可因移动和战斗不同而变化，但不能仅因排名落后提高某人的耗费。

必须一并限制：

- 箱子、普通票来源、食水、药品只发一次，重进与读档不刷新。
- 移除正赛的无限应急签发器；遇到缺票时不偷偷补票。
- 若保留持续敌群，按房间给可兑现战利品设置有限预算；预算耗尽后不再掉可换食水或药品的材料。不能靠无限脑浆交易形成无限生存。
- 教学面包、安泊首次赠送、广播奖励不可在正赛重复领取。
- 升级和晋级只改变能力或资格，不恢复生存状态。
- 生产设施必须消耗有限原料；不能加入无输入的无限净水、食物或医疗来源。
- 私人房间与共享据点的物资账本必须分别守恒，死者物资转移不算新增产量。

在不能继续上楼时，选手的可达补给总量有限，而每个有效比赛 tick 的必要消耗为正，最终只能耗尽恢复手段并死亡。暂停和退出不算有效 tick；这是用户保护，不能当作离线死亡漏洞处理。

首轮验证应测真实食水收支与救援次数，不能只根据死亡画面认为闭环已成立。现有外勤食物0.14每秒、静止饮水0.2每秒和饥渴损耗S每秒1.5可作为来源明确的调试基线；扩展到电梯后须重新测量，尚不建议直接锁为正式数值。

## 11 AI 公平行动与全局时钟

玩家与所有 AI 共用一个显式比赛 tick。AI 可以早到、晚到、受伤、缺票、囤票、救援或死亡；结果必须来自实际规则动作。

| AI 必须遵守 | 不允许的实现 |
| --- | --- |
| 走完路线并完成搜索、拾取、撤离 | 定时把楼层数字加一，玩家入场才临时生成它的位置。 |
| 承担同样的补给、票和精力成本 | 免费恢复、无来源金票、无限仓库。 |
| 读取自身可见信息与公共广播 | 直接读取玩家背包、墙后金票或未公开目的地。 |
| 离屏房间持续使用权威状态 | 玩家进入据点后才计算谁应该提前到。 |
| 同时争夺时使用统一裁决 | 为剧情、模型回答或玩家体验改写持有者。 |
| 暂停、退出后停止全体行动 | 后台按真实时间追赶，重新打开补算几个小时。 |

建议离屏私人探索先用经过校验的固定步长执行或可重放摘要模拟；抵达共享据点后使用同一实体与战斗规则。摘要必须保留位置、成本、伤害、拾取与到达因果，不能只给一个到达时间。最初切片宜使用少量选手，先证明公平再扩人数。

模型输出是意图，不是事实。每条意图引用当前观察版本；暂停、读档、角色死亡或环境变化后，过期回答不得在恢复时直接执行。模型网络等待也不得单独扣玩家或某个 AI 的资源。

存档保留全部选手、私有房间、共享据点、资格、票身份、库存、模拟tick、随机状态和正在执行的动作。退出不产生新的时钟；恢复沿保存状态继续，不重新初始化金票池。性能降级不能跳过某些选手的生存消耗或争夺动作。

## 12 百层终局与人数节奏

本稿建议100F为终局据点，发行一张终局金票。先合法带回并兑换者获胜；只是碰到100F或拿到未撤出的票都不算赢。终局票不开放101F。

常规据点10F至90F按N减X限制晋级，100F按一名最终胜者处理。若只剩一名选手，仍须完成百层目标，不提前判胜；但长段单人爬楼是否有趣，需要专门验证。有人获胜时其他存活者是未获胜，不能宣称他们已死亡。

玩家永久死亡或产生胜者后进入本季结果与真实事件复盘，可以重开新季，不能回到本季电梯免费复活。新季库存、票与资格重新初始化，保留的局外记录及再次开局是否跳教学需另行确定；本稿不默认把上一季实力带入下一季。

**人数调试建议**：完整赛季可先以玩家加11名AI、常规X为1试算；没有额外死亡时，90F剩3人，100F争1个胜者。12人不是用户确认人数。原型若只使用玩家加3名AI，应先做到5F至10F、兑换后进入11F就结束切片；连续九轮X为1会过早只剩一个人。

每点固定X、按比例淘汰和预设晋级人数表的节奏不同，需通过实测死亡率选择。不能为了凑满100层的对手数量，在后半场悄悄补参赛者、复活或给AI免费补给。

## 13 信息与少文本界面

常驻只展示当前层、下一据点、普通票数量、精力与食水状态。电梯首页保持直接行动；去掉旧版资格倒计时，改为资源准备与本点资格状态。

据点使用短提示和状态图标：本人金票数量、尚未兑换名额、已获资格。必须区分“地面暂时没看见票”和“所有名额已兑换”，不展示墙后票的位置。尚未发行的下一点明确显示“上段资格结算中”。

关键操作再展开一行信息：

| 场景 | 示例短提示 |
| --- | --- |
| 多张金票返程 | 多余金票需扔下 |
| 已兑换 | 已获11F资格 |
| 无普通票 | 返回本层找票 |
| 救援储备完整 | 救援可用1次 |
| 缺救援储备 | 倒下将永久死亡 |
| 配额用尽 | 本点晋级名额已用尽 |

“倒下将永久死亡”在首次正赛出门和储备由有变无时明确一次，之后使用图标或简短状态；不要每次开界面重复长段警告。战后账本解释用了哪些真实物资，详细成本放在选中或回看时。

广播可以详细介绍规则，但每段只讲一个概念，结合地图、票券和电梯开门演示。死亡、名额变化和AI抵达公告只来自权威事件，避免无后果台词制造假竞争。

## 14 实现边界与兼容

新规则将局部替代旧版：第三层即揭晓正赛、全楼层共享票源、可重复签发器、12分钟资格注销、驻守者加2张票审查、余票转经验、下一段赠票、倒下免费补满，以及抵达100层即获胜。

保存与回放应使用独立的新规则版本，保留旧存储键及支持的读取路径。正在进行的旧竞速赛季继续按旧规则或明确重开新赛季，不能把已登记普通票自动变成实体金票，也不能静默把免费救回的旧局变成永久死亡。旧黄金回放保留其语义和随机流。

建议新增的状态语义如下，具体类型由实现阶段决定：

| 状态 | 必须保存的内容 |
| --- | --- |
| 比赛阶段 | 引导、准备等待、广播、待出发、正赛、终局和结果。 |
| 据点 | 楼层、名册、冻结tick、X、发行量、未发行或已发行、全部票身份、兑换者和结算状态。 |
| 选手 | 生存状态、当前实例、资格、精力食水、普通票、物品、仓储、救援预留和动作进度。 |
| 世界 | 私人房间清单、共享房间快照、有限产出余额、地面物资和遗落物。 |
| 裁决 | 全局tick、种子、规则版本、事件和同tick争夺结果。 |

实现时由规则层维护原子事务与守恒，UI 不负责判断谁已经晋级；AI 意图不能直接改写权威状态。电梯产品继续与卡牌产品隔离。

## 15 验收案例与下一轮验证

以下为未来实现的验收规格，本轮未执行游戏行为测试：

| 场景 | 必须得到的结果 |
| --- | --- |
| 第三层重复返程和恢复存档 | 首张票只出现一次；未取得它不能按通关完成进入准备。 |
| 第四层玩家贴近AI、攻击、长时间闲逛 | 没有伤害或正赛食水耗费；名单完整、广播按保存进度继续。 |
| 玩家在广播后晚回电梯 | AI不偷跑5F；确认开赛后全体同tick激活。 |
| AI先到10F并拾走一张票 | 玩家晚到看到已改变的同一个房间；票没有重生。 |
| N为6、X为2 | 一次发行4张；后来死亡不新增或撤回票。最多4人兑换。 |
| 一人持两张金票撤离 | 撤离失败、数量不变；扔下一张后可带另一张兑换。 |
| 一人已兑换后再次重进 | 不能拾取或兑换第二张本点票；仓库和安全容器不能藏票。 |
| 持票者在据点倒下 | 未兑换金票全部进入遗落物，别人可拾取；救回不复制票。 |
| 缺一份救援储备而S归零 | 永久死亡，没有部分扣费后免费救回。 |
| 连续两次合法救援 | 实际消耗两套物资；用尽后第三次倒下永久死亡。 |
| 已通过10F者提前抵达20F | 10F未结算时20F金票尚未发行；10F结算且20F已有实际抵达记录时，按存活合法选手冻结名册和发行量。 |
| 所有剩余未晋级者死亡，前点还有无人领取的金票 | 前点结算，下一段仅记录存活的已晋级者；无参赛者则赛季结束。 |
| 躲在电梯且不打开暂停菜单 | 正赛食水继续消耗；不自动补满，最终按资源和救援规则死亡。 |
| 打开菜单、失焦、退出后等待现实一小时 | 玩家与AI的tick、资源和动作都不变化；恢复不补算时间。 |
| 私人房间反复重进与击杀持续敌群 | 补给、普通票和可兑现掉落没有无限新增；物资身份守恒。 |
| 同tick两人抢一票，保存后重放 | 仅一个成功，结果稳定；交换输入数组顺序不改变裁决。 |
| 100F有人拾票但在撤离前死亡 | 尚无胜者，终局票可继续争夺；完成合法兑换才结束比赛。 |

第一轮可玩切片建议只验证3F通关 → 4F集结 → 5F开赛 → 10F据点 → 11F入场，以及资源救援和永久死亡。先测AI到达分布、第一次据点的存活率、持多票时间、救援库存变化、名册冻结等待和后到者是否仍有可理解的选择，再扩展完整百层。

仍需用户确认的四项选择：

1. 正赛采用有限补给救援，还是S归零直接永久死亡。
2. 采用本稿的上段结算后冻结名册，还是赛前固定名额表以保证完全连续竞速。
3. 据点是否允许选手互相攻击；本稿推荐允许且需要明确敌对目标。
4. 正式人数与X曲线；本稿只提供12人、每点X为1的节奏试算。
