## 完整流程

| 阶段 | 实际规则 |
| --- | --- |
| 1–3F 引导 | 保留既有教学；第三层必须击败守卫并确认结算，才登记唯一首张普通票。重复结算或恢复存档不增发。 |
| 3→4F | 消耗首张票进入准备房间。玩家及11名参赛者实体在场；无攻击、敌群、补给搜刮或食水消耗。 |
| 4F 集结 | 20秒模拟时间后广播；六段各11秒，每段只显示标题和一行规则，仍可走动。暂停与保存保留进度。 |
| 4F 登梯 | 广播结束才开放自己的电梯；玩家确认前往5F后，全体同一模拟tick开赛。精力、食水各100，只初始化一次。 |
| 5–99F | 非据点为按选手和楼层分种子的私人房间；普通票支付上升距离，已离开的低层永久关闭。 |
| 10–90F 据点 | 共享房间的实际可行走探索区为750格，普通房间500格，面积增加50%。首个真实抵达且前点结算后冻结名单，发行N−X张金票，默认X=1。 |
| 据点返程 | 可持多张，但多于一张无法进入个人受保护电梯；扔下一张后另一张可带回。首次合法带回自动兑换本人资格并消耗实体票。 |
| 据点→下一层 | 只可免费进入据点层+1；不能借资格跳过11、21等初始层。之后恢复普通票付费。 |
| 100F | 只发行一张终局金票。抵达或拾取不判胜；合法带回后才产生胜者，无101F。玩家永久死亡则本次游玩结束。 |

默认12人和X=1是本轮调试参数，不是已证明的平衡结论。人数低于淘汰额度时，将X限制为N−1，保证最后一人仍需完成百层目标。有限名额限制晋级，不能保证恰好死亡X人。

## 普通票与有限房间

每个私人房间有三处一次性票源，分别1、2、2张，交互需要90tick。普通票账户上限10，超额失败不消耗票源。E持续按住和点击后持续交互执行同一规则；移动、受伤或取消会中断。部分有效进度可随存档恢复。

电梯Lv.2–5跨度分别3、5、7、9层；不能越过据点、回低层或透支普通票。保留累计脑浆和零件投喂、盈余单位、仓库扩容；正赛升级可到Lv.5。

每房间八个固定有限物资箱；同层重进保留已取物、票源、敌群和有限可兑现脑浆预算36。持续敌群不能无限产出升级材料。升层后丢弃永久封闭的私人房间快照，共享据点保留；这是受规则约束的存档压缩，不是重置或再开放低层。

## 名册、金票与物品守恒

冻结N包含当前赛段全部存活的合法选手，晚到者仍占同一份名额。死亡不增发、撤回或重算已发行票。下一据点可以提前探索，但前点尚未结算时显示“名册待结算”，没有金票。

已发行票全部兑换，或所有尚未晋级者死亡，才结算该据点。无人领取的票不会阻断后一条件。100F另按单张终局规则处理。没有通过倒计时强制注销的路径。

每张金票有固定身份，占一个背包格，不堆叠。不能装备、放入保险格或仓库、销毁、投喂。已兑换者不能再拾取本点金票。拾取、争夺、扔下和死亡回地面都使用同一账本；同tick冲突按种子与稳定身份裁决，输入顺序不改变结果。

“扔下”用于外勤背包及装备，支持单个或整叠；保留真实单位身份，物品落在脚下最近的可达公共地面，必须手动拾回。它与确认销毁是不同操作。

## 精力、救援与永久死亡

精力使用现有HP。正赛每秒基础消耗食物0.14、水0.20；移动额外耗水0.11。任一耗尽后每秒损失精力1.5。电梯、升层和救援演出均继续消耗；普通返程和切换房间不会补满。个人电梯挡住攻击，但不暂停代谢。

仓库可锁定真实的急救包×1、食物或面包×1、水×1。三件仍占仓库格，预留后不能转移或销毁；解锁不退回任何已消耗物资。缺一件不能预留完整救援，不发生部分扣费。

精力归零时，完整预留套装一次性消耗，精力恢复45，食水各增加45、上限100，救回电梯；普通背包和全部未兑换金票留在可达地面，装备和保险格保留。还想再次救援必须重新锁定另一套真实库存。两套库存可救援两次，耗尽后的下一次归零永久死亡；没有固定生命次数或免费复活。

没有完整预留套装则永久死亡，全部随身物品（含装备和保险格）落地，仓库保持私人库存。本季不能继续，结果页可查看最近真实事件并重开；新季不继承上一季库存、票或资格。终局票持有者死亡不被算为胜者，未兑换票保持可争夺状态。

电梯内休息每秒恢复精力2，额外消耗食物0.5、水0.7；缺食水或满精力时停止恢复收益。物资仍有限。

## 操作、暂停与兼容

首页只保留楼层、票、跨度、据点资格、出发／救援／休息和紧凑投喂区；删除旧资格倒计时。广播分段、规则回看及事件记录按需展开。HUD显示剩余未兑换票；已用尽与尚未发行分别表达。首次开赛和解锁救援后用短提示明确永久死亡风险。

据点角色默认中立，需明确点击“攻击编号”才进入敌对，点击停止恢复中立；武器沿用真实射程、视线和同一个冷却，不同时免费攻击怪物和选手。附近只显示一个目标入口，优先保留当前目标。

电梯终端、设置菜单、失焦、退出都会停止整季推进；恢复不补算离线时间。规则只消费显式种子和tick，墙上时钟不进入模拟。此实现没有 AI 自主决策、真实爬楼或模型调用；名册明确显示“对手控制待接入”。参赛者实体、共同阶段、共享账本与外部执行接口已提供，AI 实验仍在独立项目。

新季写入`f9-survival/9`，保留既有存储键。支持的旧6／7／8存档继续旧语义，不静默转换成金票或永久死亡局；旧黄金回放不改写。新读取器检查产品、规则版本、阶段、几何、身份唯一性、票账本和救援预留，拒绝损坏或错产品数据。

## 验收与边界

浏览器实际操作与自动化证据见[本轮验收记录](./design-log/iterations/F9/2026-10-04-elevator-complete-season-acceptance.md)。逐层5→100自动化使用真实票源、拾取、返程和保存行为；为隔离路线契约，测试固定位置和关闭战斗，不宣称玩家在浏览器手打通关100层。
