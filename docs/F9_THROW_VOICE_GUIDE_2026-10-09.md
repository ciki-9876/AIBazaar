# 《最后一张王牌》文案风格指南：英式幽默

日期：2026-10-09。适用范围：甩牌项目（`apps/throw`）全部玩家可见文字，包括对白、道具名与描述、俏皮话、结果页、引导、任务栏和按钮。

**用户要求**：诙谐、自然、充满英式幽默。

## 1. 什么是这里的「英式幽默」

| 手法 | 意思 | 本作例子 |
|---|---|---|
| **轻描淡写** | 大事说小，坏事说淡 | 「印过最多的一行字是『因雨取消』。」 |
| **礼貌的刻薄** | 用最客气的句式说最毒的话 | 菲利克斯：「真勇敢。我是认真的——非常、非常勇敢。」 |
| **自嘲** | 先笑自己 | 里德：「你就当在跟一只特别有礼貌的乌龟比赛。」 |
| **一本正经的荒诞** | 用陈述事实的语气讲荒唐事 | 「别问闹钟为什么会催牌，魔术就是这样。」 |
| **反高潮** | 铺垫隆重，落点平淡 | 「观众起立了。好吧，是有人去续茶。」 |
| **英国式日常** | 茶、雨、排队、平局、公交、天气 | 「平局：英国人最擅长的结局。」 |

## 2. 硬规则

1. **规则先说清楚，笑话后讲。** 任何玩家必须知道的规则，至少要有一句直说的话。道具卡的第一行永远是可执行的规则文字，俏皮话放在第二行斜体（`quip`）。
2. **文字与代码一致。** 数值、触发条件和道具名，必须和 `throw-loadout.ts`、`throw-duel.ts` 的真实行为一致。改规则时，要同步改对白、提示和规则弹窗。
3. **不嘲笑玩家。** 失败页的笑话对象是失败本身、对手或观众，不是玩家的能力。例如：「观众很有礼貌地假装没看见。」
4. **一句一个笑点。** 不堆梗；三句对白里有一句好笑就够了。
5. **中文要像中文。** 「英式」体现在幽默的手法上，不体现在翻译腔里。少用「哦我的上帝」「该死的」这类直译感叹词。
6. **不使用真实品牌、名人或地名梗。** 茶、雨、公交这些日常物件就足够。

## 3. 人物声音

| 人物 | 声音 | 常用手法 | 避免 |
|---|---|---|---|
| 伊莱 | 简短，嘴不饶人，自信 | 一句话回击 | 长篇抒情、过分谦让 |
| 里德 | 慈祥，絮叨，爱茶 | 自嘲、茶的比喻 | 说教、神秘大师腔 |
| 米娅 | 干脆，机械师思维 | 先吐槽再给干货 | 只提供情报、没有个性 |
| 菲利克斯 | 浮夸，礼貌的刻薄 | 反讽式赞美 | 变成纯粹的恶人或傻瓜 |
| 旁白 | 冷静，像纪录片解说 | 轻描淡写、反高潮 | 煽情 |
| 巴士司机 | 永远在找厕所 | 重复梗 | 抢主线戏 |

## 4. 系统文案

| 位置 | 写法 | 例子 |
|---|---|---|
| 按钮 | 动词，短，可以带一点性格 | 「甩出去」「原样再来一局」「重新整理巡演箱」 |
| 引导 | 先说操作，再加半句笑话 | 「点一张牌，选中它。点哪张都行，第一次嘛，不评分。」 |
| 任务栏 | 标题直说目标，副标题可以开玩笑 | 「赢下第一张参赛证 · 菲利克斯在等你。大概还在照镜子。」 |
| 道具俏皮话 | 一句，说的是道具的「性格」 | 补丁旧伞：「补丁比伞布多。英国天气面前，它从未缺席。」 |
| 结果页 | 每种结果准备两三句，按牌局编号固定挑一句（同一局永远是同一句） | 胜：「对手表示今天风向不对。」 |
| 未开放的内容 | 诚实说明没做，同时开个玩笑 | 「尚未开放 · 司机说快了」 |

## 5. 检查清单

- [ ] 删掉笑话以后，玩家还能读懂规则吗？
- [ ] 数值和代码一致吗？
- [ ] 读出来像人话吗？
- [ ] 这个笑话符合说话人的性格吗？
- [ ] 失败文案有没有在笑玩家？
