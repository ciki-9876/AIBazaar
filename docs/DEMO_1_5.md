# Demo 1.5：物品、基地与战斗操作

顶栏资源只有生命、精力、金币和电力。密封补给、燃料罐、医疗包和废料束成为可堆叠物品，保留数量、容器和位置；旧资源库存转换到仓库，旧字段归零，仅用于存档兼容。补给用于出勤/睡眠，也可恢复 25 精力；医疗包恢复 35 精力。生产设施从实际物品堆叠中消耗材料。金币与电力拾取后直接记入资源。楼层中的物品使用仅允许消耗已携带物品，基地操作可使用仓库物品。

初始提供永久、零槽位的鉴定台，房间有独立入口。旧存档也自动补齐。睡眠成功结算后播放 2.2 秒全屏过场，期间不接受游戏操作，然后显示昨日速报：其他 99 名幸存者的楼层变化、存活状态与行动说明。一天只按一次睡眠操作结算；速报保存在存档中。

天气机制与入口停用。已建观测台移除并退还 8 金币。原天气附加效果改为精制/大师品质效果；遮雨棚改为同路其他存活卡牌护甲 +10/+20。风铃保留全路充能与自身冷却 +1 秒的取舍。楼层保留场景叙事，搜索基础消耗固定为 10（探索整备仍能降低它）。

1/2/3 格卡牌初始复活时间为 6/8/10 秒；本场同一张卡每多死亡一次，增加初始时间的 25%。新战斗重置，强化等级不影响复活时间。卡牌详情只显示初始时间。强化等级格式为 Lv x。

宿主仍共享一条生命，但在上中下三路各有受击点；空路直击沿当前路水平飞行。空间坍缩已屏蔽。测试上限仍为 60 秒，超时暂按宿主剩余生命判胜，界面明确标注；平局/长局方案等待设计确认。

拾取区域左键单击物品自动寻找背包空位，失败不改变物品与库存。背包与上阵区支持双向拖拽，拒绝跨路、重叠、锁定格和空间不足的放置，保留原状态；移除上阵下拉选择。基地构筑界面单击物品在右侧固定详情面板展示鉴定、强化等操作；其他场景继续使用悬停详情。

应用固定在视口内，页面不再纵向滚动。构筑、详情、背包、安全格、仓库、商店和搜查区使用独立滚动容器；战斗棋盘保留内部滚动以维持所有格子的统一尺寸。

验证覆盖旧库存迁移、消耗实际堆叠、睡眠与速报、天气停用与新被动效果、三路宿主目标、按尺寸复活、无坍缩伤害、背包与上阵区往返及错误放置不改变状态。
