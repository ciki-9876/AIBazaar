# Demo 1.4：卡牌生命与幽魂

背包物品固定横向占格，保留拖拽、点击详情和搬运按钮，移除旋转入口与快捷键。旧存档的竖放物品自动重新排布；容器无法容纳的物品转存仓库，不删除物品。

攻击先选择同路最靠前的存活卡牌，经过该牌护甲减伤后扣除卡牌自身生命，不向宿主传递或溢出伤害。目标路没有存活卡牌时直接攻击宿主。特殊选敌描述仍优先。

卡牌生命归零进入幽魂：视为空格，不发动主动或被动效果，不可被选为效果目标；取消以该牌为来源或目标的未命中弹道。幽魂不释放实际编队占位，战斗中不允许重新部署。每张卡显示生命条和幽魂复活倒计时。

当前初始数值（集中配置于 demo-combat.ts，待平衡）：

- 最大生命：四舍五入((40 + 占格数 × 15) × (1 + 稀有度序号 × 0.15) + 强化等级 × 8 + 品质序号 × 10)。序号从 0 开始。
- 复活时间：max(2, 8 − 强化等级 × 0.5) 秒。强化缩短等待，0 级也有基础等待时间。
- 复活恢复满生命，从零重新冷却；新的战斗重新初始化所有卡牌生命。
- 现有治疗与护盾牌仍按描述作用于宿主；以后可单独设计治疗卡牌生命的效果。

回归覆盖：卡牌护甲与独立生命、幽魂禁止发动与受击、幽魂路直击宿主、弹道取消、复活时间与满血重置、旧存档横向迁移及旋转请求拒绝。
