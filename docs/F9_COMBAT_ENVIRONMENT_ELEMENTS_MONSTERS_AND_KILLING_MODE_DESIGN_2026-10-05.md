# F9 电梯环境元素怪物与杀戮模式设计草案

日期：2026-10-05，承接10月4日开始的讨论。读者：游戏策划、战斗研发、关卡、美术与未来AI研发。状态：用户方向已明确，具体机制与数值为待验证方案，未实装。

本稿扩展[挑战环境与道具经济设计](./F9_CHALLENGE_ENVIRONMENT_AND_ITEM_ECONOMY_DESIGN_2026-10-04.md)：用环境决定生存压力，用怪物行为改变走位，用原创元素反应改变清怪形状与配装，再让杀戮模式成为共享据点里的主动风险选择。主循环继续是**采购配装 → 自动战斗与搜刮 → 商品带回变现 → 为下一种挑战调整配装**。

推荐先做四种异质元素、六种两两反应、八种环境原子和一组行为清楚的怪物。技能仍自动释放，玩家主要操作移动、交互和整体策略。反应在常规输出中也能成立，电力用于强化效果；没有电仍能战斗与撤离。所有能力增长来自安装的道具。

## 战斗系统的组成

| 层次 | 回答的问题 | 示例 |
| --- | --- | --- |
| 环境 | 留在这里有什么代价，哪里更安全 | 热区持续损血，冷区可喘息 |
| 空间 | 敌人与攻击能怎样被整理 | 柱后避炮、窄道排队、开阔区聚怪 |
| 怪物行为 | 何时移动，往哪里移动 | 冲锋前锁方向，炮击后留空窗 |
| 伤害类型 | 用什么攻击，能与什么附着组合 | 蚀、振、磁、织 |
| 机制效果 | 命中后怎样改变战况 | 减速、破甲、护盾、吸血 |
| 属性 | 同一机制能发挥多强 | 范围、攻速、抗性、反应强度 |
| 杀戮许可 | 这次攻击能否影响其他参赛者 | 绿灯不伤选手，红灯允许误伤与主动攻击 |

这些是不同维度。例如“蚀伤害”不自动等于中毒；腐蚀喷头可额外附带持续蚀伤，蚀质射钉则可以只造成直接伤害。护盾、破甲和减速也不专属于某种元素。道具把维度组合成可理解的能力，关卡从对应维度选取挑战。

## 环境原子

以下均为候选。环境需要能从地面、机关或怪物表现中读懂；环境强度受楼层预算约束，不能随机把伤害、控制和视野惩罚全部叠满。自然环境对共享据点里的所有选手采用同一规则。

| 原子 | 行为与反馈 | 有优势的配装 | 保留的走位解法 | 组合限制 |
| --- | --- | --- | --- | --- |
| E01 灼热 | 可见热区持续造成热害，离开后停止；少量有预警的喷口可施加短暂灼烧 | 环境防护、有限恢复、吸血、快速清怪 | 借冷区、缩短搜刮路线、分次外勤 | 不与高密度封路同时出现；必经区域热害有上限 |
| E02 蚀液 | 蚀液只在可见池面内造成蚀伤，可短暂附着蚀；池面边缘明确 | 蚀抗、范围清怪、移速 | 绕池、利用踏板与干燥通道 | 不能铺满入口与撤离通道 |
| E03 鸣振脉冲 | 地面环纹先预告，随后一轮振伤；每轮间隔有安全行动窗口 | 振抗、护盾、移速 | 看环纹移动到无脉冲地面 | 与怪物攻击错开，不能连续覆盖全场 |
| E04 磁力带 | 箭头显示牵引方向，轻微改变移动轨迹；不自动造成伤害或附着 | 移速、抗牵引组件、短距武器 | 横向穿越、走无磁通道 | 首版不与硬定身叠加，不移动已掉落金票 |
| E05 纤网地面 | 可见纤网减速，局部网结可打断；持续停留才附着织 | 范围、穿透、移速、抗减速 | 先打网结、走空隙 | 装置数量与掉落固定；不能无尽生成网结 |
| E06 蒸汽遮挡 | 蒸汽块限制视线与远程锁定，敌方也受限制 | 近距范围、护盾、显形类宝物 | 贴掩体转角、引敌出雾 | 不能在不可见处直接锁定炮击；地面危险提示仍可见 |
| E07 分区增效 | 标记区让特定机制更有效，如穿透多命中或强化少耗电 | 对应机制模块 | 把敌群引入区域再打 | 只给优势，不在区外取消基础能力；不免费回电 |
| E08 交替开放 | 两组掩体或通路交替开放，提前闪烁；至少一条撤离路始终可达 | 移速、控制、覆盖多方向 | 预判下一条通路、提前整理敌群 | 不能夹死角色、压住唯一金票或关闭全部返回路线 |

热害是环境伤害子类，灼烧是它的持续效果，均不是第五种可反应元素。磁力带、雾和热区也不会因主题名字自动施加元素；具体配方必须写明是否附着，首版只让E02与E05附着，降低识别负担。

### 灼热房间的具体玩法

推荐普通房间约六成探索面积为热区，其余是分散的冷区和入口缓冲。高价值商品在更深的热区，普通票至少有一处可沿相对安全路线接近。玩家可选择快进快出、多次外勤，或用续航配装换取更长搜刮时间。热区不设死亡倒计时，不要求指定道具才能进入。

原型示例：热区每秒损失2HP，环境防护40%后为1.2HP。满HP100、只计算热害时，40秒停留分别损失80与48；实际还要承担怪物伤害、食水与搜刮时间。这个示例用于解释防护价值，不是通关时长或淘汰限时。

恢复模块示例：实际恢复时每秒修复1.5HP，并额外消耗0.15食物；满血不触发这笔修复消耗。搭配40%防护可抵消示例热害，但会更快用完食物。吸血可以降低战斗损失，却不能补回食水，也不能从尸体、装置或过量伤害刷回复。

冷区停止自然热害，不恢复HP、食水或电力。普通热区不自动叠加灼烧；喷口短暂灼烧与热区按同类最强热害源处理，避免示例伤害暗中翻倍。已经获得的短暂灼烧在剩余持续时间结束后消失，进入电梯也不凭空回血。原型必须验证：使用基础装备沿安全路线仍可拿票和撤离；冷区不能被持续机关和多只封路怪同时堵死。

## 属性与伤害结算

所有可成长属性由装备提供。基础HP和移动速度是运行常量；安装道具能改变上限与效率，卸下后失去增益。商店商品用“范围清群”“耐热续航”“破盾”等作用标签帮助采购，不把大量属性表铺到主界面。

| 属性 | 用途与候选边界 |
| --- | --- |
| 直接伤害 | 提高武器直接命中；与反应伤害分开，避免同一加成重复放大 |
| 攻速与冷却 | 改变输出节奏；最低冷却受武器定义限制，不突破附着与反应频率限制 |
| 范围与目标数 | 改变打击形状；穿透、弹射均有明确次数与视线规则 |
| 防御 | 降低直接物理与异质攻击，收益递减；候选减伤上限60% |
| HP上限 | 增加容错；换装保留绝对当前HP并裁到新上限，增加上限不回血 |
| 移速 | 提高调整位置的效率；建议装备总增幅上限40%，仍受地图碰撞约束 |
| 元素抗性 | 分蚀、振、磁、织；候选总值限制为−30%到70%，不产生完全免疫 |
| 环境防护 | 单独抵消热害等明确环境损耗，候选上限60%；不抵消饥渴 |
| 控制抵抗 | 缩短控制时间或降低强度；首版选手不受反应硬定身与强制拉拽 |
| 反应强度 | 装备提供的反应基值；专用模块以占格换取更强反应 |
| 恢复与吸血 | 对实际损失生效，受食水条件与触发预算约束 |
| 护盾量与恢复条件 | 临时吸收攻击，来源、时效、覆盖范围明确；不吸收饥渴 |
| 电力容量与强化效率 | 延长强化输出预算，沿用电池实体与有限补给方案 |

防御候选公式为 `防御减伤 = min(0.60, 防御 / (防御 + K))`，K由楼层档位统一配置并写入内容版本。物理攻击只经过防御；蚀、振、磁、织攻击再经过对应抗性：`结算伤害 = 原伤害 × (1−防御减伤) × (1−对应抗性)`。例如原伤害100、防御减伤25%、抗性40%，结算为45，再交由护盾与HP承担。

| 来源 | 防御 | 元素抗性 | 环境防护 | 常规护盾 |
| --- | --- | --- | --- | --- |
| 物理攻击 | 生效 | 不参与 | 不参与 | 可吸收 |
| 异质直接攻击或持续伤害 | 生效 | 对应一种生效 | 不参与 | 可吸收 |
| 反应伤害 | 生效 | 使用反应明确的一种伤害类型 | 不参与 | 可吸收，剥盾效果另算 |
| E01自然热害与其灼烧 | 不参与 | 不参与 | 生效 | 不吸收 |
| 饥渴损耗 | 不参与 | 不参与 | 不参与 | 不吸收 |

流程是：先验证阶段、目标、视线和杀戮许可，再确定攻击是否可执行并原子提交消耗与冷却；命中按稳定顺序计算直接伤害、附着与反应事件，最后结算恢复、救援或死亡。攻击因目标不合法失败不能部分扣电或占用库存；已合法发射但被走位躲开的攻击可消耗已承诺的电力。已死亡目标不能用于重复吸血或刷反应。

单次命中使用一份事前快照生成直接伤害和合法反应，杀死附着目标的这一击仍可生成一次反应；目标最终死亡后不再接受后续命中或附着。范围反应中的其他目标逐个检查是否合法。单次命中先计算直接与反应伤害，再执行额外削盾，最后给存活目标更新破甲、控制等状态；新破甲只帮助后续命中，不回算这一击。HP降到0后的救援或死亡沿用现行规则一次执行，不能让同tick多次伤害重复消费救援套装。

持续伤害保留定点精度与余数，按模拟tick累计，不逐帧四舍五入成零。暴击需要指定的命名随机流，效果结算顺序不能依赖浏览器帧率。

## 增益减益与护盾

| 机制 | 建议规则 | 玩家能看见什么 |
| --- | --- | --- |
| 增伤 | 同类百分比相加；不同来源的重复触发有上限 | 武器增强轮廓或短图标 |
| 加速 | 明确移动或攻击加速，持续时间有限 | 速度线或武器节奏变化 |
| 持续伤害 | 同一效果同一来源刷新，不无限叠层；多来源共享目标强度上限 | 对应伤害图标、明显损血节奏 |
| 破甲 | 同类取最强值，刷新持续时间；不把防御减到负数 | 破损甲片 |
| 易伤 | 首版主要用于特定怪物弱点窗口；与破甲分开 | 打开的核心，有限窗口 |
| 减速 | 同类取最强值；玩家与AI选手合并后的减速候选上限25% | 脚下网纹 |
| 拉拽与击退 | 首版作用于普通怪物；精英衰减，BOSS改为积累失衡 | 移动方向线与失衡条 |
| 定身 | 普通怪物短暂停步；BOSS转为失衡贡献；对选手转为轻减速 | 网束轮廓 |
| 护盾 | 同时存在一层；加盾补入现有盾并裁到装备盾上限，延长不能超过定义时限 | HP条外侧细盾条 |
| 吸血 | 按实际造成的HP伤害计算，排除盾伤、过量伤害、尸体、装置、自伤 | 短恢复闪光 |
| 清除减益 | 仅清除道具明确支持的状态；自动触发要有公开条件和冷却 | 清除图标闪一下 |

同类持续伤害采用最强合法来源生效，其余来源只保留各自剩余时间；强源被撤销或到期后，按强度与稳定身份重新选取，不叠加全部来源。同类破甲与减速同样按最强值处理；不同类型的减速合并后仍受选手25%上限限制。

连续控制需要抗性窗口：候选为怪物硬控制结束后1秒不再硬控，可继续受伤；BOSS失衡一次后进入明确恢复期。高频武器不能让怪物永久静止。首版PvP不引入缴械、沉默、硬眩晕、强制位移或无限减速，优先验证自动技能下的可逃离性。环境与怪物的软牵引向量候选不超过自由移速的20%，保留玩家输入，不能在墙角形成无法移动的合力。

自恢复、吸血与护盾不应推翻有限死亡规则：食物或水任意一项归零时，装备自动恢复、吸血和休息回血停止；饥渴损耗穿透常规盾、防御、抗性及短暂攻击无敌。玩家主动使用真实有限补给可以缓解危机，现行药食水救援仍可执行。暂停时一切停止，不能把现实离线时长算作损耗。

攻击治疗与金票奖励分开。PvP造成的伤害首版不提供吸血或击杀回电，避免两名选手互相治疗或轮流攻击套利。刷怪获得的治疗也不能补充食水；召唤、分裂、复活不增发资源预算。

## 原创四元素与附着

采用工业楼宇中的四种“异质元素”：**蚀、振、磁、织**。它们分别表现材料侵蚀、机械共振、磁荷偏转和活性纤维。它们是战斗伤害家族，不要求玩家理解现实化学。每种都能装在近程、远程或范围武器上。

| 元素 | 视觉与图标 | 推荐道具倾向 | 不自动附赠的效果 |
| --- | --- | --- | --- |
| 蚀 | 琥珀色破碎六边形、材料剥落 | 喷头、蚀钉、持续侵蚀组件 | 蚀命中不天然破甲或持续掉血 |
| 振 | 紫色同心波纹、机械震纹 | 波锤、脉冲环、震荡弹 | 振命中不天然眩晕 |
| 磁 | 青色成对磁极、金属轨迹 | 磁钉、牵引器、偏转组件 | 磁命中不天然聚怪或耗电 |
| 织 | 米白交错网格、纤维束 | 纤刃、织网喷头、缠绕组件 | 织命中不天然定身或中毒 |

色彩只是辅助，图标与形状必须能区分。绿灯和红灯只表达杀戮状态，元素特效不得遮住头灯。

推荐首版附着规则简单且对称：

1. 一个目标只持有一种有效附着，候选持续3秒；附着本身只给反应准备，不造成额外伤害。
2. 武器显式标记哪些命中能附着。单一武器对同一目标候选最多每0.5秒附着一次；多段命中与暴击不增加附着次数。
3. 相同元素只刷新时间；另一种元素命中触发对应反应，消耗双方附着。两种顺序得到同一种反应，不做正反向倍率表。
4. 反应后目标进入候选1秒反应冷却，期间直接伤害正常，任何新附着暂不写入；结束后重新建立附着。这一目标上限限制多武器反应风暴。
5. 物理命中不清掉附着；反应伤害、反应地面与反应传递不再附着，也不再次触发反应。
6. 常规技能就能附着与反应。电力只强化范围、命中数量、伤害或明确效果，沿用同一频率上限，不为每次反应追加不可控扣电。

合法命中被护盾吸收仍可附着和反应；被墙体挡住、阶段禁止或杀戮许可失败的命中不能附着。元素抗性只调对应伤害，控制抵抗另调控制，二者不互相代替。

没有元素轮盘、手动连招或切人。玩家通过配两种互补武器和选择接敌距离自然形成反应；首次入门只讲“两种异质命中会组合”，完整配方表在图鉴按需查看。纯物理配装应以更高直接输出、穿透或耐久形成可行路线；单元素依靠武器机制也能通关普通挑战。

反应基值F取第二元素触发者**当前安装道具提供的反应强度**。角色固有F为0，元素武器可自带少量F，反应放大器占装备格提高F。反应不吃原始命中的暴击倍率，不混合不同选手的属性。反应伤害使用表中明确的元素，并正常经过防御与抗性；机制效果另按抗性与控制限制裁决。

## 六种元素反应

数值仅用于原型比较，半径均为世界距离，不能按屏幕像素硬编码。R01–R06对两个元素的先后顺序对称，控制与破甲不无限叠加。

| 反应 | 组合 | 候选效果 | 战斗价值 | 对选手的调整 |
| --- | --- | --- | --- | --- |
| R01 碎甲 | 蚀＋振 | 主目标防御降低30%持续3秒；周围小范围一次0.6F振伤 | 拆装甲前排并波及密集敌群 | 允许有限破甲与伤害，不追加眩晕 |
| R02 剥盾 | 蚀＋磁 | 一次0.8F蚀伤，另削减主目标1.2F当前护盾；无盾时仍有直接伤害 | 破解有限盾，保留打无盾怪的用途 | 可削盾，不偷走盾、不把削盾量转成吸血 |
| R03 蚀网 | 蚀＋织 | 主目标脚下生成2秒小网区，总计0.8F蚀伤与20%减速 | 让追兵在固定区域停留，便于范围武器持续清群 | 合并后减速不超过25%；不封门、不叠多层地面 |
| R04 回震 | 振＋磁 | 小范围向中心短拉一次，随后一次0.8F振伤 | 把散开的普通怪物整理成一团 | 保留伤害，把拉拽替换为15%减速1秒 |
| R05 传响 | 振＋织 | 从主目标向最多3个可见近邻传递，各造成0.45F振伤；主目标不吃额外传递 | 沿敌群连接清理后排，强调敌群间距 | 每名选手最多吃一次传递，禁止重复弹回 |
| R06 缚牢 | 磁＋织 | 主目标及小范围普通怪物定身0.8秒，并一次0.5F织伤 | 整理冲锋节奏，创造搜刮或撤离窗口 | 定身替换为20%减速0.8秒；不打断返程规则 |

R01的小范围伤害包含主目标，但每目标只一次；R04与R06同样单次命中。R03的总伤害分摊到持续tick，同一施法者同位置网区只刷新，不叠层；多个施法者的网区采用目标共享的强度上限。R05沿每段实际视线传播，不能穿过实心墙把不可见选手当作跳板。

效果的区别是拆甲、削盾、留场、聚怪、传递与短控，不能只把六种反应做成六个不同颜色的伤害倍率。各有适用战况，例如传响需要附近存在其他目标；房间保留通用打法，不要求每层都使用反应。

PvE示例：蚀喷头先留下蚀附着，磁钉随后命中有盾怪。若F=20，剥盾产生16蚀伤与24额外削盾。先对16进行减伤与常规护盾吸收，剩余护盾再减去最多24；额外削盾不穿透到HP，且不触发吸血。换成无盾目标时只有结算后的16蚀伤，不把24改成白送HP伤害。

怪物附着、自然环境附着也可成为反应起点。玩家触发时看玩家F，怪物触发时看怪物定义中的反应基值。多人共同造成的反应按触发者归属，但其影响其他选手的许可需要保留全部直接来源，详见杀戮模式；自然附着不能成为绕过绿灯的借口。

## 怪物行为目录

怪物以“观察 → 接近或占位 → 预警 → 执行 → 恢复”组成状态机。预警一旦锁定方向或落点，本次执行不再追踪修正；目标离开视线时只使用最后可见位置或取消，不能读取玩家未来路线。下面预警时长是原型值，实际还需考虑移动速度、房间宽度与多人场景。

| 怪物 | 行动与明确空窗 | 改变的走位 | 有优势的配装 |
| --- | --- | --- | --- |
| M01 拥挤工 | 普通近战，接近后抬臂再攻击；是主要割草敌群 | 保持移动，把敌群排成队 | 范围、穿透、耐久 |
| M02 疾行犬 | 两秒疾行接近，短暂停步后再扑咬；出现时不直接命中 | 提前转向，利用停步拉开距离 | 减速、短距范围、移速 |
| M03 轨道冲锋者 | 约0.8秒显示直线并锁方向，冲锋后有恢复期 | 横移避线，诱导撞柱 | 控制、单体、缚牢 |
| M04 退射工 | 在有限活动范围内后退，停步瞄准再射直线弹；退路受碰撞限制 | 借掩体接近，把它逼向边缘 | 远程、穿透、移速 |
| M05 标线炮手 | 约1秒标记地面快照，落弹后长装填；不在雾后锁人 | 离开标记，趁装填穿过开阔地 | 护盾、远程、爆发 |
| M06 背盾搬运者 | 正面有限盾，转身慢；盾破后普通近战 | 绕侧面、引它背向其他怪群 | 剥盾、穿透、侧向覆盖 |
| M07 换位甲壳 | 合甲时减伤，攻击后约2秒打开核心；合甲不完全免伤 | 贴近诱发攻击，绕身留在开核范围 | 单体、攻速、续航 |
| M08 增幅领班 | 有限半径增伤光环，离圈失效；自身动作慢 | 引杂兵离圈，优先接近领班 | 传响、范围、优先目标模块 |
| M09 修复囊 | 可见充能后治疗同伴；每只囊有固定治疗总量，耗尽后只留弱攻击 | 趁充能接近，减少拖战 | 单体、传响、范围 |
| M10 绞网虫 | 抛出可见网弹，命中才减速；地面残网短暂可破 | 避弹、留意脚下退路 | 控制抵抗、范围、织系配装 |
| M11 牵引钉塔 | 在可见标定区制造短时磁力拖慢，场外无效；发动后有熄灯空窗 | 横穿区域、借空窗绕后 | 控制抵抗、移速、单体 |
| M12 分裂瘤 | 死亡后分为两只小子体，子体不再分裂；家族共享掉落预算 | 给分裂后敌群留空间，再集中清除 | 范围、蚀网、回震 |
| M13 残液囊 | 死前约0.7秒膨胀，留下短时小蚀液池，造成蚀伤而不附着；池面边界可见 | 杀完继续走，避开尸体位置 | 远程、蚀抗、移速 |
| M14 追猎者 | 锁定一个可见目标约4秒，亮出指向；失去视线后搜索旧位置 | 借柱断视线、与群怪拉开 | 单体、护盾、减速 |

背盾不要求元素破盾，正面持续攻击和绕背也能解决。合甲怪靠时机提供效率优势，不能让普通武器完全打不动。修复囊不能互相无尽回满；其治疗总量在生成时固定。M12的子体、M13的池和所有召唤物都有固定数量、寿命及家族资源预算，重进房间不刷新。

M14按当前可见威胁或可见搜刮行为选目标，同分按稳定身份排序；人类和AI遵守同一准则。M11的拖慢保留行走控制，不能强行把参赛者瞬移到危险区。M13若由选手的攻击直接触发，后续对其他选手的影响继承该攻击的杀戮许可；怪物自主释放的池按自然敌对伤害处理，来源类型必须分别建模。

### 保住割草比例

普通敌群建议占每波约70%–80%，剩余名额分配给一到两种特殊行为。此比例只是切片起点，不能把十几种怪物一次塞入同层。特殊怪物改变“如何清群”，杂兵负责提供连续消灭的反馈。

怪物压力分开预算：身体拥挤、追击速度、远程落点、控制区域、治疗拖战。导演限制同一局部区域同时激活的高危预警，例如最多两次；已经给出的预警必须兑现，尚未预警的怪物可以延后出手。敌人数增加时不同比例增加追踪弹、陷阱和硬控制。

禁止组合示例：连续封路加高速冲锋加全场热害；网减速覆盖唯一返回路同时炮击；两个无限治疗来源互保；分裂后继续分裂；靠元素免疫逼玩家购买唯一特定道具。

### BOSS的行为组合

| BOSS候选 | 三个主要行为 | 走位与配装选择 |
| --- | --- | --- |
| 锅炉守门人 | 提前亮起的扇形排热、短距离冲撞、开阀后核心暴露 | 沿冷区走位，选择环境防护续航或抓开阀窗口的单体输出 |
| 轨道调度者 | 锁线冲锋、有限数量的远程岗位、冲锋结束后短暂失衡 | 诱导撞柱，先拆炮手；选择远程拆点或控制整理杂兵 |
| 织巢监工 | 有限网结、可见地面缠绕、收网后的弱点窗口 | 打断网结留退路，选择范围清点或穿透打本体 |

BOSS根据距离、视线和已有技能占用选择下一个合法行为，使用显式种子与tick；不读取玩家按键预测，不临时生成一招专门克制当前装备。攻击数量有限、状态可观察，机制不能覆盖胜负与掉落条件。以上是后续BOSS目录，不替换已实现第三层守卫与首票结算。

## 配装流派与采购动机

不增加职业树。下表是道具组合方向，同一武器仍可加入不同混合配装。首版商店应保证基础反制道具有可预期的购买机会，稀缺宝物强化风格，不作为通关的唯一钥匙。

| 配装方向 | 主要道具结构 | 优势环境 | 代价与弱点 |
| --- | --- | --- | --- |
| 耐热回收 | 环境防护、食物驱动恢复、范围武器 | 灼热与高价值深区商品 | 占用输出格，食物消耗较快 |
| 碎甲推进 | 蚀＋振武器、单体或穿透模块 | 装甲前排与密集护卫 | 对散开的远程敌群需要主动接近 |
| 剥盾猎手 | 蚀＋磁武器、优先目标组件 | 有限盾与弱点精英 | 没有盾时专门削盾部分收益较低 |
| 聚群收割 | 振＋磁武器、近距范围模块 | 开阔群怪、散开的杂兵 | 普通怪物聚拢后会形成近身压力，需留撤离方向 |
| 留场牵制 | 蚀＋织武器、持续范围模块 | 追击敌群、长通道 | 固定地面覆盖对退射怪不稳定 |
| 传响清线 | 振＋织武器、射程与目标数 | 连续敌群、后排支援 | 敌人之间距离过大时传递价值下降 |
| 缚牢搜刮 | 磁＋织武器、短距覆盖与移速 | 冲锋群、危险物资点 | 对BOSS主要提供失衡，直接输出较少 |
| 物理实干 | 高直接伤害、穿透、耐久或移速 | 一般私人房间、资源紧张期 | 缺少反应的聚怪和破盾效率，需要更多走位 |

反应装备应能替换一到两个格位就形成新解法。换一层环境不应要求推翻全部十格装备；强化输出、续航、范围和反应之间的格位竞争才是采购选择。

新增怪物仍主要掉落现有有限成长物、商品来源或明确票源，不把高阶功能武器变成普通怪海的主要掉落。商品仍无战斗功能；宝物少量投放，绝大部分能力选择由商店完成。本文不再新增装备币、元素等级或反应经验。

## 楼层组合与百层节奏

普通房间采用**一个主挑战＋一个辅助挑战＋最多一个环境条件**，空间模板保持可识别；原稿“可见危险最多三项”继续成立。新环境占用其中一个条件名额，不能在原三项之外免费叠加。BOSS三种动作是一个行为套件，但其预警同时占用局部危险预算。

示例配方均为后续内容候选：

| 房间 | 组合 | 玩家实际选择 | 商品与通行布局 |
| --- | --- | --- | --- |
| 12F 锅炉库 | A01密集群＋A14深区商品＋E01热区；M01为主、少量M02 | 穿防护慢搜，或快速清怪直接拿票 | 安全路线接普通票，深区放高价值大件 |
| 16F 转运库 | A03有限盾＋A10柱墙；M06与少量M04；无全场环境 | 采购剥盾，或绕柱打背面 | 普通商品在外圈，远程岗位旁为高价物 |
| 20F 据点 | A01群怪＋A06支援＋E03脉冲；所有选手使用同一房间 | 先拆支援还是抢金票，是否开红灯争夺 | 金票分散，避开必定伤害区；个人返梯路线可达 |

据点场景继续比普通房间可行走面积大50%，金票仍按N−X规则发行。环境和怪物不能增加金票、改变持票上限或预定谁先到。仅拾取金票仍不算晋级。

内容推进建议：

| 赛段 | 新知与已有规则组合 |
| --- | --- |
| 1–4F | 保留现行引导与安全广播；只用小演示说明绿灯和红灯，不允许杀戮 |
| 5–9F | 常规商品、基础自动武器、两种元素；先看一次明确两元素反应 |
| 10–29F | 据点杀戮规则首次生效；逐步出现热区、有限盾、冲锋与远程 |
| 30–59F | 补全四元素和六反应，把已见行为组合；出现少量特殊宝物 |
| 60–89F | 提高敌群与资源压力，轮换主挑战，避免连续同配方 |
| 90–100F | 已有机制综合检验，提供终局整备机会；100F保留唯一终局票 |

100层是空间与竞速进程，不要求每名玩家逐层清完100个房间；电梯跨度选择本来就允许略过普通层。生成时控制同一赛段的主挑战轮换、关键能力的检验机会和可绕开的路线。预测楼层条件须来自已生成的确定内容，不靠反复选层重抽；共享据点内容对所有选手一致。

## 杀戮模式的基本规则

把“其他角色”落实为**其他参赛者，包括人类玩家与AI选手**。怪物始终是合法战斗对象；准备房间的NPC、自己、自己的召唤物和个人电梯不列入选手攻击目标。未来若加入非选手NPC，必须另定规则，不从这个开关自动推导可杀。

核心解释：**模式控制自己的对外伤害许可。绿灯表示自己不会伤害其他选手；红灯选手仍能攻击绿灯选手。** 绿灯承诺行为，不能提供免伤或消除已经来自他人的威胁。默认关闭，玩家需要主动开启；受击后不自动开红灯。

| 攻击者 | 目标 | 对其他选手能否造成伤害或负面效果 |
| --- | --- | --- |
| 绿灯 | 绿灯选手 | 否 |
| 绿灯 | 红灯选手 | 否；需要主动开杀戮才能还击 |
| 红灯且激活完成 | 绿灯选手 | 是，满足范围、视线和阶段规则时 |
| 红灯且激活完成 | 红灯选手 | 是，满足同样条件时 |
| 任意选手 | 普通怪物 | 正常PvE，独立于杀戮开关 |
| 任意选手 | 4F选手或已合法进入自己电梯的选手 | 否，阶段或保护判定优先 |
| 怪物与自然环境 | 房间内选手 | 正常敌对或自然损耗，不看受害者灯色 |

关闭时也禁止对选手附着、减速、破甲、削盾、拉拽、标记或窃取电力，防止“没有伤害但无法行动”的变相攻击。首版不提供对其他选手的自动治疗与加盾，也不设永久阵营；所有参赛者独立竞争。

### 快捷键与模式状态

建议默认K键，允许重绑；现有输入处理已使用E交互、F电梯终端、B外勤终端，所核对处理器中K未被占用。桌面显示一个小灯按钮与K提示，移动端用同一灯按钮，不弹确认窗。

候选状态机为：

1. 新季或首次建立角色状态默认关闭，头顶稳定绿灯；已有新版本存档按保存状态恢复。
2. 共享战斗房间按K，立即切成红灯闪烁并发一次可听见的启动声，经过0.6秒模拟时间后激活；闪烁阶段仍不能伤选手。
3. 已激活时按K立即关闭，绿灯恢复；闪烁阶段按K可取消。
4. 再次开启仍需要完整启动期。持续按住只触发一次，忽略键盘重复事件。
5. 4F、私人房间、自己的电梯、转场、永久死亡与赛季结束不允许激活。成功进入这些状态会清除对选手攻击许可。
6. 暂停、菜单、终端、输入框聚焦或窗口失焦时不接受切换；启动进度与其他行动一同冻结。退出重进恢复所保存状态和剩余启动tick，不靠现实时间自动激活。

K、0.6秒和具体图标是建议；默认关、绿红灯与AI同能力来自用户。启动提示的设计目的，是让自动范围攻击的敌对意图在第一下伤害前可见。

开启后，其他选手加入所有自动武器的合法目标集合。选择目标可优先“明确焦点 → 正在威胁自己的可见红灯选手 → 武器定义下最近合法目标”，同分按稳定身份；关闭时完全排除其他选手。现有点选敌对目标可改为焦点优先功能，不能作为某些武器偷偷绕过开关的独立许可。

范围、穿透、弹射和持续场按实际命中范围伤害其他选手，选定某人不保护其他人。仍使用同一次武器发动、冷却和电力预算，不额外生成一份对人的免费攻击。关模式时，其他选手不消耗攻击的穿透或弹射次数，不成为敌对传播的跳板。

### 残留弹道与伤害归属

建议为每次有效开启建立一个递增的杀戮授权代号。攻击记录“施法者、创建tick、当时是否可伤选手、授权代号、伤害来源”。每次命中选手都重新核对许可，而不是只在发射时检查一次。

对选手命中需要同时成立：攻击创建时已激活、施法者现在仍激活且代号相同、目标处于共享战斗区且不受保护。关闭会撤销该代号；再开启使用新代号。旧攻击不能因再开红灯复活权限。

| 情形 | 推荐结算 |
| --- | --- |
| 绿灯发弹，飞行中开红灯 | 旧弹不能伤选手，仍能打怪 |
| 红灯发弹，命中前关模式 | 旧弹不再伤选手，仍能打怪 |
| 红灯范围场已落地，随后关闭 | 对选手的持续伤害、负面效果与附着立即撤销；对怪物可按原寿命持续 |
| 关闭后很快重新开启 | 旧代号无效，只有新授权下发动的攻击能伤选手 |
| 受害者从红灯转为绿灯 | 不改变他人的攻击许可，仍可被合法红灯攻击 |
| 攻击者进入电梯、被救援或死亡 | 撤销对选手许可，清除旧攻击对选手的残留影响；复出默认关闭 |
| 受害者合法进入自己电梯 | 房间攻击与敌对持续效果不再作用于该角色；饥渴与真实救援规则保持 |

玩家攻击直接引爆的桶、直接触发的亡语爆炸、反射、召唤物和反应均沿直接生成链保留许可，不能改挂“环境”标签洗掉来源。由多个选手共同生成的反应，伤害归属第二元素触发者，影响选手需所有直接参与的选手来源均有创建时授权且目前代号有效；自然元素来源不附加选手授权。任一来源不成立时仅禁止该派生效果影响选手，打怪效果继续。

怪物自主发动的攻击、自然周期热区和脉冲保持怪物或世界来源。怪物因被挑衅而自主选择攻击仍是怪物攻击；“自主发动”与“命中直接引爆”必须分别定义，不能沿所有间接因果无限追溯。首版先限制可引爆物种类，使边界可测试。

关闭杀戮不清除其他选手在自己身上造成的效果。自己的附着撤销时保留其他合法来源的附着或效果，不能用全目标清空来干扰他人。绿色玩家身上来自自然环境的附着仍可能被红灯对手合法触发反应。

### 据点争夺与返梯

杀戮只在共享据点战斗区以及100F共享终局房间有对选手的实际意义。私人房间继续各玩各的，准备房间保持安全。每次进入共享房间从关闭开始，不继承上一个据点的红灯。

杀戮不会增加金票总数或恢复被兑换的票。拿到多张票的选手仍必须扔下多余票才能合法进自己的电梯；灯色不改变门禁。返梯保护在**合法进入成功提交后**生效，带着多张票站到门口仍处于外勤区域。其他选手不能进入别人的个人电梯获得保护。

开启杀戮可以用来夺取位置、阻止对手搜刮或抢夺未兑换的票，也会令自己的自动范围攻击误伤路过的人。击倒走真实有限救援规则，救援会掉下背包与未兑换金票；永久死亡掉落也沿现行规则。首版不新增“击杀奖励票”“杀人回满”或计时注销。

主动关闭既可减少误伤，也会立即放弃残留技能对选手的输出。成功返回自己的电梯会自动关模式，不能在受保护状态继续向外放人身伤害。出门再次开红灯要重新预警。

### AI的使用规则

AI可以提出开启、关闭、选焦点、移动、拾取与扔下意图；规则执行器按与人类同样的灯态、启动期、攻击、电力与返程约束裁决。AI不具备瞬间免前摇开杀、额外攻击、免费资源或跳过单票门禁的能力。

策略可因当前威胁、已看见的金票、生命与补给、可见对手距离、近期被攻击记录改变。默认关闭；是否为护票或夺票主动开启由角色策略决定。看到别人红灯可以先绕路或撤离，不自动复制红灯状态。受伤必须先识别可见来源，不能通过后台身份读取未见敌人位置。

需要保存并暴露到AI观察：可见选手灯态与启动进度、自己模式、可见敌对来源、金票持有的可观察线索、返程距离与保护区。过往攻击记录只来自实际目击或受击，不凭空给全体AI同步仇恨。社交声誉机制可另立提案，本稿不把“所有人围攻红灯”作为固定惩罚。

| 元素附着 | 目标头顶一枚形状图标和小时间环 | 当前元素说明 |
| 反应 | 明确特效与一次短名称，如“剥盾” | 六格反应表 |

| 失败原因 | 最近主要伤害来源与短原因 | 来源链及真实救援消耗 |

红灯增加尖角外环，绿灯保持圆点，闪烁阶段用进度环，兼顾不只靠颜色的识别。红灯、危险地面和金票的视觉层级高于武器粒子，不能被特效淹没。禁止常驻完整反应表、长段环境说明、逐条属性计算与连续弹窗教学。

4F广播只补一段短演示：绿灯角色射击不影响同伴，红灯启动后范围攻击会命中旁人；被攻击者关灯仍不免伤。完整规则放在可主动查看的终端，不能让玩家在实时争夺时阅读说明书。

## 数据模型与确定性要求

| 定义或状态 | 必须记录的内容 |
| --- | --- |
| 挑战原子 | 稳定ID、触发、效果类型、强度、时长、范围、计费和掉落预算、不兼容标签 |
| 伤害包 | 稳定事件ID、来源实体与动作、直接父来源、伤害家族、基础量、可附着标记、目标、tick、授权代号 |
| 附着 | 元素、来源、建立与到期tick、当前源授权；同目标有效附着唯一 |
| 反应 | 反应ID、两元素、明确伤害家族、系数、效果上限、有效范围、触发者、直接父来源、禁止再附着标记 |
| 效果实例 | 来源、目标、剩余tick、叠加组、强度、撤销条件、生命周期与派生授权 |
| 怪物 | 稳定身份与家族、行为阶段、锁定目标与落点、剩余tick、技能与治疗预算、掉落预算 |
| 杀戮状态 | 关闭或启动或激活、授权代号、剩余启动tick、模式切换事件 |
| 已安装能力 | 实体道具UID、装备位置、属性编译结果、弹道与冷却相位、电池能量 |
| 房间 | 冻结配方、装置和地面状态、敌群预算、已消耗来源、物品与票账本 |

种子、内容版本和模拟tick显式传入。新怪物与反应使用独立命名随机流，不推进旧规则的RNG；每tick按稳定事件顺序结算。任何伤害来源都可回溯到实际攻击与模式状态，显示文本不决定行为。

关模式、入梯、救援、死亡与效果撤销在同一次状态更新中完成，不能出现绿灯已显示但下一帧仍能伤人的空窗。模式切换意图在当tick攻击判定前统一处理，合法进入保护区的结果在碰撞命中前统一提交；动作之间的物品、票、电力与库存变更仍保持原子性。

换装备只改变未来能力与合法数值上限，不能重置既有冷却、补满电池、恢复HP或复制持续场。解除道具产生的有条件buff需要明确依赖关系；已发射攻击保留技能快照，但伤害许可始终实时核对。

## 第一轮开发切片与验收

建议先验证一组能覆盖循环的内容，再铺开百层：

| 首轮范围 | 内容 |
| --- | --- |
| 环境 | E01灼热、E02蚀液、E03脉冲；各有可达安全路线 |
| 元素 | 四元素的基础常规武器与六反应，均不依赖剩余电力 |
| 怪物 | M01基础、M03冲锋、M05炮手、M06背盾、M08支援、M10网虫 |
| 配装 | 耐热恢复、范围清群、反应放大等少量模块，接上候选个人商店 |
| PvP | 人类操作与可脚本控制的测试选手共用杀戮状态机、灯与真实伤害 |
| 关卡 | 两个私人原型房间、一个共享据点，不改现行v9存档 |

后续再加入其他环境、治疗怪、分裂、亡语场与复杂BOSS，优先验证多人来源链后再放入共享据点。脚本测试选手只用于验证规则，不代表未来AI策略已完成。

### 必须通过的功能场景

1. 六个无序元素组合各对应唯一反应；正反顺序相同，同元素不反应；冷却与到期tick保存恢复一致。
2. 无电时仍可自动攻击、附着与反应；非法目标不扣电，合法发射后的躲避不退款；反应不产生递归爆炸。
3. 热区伤害、防护、冷区停伤与有限恢复符合示例；食水归零不能用恢复、吸血或盾无限续命。
4. 换装不回血、不回电、不刷新冷却；吸血只计真实允许的PvE HP伤害。
5. 绿对绿、绿对红不伤人也不附着或控制；红对绿与红对红遵守同样射程、视线和阶段规则。
6. 启动前不伤人；关灯立刻撤销自己的残留人身伤害；旧弹不因重新开启恢复许可；受害者关灯仍可被攻击。
7. 桶、反射、召唤物、跨选手附着与反应传播不能洗掉来源；每个范围目标分别核对许可与保护。
8. 多金票返梯失败时没有保护、票或库存的部分提交；合法返梯撤销对人攻击，个人保护不被借用。
9. 救援一次消费完整真实套装并撤销模式，重复命中不重复消费；金票守恒、100F返程获胜保持。
10. 怪物预警后不追踪修正，分裂与治疗来源有限；重进、暂停、退出恢复不生成新物资与离线进度。
11. 固定种子与相同输入事件重放一致；同tick开关模式、命中和进梯有唯一可重复结果。
12. AI测试意图不能跳过启动、费用、目标权限与金票门禁，正式与实验项目边界保持。

### 体验与平衡待验证

要观察：不读长说明能否识别危险；基础配装是否有可行走位解法；两套不同配装能否在不同环境各有明显优势；一次换一到两格是否足以改变解法；热害是否促进路线与采购而非只增加等待；控制后是否仍能移动撤离；反应特效是否遮挡灯和预警。

PvP伤害比例建议独立配置，不直接沿用完整PvE伤害。原型可从统一0.6倍选手伤害开始，对直接、持续与反应伤害共同生效，额外削盾也乘同系数；再用同档配装满血对打检验约4–8秒的接敌容错目标。这是调参起点，不保证任何满血选手都可存活固定时间。怪物伤害、自然环境与食水损耗不乘该系数。

需要比较红灯收益、被误伤比例、逃离成功率、最后金票的争夺时长、救援消耗和弱势选手的可行动性。若胜法集中为入口红灯范围秒杀，先调整预警、伤害、覆盖与通路；不要靠给绿灯永久免伤补救。若每层都必须凑同一反应，优先调整敌群与道具效率，保留纯物理与混合路线。

本轮仅完成设计与规则边界核对，没有运行战斗原型、数值模拟、玩家试玩、npm测试、AI训练或部署。八环境、六反应和十四怪物是内容目录，不是已经验证的体验成绩。
