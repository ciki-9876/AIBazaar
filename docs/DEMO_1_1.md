# Demo 搜查、交易与战斗表现迭代

## 已实现

1. 本地种子生成不再仅替换楼层名称。路线有不同长度、组合和顺序；主题决定场景名称；事件代价、机关题型、商品及守卫身份变化。尚未接入大模型。
2. 搜查只扣费一次并停留当前节点。拾取后物品立即进入右侧背包，只有点击“前往下个目的地”才结束搜查。
3. 交易同屏展示商品、背包和保险空间；支持转移、鉴定、装备、卸下、丢弃和出售。购买先验证容量再扣材料；商品售罄状态保存。
4. 直线拖尾弹道以卡牌中心为起点，以目标卡牌或宿主中心为终点，跟随暂停和播放速度。伤害红、治疗绿、护甲/护盾黄；灼烧橙、毒素墨绿、冰冻淡蓝已预留映射，当前卡池尚未加入这三类新机制。
5. 稀有度以灰、蓝、黄、暗金、红底色呈现；“异常”改称“传说”。品质以边框区分，强化等级位于左上角。护甲位于朝向敌人的一侧，冷却使用整卡蒙层，数值效果位于底部，特殊描述居中。
6. 幸存者遭遇与楼层守卫分别显示身份及第几场战斗；击败幸存者后明确提示还有守卫，玩家主动开始下一场。

## 存档与验证

旧存档可继续。未被玩家访问的旧楼层在进入时升级路线；已访问楼层保留原路线，避免改变进行中的挑战。新开局可完整体验新生成内容。

自动化覆盖 67 项：搜查状态保持、物品转移、满包交易原子性、售罄保存、旧档兼容、路线变化、实际战斗目标、连续两场战斗与多个种子的十层完整流程。另执行类型检查、静态检查、生产构建和 HTTP 检查；未执行浏览器交互或视觉验收。

第 8 项跳层失败困境暂未改变规则，方案见 FLOOR_RECOVERY_OPTIONS.md。
