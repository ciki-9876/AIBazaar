# 《最后一张王牌》第二、三幕细化：时间与玩法

- 日期：2026-10-11
- 状态：**设计稿，等用户确认后再落地**。

## 0. 一句话

**每座城市一本日程本，每座城市一组专属玩法。**

- **时间**：所有事件都写在日历上，有日期、时段和截止。人有作息，店有营业时间，错过就是错过。世界不会等你，但也不会让你卡关。
- **玩法**：
  - 布里奇波特的故事是「赢得观众」，所以新玩法是**街头表演**和**招徕观众**；
  - 韦斯特港的故事是「情报战」，所以新玩法是**观察**、**推理**和**放假消息**。

  甩牌对决仍然是高潮，但不再是唯一推进剧情的方式。

## 第一部分 · 时间：日程本

### 1.1 现在的问题

- 日程已经有了（上午、下午、晚上，周日结账），但只是一个计数器。
- 主线比赛没有日期，随时可以打；事件也没有时间窗口。
- 玩家无法「错过」任何东西，所以时间不重要。

### 1.2 规则

| 规则 | 内容 |
|---|---|
| **日历上的事件** | 每个事件都有**日期 + 时段**，或者一个**时间窗口**（例如「第 2 周周二到周四的晚上」） |
| **固定日期的主线** | 主线比赛排在固定的日期，例如布里奇波特公开赛：早场在第 1 周周四，小组赛在第 2 周周二、四、六晚上，决赛在第 3 周周四晚上 |
| **人有作息** | 每个有名字的人，在不同的时段待在不同的地方。例如朱诺：上午在桥头，下午在集市，晚上在醉鹅。约人就要去对的地方、在对的时间 |
| **店有营业时间** | 霍布斯旧货铺只在下午开；报刊亭只在上午开；周四剧院只在周四开 |
| **约会** | 有人约你：「周五下午来厨房」。答应了，就写进日程本。两件事撞在同一个时段，只能选一件 |
| **截止和后果** | 错过的事不会让游戏卡住，但会改变结果。比如没去园艺展，艾格尼丝会生气，她的情报变贵；没赶上决赛前夜朱诺的约，她入团时的第一句话就不一样 |
| **主线不会被错过** | 主线比赛如果错过了日期，就顺延到下一个比赛日，代价是名气和一周的房租。只有支线和节庆真的会过期 |
| **时间压力来自故事** | 每座城市都有一个看得见的倒计时：布里奇波特是「剧院在本季结束后出售」，韦斯特港是「海边档期最后一晚」 |

### 1.3 日程本（界面）

一本皮面日程本，是这座城市所有事情的入口：

- **周视图**：七天 × 三个时段。已经答应的约会、比赛、节庆都写在格子里；撞车的格子用红笔圈出来。
- **人物作息**：认识的人，各时段会在哪里（第一次见面后解锁，打听可以提前解锁）。
- **待办**：报纸、信件、对白里提到的事，都会自动记成一行：「周四晚 · 公开赛早场 · 周四剧院」。
- **倒计时**：这座城市的大日子还有几天。
- **地图联动**：在街上，正在营业的店亮灯；当前时段有约的地方有标记。

### 1.4 一天的节奏

| 时段 | 典型的事 | 光线 |
|---|---|---|
| 上午 | 报刊亭、市场、晨练、办事 | 冷光，雾 |
| 下午 | 街头表演、下午茶、店铺、调查 | 暖光 |
| 晚上 | 比赛、酒馆、约会、密会 | 灯光，夜色 |

- **在街上走动不花时间**；进行一项活动、赴约、比赛才花一个时段。
- 「歇一会」保留，但只跳到下一个时段。

## 第二部分 · 新玩法

### 2.1 通用：所有城市都有

| 玩法 | 是什么 | 用到的已有系统 | 推进什么 |
|---|---|---|---|
| **日程本**（1.3） | 安排时间 | 时钟、周日结账 | 所有线 |
| **打听** | 和人聊天，有对话选项。问对人、问对时间才有用 | 对白、好感 | 情报、镇志 |
| **线索板** | 打听来的传闻贴在一块软木板上，用红线把相关的连起来。连对了，故事推进一步 | 传闻（已实装） | C 线、情报 |
| **差事** | 帮人做一件事，有时间限制 | 对白、时段 | 好感、钱 |

### 2.2 布里奇波特专属：赢得观众

城市主题是**爬梯子**：从三个观众到全场爆满。玩法要让玩家**亲手把观众一个个拉过来**。

#### 街头表演（新玩法，不是对决）

在街角表演魔术，用手牌满足路人的点单：

| 要素 | 内容 |
|---|---|
| 规则 | 路人陆续走来，每人头上一个气泡，写着他想看的东西：「一张红心」「一对」「比 10 大的牌」「三张同花色」 |
| 操作 | 从手牌里打出符合要求的牌，就是完成他的点单。手牌按现有的发牌轮补充 |
| 观众 | 完成一个点单，这个人就留下来，人群变大；人群越大，来的路人越多，点单也越难（「同花顺！」）。等太久的人会走 |
| 收益 | 打赏（钱）、名气、偶尔有「特别观众」（剧情人物：多德太太、派克警长、阿德里安的星探……） |
| 时长 | 一场约 90 秒；一个时段 |
| 地点与时间 | 不同街角在不同时段的人流不同：上午桥头（上班的人，点单简单，赏得少）；下午集市（人多）；晚上醉鹅门口（醉汉点单奇怪，赏得多） |
| 与故事的关系 | 第 1 周，朱诺会在同一时段出现在人最多的街角，**抢走你的人群**（她的点单完成得比你快）。打听她的作息、错开她的时间，或者选择和她同台，都是解法 |

为什么要这个玩法：

- 它让「名气」「观众」从一个数字变成玩家亲手做的事；
- 它复用了手牌、牌型、发牌轮，不需要新的规则层；
- 它天然是一个「以时间和地点为核心」的玩法，和日程本互相成就。

#### 招徕观众

- 在日程本上选择**贴海报的地点和日期**：海报会提高那个街角之后几天的人流。
- 决赛那晚的上座率 = 三周里的街头表演、海报，以及 C7 支线的结果。

#### 谈判

- 和多丽丝（售票处）、霍布斯（旧货铺）、庄家的对话里，有一个简单的**讨价还价**：选择强硬、恳求或幽默，对方会根据性格回应。
- 结果是价格、门槛或者情报。

### 2.3 韦斯特港专属：情报战

城市主题是**谍战**：两个魔术师互相研究。玩法要让玩家**亲手侦察、推理、误导**。

#### 观察（新玩法）

| 要素 | 内容 |
|---|---|
| 规则 | 在对的时间去对的地方，例如周二晚上去码头仓库剧场后排，就能看到对手排练。画面是对手在台上排练的动画，他会做出一些「破绽」：从箱子里拿出某件道具、亮出某种牌型、在某个时间点停顿 |
| 操作 | 在一段时间内点击你看到的破绽，记进笔记本 |
| 收益 | 点对的破绽，就是**确认的情报**；点错的，会在笔记里留下一条错误的推测（和假传闻同一套「核对」机制） |
| 风险 | 被发现：被对手看到，他会**换掉一件道具**。你看到的就不一定准了 |

#### 推理：谁在泄密

- 第 2 周起，伊莱的巡演箱配置总是提前出现在对手手里。
- 线索板上会出现一组线索：谁在什么时间去过哪里、谁欠了钱、谁的信是从哪个邮局寄出的。
- 玩家把**人、时间、地点**连起来，指认泄密者（菲利克斯）。
- 指认错了，被冤枉的人好感下降，真正的泄密者继续泄密一周。

#### 放假消息

- **广播塔访谈**：一段对话小游戏。主持人提问，玩家选择怎么回答：说真话、半真半假、彻底的假话。
- 你说「下一场我会用火」，下一周的对手就会带克制火的箱子。这是情报系统的反向玩法：让对手按你的意图备战。
- 菲利克斯如果被你「反过来利用」，就是第二条放假消息的渠道。

#### 车轮战 2v2

- 地铁卖艺人联盟的街头团体赛。剧团成员第一次正式上场。
- 每周一场，固定在周六下午。

## 第六部分 · 需要你确认的

1. **时间规则**：
   - 事件都有日期和窗口；
   - 主线比赛错过会顺延，但支线和节庆真的会过期。
2. **布里奇波特的新玩法**：街头表演（用手牌满足路人点单）、招徕观众、谈判。
3. **韦斯特港的新玩法**：观察、推理、放假消息。
4. **第二幕按三周日历重排**：已有的对决和奖励都保留，流程、门槛和对白重写。
5. **开发顺序**：
   1. 事件日历和日程本；
   2. 街头表演；
   3. 布里奇波特重排；
   4. 线索板；
   5. 第三幕。
