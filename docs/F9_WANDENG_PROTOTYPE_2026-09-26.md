# 万灯城归物师：开场与三程旅途原型

日期：2026-09-26。入口 `/wandeng`，本地现有开发服务 `http://localhost:4173/wandeng`。世界观决策见 [ADR-0014](./design-log/decisions/ADR-0014-wandeng-ransom-and-opening.md)。

## 本次可玩的内容

标题页 → 四格漫画 → 许师傅教学（实放座钟至中路右格）→ 真实自动对战 → 来信 → 启程 → 拾灯旧街 / 雨声寄售巷 / 万灯桥 → 终局统一送交归物所。

漫画讲述商行学徒反复修复同一只音乐盒，发现机芯完好但灵魂被遗忘，听见它希望有人听完整首曲子，转向许师傅学习。音乐盒作为真实储备卡随主角启程。师傅另赠茶壶与夜灯，初始六件上阵，音乐盒在口袋中可换上。

每程三次事件，每次三个卡片窗口。第一、第三次可接引/免费修缮/帮工；第二次可逛摊/免费修缮/正式对决。选择窗口后进入详情，可以返回，不消耗节点；确认具体选择才推进。完成三次后挑战本程守关人。

UI 使用纸纹背景、彩铅器物、纸质窗口与贴纸装饰。插画无文字，名称、数值、对白、冷却都由实际游戏渲染。素材和完整生成提示见 [美术来源](./art/F9_WANDENG_OPENING_ASSETS_2026-09-26.md)。

## 当前规则与数字（可调）

| 项目 | 实际行为 |
| --- | --- |
| 战斗 | 复用三路九格确定性引擎，每路三格，物品占 1–3 格，不能跨路、重叠；同名最多两件上阵 |
| 信息 | 上部名称，下部独立冷却和可换行彩色核心数字；完整机制点选查看，卡面不按固定数量限制核心数值 |
| 基础修复 | 新接引的物品可直接作战；0 级表示基础修复完成，而非灵魂仍残破 |
| 数值培养 | 免费修缮事件 +2 级；旅途整备也可花 6 路费 +2 级；最高 6 级，继承引擎每级 12% 的系数，特定机制沿用原规则 |
| 经济 | 初始 18 路费；帮工 +10，摊位两件报价 6 / 9；正式对决胜利 +6，BOSS 胜利 +10；收入先偿还师傅垫付 |
| 玩家获胜 | 对方真实上阵实例按种子随机一件转入口袋，保留身份与等级；上阵阵容不自动被挤掉 |
| 玩家战败 | 普通正式对决赎回费 6；三位 BOSS 为 8 / 12 / 16。所有卡保留，包括等级与位置；不足额由师傅垫付，后续收入先偿还 |
| 教学/平局 | 不收路费、不掉物；教学获胜才收到信。BOSS 未胜可额外整备一次再挑战 |
| 战后 | 下一场重新建立生命/屏障；局内物品和培养持续保留 |
| 送达 | 只在第三位 BOSS 获胜后，全部上阵与储备物品一起送达；没有特定品类、最低张数、满级检查；送达后只读本局记录 |
| 保存 | 每次规则动作后自动本地保存；重新进入从旅途书签继续；战斗存档从冻结的入场阵容重新播放，结算幂等 |

三位守关人的生命暂为 190 / 250 / 315，每路屏障 50 / 65 / 80，卡牌等级 0 / 1 / 2。玩家生命 300 / 330 / 360，每路屏障 90。数字用于体验切片，未做最终平衡。

## 范围与实现入口

- `app/wandeng/`：页面、教学、事件窗口、布阵、自动战斗展示、结算与送达；CSS 全部局部命名。
- `lib/wandeng-game.ts`：阶段状态机、确定性候选与实例转移、成长与经济、原子动作、存档校验。
- `lib/wandeng-game.test.mjs`：真实战斗与全旅程测试。
- `public/art-assets/wandeng/`：六幅叙事插画图集、十二件器物图集，以 CSS 定位使用原始位图。

复用现有引擎和固定稀有度，不修改其他对战入口、电梯生存规则或共享存档。物灵卡名是当前主题的表现别名，底层卡 ID 保持稳定。

尚未包括：完整 60–90 分钟长局、复杂章节随机地图、独立物品愿望支线、记忆改装、局外图鉴解锁、配音与音乐、长线数值平衡。当前为约十几分钟的流程验证切片，实际时长随阅读和战斗倍速变化。
