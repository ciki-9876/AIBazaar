## 验证目标

用一间可撤离的俯斜视角 3D 房间验证「走位 → 搜刮 → 装备自动生效 → 承担持续威胁 → 带回物资」是否成立。重点观察搜刮路线和返程决定，而非证明完整爬楼、局外成长或 AI 竞争者已经成立。

## 操作

- 电梯内按住拖动或使用方向键环顾；点击门上的 3D 开门图标或按 E 出发。先以人眼视角走出，再抬升为俯视；共 4.6 秒，完成后开始战斗计时。电梯和入场演出没有常驻二维界面。空格可暂停演出，暂停面板的减少动态可省去抬升动画。

- WASD / 方向键移动；也可点击地面或物资标签，角色自动绕过大型设备。
- 靠近后停留自动搜取：散件 0.8 秒、设备箱 3 秒、补给柜 5 秒。精力低于 25 时乘 1.7；移动中断搜索。一次翻找收取多件，放不下的留在容器；已翻找容器取剩余不再长读条。
- B 打开行囊，整理期间暂停。点击装备，再点击 01–10 的起始编号换位；可卸入背包、保护、取出或放下物品。背包里的装备需点击“装备”才生效；放下后 5 秒可以重新拾取。
- 普通背包为 4×2 格，拖动或选择物品后点击目标格。两格物品可旋转，三格不能竖放进两行；自动整理寻找合法布局。容量足够但空间碎裂时也可能放不下。
- 空格 / Esc 暂停或继续；切出窗口自动暂停。
- 真正进入电梯轿厢后按 E，或点击撤离按钮。约 2.2 秒后结算，移动或受伤打断；门外两米范围不再算撤离区。
- 电梯在当前视野中时，可点“返回电梯”标签寻路进入轿厢。该操作不传送、不暂停、不保证沿途安全。
- 撤离成功后回到第一人称，左墙电子屏显示保住价值、击倒数与用时。再次点击门图标或按 E 重新开始试玩，物资重置；当前没有跨局保存。

## 本版可执行规则

| 系统 | 当前实验规则 |
| --- | --- |
| 自动武器 | 钉枪 2 格、线圈 2 格、锯环 2 格、贯穿激光器 3 格；无需瞄准或弹药管理。仅装备栏内武器自动发动，不能攻击视野外或机械遮挡后的敌人。 |
| 十格构筑 | 单行 10 格；增幅电容 1 格使左右紧贴武器伤害 +25%，冷却模块 1 格使频率 +20%。空格断开连接。移动装备不重置已有冷却。 |
| 物资与容量 | 独立 10 格装备栏、4×2 格普通运输包、1 格安全容器。装备占 1–3 格，机芯 2 格，补给／零件 1 格。运输包检查真实形状、边界与重叠。物品身份稳定，失败转移不复制、不部分消耗。 |
| 箱柜搜刮 | 设备箱与补给柜含多个固定身份物品；开启后按空间收取全部可放入物资，其余留存。搜索完成后保留开盖／开门模型；空容器不再产生物资。 |
| 装备与保全 | 拾取装备优先放入十格栏的连续空位，否则进普通包；两者均满则留原地。普通包／安全容器内装备不生效。初始钉枪与电容也可移动、卸下，死亡会损失。 |
| 失败与成功 | 死亡丢失全部已装备和普通背包物品，结算显示安全容器保留；撤离保留装备、普通包和安全容器。此 demo 无局外仓库，重开或刷新均重置，保留不代表跨局存档。 |
| 生活数值 | 离开电梯后饮水、饱食、精力随时间下降；移动额外消耗饮水和精力。精力低于 25 时搜索更慢；任一项归零持续失血。不削弱基本移动速度。 |
| 补给 | 普通背包内的净水瓶、口粮在相应数值不高于 35 时自动消耗，恢复 45；急救包在生命不高于 45 时恢复 45。安全容器内的补给不会自动消耗。 |
| 持续敌群 | 4 种节奏循环，包含六足虫、漂浮触须体和重甲虫；附近 10–23 米的模块入口持续生成，有数量上限及预警，不以清空敌人通关。 |
| 驻守者 | 房间深处可选 BOSS，靠近后激活，地面预告范围攻击；本次出勤只出现一次，击败生成一件净水机芯。 |
| 撤离压力 | 返程仍有怪物和生活消耗；电梯区域不提供自动无敌或补满。玩家需创造短暂安全窗口完成撤离。 |
| 资源收益 | 资源点有限，小怪只形成威胁、不掉经验和材料。价值是本次结算的比较尺度，暂不能兑换建造或强化。 |

这些数字与细化选择只是本版实验配置。房间从 28×24 扩为 96×80（11.43 倍面积），按种子组合 16 个模块。12 米视野随角色移动，机械阻挡视线；已探索地形保留暗色记忆，敌人和物资提示只在当前视野显示。左下小地图显示探索、当前视野、电梯与可见目标。详见[生成方案](./F9_SURVIVAL_WORLD_GENERATION_2026-09-26.md)。

## 技术和边界

玩法使用 30 Hz 固定步长、种子随机序列、稳定物品身份和可序列化状态；相同种子与输入序列可复现。画面采用冥河庭院手绘轮廓与明暗，保持水处理站工业物件；按实际结算显示射击拖尾、电弧、环形切割、贯穿光束、命中粒子、伤害和治疗。暂停不推进模拟。

独立路由不读取或改写原冒险存档。当前场景为程序生成模型，无音效、跨局存档、升级商店、多楼层或 AI 竞争者。生活数值尚未加入精神状态、睡眠和长期恢复。桌面键鼠为主要验证方式。

电梯以弱顶灯和左墙广告屏局部照亮，门缝黑烟与遮光面隐藏闭合时的外景；开门时淡出。电子屏目前仅有广告和出勤结果，未来操作系统尚未接入。房间 HUD、主动打开的暂停界面和死亡结算仍保留。

## 试玩时需要回答

1. 玩家是否主动为了某件装备或机芯改变路线，而不是原地等怪？
2. 自动武器是否给走位带来差异，搜刮停留是否产生可理解的风险？
3. 生存消耗是否帮助玩家决定何时返程，而非只增加计时条？
4. 十格排列、相邻支援与独立运输包是否形成取舍？暂停整理是否鼓励过度切换？
5. 拿到两个装备后站桩是否过强？早期怪物偏温和，不能把「能完成流程」视为平衡通过。

箱柜和背包规则见[迭代记录](./design-log/iterations/F9/2026-09-26-survival-containers-cargo.md)。电梯当前为[现实尺度初始轿厢](./design-log/iterations/F9/2026-09-26-survival-passenger-lift.md)：约 1.1×1.4×2.139 米，具备门、按钮面板、扶手和顶灯，采用同风格旧漆与黄铜。原大维修营地保留为后期扩容候选资产，尚无升级经济或设施功能。撤离成功后回到人眼视角并关门，读条期间保持通道打开。
