# 甩牌历史美术归档

当前正式美术采用同伴分支的 **Limelight & Velvet / SVG + CSS**，源文件位于 `apps/throw/src/app/stage/`。剪纸、Godot 与 Aseprite 像素版已转为历史参考，不再作为正式项目的并行维护目标。用户的新决定见 [ADR-0052](../../design-log/decisions/ADR-0052-throw-v6-vector-stage-and-tempo.md)。

## 本机完整备份

见 [2026-10-09 决定的归档清单](./throw-art-2026-10-09.json)，最终归档与校验于 2026-10-10 完成。清单记录压缩包的本机绝对路径、大小、SHA-256、文件数、内容范围与排除项；压缩包内部包含逐文件 SHA-256 的 `ARCHIVE-MANIFEST.json`。

归档保存于 `D:/CodexGames/backups/`，**不随 Git 发布**。另一个协作者拉取仓库后只会获得这份索引，不能凭索引恢复位于此电脑上的文件；需要恢复时须取得对应压缩包并核验哈希。

压缩包保留原相对目录，解压到新的参考目录即可检查历史 Godot 项目、Aseprite 母版、制作脚本与当时的表现层。Godot 首次打开会重建导入缓存；浏览器导出的 WASM/PCK、index 页面与脚本、引擎图标和构建信息不在归档中，需要从源项目重新导出。源 PNG、UI 素材和历史预览仍保留。归档只负责恢复历史资料，重新接入正式版本须另有明确任务。

## 历史完整性

- `D:/CodexGames` 的原文件保留，未移动、删除或重置其未提交改动。
- 剪纸版与像素版旧 ADR 按原相对路径存入压缩包，保留当时决定与证据。
- 两条开发线曾分别使用相同 ADR 编号。旧本地 ADR-0048 至 ADR-0052 不复制进当前决策目录，避免覆盖同伴分支中的同号历史记录。
- 当前分支保持零位图发布规范；归档中的 PNG、GIF 与 Aseprite 文件只用于历史恢复，不重新加入正式资产树。
