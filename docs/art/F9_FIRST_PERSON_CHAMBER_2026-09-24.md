# 第一人称值守室 · 本地验收

访问：http://localhost:4173/art/chamber 。本地服务未启动时，在项目根目录执行 `npm run dev -- --host 127.0.0.1 --port 4173`。

## 操作路线
1. 点击保管柜，靠近并打开柜门。
2. 收取皮质缓冲垫，走向装备台。
3. 将垫子拖到中路，或点击选牌再点格子。可取消、收回与重新摆放；起身后布局保留。
4. 开始战斗。查看卡牌详情会暂停，关闭后恢复此前播放状态；可以手动暂停和倍速。
5. 获胜后拿起卷簧弩、收入行囊、起身、走向出口、离开。

右上角可开启合成音效和减少动态。此版本主要支持桌面鼠标；验证了 1440×900 和 800×900，尚未完成手机触屏实机验收。

## 本轮文件
- `app/art/chamber/page.tsx`：独立体验、物件取得、原子布阵、战斗播放、奖励和离开流程。
- `app/art/chamber/chamber.css`：清晰 UI、暗角与少量画面纹理、窄窗布局。
- `app/art/slice/chamber.ts`：原创程序化房间、种子化磨损纹理、镜头姿态、柜门、房门、光源与尘粒。
- `app/art/slice/scene.tsx`：增加可选第一人称场景模式；保留旧正交切片默认行为。

没有引入新引擎、付费资产或新的全局状态系统。装备复用既有 Blender 导出 GLB；房间本身由程序化几何搭建。没有修改其他会话的鉴定台模型。
