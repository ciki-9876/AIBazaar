# F9 · 物品与实体卡牌美术样例

日期：2026-09-25。状态：独立 demo 已实现，待用户视觉验收。

## 访问与范围

本地入口：<http://localhost:4173/art/cards>。

在项目根目录运行 `npm run dev -- --host 127.0.0.1 --port 4173`。页面提供行囊、图鉴、鉴定三个标签。推荐先看行囊的 32/64/96 像素图标，再到图鉴拖动、翻面、切换稀有度，最后播放鉴定。

本轮只使用缓冲垫一个物件族。复用当前五个命名变种的真实基础品阶、Lv.0 能力；不新增卡牌规则，不改变鉴定概率，不读写冒险存档。稀有度选择器用于美术比较，并非允许玩家指定正常游戏的鉴定结果。未发布生产。

## 原始物件出现在哪里

以下是资产规划；demo 实际演示背包、搜刮、机关三种 UI 上下文及 3D 近看。

| 游玩场景 | 信息目的 | 建议资产形式 | 本轮 |
| --- | --- | --- | --- |
| 背包、仓库、安全容器 | 快速辨认与数量管理 | 32–96px 透明 ICON；边框和数量由 UI 叠加 | 背包样例，32/64/96 显示检查 |
| 搜刮、宝箱、战利品、归返清单 | 确认获得了什么 | 同源 ICON，重点奖励可放大至 128–256px | 搜刮横条样例 |
| 商店购买、出售 | 比较物件与价格 | 同源 ICON + UI 价格/库存，不另画带价格图片 | 资产可复用，未接商店 |
| 特殊房间的可用工具栏 | 对上现场需求、区分可用状态 | 同源 ICON + 数量、状态、实际用途 | 机关工具横条样例 |
| 箱庭内拾取、近距离检查 | 建立物件体积与材质印象 | 有轮廓和表面细节的 GLB；以后按距离分 LOD | 独立 3D 标本查看 |
| 鉴定前 | 保持物品身份连续，留下未知 | 同一 GLB；低性能设备可用大 ICON | 3D 读取与转化 |
| 图鉴、鉴定完成、收藏检查 | 明确获得一张可收藏的卡 | 通用实体卡几何 + 每张卡的印刷图/数据 + 稀有度材质与效果 | 已实现 |
| 战场器械 | 读懂攻击、冷却与受击 | 现有实体装备模型及动画 | 本轮不替换战场 |

**资产原则**：一个原始物件保留一个稳定轮廓和原色；数量、状态、品质框不烘进 ICON。未鉴定物件不提前使用鉴定后变种的特效。图标用固定三分之四视角、透明底，避免在小尺寸塞入背景、文字或微粒。

## 卡牌的材质与稀有度

方向是“异常物件档案中的实体收藏卡”：墨绿卡纸、米色能力纸签、细金属压印。保留非像素渲染，纸张、金属箔和图像薄膜分层着色。真实圆角薄片几何具有卡纸厚度、细切边及正反面；拖动时可以观察厚度与反光，而不是平面图片随鼠标变形。

| 固定变种 | 稀有度 | 主色 | 主要差异 |
| --- | --- | --- | --- |
| 破烂缓冲垫 | 普通 | 灰银 | 哑光纤维纸、素银线、无漂浮粒子 |
| 加固缓冲垫 | 罕见 | 绿银 | 绿银嵌线、弱反射、无漂浮粒子 |
| 皮质缓冲垫 | 稀有 | 蓝银 | 局部变色箔、少量角点微光与浮尘 |
| 深空缓冲垫 | 传说 | 橙金 | 更强蚀金压印、薄膜流光、较多浮尘 |
| 时隙缓冲垫 | 奇迹 | 紫粉虹彩 | 更明显虹彩、缓慢异常光环、最高一档浮尘 |

光效集中在卡边和插图；能力文字区保持哑光。稀有度同时通过名字、色彩、1–5 个菱形刻记表达。颜色不是唯一辨认依据。

当前五档共用缓冲垫模型及同一幅模型渲染插图，用于控制变量比较卡面工艺。尚未制作五套变种独立外形、独立插画或损坏程度。数值与名称直接读取 `cardDef` 和 `describeCard`，稀有度、品阶、等级没有混用。

## 鉴定演出

完整演出约 5.6 秒：读取实物残留 → 呼吸光与扫描 → 物件收束、卡背显形 → 翻卡 → 品质光色落定 → 显示名称与查看卡牌入口。光色由普通向预选结果递进，效果层不重掷结果。

播放过程中锁定场景切换和稀有度选择。允许跳过、重播；跳过与减少动态模式保留同一结果。支持系统减少动态偏好和页面内开关。无音效，本轮没有接入鉴定仪消耗或正式奖励流程。

## 文件与制作链路

- `app/art/cards/page.tsx`：三个场景、交互与可访问的能力文字。
- `app/art/cards/scene.tsx`：实体卡几何、材质、粒子、拖动、鉴定演出及资源释放。
- `app/art/cards/card-textures.ts`：1024×1440 原创印刷正背面、纸纹与箔层蒙版。
- `app/art/cards/specimen.ts`：现有卡牌到展示样本的映射。
- `app/art/cards/cards.css`：桌面与窄布局。
- `scripts/art-battle/build-card-specimen.py`：隔离 Blender 背景进程中提取原始缓冲垫、导出和打光渲染。
- `public/art-assets/card-specimen/cushion-icon.png`：1024×1024 RGBA 母图，约 1.03 MiB。32/64/96 是显示尺寸，尚未单独输出小图集。
- `public/art-assets/card-specimen/cushion.glb`：嵌入表面纹理的独立模型，约 3.79 MiB。
- `public/art-assets/card-specimen/manifest.json`：来源记录。
- `outputs/card-specimen/cushion-specimen.blend`：可编辑提取源场景，在项目目录中使用，表面依赖已有项目纹理。

几何来自项目原有 `battle-slice-v5.blend` 的 rubber 物件；皮革表面复用已有 Poly Haven CC0 brown_leather。ICON 在 Blender Cycles 中渲染，卡面由项目代码生成，没有新增外部商业资产。未改动原场景文件。

## 用户验收清单

- [ ] 背包小图一眼能认出缓冲垫，放大后仍对应同一件实物。
- [ ] 拖动与翻面时感觉是一张有纸张厚度的卡，而不是玻璃板或悬浮截图。
- [ ] 稀有到传说、奇迹的工艺差异足够明显，且不过度遮挡内容。
- [ ] 卡面名称、周期、能力优先于装饰，近看无需猜测文字。
- [ ] 鉴定有“发现”的节奏，结果落定后方便观察；重播不会变成负担。
- [ ] 墨绿档案、纸签与局部金属箔适合现实微恐的世界观。
- [ ] 确认是否沿用这套卡面结构，再扩展武器、机关和其他物品。

## 限制与下一步

未接入正式背包、图鉴、鉴定流程；未做全卡池、独立变种插画、音效、WebGL 丢失恢复或低端硬件帧率验收。ICON 和 GLB 尚未做生产压缩、图集和 LOD。画布细字在默认缩略观看时仍小，正式接入应保留放大和 HTML 能力详情。

用户确认视觉后，优先用一件轮廓差异明显的武器验证通用性，再接入真实鉴定结果与图鉴选中卡；生产中的大量列表继续使用 ICON/轻量卡面，不为每格常驻独立 WebGL 场景。动画只消费已确定的结果，不参与资源结算或概率抽取。
