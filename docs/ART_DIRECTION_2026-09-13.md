# F9 美术迭代方案

2026-09-13 · 美术设计提案与战斗表现原型

## 共同前提

### 先锁定 F9，再选择画法

保留“只能向上的电梯、彼此割裂的异常楼层、有限生存配额、搜刮与撤离、电梯内经营、其他幸存者、物品构筑自动战斗”的世界框架。情绪仍是孤独、克制、不确定，以及回到电梯时短暂的安全感。美术迭代不新增宗教仪式、战争背景或驾驶玩法。

“倒置医院、鲸腹车站、漂浮皇宫、月面金库”等内容继续存在。统一的是轮廓、材质处理、光照、构图与界面语法；楼层可以有不同的建筑文化与主色。一个世界不必所有地方都长得像同一间废旧工厂。

以现有三路九格、物品占连续 1—3 格、独立冷却、弹道到达时结算、屏障永久破损为表现基线。卡牌始终行动，不被击毁；屏障与宿主生命分开；前后摆放不凭美术新增拦截规则。天气与空间坍缩在本次战斗小样中停用，避免暗示已恢复机制。英雄回响与其专属卡沿用现有定义，只改变表现。

两套方案各有一个主锚点，覆盖所有模块。2D 以《This War of Mine》的炭笔媒介、人物尺度和庇护所空间观察为锚；3D 以《Pacific Drive》的风格化工业物件、异常环境和维修生活感为锚。这里的 2D/3D 指 F9 建议的制作路线，不把参考作品自身的引擎实现简单归类。

### 为什么选这两个锚点

《This War of Mine》的可借鉴之处，是普通人的身体在巨大、残破空间中的脆弱感，以及“修理、整理、熬过一天”也能成为画面主体。F9 可以借这套视觉语言表达异常楼层中的幸存者，而不接受原作的战争叙事。官方对炭笔美学有明确说明；下文的配色比例与镜头参数均是我为 F9 提出的设计建议。

《Pacific Drive》的可借鉴之处，是把维修基地与异常外界放在同一套可信的物质语言里：旧塑料、搪瓷、胶带、仪表、灯管，以及突然不讲物理的光。F9 的电梯、背包工具、鉴定台和战斗卡都能从这一套物件体系生长出来。下文桌面对战是 F9 的转译，并不是《Pacific Drive》原有玩法。

《邪恶冥刻》只提供一个局部参照：先让玩家感到“我正与某个存在对坐”，再把注意力交给桌面。F9 不移植木屋、烛火、献祭、天平、兽牌、角色造型与专有界面。尤其不能为了一张桌子，把所有野外遭遇都改写成敌人邀请你坐下打牌。

## A / 2D 炭笔档案

### 01 / 大方向：2D 炭笔档案

采用纯 2D 资产与正交构图。背景分前景遮挡、主要建筑、远景三至五层；人物使用少量骨骼或逐帧动画；卡牌、设施和可拾取物保持同一套手绘物件资产。允许 2D 视差与光照蒙层，但不把界面做成倾斜的假 3D 桌面。空间感来自层次、遮挡和明暗，而非镜头环绕。

主风格为炭笔打底、干刷轮廓、少量油彩染色与档案拼贴。不是像素，也不是二次元；人物比例接近真实，脸部信息少，衣服有重量。大块炭黑占约 65%，中灰约 25%，可读信息的脏白约 8%，当场强调色约 2%。参考色：煤黑 #171715、炭灰 #414239、旧纸 #D8D0B8、灯黄 #C8AC70、危险铁锈 #B16B55。比例是场景构图目标，不限制 HUD 的必要对比度。

所有模块共用“手里的东西被认真保存过”的视觉逻辑：标签是粘上的，边缘是磨损的，记录是盖章或划线的。叙事标题用宋体，数字和高频操作用清楚的窄体无衬线。手写只用于少量注释，不能要求玩家读潦草的机制说明。

### 02 / 核心战斗：先看见人，再看清物件

1. 遭遇前：楼层探索画面保持横向空间。幸存者在左侧近景，封锁者在右侧建筑阴影中。两人之间留出大块负空间；异常只出现一个显著线索，例如没有风却持续晃动的导线。敌人的构筑提示先以三枚类别图记出现，不提前挤出完整卡墙。

2. 开战 0—0.6 秒：环境声压低，人物停下，四周炭黑加深。镜头只做约 6% 的缓慢推进；背景纸纹不随 UI 一起缩放。玩家轮廓仍留在边缘，保证这场战斗发生在楼层现场。

3. 0.6—1.2 秒：物件档案从双方靠身的一侧依序铺进中央区域，像翻开随身的折叠工具清单。不是凭空弹出圆角窗口。三路标记依次盖上 I、II、III，双方屏障线亮起；敌方资料始终正向，不能迫使玩家倒着读。

4. 1.2—4.2 秒：中间出现 3、2、1 倒计时。三路每路先亮一次对应关系，再开始冷却。首次完整播放，之后可跳过；减少动态时直接到读盘状态，保留简短倒计时。入场不消耗战斗时间。

5. 稳定读盘：采用“我方左、敌方右；上中下三路水平对应”的正交布局。以 1920×1080 为目标，战场占主要视区约 70%；边缘保留人物与场景。卡牌中型横跨两格，小型一格；同一中型物件只保留一张插画与一个冷却条。中间留出两道屏障与窄弹道区，不能画成让人误解为可放卡的空槽。

6. 卡面：上沿显示固定稀有度的孔点；中部占约一半高度的物件原画；下部依次是名称、主效果值、冷却与品质/等级。原画采用大轮廓和可辨功能结构，常态隐藏长描述。2 格卡扩大插画构图，不能简单把 1 格卡横向拉伸。点击后在桌面外的档案栏展示机制，避免悬浮框盖住正在结算的一路。

7. 冷却：蒙层从上到下退去，底边一根细线作为第二读数。最后 0.3 秒只提升物件边缘亮度；准备完成时卡面短促提亮，不无限抖动。充能从来源牌到目标牌走一条细铜色线，目标冷却条立即前推，并显示“+0.8s”等实际推进量；没有合法目标时不出现假连线。

8. 发射与命中：钉枪先局部后坐，再发出一条细短亮线；飞行期间来源保留很淡的划线尾迹。到达屏障时先出现局部墨裂、再更新屏障数值；真正穿透到宿主的伤害单独显示在宿主侧。不能在发射瞬间提前掉血，也不能把弹道画成撞击并杀死一张卡。

9. 三种流派：速攻是向前的硬划痕和快收尾；固守是材料受压、压痕积累与反冲释放；侵蚀是纸缘渗染与屏障刻度被逐段吃掉。修复填回完整屏障的裂纹，破损屏障始终留下烧穿缺口。培养皿成长体现在插画内菌落轮廓与一个明确数值，不能全场堆绿色粒子。

10. 破障：持续约 0.35 秒的局部断裂，原屏障的实线断开并留下锈色“破损”字样。后续弹道沿同路越过缺口到宿主。其余两路维持正常亮度，不用全屏红闪抢走注意力；同一时刻多处命中时，按位置聚合数字，显示实际结算总量。

11. 胜负：最后一个有效命中完成后停留约 0.7 秒，保留破损位置和剩余生命。胜利以“通路已打开”的档案章出现，敌人退回阴影；失败是幸存者的灯灭一盏和撤离信号中断。不要清空桌面再给抽象大数字。随后收起档案，回到原探索场景。

12. 复盘：可以暂停、调速与拖动时间；选择卡片后高亮它的来源/去向。卡牌变暗仅代表冷却，屏障缺口代表破损，人物生命减少代表宿主受伤；三类含义不能混用一种红闪。

### 03 / 基地建造：一间能看见生活留下痕迹的电梯

1. 空间形式：电梯采用单屏横向剖面，前墙被隐去，外侧看得到部分井道和缓慢经过的楼层标记。门、终端、床位、构筑工作面是永久锚点；设施槽沿后墙和底部摆放。主体仍是一间电梯，不随等级突然变成多层豪宅。

2. 观看规则：日常镜头显示整个生活舱，人物约占画面高度的 20%—25%。点设施后，镜头向所在区域推进约 10%，其余环境保留。只有“建造”模式才露出离散槽位；平时看到的是锅、管线、工具架和盖着毯子的床。

3. 进入建造：玩家展开一张薄的工程草图，空槽用虚线描边；选设施后出现半透明手绘轮廓，并同时显示占用槽数、实际成本、用途与今日可用状态。合法位置用完整边框和勾号；不合法位置用斜线和文字原因，不能只靠红绿区分。

4. 放置：点目标槽先预览，界面贴着设施显示确认与取消。确认后先出现支架，再补管线、外壳、标签，0.8—1.2 秒结束。完成一次建造只扣一次资源；画面动效不延迟真实事务，也不增加额外等待日。

5. 扩建：先让侧边收纳板或吊轨展开，再露出新增合法槽位。旧设施不自动换位置；构图用横向展开和适量缩放处理增长，门和床等熟悉参照继续存在。扩容改变能摆的空间，装饰不改变游戏容量。

6. 设施日常动作：发电机是飞轮转半圈和仪表回弹；医疗区是灯罩转向折叠床；净水/生产区是液面变化和容器更换；回收区是钳台压合；鉴定区是灯扫过物件；观测区是小望远镜或监测头对准舱外。高频动作 0.4—0.8 秒，允许跳过。

7. 已用状态：今日用过的设施盖一个小日期章，机器回到低功耗待机姿态，功能区仍清楚可点。停机、缺料、今日已用、未建造四种状态要有不同轮廓与文字。不能让所有不可用状态都变成同一种灰色。

8. 升级：每个设施只保留三个清楚的剪影阶段。基础是裸露框架；改善是补上功能外壳与一个可见储罐/托盘；高级是整理过的管线与标定仪表。不要用稀有度光柱代替结构升级。品质变化可以“修得更可靠”，不要求“变得更奢华”。

9. 拆除：选中后预览真实返还量与腾出的槽位；完成时按外壳—连接—底座收回，留下淡的安装痕迹作为装饰。返还、每日使用记录与设施身份按原规则结算，拆装不靠动画重置生产次数。

10. 休息与返回：撤离时手绘的电梯门合上，外界高反差光被截断，床边小灯成为全舱最暖的点。睡眠后只改变日期和对应状态，不加入真实昼夜倒计时。安全感来自声音、光与熟悉布置，不等同于取消生存配额压力。

### 04 / 其余模块如何统一

1. 探索：使用可分层拼装的横向场景，每个节点保留一个主要空间特征和一个可调查物。倒置医院把吊床与灯具挂在异常的“地面”上；鲸腹车站让站台标识与有机褶皱并置；漂浮皇宫用悬空台阶和留白表达失重。三者都使用同样的炭笔边缘与克制明暗，但分别使用冷消毒绿、盐水灰蓝、褪金墨黑。

2. 背包与仓库：将 UI 做成展开的背包内衬和电梯收纳架，格位由缝线/隔板确定。未鉴定物显示同一物件的遮罩轮廓与封签，已鉴定显示正式插画；多格体积在拾取时就可读，不通过换皮偷偷改变容量。安全格有锁扣形状与明确文本，普通背包用织物边框。

3. 鉴定：把实物放到光下，先读出体积与可知信息，扫描后撕开封签并落下正式标签。稀有度固定在标签上沿；品质用修补/封装程度；强化级别用离散刻痕和数字。三条成长轴在图形位置上永远分开。首次鉴定可以演 1.2 秒，重复查阅直接显示结果。

4. 卡牌成长与回收：强化是在档案上增加校准刻度，品质提升替换物件局部原画层；固定稀有度徽记不变。回收先给出获得资源，再做压合/拆件的小动作。避免开箱金光、随机稀有度滚动等误导反馈。

5. 商人与交换：商人是一幅与场景同材质的半身像，商品摆在其携带的箱子上。价格是系在物件上的纸签，库存枯竭留下空印；购买结果进入明确容器。商人可以古怪，但不要突然换成高饱和 Q 版肖像。

6. 幸存者与英雄回响：人物先用背包形状、站姿、工具位置和衣服层次区分，脸不是唯一身份线索。普通幸存者保持真实比例，英雄回响用档案叠印、维修标记等来自其机制的独有动作；同一英雄的头像、卡牌标识、战斗指示与账本印记共用一个小符号。

7. 楼层导航与账本：电梯控制面板是可读的楼层列表，未知区域用空白条与缺页表示。其他幸存者的结果进入打字条账本，显示实际日期和事件来源；不把静态摘要包装成所有 NPC 正在实时演出。

8. 事件、谜题、死亡与排名：事件在具体物件旁展开短档案页；谜题的可操作部件必须比炭黑背景更清楚。死亡保留一页带日期的旅程记录；排名像旧升降日志，只突出已通关高度，不用抵达楼层冒充成绩。

### 05 / 细节规范与制作取舍

材质噪点只放在画面和边框，不覆到正文或细数字上。战斗主要数值在目标桌面分辨率下至少 16px，常用标签至少 14px；小尺寸端只保留图、名称、主值与进度，完整说明移到详情，不整体缩到无法辨认。HUD 纸白优先于气氛压暗。

声音同一材质体系：纸张摩擦用于查看，金属扣用于确认，钳击用于发射，玻璃细裂用于完整屏障受损。破障使用一个更低的短促断音，宿主受伤用呼吸/衣料与钝击；不要让所有事件都发同一个提示音。默认低音量，可关闭。

资产生产建议：先完成一个检查站、一个完整电梯、三名幸存者、12 张卡的正式插画和 6 类效果。环境每个题材使用 3—5 层，设施共享连接件与标记；不要先做 100 张背景。低成本来自可复用的造型和分层，不来自给每张图统一套滤镜。

这条路线的长处是异常楼层的画面变化成本较可控，战斗可读性容易保持，基地剖面适合高频管理。风险是静态感与灰度同质化：需用人物动作、物件尺度与异常空间关系创造变化，不能靠加更多脏纹理解决。它的气质更像一份亲手保存的生存档案。

## B / 3D 工业异象

### 01 / 大方向：3D 工业异象

采用真实 3D 场景、透视镜头与风格化材质。不是体素，也不是追求照片级写实：轮廓略简化、边缘有可见倒角，贴图留出清楚的大色块；旧塑料、涂漆钢、橡胶和玻璃有不同粗糙度。角色采用近真实比例的低至中等面数模型，不做大头卡通，也不依赖写实皮肤表现。

主色建议：深石油蓝 #14262C、旧搪瓷青 #53686A、检修灯琥珀 #DDA85F、标签灰白 #D7DBCC。冷色用于外界与深处，暖色用于手边操作物。异常光可以短时出现不自然的青绿、偏红或反向投影，但一般环境里不能同时铺满霓虹。

全游戏的 UI 物质基础是“电梯系统与幸存者共同维护的设备”：仪表刻度、薄金属面板、纸质维护标签、旋钮和少量 CRT 显示。信息界面仍保留清楚的屏幕层文字，不把每一行都塞进透视变形的实体显示器。可信的生活物件负责沉浸，稳定的排版负责操作。

### 02 / 核心战斗：入席、升镜、读盘

1. 先确定叙事接口：在封锁站、商人挑战、幸存者据点等合理位置，可直接使用实体检查台对坐。普通楼层遭遇则由玩家展开随身战术台，敌方对应的是扫描轮廓或战术映像；是否把这种装置写入正史，需要另外确认。本次小样限定“封锁检查站”，不强行为全部遭遇新增设定。

2. 入场 0—0.8 秒：第一人称坐在检查桌的一端，能看到夹克下摆、膝部、前臂和戴手套的手，不能看到自己的头。对面人物有完整躯干、呼吸姿态与手部轮廓；先看到旧护目镜反光和台灯，再辨认衣服。空间要能读成一个真实房间，而非漂浮在黑色背景里的卡盘。

3. 0.8—3.0 秒：玩家双手把卡匣推入桌面定位槽，检修灯增亮，摄像机从坐姿缓缓升高并绕到统一战术朝向。先抬高再调整朝向，避免桌边、手或对手从镜头中穿过。玩家与敌人实体在桌两端对坐，按 2026-09-14 的修订，镜头最终保证敌方在屏幕上方、己方在下方；原三路从左到右标为 I、II、III，卡面文字保持正向。

4. 3.0—6.0 秒：进入近俯视视角后，再出现 3、2、1。目标方案的战术俯角为 75—88°，三路全部处于清晰焦平面；不把浅景深延续到读牌阶段。让玩家能在开战前看清各路屏障、物件大小和对路关系。镜头移动阶段不推进引擎时间。

5. 稳定视角：战斗中锁定战术镜头，仅允许用户主动切换“入席观察”和“战术俯视”；观察时暂停。本次原型提供两种预设视角，正式版可补一个小范围观察摇杆。默认无呼吸摇镜、无手持摄影式抖动；入席镜头可跳过，减少动态时直接俯视。

6. 桌面结构：表面是带三路凹槽的旧搪瓷检修板，边缘有金属压条、螺钉与磨损，磨损集中在手会触碰的地方。格线是印刷刻线，不是九个发光按钮；每格尺寸一致，中型卡真实占据两格宽度。中央留一条明显不可布置的隔离带，双方三道屏障装在各自内缘。

7. 卡牌结构：建议为有厚度的薄型物件匣，顶面嵌入印有工具/角色图案的档案片。边缘有约 2—4mm 的倒角和细小投影，中型匣在长边增加一道结构接缝。插画仍是物件的主要识别入口，可在少数关键卡上加浅浮雕，不要求每张卡上站一名 3D 战士。

8. 卡面 UI：顶部固定稀有度用铆钉/孔点与文字；中间 50%—60% 区域给插画；下部显示名称、主值、冷却，最底部留品质、等级和尺寸。数字始终面向玩家；当实体卡面不足以阅读时，用绑定物件位置的清晰标签补充。不能为了“真实”把敌人的文字颠倒、反射或缩得极小。

9. 选中与查看：点卡时物件匣离桌约 8—12mm，边缘灯变亮，接触阴影拉开；详细档案出现在桌外栏。查看不把卡从阵容中取走，也不改其冷却。鼠标、键盘焦点和触摸都能选择同一物件；入席角度下有可读的物件索引作为替代。

10. 发射：物件匣先发生 60—100ms 的局部动作，再从插画中心或对应出口产生弹道。钉枪为短直金属亮点；反冲板为受压—回弹—推出；侵蚀为小滴状路径；充能为沿线传递的短电光。绝大多数弹道在桌上方 5—15cm，避免飞过 HUD 或对手脸部。

11. 命中：弹道到达才能变数值。完整屏障的薄玻璃/复合板局部出现应力亮纹，屏障承伤与宿主承伤分别显示；不能让打向屏障的子弹撞上一张卡。修复是应力纹收拢，屏障上限被侵蚀则保留被吃掉的刻度。卡片材质可以被照亮，但不得碎裂退场。

12. 永久破障：支座仍在，上层防护面板失去连续形状并留下一截断边；碎片只短时出现，0.6 秒内停止或淡出。后续同路弹道越过断口到宿主侧的生命端口；宿主角色只做短促肩部反应。美术遗迹应持续到结算，不能过两秒又恢复成漂亮的完整光墙。

13. 成长与连锁：反冲储量表现为压紧的弹簧刻度和明确数字；培养皿表现为生长的局部图案/浅浮雕；充能明确标示来源、目标和实际推进秒数。多张牌同刻发动时，特效按伤害、修复、充能分组，音效限声部；视觉强度由结果决定，不由稀有度决定。

14. 收尾：最后命中后保留约 0.7 秒读数，镜头再缓慢降回桌边。胜利时封锁者收回手、通道锁灯从封闭转为可通行；失败时玩家的生命端口熄灭、扶桌的手失力，随后进入原有救援/失败流程。不加入处决镜头，也不把数值胜利自动改写为杀死所有敌人。

15. 效果强度分级：普通命中只占一路局部；首次破障可略抬高环境音；决定胜负的命中才用低幅整体反馈。开启减少动态时关闭升镜、卡匣跳动与震屏，保留颜色之外的图形变化、文字与进度。

### 03 / 基地建造：把电梯当作需要亲手照料的机器

1. 空间形式：整个基地是一个有内部尺度的 3D 生活舱。进入时先看见门、灯、工作台、床和带日期的终端；玩家能听到机器来自哪里。保持第一人称互动，但日常经营不强迫玩家反复步行找按钮；已发现设施有清楚的快捷索引。

2. 建造视角：按建造后摄像机沿固定路径升到舱内斜俯视，隐藏或半透明处理前墙与遮挡部件，露出离散模块槽。镜头不离开电梯到无限黑背景。退出建造回到原来的站位，避免迷失朝向。

3. 设施选择：目录是一块可展开的检修终端，设施以真实模型小预览加平面说明呈现。选中后在目标槽出现低对比网格轮廓，已占区域保留实物，合法位置有卡扣对齐标记。仍遵守原来的模块槽与占用规则，不因为 3D 而加入任意自由摆放。

4. 落地动作：用户确认位置后，底座先扣进轨道，主体短距离滑入，电线接头卡合，仪表上电。三段动作合计约 1.2 秒；资源扣除、占用与设施身份只提交一次。取消时整件轮廓回收，没有材料损失。

5. 建造可读性：在当前槽边显示设施名、所需资源与实际剩余量；遮挡模型时显示外轮廓而不是穿墙文字。缺资源、未解锁、槽位不足分别显示对应原因。平时关闭网格，生活舱恢复正常材质和光线。

6. 扩建：让原有舱壁的可扩展导轨伸开，收纳层向外展开或增加服务舱段。机械动作必须能对应容量变化；不能仅把相机拉远造成“升级了”的错觉。已经安装的设施位置与操作编号保持稳定。

7. 设施表现：鉴定台有可移动检查灯和夹具；医疗设施是折叠床、药箱与布帘；回收设施是钳台和分拣盘；发电设施是转子、橡胶垫和机械表；观测设施是外接传感头与可读监视屏；存储设施是有隔板的柜体；生产设施通过进料口、处理腔和出料容器表达原料去向。每件先用轮廓解释功能，再补贴纸。

8. 生产与使用：按下实体按钮可以触发原有一次性动作，并在屏幕层给出资源变化回执；产物从明确的出料口进入托盘。今日已用时保持小型日期灯和终端记录，不能靠机器是否旋转判断可用性。装饰性的转子可以待机转动，但不产生后台免费资源。

9. 升级差异：基础设施裸露管路、单个手动表；第二阶段增加封闭外壳、减震结构或更大功能容器；第三阶段有双表、可替换滤芯或整理好的布线。配色维持电梯材质体系，不能每次升级把整间屋子刷成新的稀有度颜色。

10. 拆卸：先在原位显示将回收的资源和空出来的槽，再断开线缆、打开锁扣、收起设施。遗留的锈印是装饰，逻辑槽位完全释放；每日使用标记继续按原规则保留。不得让拆卸模型的动画提前删除背后的库存。

11. 生活与安全感：床头暖光只照一小块织物，工作台有整理过的工具，门缝仍漏进一条外界冷光。电梯越成长，东西越有秩序而不是越像豪华基地。外界的异常声在门关上后被低通滤掉，终端仍冷静显示剩余配额。

12. 高频效率：打开背包、构筑和终端可直接调用同一固定操作视角；首次用镜头建立“它在哪里”，以后让熟练玩家一键进入。菜单返回不要每次演完整长镜头，沉浸不能以重复动画为代价。

### 04 / 其余模块如何统一

1. 探索：第一人称的短节点空间或固定可观察角度，两者选一后保持一致，首版推荐固定热点加有限视角，控制内容成本。倒置医院通过重力方向冲突构图，鲸腹车站通过有机壁面包裹标准站台物件，漂浮皇宫通过建筑部件悬浮与不可能的影子构图。物件识别、粗糙度与交互灯色遵循同一标准。

2. 拾取与背包：检视时手把实际物件拿近，屏幕层出现尺寸和去向；放入背包后转换成同一物件渲染图的格位表示。只对首次拾取使用完整检视动作，重复物资直接计数。背包仍是高效平面格位，不能强制玩家在三维袋子里翻找遮挡物。

3. 鉴定：物件放进夹具，扫描灯扫过表面，终端打印标签；未知态到已知态的变化来自真实鉴定回执。稀有度是固定标签，品质是修补/封装状态，等级是校准刻度。不要用随机跳色灯提前暗示未生成的信息。

4. 成长与回收：相同物件模型可复用，品质替换局部零件与材质，强化改校准盘和数字；稀有度不会随修理改变。回收采用拆件盘的材质与音效，给出清楚的投入产出，而不是一团通用消失粒子。

5. 商人与交易：货物在交易箱或推车内展示，挑选后进入屏幕层详情，价签与电梯维护标签同一排版。商人的职业通过携带物与手部动作表达。每次交易的重复交接动作短于 0.5 秒，批量操作直接给回执。

6. 幸存者与英雄回响：整体采用风格化真实比例、耐用衣料、缝补与工具挂点；异常职业可以有不合理的局部，例如护目镜映出别的楼层。英雄特殊效果沿用其已有设定，以专用仪表、记录薄或工具反馈表现，不额外给所有人增加魔法光环。

7. 楼层导航、终端和幸存者账本：终端机壳是真实 3D，打开后文字转为清晰的屏幕层 UI，边缘保留实体机框作为参照。楼层选择保持垂直结构；未知信息用缺失记录表达；机器人远处行为仍标为日志事件，不在地图上伪造实时位置演出。

8. 谜题、事件、结算和排名：谜题必须由可辨材质与机械关系表达可操作性；事件长文本在稳定阅读角度展开。通关和死亡输出带编号的旅程票据，排名进入电梯调度记录，记录已通关高度、日期和并列状态。所有结果界面都沿用机壳、标签、仪表三类材料。

### 05 / 细节规范与制作取舍

材质建议：同一功能件准备干净、磨损、异常污染三个受控状态。磨损跟接触位置走，不能每个表面都均匀贴满锈。卡匣与设施使用相同的金属粗糙度区间、边缘宽度和标签尺度；物件是互相能认出来的同一套东西。

角色与镜头建议：最先完成两双手、玩家下半身和一个可对坐的封锁者。手必须能抓住卡匣边缘、压按钮、扶住桌沿；不要先投入大量表情捕捉。座位镜头建议 FOV 45—55°，战术镜头 35—45°；正式版要用最低目标屏幕逐卡验证文字大小，不把大屏效果当作全部设备的表现。

光效与性能建议：以烘焙/静态环境光、一盏主要投影灯、少量受控局部灯开始。桌面优先稳定帧率与可读对比，环境雾不盖住卡字；战斗时关闭景深和运动模糊。目标为桌面 1080p 稳定 60fps，低档 30fps；这是待实测目标，不是本次原型已验证的性能结论。

声音建议：金属、塑料、玻璃、织物各有独立动作音组；设施声按位置发出，桌面弹道按来源与命中位置移动。处理“等冷却”的节奏时使用机器运转和少量继电器声，不填满持续战斗音乐。关键破障音比普通命中更低、更短、更明确。

这条路线的长处是电梯能成为有记忆的生活空间，探索—鉴定—构筑—战斗可共享真实物件资产，镜头能产生很强的遭遇感。主要风险是三维可读性、手部动画、镜头穿插和每层的空间成本。预算不足时应减少场景数量与演出种类，不能只把平面卡牌歪一下就称作完成 3D 迭代。

## 范围与建议

### 本次原型实际做到了什么

A / 2D：原创炭笔检查站背景、物件图鉴卡面、三路双侧布局、冷却蒙层与进度、屏障破损、弹道与局部命中、宿主生命、倒计时、卡牌详情、暂停/调速/拖动回放、三种对手构筑。当前环境是一张完整背景画，还没有正式制作中分层视差和人物逐帧动画。

B / 3D：真实 WebGL 房间、桌面与格线、低多边形对手及玩家身体/手部、带厚度和纹理的卡匣、灯光与接触阴影、入席至战术俯视镜头、两种观察视角、物件点击选择、屏障随数值改变与破损支座、三维弹道及命中环。角色目前是体块模型，手部没有抓握骨骼动画；没有正式裂纹贴图、碎片模拟、完整角色演出与空间音频。

两版在同一入口切换并保留回放进度，使用相同 F9 引擎输出和对局参数。选择不同对手才重置对局。这里验证表现与可读性，不给这轮美术方案打未经玩家验证的品质分，也不把示例战斗当作新平衡方案。

原型图集由内置 imagegen 生成。工具图采用维护道具概念形态：电钻代钉枪、弹簧组件代卷簧弩、刮刀代猎隙刃，若干防守/辅助卡暂共用同类图。这是清楚标记的概念代用，正式原画应依据每张牌的身份重绘，并为 3D 版制作独立材质/浅浮雕。两版当前音频只有简化的合成命中提示，默认关闭。

2026-09-14 已补充独立 3D 电梯基地沙盘（/art/base），包含建造、运行、外观升级与拆除；其余模块仍是详细设计。WebGL 不可用时显示提示，仍可切回 2D；原型不读写冒险存档。桌面网页布局为主要目标，窄屏提供适配但尚未进行设备实测。

### 建议选择与下一步验收

1. 如果把“尽快把整个 F9 做得统一、精致，同时继续扩展大量异常楼层”作为第一目标，我优先推荐 A / 2D。它能把战斗、基地剖面、背包和事件串得很自然，也更容易把有限美术精力放到具体物件与楼层构图。

2. 如果把“玩家真的住在这部电梯里，并且记住一次次与封锁者的遭遇”作为第一卖点，而且能够持续投入场景建模、手部动画和灯光制作，我推荐 B / 3D。它的上限更符合你举例的身体感与桌面仪式感，但不应承诺只花改 UI 的成本。

3. 评估原型时先选同一对手，在 1× 下看开场、首次破障与最后命中，再拖到相同时间切换 A/B。分别回答：第一眼看向哪里、能否识别六件己方物品、能否指出弹道来源、能否区分屏障伤害与宿主伤害、愿不愿意连续观看十场。不要仅比较静态截图哪张更漂亮。

4. 用同一个电梯与同一段“进入楼层—搜刮—鉴定—构筑—对战—返回—建造”做下一轮完整切片。先完成一层，验证统一性后再扩展三种差异极大的楼层，最后才制定批量生产规范。

5. 建议资产顺序：统一色彩/字体/图标 → 12 张正式物件与一套卡框 → 三路战场/屏障/宿主反馈 → 一个完整电梯与三种设施 → 三个异常楼层 → 商人/幸存者/账本 → 稀有度、品质、强化和动效细修。对应你要求的从大到小，不能从粒子和发光边框倒着开始。

6. 验收门槛：1920×1080 与最低目标屏幕均能清楚读主值；关闭颜色仍能区分状态；切换方案不改变胜负与数值；长局暂停后能解释破障原因；建造前后能看清实际槽位与资源变化；连续操作不被长镜头反复打断；减少动态模式可以完成同样的操作。
