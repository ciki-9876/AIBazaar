# f9 幸存者电梯 Demo 1.0

## 交付范围

按 v0.4 验收选择的「十层共享存档闭环」实现。首页现为正式 Demo；`/demo/` 是同一游戏，`/design/` 保留历史设计验收，`/legacy/` 保留最初集市实验。存档是已验收首阶段范围内的本机单人存档，可自动保存、导入、导出；不依赖在线服务。

玩家从电梯醒来，确认协议，领取初始鉴定卡与工具。进入 1–10 层中的目标层，只能向上或重试当前层。每层串联事件、搜索、解谜、商人、守卫；可跳过搜索/交易或提前撤离。完成主目标且正常撤离才提交通关，十层撤离后结算。高层的机械组件束和首次通关材料奖励更高。

## v0.4 验收落实

- 初始配额 12；每日出勤一次；睡眠推进日期并扣 1 配额，消耗 1 补给恢复 50 精力，无补给恢复 15。
- 救援额外扣费 3、5、7……继续递增；正常撤回清零，睡眠保留。普通包丢失，上阵卡、安全格、基地保留。最终战失败在尚有配额时可隔日重试。
- 九格上阵卡组、随身包、安全格与基地仓库在同一整理界面。点击详情后转移；上阵释放背包容积，多格卡不可跨路。安全格独立成长：电梯 Lv.1/3/5 对应 2/4/6 容积。背包 12/16/20。任务核心禁止进入安全格。
- 实体无稀有度；鉴定后稀有度永久锁定。终端免费；楼层需要携带仪器并扣电荷。仪器丢失后可在终端重制。品质、等级和回收资源接入同一局。
- 八种基地设施可建造、拆除、扩建、生产；每设施每日一次，重建不重置使用记录。观测台改为建造 8 材料、免费观测。天气在楼层/日期内固定，影响地形和探索消耗。
- 99 名机器人拥有与玩家相同配额，按计划楼层、构筑强度进行挑战；同层机器人可封锁对决。真实减少对应楼层库存并记录原因。玩家可能遭遇其中一人；封锁胜者继续，败者回收。
- 最高已通关楼层排序，同高度并列；抵达楼层不代替通关成绩。

## 本轮追加的核心战斗修订

用户在开发期间要求「卡牌受击、宿主受伤」，并确认空路直击宿主，已替换 Demo 的旧伤害模型。

1. 默认攻击同路最靠前的敌方卡。每路三个格，左前右后，格位按卡的起始格判断，多格卡是一个目标。
2. 卡牌只有护甲，没有生命值，不会被击毁或退场。
3. 护甲暂定：卡牌基础护甲 + 品质阶数 × 5 + 成长等级 × 2。基础护甲因卡而异，防御设施较高。
4. 传递伤害 = 原伤害 × 100 / (100 + 护甲)，保留一位小数；再由宿主护盾吸收，剩余扣宿主生命。
5. 同路为空时直接伤害宿主，护甲视为 0。此规则由用户明确确认。
6. 脉冲线圈作为特殊选敌样例：优先其他路最靠后的卡，同列先上路；其他路为空时退回同路前排，再无目标则直击宿主。规则显示在卡牌详情中。
7. 奇迹回响再次走同一选敌/护甲流程，不递归。治疗和护盾仍作用于宿主；充能作用于描述指定的友方卡。
8. 同时触发先汇总双方攻击，再扣血，避免我方先手处理偏差。40 秒后空间坍缩属于环境伤害，明确绕过卡牌护甲与宿主护盾。
9. 敌方在上、我方在下；敌方主体在其卡区上方，我方主体在其卡区下方。受击卡高亮，宿主生命损失/治疗/护盾/能量飘字。日志展示原伤、目标卡、护甲、传递伤害、护盾吸收与生命损失。

## 当前实现边界

楼层题材使用离线种子重组，不宣称已连接真实大模型。十层共享循环可完整游玩，事件叙事和解谜属于有限样例池；机器人是可解释数值模拟，并非逐张卡模拟 99 场完整策略对局。暂无真人联机、云存档、永久跨局排行榜或 100 层内容。历史 PRD 页面是已归档的规则版本；本 Demo 的追加战斗改动以本文件和游戏内说明为准。

## 验证

61 项模型/回归测试通过，包含 13 项完整 Demo 流程测试、5 项新选敌/护甲测试。三个不同种子通过真实战斗与资源操作从一层完成十层，未通过测试修改资源或强制胜利；另外单独验证最终失败回收、读档、容量、稀有度、重建限制和机器人库存守恒。TypeScript 与 lint 通过。页面采用 HTTP 与静态构建检查，未做浏览器点击或截图验收。
