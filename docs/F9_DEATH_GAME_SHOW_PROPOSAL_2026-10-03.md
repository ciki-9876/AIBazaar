# F9 候选世界观：跨世界生存综艺《最后一部电梯》

日期：2026-10-03。状态：调研与助手方案，待讨论、未实装。

同日后续：用户明确要求竞争者由大模型真正驱动，并以选手博弈、晋级和淘汰为核心。见 [ADR-0025](./design-log/decisions/ADR-0025-llm-contestants-and-elimination-experience.md) 与 [深化方案](./F9_LLM_CONTESTANTS_AND_ELIMINATION_PROPOSAL_2026-10-03.md)。下文将选手视为可选同行者的范围不足以满足新要求；原建议保留历史，后续方案仍待讨论。

用户希望拓展综艺大逃杀方向，研究目标、规则、紧迫感与持续游玩动机。本文不代表用户已选择这一方向，不覆盖 [ADR-0024 的“我被取代了”题材决定](./design-log/decisions/ADR-0024-replacement-mystery-direction.md)。现行规则以 [ADR-0023](./design-log/decisions/ADR-0023-survival-sight-brains-and-recovery.md) 等已实施记录为准。本文中的赛事、时长、选手和结局都是新提案；作品事实、设计推论和验证假设分开表述。

## 1. 判断

综艺方向比替身悬疑更容易进入现有玩法：电梯是选手休息室，楼层是每期赛场，搜刮是参赛准备，自动战斗与走位是完成挑战的手段，其他人是会争夺资源的参赛者。主题资产包也有统一理由：节目不断换赛场。

最大风险是把 F9 做成互不相关的小游戏合集，或用持续倒计时破坏探索。建议保留同一套移动、搜刮、自动战斗、十格装备与撤离操作，只改变每期的目标和一条特殊规则。先用单期切片验证，再决定是否替换主线。

## 3. 世界设定与能力边界

暂定节目名《最后一部电梯》。一个掌握跨世界运输技术的商业组织，把不同世界的真实区域划成赛场，向其他世界的付费观众制作生存节目。玩家在陌生电梯里醒来，被登记为新一季选手。

每名选手有一部电梯。它既是休息室、装备间，也是节目授权的救援与通行设备。安泊是这部电梯的管理 AI，负责照顾仍有资格的选手；它受节目协议约束，却有自身判断。首次修复后，它才恢复接收赛事通告的能力，因此现有无信号手机、荒原遭遇和开灯流程可以保留。

主办方能开放或关闭指定门路、部署赛场设施、投放怪物和补给、记录选手行为，不能任意读心、复活已经死亡的人、临场改写公开判定或凭空重置物资。怪物来自赛场原有生态或节目投放，全部维持非人类；人类角色只有玩家和其他选手。外勤精神力耗尽属于失去行动能力，安泊救回的是尚存活的选手，不是复活死人。

脑浆为电梯生物计算部件的维护、升级材料，保留现有名称、描述、品质与经验规则。主办方为何采用这种计算设备可成为环境叙事，但不再额外引入一套“脑浆购买生命”的经济。

每期可以是一至两层，建议完整短篇原型先做六期；期数只是范围建议，不是已确定制作承诺。楼层数与期数分别展示：楼层是空间进度，期数是赛事进度。完整赛季必须给出真实终点：通过终局挑战，返回自己的世界，拿到节目承诺的奖励。主办方的恶意体现在规则里的风险交易和淘汰回收，不靠反复宣布“出口又是假的”拖延结局。

## 4. 玩家目标

| 尺度 | 目标 | 玩家因此要做的事 |
| --- | --- | --- |
| 一次出门 | 拿到任务进度与有价值的物资，活着撤回 | 选路线、搜箱柜、利用迷雾与遮挡脱战、管理占格 |
| 一期 | 达成晋级目标；有余力再争夺额外奖励 | 在保底与高收益之间选择，准备适合本期的构筑 |
| 数期 | 升级自己的电梯，让装备与机制组合成形 | 使用脑浆和建筑材料、取舍装备、预判下一期规则 |
| 整季 | 保住选手资格，通过最终出口挑战，回家 | 持续攀爬，并决定如何对待曾合作或竞争的人 |

自由是首要奖品。奖金强化世界可信度，不能替代玩家已经体验到的成长、关系与风险。首期末应让玩家看见一份往届成功返乡的记录，建立“确实有人通过”的信任；记录可以隐藏商业内幕，但不推翻出口本身。

## 5. 一期比赛的规则

### 5.1 出发前只告知四件事

主目标、出勤额度、一条特殊规则、晋级与额外奖励。必须先公布再允许进入；特殊规则通过环境和一次安全示范教会，不在战斗中塞长篇弹窗。

主目标通常是保证可获得的事件目标，比如启动设施、完成运输或击败指定驻守者。主线进度独立记录，不占普通背包，不允许竞争者偷走唯一通关物；不要让随机掉落、满包或首次玩家已经消费的物资堵死主线。

### 5.2 推荐测试“累计外勤额度”

首版样板试用每期 8 分钟有效外勤时间。玩家明确进入赛场、运镜结束后开始；回到电梯、暂停、强引导和必须观看的演出不计时。重新出门不会重置额度，倒下救援也不会重置。电梯休整时冻结整期模拟，竞争者不会趁玩家读菜单推进；这是单机体验约定，节目采用分段赛事实录呈现，不宣称存在不停运转的真实全球直播。

这条规则的代价很明确：它给探索增加额外限制，可能与原本依靠饥渴约束停留的方向重复。初版必须对照“只有饥渴”和“饥渴＋额度”，不能仅因为 UI 做出来就认定它好玩。若额度使多数玩家只沿任务线奔跑，改为仅在关键赛事使用，普通资源层保留原有饥渴压力。

玩家在电梯里可以一直思考，但不能靠无限外出刷怪突破一切风险。怪物仍按同时存在上限生成，饥渴仍按实际探索消耗；末段压力通过刷怪节奏和路线风险变化实现，不能突破上限、透墙追踪或把突袭怪刷在身上。

### 5.3 及格与争奖分开

完成主目标且成功返回电梯即可登记晋级，剩余时间可主动结束本期，也可再出门争取物资与合同奖励。登记后不撤销及格，不因后一次倒下夺走已获得的晋级资格；那次探索仍会留下普通背包，需要追回或放弃。

未及格时额度耗尽，触发本期淘汰结局：资格注销、电梯进入回收通道。及格后耗尽只停止进一步出勤，场内尚未撤离的玩家按救援流程返回，普通背包留在赛场，不替他兑现未撤回的战利品。关场后地图保留作结算快照，禁止再进入；此前的背包不可追回。正式离开本期仍然单向，不能访问旧层。

章节失败后提供读取本期赛前检查点，恢复当时的角色、电梯、物资、地图与选手状态；不能保留失败分支赚到的脑浆再重开。这是游戏层面的重试，不是世界里死而复生。建议采用章节重试，首版不做整季永久死亡模式。

现有升级配方继续表达设备能力；新赛事资格表达节目许可，二者互不消费。若后续采用这一方向，上层入口要明确列出设备条件与赛事条件，并保证通关所需设施材料可确定获得；本轮不修改现有一到三层入口。

## 6. 紧迫感与继续游玩的动机

紧迫感有三个来源，各自承担不同作用：

1. 身体与遭遇：饥渴、精神力、翻找时暴露、有限视野和怪物追击，让当前地点不能无限停留。
2. 本期选择：有限外勤额度、会被争夺的可选资源、需要绕远路的额外奖励，让“再搜一间”有明确机会成本。
3. 赛季进展：终局出口和未完成的构筑、下一期提前公开的挑战、仍在场的熟人，让玩家期待继续上升。

赶快完成保底目标，会留下更多时间追回背包、争奖励或帮助别人；磨蹭则压缩这些选择，最终可能淘汰。完成目标后退出更安全，继续探索更有利于下期。回电梯整理装备不惩罚，退出游戏不惩罚，不用现实时间催促玩家。

持续动机也不能只靠恐惧。每期兑现一个具体收益：电梯一处可感知升级、一件改变战斗或探索方式的物品、一次熟人关系的后果。结算随后展示下一期的一张场景预告和一条规则，留下“我的构筑在那里会怎样”的期待。

例如下期搬运使玩家考虑移速与视野装备；守点使玩家考虑范围攻击和持续恢复；需要绕开驻守者的收集赛使脱战成为价值。相邻与十格布局因此成为赛事准备，而不是独立的菜单作业。

## 7. 赞助与竞争者：小规模、可兑现

第一版不做综合人气条或隐藏评分。每期至多出现一个可选择的赞助合同，提前写明条件与奖励，例如“完成主目标后再带回两件赛场藏品，可获得一件三格装备”。未接受的合同不惩罚；接受前可查看装备作用和占格。同一合同只能结算一次，重复刷弱怪或往返电梯不能刷赞助。

赛季先写三名持续出现的 AI 选手，而非模拟数百人。每期最多让一至两名在玩家所在地图真实活动：路线、翻找、交易和抢可选物资。其他人的镜头只是预先编排的跨期叙事，不参与虚假的实时排名。

选手默认中立，玩家武器不自动攻击人类；只有明确切为敌对、或对方先发动攻击才成为攻击目标。这是与当前自动战斗需要一起设计的新规则，未经实装验证。合作收益通过真实交换、共同清除驻守者、分享已探索区域落实。承诺只记录少量可观察事件，不做完整人格模拟。

主目标采用公开达标制，允许多名选手晋级；可选大奖才按先到先得竞争。淘汰来自未达到已知标准，不用隐藏的“你只能排前四”算法。节目允许合作，终局也不要求玩家杀光所有伙伴；通过最后挑战的人获得返乡权，特别奖可以只有一个。

这意味着本提案更接近有淘汰的生存竞赛，弱化严格“最后一人存活”的大逃杀。如果用户最在意必须杀到只剩一个人，则需另选竞争核心，并接受其与自动战斗、救援和合作玩法的冲突。

## 8. 中国风样板：听雨庭《夜宴收场》

以下时间、数量、奖励仅用于切片测试，不改变当前第三层或升级经济。

场景沿用听雨庭资产包：灰暗雨夜、朱红旧木、纸灯与水面。庭院深处挂着异常现代的节目摄像头和小型赛牌；主持声热情，现场却只有中国题材鬼怪，形成综艺包装与危险现场的反差。

主目标：找到两个明示位置的供能设施，完成各一次通电，在出勤额度内撤回。标记只指区域，仍需要探索迷雾；低矮院墙可阻路，高墙和竹林可遮视野。设施动作允许中断并保留合法进度，不要求固定物品或随机掉落。

特殊规则：正在通电的设施会引来附近怪物。第一次在可控小遭遇中示范；怪物仍按视野与追击规则行动，声响只能引导调查位置，不能让它们直接知道玩家的隐藏坐标。

| 阶段 | 玩家看到或经历什么 | 核心决策 |
| --- | --- | --- |
| 入场前 | 安泊展示目标、8 分钟额度、通电声响规则 | 是否调整装备相邻关系与机制装备 |
| 初段 | 第一设施靠近撤离路线，出现少量领地怪 | 先拿保底进度，还是先搜补给 |
| 中段 | 一名选手出现，表示要去可选的藏品柜；路径与到达由实际模拟决定 | 抢柜子、交易、跟随利用其清怪，或避开 |
| 后段 | 第二设施更深入；突袭节奏上升但数量预算保持 | 继续绕远搜刮，还是利用遮挡迅速完成目标 |
| 达标后 | 回电梯登记及格；展示剩余时间和未领取的可选大奖 | 结束本期，或再出门换取下期优势 |
| 结算 | 展示真实带回物资、合同结果与那名选手的去向 | 升级准备，并看下一期预告 |

演出只在关键节点出现：入场公布、大奖被领取、最后一分钟提示、结算。平时保持阴暗氛围，不用弹幕墙覆盖地图。重要提示由安泊在现有气泡组件中传达，任务 HUD 只增加剩余额度和当前目标。

本期不是“打死更多怪便胜利”。玩家即使战斗能力一般，也能凭路线、脱战和准备达标；强构筑能赢更多余裕与战利品。

## 9. 现有内容复用与首段改写

| 现有内容 | 复用方式 |
| --- | --- |
| 睁眼、手机无信号、打开电梯、荒原电筒与三怪 | 保留身体体验和操作教学；首段不计赛事时间 |
| 返回、电梯屏幕、恶魔与安泊、投喂开灯 | 开灯后恢复节目通告；安泊第一次说明“这是你的选手休息室” |
| 面包、饥渴、第二层找水、精神力、死亡背包 | 保留教学；第一期目标覆盖原找水任务，不同时增加复杂赞助合同 |
| 增幅器、十格装备、相邻、背包拖拽 | 作为下一期准备；提前展示下一期考验的能力 |
| 升级演出与单向上楼 | 升级设备后进入下一期；增加一次明确的关场提示 |
| 主题资产包、迷雾、双高度与主题怪物 | 每期共享机制，变化大轮廓、气候、怪物与目标布置 |
| 任务、终端 Tab、气泡、结算、GM | 承载赛事说明、目标、奖励、重播和阶段调试，不新做第二套 UI |

建议首次节目揭晓保持短：先看到自己的号码与其他人的休息室画面，再听安泊说明下一期目标，最后看到淘汰选手的电梯被送入回收通道。具体死亡演出不必成为新手教学。玩家先知道自己要做什么，再逐步认识节目背后的组织。

## 10. 生成方案与制作边界

每期由主题包、布局种子、目标模板、一条特殊规则、怪物预算、可选合同和选手事件组成。主题包仍含建筑、地面、装饰、配色、天气、环境音与怪物形象。目标模板先只做收集、设施启动、搬运、守点四类，复用已有移动、搜刮与自动攻击。

不是每层生成一个全新剧本。内容生产只配置少量字段与短台词，运行时由既有主题构件和确定性规则组装。需要保存设施状态、时长、唯一奖励所属、选手路线与背包状态；重进或读档不得刷新稀有物资、重置额度或重复发奖。新规则采用独立版本，不改旧地图的随机序列，不触碰卡牌产品。

首个切片仅增加一个完整赛事目标、可开关的外勤额度、一名可争夺藏品柜的选手和一期结算。赞助合同先用静态演示或下一步接入；不在首轮一起实现社交投票、观众模拟、完整六期、动态台词生成和分支结局。

## 11. 验证与否决条件

需要比较同一地图两版：只有既有饥渴压力；饥渴加累计外勤额度。8 分钟须由路线实测调整，主目标应为初学者留出一次失败追回或主动补给的余裕，不能把完美路线当作达标基线。

观察玩家是否理解规则，是否产生至少一次有理由的“再搜／撤回”选择，是否因下一期规则调整装备，是否能理解选手争夺的真实结果。检查暂停、救援、结算、重进和读取检查点是否保留完整一致状态。设计指标是待验证目标，不宣称已有试玩结果。

如果玩家只盯着倒计时跑任务，减少额度使用范围；如果竞争者只造成恶意抢夺且没有合作或绕路空间，先调整可选奖励而非扩大 PvP；如果每期目标只是击杀计数换皮，继续增加目标带来的路线与构筑差异。

## 12. 建议

值得做一场比赛的候选切片，验证它能否提供“我得晋级，但我还想赚更多”的动力。先证明公开规则、搜刮机会与跨期成长能构成好玩的选择，再投入节目内幕与长篇角色剧情。该方向对现有内容复用度高，但倒计时与淘汰制度会改变探索节奏，必须在用户确认方向后另行设计、实施和验收。
