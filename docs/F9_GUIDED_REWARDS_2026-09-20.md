# F9 首战、战利品与鉴定时机迭代 · 2026-09-20

## 本轮结果

本轮覆盖用户七项战斗反馈及两项补充。替代上一版新开局的“第二间鉴定”；不是完整新手引导终稿。已有首页、楼层结构、四个初始合法格与旧存档保留。

新开局顺序：开场 → 电梯门 → 首次精力讲解 → 出发 → 弹弓首战与七步暂停引导 → 抽取敌方猎隙刃 → 背包手动上阵 → 第二间搜刮两件工具 → 第三间图形管道 → 检修箱鉴定仪 → 鉴定缓冲垫 → 敌情前室 → 守卫 → 战利品 → 返回电梯。

## 规则边界

- 在战斗中打开背包会暂停播放；关闭后恢复之前的播放或暂停状态。整理的卡牌位置用于下一场，当前对局与回放始终使用开战快照。鉴定和消耗道具仍在战斗外执行。
- 即时攻击没有飞行弹丸，保留命中反馈。同一帧双方即时致命攻击可同归于尽；已到达的弹道先结算，再发动该帧的新攻击。
- 每次真实胜利产生一份待领取武器。重复确认、领取、读档不重复发放或重抽；重新打赢一次遭遇属于新胜利，发武器，旧的金币节点去重规则保留。
- 第二间缓冲垫与补漏胶必须保持实体到第三间。安装和旋转不收费，成功泄压时一次结算：操作消耗 2 精力、恢复 12 精力、猎隙刃所在路线下场屏障 +24；补漏胶消耗、缓冲垫保留。继续前进再付 3 精力。
- 鉴定仪收入背包时一次性获得 1 电荷；鉴定缓冲垫消耗 1，电力不变。重复或失败鉴定不扣费。
- 不开放引导关提前撤离 / 紧急回收；没有新增全局战斗引擎或全局状态库，没有扩大机关池。

### 验收清单

- [ ] 首次出发前讲解精力，看讲解不扣费。
- [ ] 初始仅一把弹弓，3 秒发动，首敌可轻松击败。
- [ ] 先看完整三路，再看屏障；弹窗贴近目标且有箭头。
- [ ] 弹道教学暂停时能看见飞行中的弹丸；猎隙刃没有飞行弹道。
- [ ] 胜利默认不展开战斗记录，需揭晓并收取敌方武器。
- [ ] 首战后全局背包开启；能预览、取消、确认放置猎隙刃。
- [ ] 第二间只有缓冲垫与补漏胶，没有鉴定仪。
- [ ] 第三间用两件实体接管泄压，成功才消耗补漏胶。
- [ ] 通关机关后获得鉴定仪与一次电荷，然后引导鉴定缓冲垫。
- [ ] 满包领奖不丢卡、不自动换金币；整理后可继续领。
- [ ] 战斗中可整理，当前快照不变；关闭背包恢复原播放状态。
- [ ] 旧档不被清空，原引导链仍能继续；新存档刷新后保留奖励和进度。

待独立玩家测试：是否发现背包；是否理解上阵增加了输出；是否理解实体先用于机关、再转成卡；是否能复述精力图标与消耗；是否愿意尝试第二种路线。对没有可用组件的情形单独记录，不计为交互理解失败。本轮不宣称独立用户学习效率已提升。

风险与下一步：每次胜利增加武器会提高长线成长速度，本轮只验证既有回归与首轮供给，后续应观察重复出勤的卡牌积累；即时刀更频繁受到缓冲效果减伤，名义 DPS 相近不等于所有对局等强。首次回家、成长系统与第二次出勤引导仍待用户对齐，未自动扩展。
